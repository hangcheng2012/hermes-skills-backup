# 容积式泵选型与设计子 skill

## 何时调用 (When to use)

**触发条件**(任一即可):
- 用户说"出泵选型 / 选泵 / 泵比较 / 泵设计"
- 用户说"齿轮泵 / 柱塞泵 / 螺杆泵 / 计量泵 / 容积式泵"
- 用户说"高粘度泵 / 含固泵 / 自吸泵 / 计量精度"
- 用户说"出泵规格书 / pump data sheet / 泵询价"
- petrochem-process-design 主 skill 进入"泵选型"步骤

**不调用**(其他 skill 处理):
- 离心泵(API 610) → 单独 skill
- 屏蔽泵/磁力泵 → 单独 skill
- 真空泵 → 单独 skill
- 水力机械(泵送系统) → 单独 skill
- 压缩机选型 → 主 skill 第 28 章,或参考本 skill 的 `references/pump-vs-compressor-fluids.md`(确认是液体工况后再用本 skill)
- **气体增压泵(Gas Booster / Air-Driven Booster) → `gas-booster-pump` 子 skill** ⚠️ 重要边界: 本 skill 仅覆盖**液体**工况;气体增压泵属于气体工况的特殊容积式设备(气动驱动 + 气体压缩),其选型逻辑(增压比 R= A₁/A₂、跷跷板模型、驱动气 vs 入口压力关系)与液体泵完全不同。**07-17 女王立规教训**: 本人曾错误地用 `P_out,平衡 = P_in × R` 公式(把压缩机术语"压力比"与气体增压泵术语"增压比"混淆),导致入口压力被误判为最大出口限制。详见 `gas-booster-pump` skill § 8 铁律 + `references/error-history.md`。

## 6 大选型维度速查

| # | 维度 | 关键问题 | 答案分支 |
|---|---|---|---|
| ① | **介质粘度** | 多少 cP? | <1000: 普通齿轮泵;>1000: 高粘度齿轮泵/螺杆泵 |
| ② | **能否计量 + 精度** | 需 ±0.5-1% 计量? | 是: 柱塞泵 ⭐; 否: 齿轮泵/螺杆泵 |
| ③ | **压力大小** | 多少 bar? | <40: 齿轮泵/螺杆泵; >40: 柱塞泵 ⭐ |
| ④ | **含固体颗粒** | 有颗粒? 有多少? | 0%: 任意; 1-60%: **螺杆泵** ⭐ |
| ⑤ | **工况(连续/短时)** | 连续 vs 短时? | 连续: 齿轮泵/螺杆泵; 短时: 柱塞泵 |
| ⑥ | **NCO 兼容** | 含异氰酸酯? | 是: FFKM/Kalrez 密封 |

## 3 大类泵核心对比

| 泵型 | 适用压力 | 适用粘度 | 流量精度 | 含固 | 典型应用 |
|---|---|---|---|---|---|
| **齿轮泵** | 0.1-25 bar | 1-100,000 cP | ±1-5% | ❌ | 油、聚合物、PU |
| **柱塞泵** | 1-1000 bar | <1000 cP | **±0.5-1%** ⭐ | ❌ | 浇注、计量、高压水 |
| **螺杆泵** | 0.1-40 bar | **1-200,000 MPa·s** ⭐ | ±1-3% | **0-60%** ⭐ | 含固、含纤维、极高粘度 |

## 8 大铁律 (Quick Reference)

| # | 铁律 | 关键点 | 错误案例 |
|---|---|---|---|
| ① | **齿轮泵分高/低粘度** | 间隙/材质/密封不同,选错会卡死或低效 | 我之前以为"统一齿轮泵",实际有 2 种 |
| ② | **螺杆泵对固最友好** | 含固 40-60%,最大 16mm 颗粒+100mm 纤维 | 我之前不知道螺杆泵含固能力 |
| ③ | **柱塞泵是计量型** | ±0.5-1% 精度,本质计量,可达 1000 bar | 误以为柱塞泵只用于高压水 |
| ④ | **NCO 必须 FFKM** | 异氰酸酯物料必须全氟橡胶/Kalrez 密封 | 误用 NBR 会被 NCO 反应破坏 |
| ⑤ | **高粘度齿轮泵间隙大** | 间隙 0.1-0.3mm + 硬化齿轮 + 可换磨损板 | 误用低粘度型处理 2000 cP 会卡死 |
| ⑥ | **螺杆泵剪切最低** | 适合活性污泥/生物制剂/酵母等剪切敏感介质 | 误用齿轮泵会破坏生物活性 |
| ⑦ | **柱塞泵有脉动** | 单柱塞有脉动,多柱塞可降 | 误用单柱塞做稳流应用 |
| ⑧ | **齿轮泵可反转** | 外齿轮泵可双向输送 | 螺杆泵/柱塞泵不能反转 |

## 选型决策树(详细版)

```
泵选型决策:

Q1: 介质含固体颗粒?
├─ 是 → 螺杆泵 ⭐(高固)/齿轮泵(低粘度清洁)
│       螺杆泵最高含固 40-60%,最大 16mm 颗粒
└─ 否 → Q2

Q2: 流量精度要求?
├─ ±0.5-1% → 柱塞泵 ⭐
├─ ±1-2% → 精密齿轮泵(DP 系列)/柱塞泵
└─ ±2-5% → 普通齿轮泵/螺杆泵

Q3: 介质粘度?
├─ < 100 cP → 柱塞泵(齿轮泵效率低)
├─ 100-1000 cP → 普通齿轮泵/柱塞泵
├─ 1000-10,000 cP → 高粘度齿轮泵 ⭐
└─ > 10,000 cP → 螺杆泵 ⭐(最广粘度范围)

Q4: 操作压力?
├─ < 10 bar → 齿轮泵/螺杆泵
├─ 10-40 bar → 齿轮泵/螺杆泵/柱塞泵
└─ > 40 bar → 柱塞泵 ⭐(可达 1000 bar)

Q5: 介质是否剪切敏感?
├─ 是(生物/活性) → 螺杆泵 ⭐(剪切最低)
└─ 否 → 任意

Q6: 自吸需求?
├─ 强自吸 → 螺杆泵 ⭐
└─ 不要求 → 任意

Q7: 反转需求?
├─ 需要 → 外齿轮泵 ⭐
└─ 不需要 → 任意
```
