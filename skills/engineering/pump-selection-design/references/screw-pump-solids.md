# 螺杆泵对固体颗粒的要求详解(女王重点)

> 女王 06-26 重点问题: 螺杆泵对固体颗粒含量的要求。本文档详细说明螺杆泵的含固能力、颗粒尺寸限制、适用场景。

---

## 一、螺杆泵是含固介质处理的首选泵型 ⭐

**为什么螺杆泵最适合含固介质**:
- **弹性定子结构**:允许小颗粒通过(定子橡胶变形让位)
- **连续密封腔**:颗粒被"包裹",不卡齿轮
- **单螺杆 PC 泵原理**:偏心旋转,无啮合冲击
- **剪切低**:不破坏颗粒/纤维

**对比齿轮泵/柱塞泵**:
- 齿轮泵:**不可含固体**(齿轮间隙磨损)
- 柱塞泵:**不可含固体**(密封件磨损)
- 螺杆泵:**可含固体 0-60%** ⭐(独有优势)

## 二、螺杆泵分类

| 类别 | 结构 | 适用压力 | 含固能力 | 粘度范围 |
|---|---|---|---|---|
| **单螺杆 PC 泵** ⭐ | 单转子+弹性定子 | 0.1-40 bar | **0-60%** ⭐ | **1-200,000 MPa·s** ⭐ |
| 双螺杆泵 | 双转子+金属定子 | 0.1-40 bar | 1-40% | 1-10,000 cP |
| 三螺杆泵 | 1 主动+2 从动 | 1-100 bar | ❌(< 1%) | 1-2000 cP |

**重点**:**单螺杆 PC 泵是含固处理的首选**(其他类型含固能力较弱)

## 三、单螺杆 PC 泵含固能力详解 ⭐

### 3.1 含固率分级

| 含固率(%) | 螺杆泵适用 | 定子选择 | 备注 |
|---|---|---|---|
| 0% | ✅ 优 | 标准定子 | 完全适用 |
| 0.1-5% | ✅ **优** | 标准定子 | 标准工况 |
| 5-20% | ✅ **优** | 标准定子 | 含固工况 |
| 20-40% | ✅ 良 | **加厚定子橡胶** | 中等含固 |
| 40-60% | ✅ 可 | **特殊定子** | 高含固(粉状/细颗粒) |
| > 60% | ⚠️ 困难 | 不推荐 | 改用其他泵 |

### 3.2 颗粒尺寸限制 ⭐⭐

| 颗粒类型 | 最大尺寸 | 备注 |
|---|---|---|
| 软颗粒/污泥/有机物 | **16 mm** | 转子偏心决定 |
| 结晶/盐类 | 5-10 mm | 视硬度 |
| 纤维(纺织/纸浆) | **100 mm(长)** | 0.4 倍转子螺距 |
| 粉状/细颗粒 | 任意(高浓度可达 60%) | 适合 |
| 硬质尖锐颗粒(玻璃/金属碎屑) | **不推荐** ⭐ | 损伤定子橡胶 |

### 3.3 固含量 vs 颗粒尺寸综合

| 含固率 + 颗粒大小 | 螺杆泵适用度 |
|---|---|
| < 1% + 任意 | ✅ 优 |
| 1-5% + 软颗粒 < 5 mm | ✅ 优 |
| 5-20% + 软颗粒 < 10 mm | ✅ 优 |
| 20-40% + 软颗粒 < 16 mm | ✅ 良(加厚定子) |
| 40-60% + 粉状/细颗粒 | ✅ 可(特殊定子) |
| 任意 + 硬质尖锐颗粒 | ❌ 不推荐 |

## 四、为什么螺杆泵能处理固体? ⭐

### 4.1 螺杆泵原理优势

**单螺杆 PC 泵结构**:
```
   电机 → 万向节 → 转子(单头金属螺杆)
                     ↓ 偏心旋转
              定子(双头弹性衬套)
              形成连续密封腔
```

**转子与定子**:
- 转子:单头金属螺杆(刚性)
- 定子:双头弹性衬套(橡胶)
- 转子在定子内偏心旋转(行星运动)
- 形成连续密封腔

**为什么能处理固体**:

1. **弹性定子让位**:颗粒进入时,定子橡胶**变形让位**,颗粒通过后恢复
2. **连续密封腔**:颗粒被"包裹"在密封腔内,不会卡在啮合处(齿轮泵会卡)
3. **偏心旋转**:无高速冲击,颗粒不被剪切
4. **无啮合冲击**:不像齿轮泵的齿轮啮合会冲击颗粒

### 4.2 与齿轮泵对比

**齿轮泵处理固体会怎样**:
```
   齿轮 A ←— 啮合 → 齿轮 B
        ↓ 颗粒
   颗粒卡在啮合处 → 齿轮卡死
   ↓
   泵损坏
```

**螺杆泵处理固体**:
```
   转子 ←— 偏心 → 定子(弹性)
        ↓ 颗粒
   颗粒进入密封腔 → 定子变形让位 → 颗粒通过
   ↓
   泵正常运行
```

## 六、螺杆泵不适用场景

### 6.1 不推荐螺杆泵的场景

| 场景 | 原因 | 替代方案 |
|---|---|---|
| **清洁高压液体**(> 40 bar) | 螺杆泵压力上限 | **柱塞泵** ⭐ |
| **高精度计量**(±0.5%) | 螺杆泵精度不够 | **柱塞泵** ⭐ |
| **含硬质尖锐颗粒**(玻璃/金属碎屑) | 损伤定子橡胶 | 特殊螺杆泵或预处理 |
| **极高粘度**(> 200,000 MPa·s) | 超出螺杆泵能力 | 特殊设计 |
| **强腐蚀性介质** | 限制定子材质选择 | 特殊材质 |
| **食品/医药级**(某些工况) | 定子橡胶可能污染 | 食品级定子 |

### 6.2 硬质颗粒处理

**如果必须用螺杆泵处理硬质颗粒**:
- 选**碳化钨或陶瓷涂层转子**
- 选**加厚定子橡胶**
- **降低转速**(减少冲击)
- **降低含固率**(如果可能)
- 寿命缩短,需频繁更换定子

## 九、螺杆泵选型流程

### 9.1 选型自检

```
Q1: 介质含固体?
├─ 否 → 齿轮泵/柱塞泵(看其他条件)
└─ 是 → 螺杆泵 ⭐

Q2: 含固率?
├─ < 5% → 标准定子
├─ 5-20% → 标准定子(常规模)
├─ 20-40% → 加厚定子 ⭐
└─ > 40% → 特殊定子 + 评估寿命

Q3: 颗粒类型?
├─ 软颗粒/污泥 → 标准螺杆泵
├─ 结晶/盐类 → 碳化钨转子
├─ 纤维 → 标准螺杆泵(检查纤维长度)
└─ 硬质尖锐 → 特殊设计或预处理

Q4: 最大颗粒直径?
├─ < 5 mm → 任意螺杆泵
├─ 5-10 mm → 标准螺杆泵
├─ 10-16 mm → 标准螺杆泵(注意转子偏心)
└─ > 16 mm → 预处理(过滤/破碎)

Q5: 纤维长度?
├─ < 50 mm → 标准螺杆泵
├─ 50-100 mm → 标准螺杆泵(检查螺距)
└─ > 100 mm → 预处理

Q6: 介质粘度?
├─ < 1000 cP → 标准螺杆泵
├─ 1000-10000 cP → 标准螺杆泵
└─ > 10000 cP → 高粘度型螺杆泵
```

## 十、典型含固应用案例

### 10.1 案例 1:活性污泥输送(污水处理厂)

**工况**:
- 介质:活性污泥
- 含固:3-5% 有机物
- 粘度:200-1000 cP
- 流量:50 m³/h
- 压力:4 bar

**选型**:**单螺杆 PC 泵 DN80**
- 标准定子(丁腈橡胶)
- 转速 300 rpm
- 价格:¥30,000-50,000

**为什么**:
- 螺杆泵可处理活性污泥不卡死
- 剪切低,保持生物活性
- 寿命 12-18 月(定子)

### 10.2 案例 2:矿浆输送(选矿厂)

**工况**:
- 介质:铁矿浆
- 含固:30% 铁矿石
- 颗粒:最大 5 mm
- 粘度:2000-5000 cP
- 流量:30 m³/h
- 压力:10 bar

**选型**:**单螺杆 PC 泵 DN65(高含固型)**
- **加厚定子**(高耐磨)
- 碳化钨涂层转子
- 转速 200 rpm
- 价格:¥80,000-150,000

**为什么**:
- 螺杆泵是 30% 含固的最佳选择
- 加厚定子寿命 6-12 月
- 碳化钨转子抗磨损

### 10.3 案例 3:含砂原油输送(油田)

**工况**:
- 介质:含砂原油
- 含固:2% 砂(最大 2 mm 砂粒)
- 粘度:100-500 cP
- 流量:100 m³/h
- 压力:16 bar

**选型**:**单螺杆 PC 泵 DN100**
- 标准定子
- 转速 400 rpm
- 价格:¥50,000-80,000

**为什么**:
- 螺杆泵可处理含砂原油
- 砂粒 < 2 mm 不会卡
- 标准定子寿命 18-24 月

### 10.4 案例 4:高粘度聚合物 + 少量固(化工)

**工况**:
- 介质:聚合物溶液(含微量催化剂颗粒)
- 含固:0.5% 催化剂颗粒
- 粘度:10,000 cP
- 流量:5 m³/h
- 压力:10 bar

**选型**:**螺杆泵或高粘度齿轮泵**
- 螺杆泵:含固 + 高粘度(优)
- 高粘度齿轮泵:仅高粘度(不含固时优)

**选螺杆泵**,因为含 0.5% 固(齿轮泵不耐固)
