# 泵 vs 压缩机 — 工作介质与边界

> **来源**：《化工工艺设计手册》(第五版) 上册第 27 章「泵」、第 28 章「压缩和膨胀机械」,下册第 31 章 8 节 P&ID 单元设计。原文逐字摘录,出处可查。

---

## 核心结论 (TL;DR)

| 设备 | 适用介质 | 知识库原文 |
|---|---|---|
| **泵 (Pump)** | **液体** (含浆料、气液混合物) | 第 27 章 2.1.1: 「一般离心泵启动前泵壳内要灌满**液体**……」 |
| **压缩机 (Compressor)** | **气体、蒸汽** (含可凝性气体) | 第 28 章 1.1: 「**气体**在等温压缩中,温度始终保持不变……」 |

**唯一的"灰色地带"是液环式压缩机** — 但其**液体只做密封/冷却介质,被压缩的依然是气体**。

## 一、泵的工作介质 (来自手册第 27 章)

### 离心泵 (叶片式泵代表)

> 「一般离心泵启动前泵壳内要灌满液体,当原动机带动泵轴和叶轮旋转时,**液体**一方面随叶轮做圆周运动;另一方面在离心力的作用下自叶轮中心向外周抛出,液体从叶轮获得压力能和速度能。当液体流经蜗壳到排液口时,部分动能将转变为静压力能。在液体自叶轮抛出时,叶轮中心部分造成低压区,与吸入液面的压力形成压力差,于是液体不断地被吸入,并以一定的压力排出。」

**关键参数 (手册第 27 章 2.1.1)**:
- 流量 Q (m³/h 或 m³/s)
- 扬程 H (m, 液柱高度)
- 有效功率 Pu = ρgQH/1000 (kW) ← **ρ 是液体密度**

### 第 27 章「特殊介质的输送」分类 (1223-1226 页)

| 介质 | 选用要点 |
|---|---|
| 黏性液体 | 黏度修正 |
| **含气液体** ⚠️ | 需特殊处理 (含气量 < 5% 才可直接用普通离心泵) |
| 含固体颗粒的液体 | 用浆料泵/螺杆泵 |
| 易气化液体 | 注意 NPSH |
| 不允许泄漏的液体 | 屏蔽泵/磁力泵 |
| 腐蚀性介质 | 耐蚀材料 |

> ⚠️ **"含气液体"** 在泵领域指的是**液体中含有少量气体** (不是气体为主介质)。当含气量 >5% 时,需要用容积式泵或专门的气液两相泵,否则会发生气缚。

## 二、压缩机的工作介质 (来自手册第 28 章)

### 按排气压力分类 (手册第 28 章 3.1.1)

| 名称 | 压力范围 (×10⁵ Pa) |
|---|---|
| 鼓风机 | ≤ 2 |
| 低压压缩机 | 2~10 |
| 中压压缩机 | 10~100 |
| 高压压缩机 | 100~1000 |
| 超高压压缩机 | > 1000 |

### 按工作原理分类 (手册下册第 31 章 8 节)

> 「压缩机按其工作原理可分为容积式和流体动力式两大类。**容积式压缩机**通常使用的有**活塞式、螺杆式、液环式**;**流体动力式压缩机**通常使用的有**离心式和轴流式**。」

### 介质特性要求 (手册第 28 章 3.2.1)

> 「② 必须满足介质特性的要求。
> a. 对于**易燃、易爆、有毒或贵重的气体**,要求轴封可靠。
> b. 对于**腐蚀性气体**,要求接触介质的部件采用耐蚀材料。」

**默认介质表述全是"气体"** — 手册通篇未把压缩机用于液体的情况 (除液环式外)。

## 三、唯一的反例:液环式压缩机 (手册第 28 章 3.8.1)

> 「液环式压缩机利用**密封液**与偏心安装带叶片的转子所形成的密封腔体积的变化来**压缩气体**。由于使用液体密封,所以可用于被压缩气体**夹带液体**的工况。」

**液环式压缩机特点**:
1. 结构简单、使用方便
2. 气缸不需要润滑,可作为特殊用途的无油润滑压缩机
3. 由于液体的充分冷却,排气温度很低
4. 叶片扰动液体的能量损失很大,效率较低,等温效率仅 0.30~0.45

**典型应用** (手册原文):
- 高温下易于分解的气体:乙炔、硫化氢、硫化碳
- 高温时易于聚合的气体
- 腐蚀性气体:氯气
- **被压缩气体中夹带液体的工况**

⚠️ **关键澄清**:液环式压缩机的液体是**密封+冷却介质**,**被压缩工质仍然是气体**。不是"用压缩机压缩液体"。

## 四、本质区别:可压缩性

| 维度 | 泵 (液体) | 压缩机 (气体) |
|---|---|---|
| 可压缩性 | 几乎不可压缩 | 高度可压缩 |
| 能量形式 | 静压能 + 动能(少量) | 静压能 + 动能 + **状态变化 (PV=ZnRT)** |
| 关键方程 | ρgQH | PV = ZnRT (多变压缩) |
| 核心参数 | 扬程 H (m) | 压缩比 ε、压力比、绝热/多变效率 |
| 性能曲线 | H-Q 曲线 | 排气压力-流量曲线,有喘振问题 |
| 温升 | 可忽略 | 显著(绝热压缩终温可达 200-300℃+) |
| 抗气蚀设计 | **必需** (NPSHr ≥ NPSHa) | 不需要 |

**为什么这样划分**:
- 液体几乎不可压缩,泵加压主要克服管路阻力和提升位能
- 气体高度可压缩,压缩机耗功主要用在气体状态变化,需按多变指数 m、等温/绝热效率专门核算
- 两者能耗机制完全不同

## 五、选型时如何判断

**问题 1:介质是气体还是液体?**
- 气体 → 进入压缩机选型 (用主 skill `petrochem-process-design` 28 章 + API 617/618/619/672)
- 液体 → 进入泵选型 (用本 skill `pump-selection-design`)

**问题 2:气液两相(气液混合物)?**
- 气体为主 → 液环式压缩机 (夹带液体 OK)
- 液体为主 + 含气 < 5% → 普通离心泵 (注意气缚)
- 液体为主 + 含气 5-30% → 容积式泵 (齿轮/螺杆) 或专门气液两相泵
- 含气 > 30% → 重新考虑工艺,可能应走气体管路

**问题 3:蒸汽(可凝性气体)?**
- 蒸汽属于**气体** → 走压缩机 (蒸汽压缩机/MVR 用离心式或罗茨)
- 冷凝后液体 → 走泵

## 六、常见混淆点

| 容易混淆 | 区分 |
|---|---|
| 真空泵 (Vacuum pump) | 是**气体输送设备**,抽气用,不是泵液体 → 走压缩机选型 |
| 计量泵 (Metering pump) | 是**泵** (容积式),用于液体精密计量 |
| 蒸汽往复泵 (Steam reciprocating pump) | 名字带"泵"但用于**输送液体** (蒸汽是动力源) |
| MVR 蒸汽压缩机 | 是**压缩机** (压缩蒸汽,典型应用:蒸发系统) |
| 喷射泵 (Ejector) | 用流体(液体或气体)做工作介质,**抽送的是气体** → 走压缩设备选型 |

## 七、女王调用时机

**调用本 reference 的场景**:
- 泵选型时,业主/同事问"为什么不用压缩机?"
- 工艺出现气液两相,需要判断走泵还是压缩机
- 选完泵后写 P&ID,要标注"含气液体"工况
- 有人问"蒸汽压缩机和泵有什么区别"
- PU/TDI/PTMG 等物系,异氰酸酯遇水/醇要反应,液环式压缩机不能用 → 需要走干燥气体压缩机 + 干燥密封液

**不调用本 reference 的场景**:
- 单纯泵选型(只看主 skill 即可)
- 单纯压缩机选型(主 skill 第 28 章)
- P&ID 标注 (用 `pid-pfd-v69-standards` skill)
