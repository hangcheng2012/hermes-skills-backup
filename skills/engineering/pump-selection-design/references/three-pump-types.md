## 二、齿轮泵详解

### 2.1 分类(高/低粘度)

| 类别 | 子类 | 适用粘度 | 关键特征 |
|---|---|---|---|
| **外齿轮泵** | 低粘度型 | 1-1000 cP | 标准齿轮,小间隙,机械密封 |
| | **高粘度型** ⭐ | 1000-100,000 cP | 硬化齿轮,可换磨损板,唇形密封 |
| **内齿轮泵** | 中高粘度 | 100-50,000 cP | 齿轮内齿轮原理,适合含固体 |
| **齿轮+月牙** | 高粘度含固 | 500-100,000 cP | 凸轮转子,处理固体 |

### 2.2 工作原理

**外齿轮泵**:
```
   主动轮 ←— 电机驱动
     齿轮啮合 → 形成密封腔
   从动轮 ←— 随动旋转
```
- 主动轮+从动轮啮合,在泵体内形成封闭空间
- 齿轮旋转,封闭空间沿泵壳移动,推动液体

**内齿轮泵**:
```
   外转子(主动) ←— 电机驱动
   内转子(从动) ←— 啮合传动
   月牙块 ←— 隔开进/出口
```
- 外转子带动内转子旋转
- 月牙块隔开进/出口
- 适合含气/含固液体

| 参数 | 低粘度型 | **高粘度型** ⭐ |
|---|---|---|
| 适用粘度 | 1-1000 cP | 1000-100,000 cP |
| 齿轮间隙 | 0.01-0.05 mm | 0.1-0.3 mm |
| 齿轮材质 | 45# 钢 | 20CrMnTi 渗碳 + 淬火 |
| 齿轮硬度 | HRC 50-55 | HRC 58-62 |
| 轴承 | 标准滚动轴承 | 重载滚动轴承 |
| 密封 | 机械密封 | 唇形密封或填料密封 |
| 转速 | 1450-1800 rpm | 300-750 rpm |
| 最高压力 | 25 bar | 16 bar |
| 容积效率(适用粘度) | 95%+ | 90%+ |
| 磨损件 | 无 | **可换磨损板** ⭐ |
| 价格 | ¥5,000-15,000 | ¥15,000-50,000 |
| 适用介质 | 油、轻聚合物 | 重油、PU 预聚体、沥青 |

### 2.4 齿轮泵选型决策

| 介质粘度 | 推荐齿轮泵类型 |
|---|---|
| < 100 cP(水、轻油) | 柱塞泵(齿轮泵效率低) |
| 100-1000 cP | 低粘度齿轮泵 |
| 1000-10,000 cP | **高粘度齿轮泵** ⭐ |
| > 10,000 cP | 螺杆泵(齿轮泵也吃力) |

| 应用 | 介质 | 粘度 | 泵型 |
|---|---|---|---|
| 油品输送 | 油 | 100-500 cP | 低粘度齿轮泵 |
| 聚合物输送 | PU 预聚体、聚醚 | 500-5000 cP | **高粘度齿轮泵** ⭐ |

## 三、柱塞泵详解

### 3.1 分类

| 类别 | 结构 | 适用压力 | 流量脉动 | 精度 |
|---|---|---|---|---|
| **单柱塞** | 1 柱塞+1 缸 | 中高压 | 大(60-100%) | ±1% |
| 双柱塞 | 2 柱塞相差 180° | 中高压 | 中(30-50%) | ±0.5-1% |
| **三柱塞** ⭐ | 3 柱塞相差 120° | 中高压 | 小(< 10%) | ±0.5% |
| 多柱塞(5+) | 多个柱塞 | 高压 | 极小 | ±0.3% |

### 3.2 工作原理

```
   电机 → 减速机 → 曲轴 → 柱塞往复运动
                          ↓ ↑
                       缸体(吸/排)
```
- 曲轴带动柱塞往复运动
- 吸程:柱塞后退 → 进口阀开 → 液体吸入
- 排程:柱塞前进 → 出口阀开 → 液体排出
- 每个行程排出固定体积

### 3.3 关键参数

| 参数 | 单柱塞 | 三柱塞 |
|---|---|---|
| 最高压力 | 1000 bar | 1000 bar |
| 最高精度 | ±1% | ±0.5% |
| 流量脉动 | 60-100% | < 10% |
| 转速 | 100-400 rpm | 100-400 rpm |
| 维护 | 简单(1 套密封) | 复杂(3 套密封) |
| 价格 | ¥30,000-80,000 | ¥80,000-200,000 |

### 3.4 柱塞泵典型应用

| 应用 | 介质 | 压力 | 精度 |
|---|---|---|---|
| **PU 浇注** | PU 反应料 | 5 bar | **±1%** ⭐ |
| **聚合物计量** | PU、聚酯 | 10-50 bar | **±0.5%** ⭐ |
| **高压水切割** | 水 | 4000 bar | ±2% |
| **油田注水** | 水 | 100-300 bar | ±1% |
| **油品计量** | 油 | 10-40 bar | **±0.5%** ⭐ |

### 3.5 柱塞泵 vs 隔膜泵(类似应用)

| 对比 | 柱塞泵 | 计量隔膜泵 |
|---|---|---|
| 压力 | 1000 bar | 50 bar |
| 精度 | ±0.5% | ±1% |
| 介质含固 | ❌ | ⚠️ 有限 |
| NCO 兼容 | ⚠️ FFKM | ⚠️ PTFE 隔膜 |
| 价格 | 高 | 中 |

## 四、螺杆泵详解

### 4.1 分类

| 类别 | 结构 | 适用压力 | 适用粘度 | 含固能力 |
|---|---|---|---|---|
| **单螺杆 PC 泵** ⭐ | 单转子+弹性定子 | 0.1-40 bar | **1-200,000 MPa·s** | **0-60%** ⭐ |
| 双螺杆泵 | 双转子+金属定子 | 0.1-40 bar | 1-10,000 cP | 1-40% |
| 三螺杆泵 | 1 主动+2 从动 | 1-100 bar | 1-2000 cP | ❌ |

### 4.2 单螺杆泵工作原理

```
   电机 → 万向节 → 转子(单头金属螺杆)
                     ↓ 偏心旋转
              定子(双头弹性衬套)
              形成连续密封腔
```
- 转子在弹性定子内偏心旋转(行星运动)
- 入口端形成真空,吸入液体
- 转子旋转,液体沿定子螺旋向前推进
- 出口端排出液体
- 连续密封腔,无脉动,剪切低

## 五、3 大类泵选型决策矩阵

### 5.1 按粘度选型

| 粘度范围 | 推荐泵型 |
|---|---|
| < 100 cP | **柱塞泵** ⭐(齿轮泵效率低) |
| 100-1000 cP | 低粘度齿轮泵 / 柱塞泵 |
| 1000-10,000 cP | **高粘度齿轮泵** ⭐ |
| 10,000-100,000 cP | **高粘度齿轮泵 / 螺杆泵** |
| > 100,000 cP | **螺杆泵** ⭐(最广) |

### 5.2 按压力选型

| 压力范围 | 推荐泵型 |
|---|---|
| < 10 bar | 齿轮泵 / 螺杆泵 |
| 10-40 bar | 齿轮泵 / 螺杆泵 / 柱塞泵 |
| 40-100 bar | 螺杆泵 / 柱塞泵 |
| 100-1000 bar | **柱塞泵** ⭐ |

### 5.3 按精度选型

| 精度要求 | 推荐泵型 |
|---|---|
| ±0.5% | 柱塞泵(精密型) |
| ±0.5-1% | **柱塞泵** ⭐ |
| ±1-2% | 精密齿轮泵(DP 系列) / 柱塞泵 |
| ±2-5% | 普通齿轮泵 / 螺杆泵 |

### 5.4 按含固选型

| 含固率 | 推荐泵型 |
|---|---|
| 0% | 任意 |
| 0.1-1% | 齿轮泵(短期) / 螺杆泵 |
| 1-5% | **螺杆泵** ⭐ |
| 5-40% | **螺杆泵** ⭐(标准型) |
| 40-60% | **螺杆泵** ⭐(特殊定子) |

### 5.5 按工况选型

| 工况 | 推荐泵型 | 理由 |
|---|---|---|
| 连续输送(> 10 min) | 齿轮泵 / 螺杆泵 | 连续无脉动,寿命长 |

| 双向输送 | 外齿轮泵 | 齿轮泵可反转 |
| 剪切敏感介质 | **螺杆泵** ⭐ | 剪切最低 |

## 六、含固场景的详细对比(女王重点)

### 6.1 3 大类泵含固能力对比

| 颗粒特性 | 齿轮泵 | 柱塞泵 | **螺杆泵** |
|---|---|---|---|
| 清洁液体(0% 固) | ✅ 优 | ✅ 优 | ✅ 优 |
| 软颗粒(1% 固) | ⚠️ 短期 | ⚠️ 短期 | ✅ 优 |
| 中等颗粒(5% 固) | ❌ 不可 | ❌ 不可 | ✅ 优 |
| 高固含量(20% 固) | ❌ 不可 | ❌ 不可 | ✅ **优** ⭐ |
| 极高固含量(40% 固) | ❌ 不可 | ❌ 不可 | ✅ 良 |
| 硬质尖锐颗粒 | ❌ 不可 | ❌ 不可 | ⚠️ 需注意 |
| 长纤维(< 100 mm) | ❌ 不可 | ❌ 不可 | ✅ 优 |
| 大颗粒(< 16 mm) | ❌ 不可 | ❌ 不可 | ✅ 优 |

### 6.2 螺杆泵含固分级(女王重点) ⭐

| 固含量(%) | 螺杆泵适用 | 定子选择 |
|---|---|---|
| 0-5% | ✅ 优 | 标准定子 |
| 5-20% | ✅ 优 | 标准定子 |
| 20-40% | ✅ 良 | 加厚定子橡胶 |
| 40-60% | ✅ 可 | 特殊定子(粉末/细颗粒) |
| > 60% | ⚠️ 困难 | 不推荐 |

### 6.3 颗粒尺寸限制(女王重点) ⭐

| 颗粒类型 | 最大尺寸 | 备注 |
|---|---|---|
| 软颗粒/污泥 | **16 mm** | 转子偏心决定 |
| 结晶/盐类 | 5-10 mm | 视硬度 |
| 纤维 | **100 mm**(长) | 0.4 倍转子螺距 |
| 硬质尖锐颗粒 | **不推荐** | 损伤定子橡胶 |
| 粉状/细颗粒 | 任意(高浓度可达 60%) | 适合 |

### 6.4 螺杆泵含固优势机理

**为什么螺杆泵能处理固体**:
- 转子在弹性定子内偏心旋转,形成连续的密封腔
- 颗粒被"包裹"在密封腔内
- 弹性定子允许小颗粒通过(变形让位)
- **不会卡在齿轮啮合处**(齿轮泵会卡)
- **不会损坏柱塞密封**(柱塞泵会)

## 十、错误案例与避坑

### 10.1 错误案例

| 错误案例 | 后果 | 正确做法 |
|---|---|---|
| 齿轮泵处理 2000 cP PU 预聚体(用低粘度型) | 齿轮卡死,损坏 | 选**高粘度齿轮泵** ⭐ |
| 齿轮泵处理 20% 矿浆 | 磨损,泄漏 | 选**螺杆泵** ⭐ |
| 柱塞泵处理 5000 cP 高粘度油 | 效率低,密封易损 | 选**高粘度齿轮泵** ⭐ |
| 普通齿轮泵作 PU 浇注(±1%) | 精度不够(±3-5%) | 选**柱塞泵** ⭐ |
| NBR 密封处理 NCO | 几天内密封损坏 | 选**FFKM/Kalrez** ⭐ |
| 单柱塞做稳流应用 | 流量脉动大 | 选**多柱塞** ⭐ |
| 离心泵处理 5000 cP 油 | 效率低,汽蚀 | 选**容积式泵** ⭐ |
