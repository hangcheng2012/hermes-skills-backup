# 齿轮泵高/低粘度分类详解

> 女王 06-26 重点问题: 齿轮泵确实分高粘度和低粘度,本文详解分两类的原因、参数差异、选用规则。

---

## 一、核实:齿轮泵确实分高/低粘度

**答:是,齿轮泵明确分高粘度型和低粘度型**,这是一项基本分类。

### 1.1 网上资料确认

**PSG Dover(齿轮泵专业厂家)**:
> "百士吉®提供了各种**内齿轮泵**,极其适合**高粘度或宽范围粘度**的应用。"

**KNF(齿轮泵技术比较)**:
> "齿轮泵通常有两种类型:**内齿轮泵**和**外齿轮泵**,前者适用于**含有固体颗粒的粘性流体**,后者在处理**低粘度流体**时性能更佳。"

**直接证明分两类**:
- 外齿轮泵:**低粘度**(1-1000 cP)
- 内齿轮泵 + 高粘度外齿轮泵:**高粘度**(1000+ cP)

## 二、为什么齿轮泵分高/低粘度?

### 2.1 根本原因:粘度对齿轮泵效率的影响

**齿轮泵原理**:
```
   主动齿轮 ← 电机
     ↓ 啮合
   从动齿轮
     ↓
   齿轮+泵体形成密封腔
     ↓
   推动液体(从入口到出口)
```

**关键点:齿轮啮合处的"间隙"决定了密封和效率**

**间隙的两难**:
- **间隙小**(0.01-0.05 mm):
  - ✅ 密封好 → 容积效率高(95%+)
  - ❌ 高粘度时,粘性摩擦阻力大 → **易卡死**
  - ❌ 磨损风险大(无润滑油膜)

- **间隙大**(0.1-0.3 mm):
  - ✅ 摩擦小 → 适应高粘度
  - ❌ 低粘度时,内泄漏大 → **效率低**(70-80%)

**结论**:
- **低粘度需要小间隙**(密封好)
- **高粘度需要大间隙**(不卡死)
- 两种工况需要**不同设计** → 分两类

### 2.2 粘度对齿轮泵的具体影响

| 粘度(cP) | 间隙 0.02mm(标准) | 间隙 0.15mm(高粘度型) |
|---|---|---|
| 1(水) | ✅ 95%效率 | ⚠️ 70%(内泄漏) |
| 100(轻油) | ✅ 95% | ✅ 85% |
| 500(中油) | ✅ 92% | ✅ 90% |
| 1000(重油) | ⚠️ 80%(摩擦大) | ✅ 92% |
| 5000(聚合物) | ❌ 卡死 | ✅ 90% |
| 10000(高粘度) | ❌ 卡死 | ✅ 85% |
| 50000(沥青) | ❌ 不可 | ⚠️ 80% |
| 100000(极高粘度) | ❌ 不可 | ⚠️ 70%(考虑螺杆泵) |

### 2.3 齿轮泵选型决策

| 介质粘度 | 推荐齿轮泵类型 | 备注 |
|---|---|---|
| < 100 cP | 柱塞泵(齿轮泵效率低) | 改用其他泵 |
| 100-1000 cP | **低粘度齿轮泵** ⭐ | 标准型 |
| 1000-10,000 cP | **高粘度齿轮泵** ⭐ | 硬化齿轮+大间隙 |
| > 10,000 cP | 螺杆泵(齿轮泵也吃力) | 改用螺杆泵 |

**介质**:重油、聚合物、沥青、PU 预聚体(1000-100,000 cP)
**典型介质**:

- 聚合物熔体(1000-10,000 cP)

### 4.4 关键设计细节:可换磨损板

**为什么需要磨损板?** ⭐
- 高粘度物料中含有微量硬质颗粒(如 PU 预聚体中的微量凝胶)
- 颗粒进入齿轮间隙,造成磨损
- 磨损板作为**易损件**,磨损后只需更换磨损板,无需更换齿轮
- **延长齿轮寿命 3-5 倍**

**磨损板位置**:
```
   齿轮端面 ← 磨损板(易损件,定期更换)
     ↓
   泵体(永久)
```

**磨损板材质**:
- 标准:工具钢
- 高耐磨:碳化钨涂层
- 超耐磨:陶瓷涂层

**更换频率**(典型):
- 标准工况:12-18 个月
- 含固工况:3-6 个月
- 极端工况:1-2 个月

## 六、为什么用低粘度齿轮泵处理高粘度物料会出问题?

### 6.1 错误案例与后果

**错误**:用低粘度齿轮泵处理 2000 cP PU 预聚体

| 阶段 | 现象 | 原因 |
|---|---|---|
| 启动 1 天 | 泵温升,异常响声 | 高粘度摩擦大,小间隙 |
| 启动 1 周 | 泵端面泄漏 | 磨损 |
| 启动 1 个月 | 齿轮卡死,泵损坏 | 高粘度 + 小间隙 → 卡死 |
| 故障原因 | **选错泵型** | 低粘度齿轮泵不适合 |

### 6.2 选错齿轮泵的 5 大后果

1. **泵卡死**:高粘度 + 小间隙 → 摩擦力超过电机扭矩
2. **齿轮磨损**:无润滑油膜 → 干摩擦 → 磨损
3. **密封损坏**:高粘度摩擦热 → 密封件老化
4. **效率急剧下降**:粘度大 → 摩擦功耗大 → 实际流量小
5. **电机烧毁**:过载 → 电机烧毁

### 6.3 选错高粘度齿轮泵处理低粘度物料

**错误**:用高粘度齿轮泵处理 50 cP 轻油

| 阶段 | 现象 | 原因 |
|---|---|---|
| 启动时 | 流量不足 | 大间隙 → 内泄漏 |
| 长期 | 效率低(70-85%) | 间隙大 → 泄漏大 |
| 解决 | 改回低粘度型 | |

## 七、齿轮泵选型自检流程

### 7.1 选型自检

```
Q1: 介质粘度?
├─ < 100 cP → 改用柱塞泵(齿轮泵效率低)
├─ 100-1000 cP → 低粘度齿轮泵 ⭐
├─ 1000-10,000 cP → 高粘度齿轮泵 ⭐
└─ > 10,000 cP → 改用螺杆泵

Q2: 介质是否含固体?
├─ 含固体 → 改用螺杆泵(齿轮泵不耐固)
└─ 无固体 → 齿轮泵

Q3: 流量精度要求?
├─ ±0.5-1% → 改用柱塞泵
├─ ±1-2% → 精密齿轮泵(DP 系列)
└─ ±2-5% → 齿轮泵/高粘度齿轮泵

Q4: 压力?
├─ < 25 bar → 齿轮泵
└─ > 25 bar → 改用柱塞泵
```
