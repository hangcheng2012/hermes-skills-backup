# 泵选型决策树(完整版)

> 通用参考: 适用于所有化工/石化/医药/食品/水处理项目,涵盖 3 大类容积式泵(齿轮泵/柱塞泵/螺杆泵)的选型决策。

---

## 一、决策树主框架

```
泵选型决策:

Q1: 介质含固体颗粒?
├─ 是 → 螺杆泵 ⭐(高固)/齿轮泵(低粘度清洁)
│       └→ Q5(检查含固率)
└─ 否 → Q2

Q2: 流量精度要求?
├─ ±0.5% → 柱塞泵(三柱塞) ⭐
├─ ±0.5-1% → 柱塞泵 ⭐
├─ ±1-2% → 精密齿轮泵(DP 系列) / 柱塞泵
└─ ±2-5% → 齿轮泵/螺杆泵

Q3: 介质粘度?
├─ < 100 cP → 柱塞泵(齿轮泵效率低)
├─ 100-1000 cP → 普通齿轮泵 / 柱塞泵
├─ 1000-10,000 cP → 高粘度齿轮泵 ⭐
└─ > 10,000 cP → 螺杆泵 ⭐(最广粘度)

Q4: 操作压力?
├─ < 10 bar → 齿轮泵/螺杆泵
├─ 10-40 bar → 齿轮泵/螺杆泵/柱塞泵
└─ > 40 bar → 柱塞泵 ⭐(可达 1000 bar)

Q5: 含固率?(从 Q1 进入)
├─ < 5% → 标准螺杆泵
├─ 5-20% → 标准螺杆泵
├─ 20-40% → 加厚定子螺杆泵
└─ > 40% → 特殊定子螺杆泵

Q6: 介质是否剪切敏感?
├─ 是(生物/活性) → 螺杆泵 ⭐(剪切最低)
└─ 否 → 任意

Q7: 自吸需求?
├─ 强自吸 → 螺杆泵 ⭐(8-9 m 自吸)
└─ 不要求 → 任意

Q8: 反转需求?
├─ 需要 → 外齿轮泵 ⭐
└─ 不需要 → 任意
```

## 八、决策流程(完整)

```
泵选型完整流程:

第 1 步:介质参数收集
  ├─ 介质名称、化学式
  ├─ 粘度(cP) + 温度(°C)
  ├─ 含固率(%) + 最大颗粒(mm) + 纤维长度(mm)
  ├─ 介质温度范围(°C)
  ├─ 介质特性(润滑性/腐蚀性/毒性/可燃性)
  └─ NCO 兼容(是/否)

第 2 步:工艺参数收集
  ├─ 操作压力(bar)
  ├─ 设计压力(bar)
  ├─ 流量(m³/h)
  ├─ 流量精度要求(±%)
  ├─ 连续/短时工况
  ├─ 自吸需求
  └─ 反转需求

第 3 步:应用决策树
  ├─ Q1:含固? → 螺杆泵/其他
  ├─ Q2:精度? → 柱塞泵/其他
  ├─ Q3:粘度? → 高粘度齿轮泵/螺杆泵
  ├─ Q4:压力? → 柱塞泵/其他
  ├─ Q5:含固率? → 螺杆泵
  ├─ Q6:剪切敏感? → 螺杆泵
  ├─ Q7:自吸? → 螺杆泵
  └─ Q8:反转? → 外齿轮泵

第 4 步:确定泵型
  └─ 综合 8 大铁律 + 决策树 → 选定泵型

第 5 步:确定材质和密封
  ├─ 泵体/转子/定子材质
  ├─ 密封材质(NCO 兼容?)
  ├─ 轴承/机械密封/填料

第 6 步:出 Pump Data Sheet
  └─ 见 templates/pump-data-sheet.md
```

## 十二、最终决策规则(速记版)

**3 大类泵速记**:
- **齿轮泵**:连续输送,中低压,高粘度专用型,精度一般
- **柱塞泵**:精确计量,高压,本质计量型,±0.5%
- **螺杆泵**:含固介质,极广粘度,低剪切,自吸强

**4 大判断(决定泵型)**:
1. **含固?** → 螺杆泵
2. **精度 ±0.5%?** → 柱塞泵
3. **粘度 > 1000 cP?** → 高粘度齿轮泵
4. **压力 > 40 bar?** → 柱塞泵

**3 大避坑**:
1. **不用低粘度齿轮泵处理高粘度物料**(会卡死)
2. **不用齿轮泵处理含固介质**(会磨损)
3. **不用 NBR 密封处理 NCO 介质**(会损坏)
