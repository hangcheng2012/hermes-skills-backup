# 柱塞泵计量应用详解

> 柱塞泵是 3 大类泵中**计量精度最高**的泵型,本质计量型。本文详解柱塞泵的计量原理、分类、典型应用。

---

## 一、柱塞泵是本质计量型泵 ⭐

**为什么柱塞泵是计量型**:
- 柱塞每往复一次,排出**精确固定**的体积
- 通过调节柱塞行程或冲程数,精确控制流量
- 计量精度可达 **±0.5-1%**(本质计量)
- 配合伺服电机或变频器,可实现精确比例控制

**对比其他泵型**:
- 齿轮泵:±1-5%(受粘度/压力影响)
- 柱塞泵:**±0.5-1%** ⭐(本质精确)
- 螺杆泵:±1-3%

## 三、柱塞泵工作原理

### 3.1 基本结构

```
   电机 → 减速机 → 曲轴 → 柱塞往复运动
                          ↓ ↑
                    缸体(吸/排)
                    进口阀 ←→ 出口阀
```

**吸程**(柱塞后退):
- 进口阀打开
- 出口阀关闭
- 液体被吸入缸体

**排程**(柱塞前进):
- 进口阀关闭
- 出口阀打开
- 液体被排出

**每个行程排出精确固定体积**

### 3.2 流量调节方式

| 方式 | 原理 | 调节范围 | 精度 |
|---|---|---|---|
| **调节行程** | 改变柱塞行程长度 | 10-100% | **最高** ⭐ |
| 调节冲程数(转速) | 改变柱塞往复频率 | 10-100% | 高 |
| 调节+变频 | 行程 + 转速 | 1-100% | **最高** ⭐ |

**典型应用**:
- 固定行程 + 变频调速:**±0.5% 精度**
- 调节行程 + 变频调速:**±0.3% 精度**(计量级)


**三柱塞优势**:脉动 < 10%,流量稳定

## 六、柱塞泵选型决策

### 6.1 选型自检

```
Q1: 流量精度要求?
├─ ±0.5% → 三柱塞泵 ⭐
├─ ±1% → 单柱塞/三柱塞
└─ ±2% → 任意

Q2: 压力?
├─ < 10 bar → 任意
├─ 10-100 bar → 柱塞泵
└─ > 100 bar → 高压柱塞泵 ⭐

Q3: 介质粘度?
├─ < 100 cP → 柱塞泵 ⭐
├─ 100-1000 cP → 柱塞泵(密封需耐温)
└─ > 1000 cP → 齿轮泵(高粘度型) / 螺杆泵

Q4: 含固体?
├─ 含固 → 螺杆泵 ⭐(柱塞泵不耐固)
└─ 无固 → 柱塞泵

Q5: NCO 兼容?
├─ 是 → FFKM/Kalrez 密封 ⭐
└─ 否 → 标准密封
```
