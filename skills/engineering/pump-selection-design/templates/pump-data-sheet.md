## 二、典型应用填表示例

### 2.1 PU 预聚体输送(高粘度齿轮泵)

```
项目:PU 弹性体中试装置
泵位号:P-301
泵类型:□ 齿轮泵 → ☑ 高粘度齿轮泵
介质:PU 预聚体(NCO 端基)
粘度:500-2000 cP @ 80°C ⭐
含固:0%(无固)
温度:80°C
压力:0.05 MPa(扬程 10 m)
流量:0.5 m³/h
精度:±3%(普通齿轮泵)

材质:
  泵体:304SS
  齿轮:20CrMnTi 渗碳 HRC 58-62 ⭐
  轴承:重载滚动轴承
  密封:Kalrez 4079(全氟橡胶, NCO 兼容) ⭐
  磨损板:是(工具钢,12-18 月更换) ⭐

电机:0.75 kW,380V,IP55
保温:夹套加热(导热油,80°C)

价格:¥25,000-35,000

选型理由:
- PU 预聚体粘度 500-2000 cP,属高粘度,故选**高粘度齿轮泵**
  (标准齿轮泵间隙 0.02mm,高粘度会卡死)
- 介质含 NCO,密封必须用 **Kalrez 4079** 全氟橡胶(NBR 几天就坏)
- 含硬化齿轮 + 可换磨损板,寿命长
- 齿轮泵结构简单,维护方便
```

### 2.2 PU 反应料浇注(柱塞泵)

```
项目:PU 弹性体浇注
泵位号:P-601
泵类型:□ 柱塞泵 → ☑ 三柱塞计量泵
介质:PU 反应料(凝胶前)
粘度:300 cP @ 80°C
含固:0%
温度:80°C
压力:5 bar(浇注压力)
流量:0.6 m³/h
精度:**±1%** ⭐(配方要求 PTMG:NCO=1:1)

材质:
  泵体:316L(高纯度)
  柱塞:陶瓷涂层
  缸体:陶瓷
  阀:陶瓷球阀
  密封:**Kalrez 4079** ⭐(NCO 兼容)
  填料:PTFE

电机:1.5 kW,380V,IP55,带变频 ⭐
流量调节:行程调节+变频调速(综合调节)

价格:¥80,000-150,000

选型理由:
- PU 浇注要求 ±1% 精度,**柱塞泵是本质计量型**(±0.5-1%)
- 齿轮泵精度只有 ±3-5%,**达不到浇注要求**
- 介质含 NCO,**必须 Kalrez 4079** 密封
- 三柱塞设计,**流量脉动 < 10%**,浇注稳定
- 带变频 + 行程调节,**流量 1-100% 可调**
```

### 2.3 含砂水输送(螺杆泵)

```
项目:水处理厂
泵位号:SP-101
泵类型:□ 螺杆泵 → ☑ 单螺杆 PC 泵
介质:含砂水
粘度:1 cP @ RT
含固:5% 砂(最大 2 mm 颗粒) ⭐
温度:RT
压力:4 bar
流量:50 m³/h
精度:±5%(普通)

材质:
  转子:不锈钢 316L
  定子:**丁腈橡胶(NBR)** ⭐(耐砂粒磨损)
  泵体:铸铁
  万向节:钢,碳化钨涂层
  机械密封:碳化硅

电机:11 kW,380V,IP55
转速:300 rpm(低转速降剪切)

价格:¥50,000-80,000

选型理由:
- 含固 5% 砂,**螺杆泵是含固介质的首选**
- 齿轮泵/柱塞泵不耐固体,会快速磨损
- 螺杆泵弹性定子允许小颗粒通过(变形让位)
- 砂粒最大 2 mm < 16 mm 转子偏心,完全允许
- 寿命 18-24 月(定子)
```

### 2.4 沥青输送(螺杆泵 - 极高粘度)

```
项目:道路施工
泵位号:SP-201
泵类型:□ 螺杆泵 → ☑ 单螺杆 PC 泵(高粘度型)
介质:沥青
粘度:50,000 cP @ 180°C ⭐
含固:0%
温度:180°C
压力:10 bar
流量:10 m³/h
精度:±3%

材质:
  转子:不锈钢 316L
  定子:**氟橡胶(Viton)** ⭐(耐 180°C 高温)
  泵体:铸铁
  保温:夹套加热(导热油,180°C 保温) ⭐

电机:15 kW,380V,IP55,带变频
转速:200 rpm(低转速,降剪切)

价格:¥100,000-150,000

选型理由:
- 沥青粘度 50,000 cP,极宽粘度范围,**螺杆泵是唯一合适选择**
- 高粘度齿轮泵在 50,000 cP 已经很吃力
- 温度 180°C 高,定子选**氟橡胶(Viton)耐高温**
- 夹套加热防止沥青冷却凝固
- 自吸能力强,可以从罐车直接吸入
```

## 四、规格书常见错误

### 4.1 选型错误

| 错误 | 后果 |
|---|---|
| 低粘度齿轮泵 + 2000 cP | 1 个月内卡死 |
| 普通齿轮泵 + 含固 20% | 1 个月内磨损 |
| NBR 密封 + NCO 介质 | 几天内密封损坏 |
| 单柱塞 + 稳流应用 | 流量脉动大 |
| 离心泵 + 5000 cP 重油 | 汽蚀,效率低 |

### 4.2 规格书错误

| 错误 | 正确 |
|---|---|
| 缺粘度参数 | 必填,带温度 |
| 缺含固率 | 必填,含颗粒尺寸 |
| 缺 NCO 兼容 | 必填,影响密封 |
| 缺精度要求 | 必填,影响泵型 |
| 缺材质详情 | 必填,含密封 |
| 缺维护要求 | 必填,含易损件 |
| 缺选型理由 | 必填,引用决策依据 |
