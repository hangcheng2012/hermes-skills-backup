**女王工程(化工 / 石化)主要用前 7 种标准焓:**

**另外 8 种在特殊领域用:**

## 二、8 种次要标准焓逐个详解

### 2.1 标准溶解焓 ΔH°sol #8

**定义:**
> 25°C, 1 bar 下,**1 mol 纯态物质 → 1 mol 物质在大量溶剂**(理想稀溶液)中的焓变。

**反应:**
```
1 mol 物质 (纯态, 25°C, 1 bar) + n mol 溶剂 → 1 mol 物质(溶液,25°C, 1 bar)
```

**工程意义:**
- 判断物质在溶剂中的"溶解是吸热还是放热"
- 影响冷却 / 加热需求
- 结晶器需要

**典型数据(25°C, 1 bar):**

| 物质 | 溶剂 | ΔH°sol(kJ/mol)| 含义 |
|------|------|------------------|------|
| NaCl | H₂O | +3.88 | 溶解轻微吸热 |
| NaOH | H₂O | -44.51 | 溶解强烈放热 |
| **NH₄NO₃** | H₂O | **+25.69** | 溶解强烈吸热(冷包实验)|
| KNO₃ | H₂O | +34.89 | 强吸热 |
| Na₂CO₃ | H₂O | -23.4 | 放热 |
| CaCl₂ | H₂O | -82.93 | 强烈放热(用作干燥剂)|
| HCl(g) | H₂O | -74.85 | 强放热 |
| H₂SO₄(l) | H₂O | -74.32 | 强放热 |
| 蔗糖 | H₂O | +5.4 | 轻微吸热 |

**工程价值:**
- 溶解罐需要冷却/加热功率
- 反应釜是否要外加热源

### 2.2 标准原子化焓 ΔH°at #9

**定义:**
> 25°C, 1 bar 下,**1 mol 化合物 → 各原子(气态)**的焓变。

**反应:**
```
化合物(25°C, 1 bar) → 各原子(g, 25°C, 1 bar)
```

**工程意义:**
- 化学键能计算的关键数据
- 反应机理分析(分子反应断裂 / 形成的能量)

**典型数据:**
| 物质 | ΔH°at(kJ/mol)| 工程用途 |
|------|------------------|----------|
| **CH₄** | **+1649.5** | 理论计算、燃烧机理 |
| **C₂H₆** | 2859.6 | 燃烧机理 |
| **H₂O(g)** | +926.3 | 燃烧机理 |
| **CO₂(g)** | +1605.1 | 燃烧机理 |
| **NH₃(g)** | +1171.0 | 合成氨机理 |
| **N₂(g)** | +945.4 | 反应动力学 |

**核心作用:** 计算键离解焓 ΔH°BD。

### 2.3 标准键离解焓 ΔH°BD #10

**定义:**
> 25°C, 1 bar 下,**切断一个特定的化学键**形成原子的焓变。

**反应:**
```
A-B(g, 25°C, 1 bar) → A(g) + B(g)    @ 25°C, 1 bar
```

**典型数据(键能):**

| 键 | ΔH°BD(kJ/mol)| 工程场景 |
|-----|----------------|----------|
| **H-H** | **+436** | **氢气裂解** |
| **C-H**(CH₄) | +439 | 自由基反应 |
| C-H (CH₃):烷基 | +410 | 碳氢燃烧 |
| **C-C**(乙烷)| **+346** | **聚合机理** |
| C=C (乙烯) | +620 | 不饱和键 |
| C≡C (乙炔) | +960 | 不饱和键 |
| **C=O**(CO₂)| **+799** | **燃烧关键** |
| C=O (醛) | +712 | 有机 |
| C-O (醇) | +358 | 醚化反应 |
| O-H (水) | +460 | 水的电离 |
| O=O (氧) | +498 | 氧气反应 |
| N≡N (N₂) | +945 | 合成氨 |
| N-H (NH₃) | +390 | 合成氨 |
| C-N (胺) | +290 | 胺 |
| C≡N (HCN) | +890 | 氰化物 |
| **N=O** (NO) | **+630** | 燃烧产物 |

**核心应用:**
- 燃烧理论(键断裂 + 形成)
- 自由基聚合动力学
- 催化剂设计

**用途示例:**
```
CO₂ 中的 C=O 双键,键离解能 799 kJ/mol
火焰温度下 CO₂ 会部分离解成 CO + O,然后再形成:

火焰反应机制:
CO₂ + M → CO + O + M   吸收 799 kJ/mol → 火焰温度提供能量
CO + OH → CO₂ + H       释放 103 kJ/mol
```

### 2.4 标准离子化焓 ΔH°ion #11

**定义:**
> 0 K 气态基态**原子 → 1+ 气态阳离子 + 电子**

**反应:**
```
A(g, 0 K, 基态) → A⁺(g, 0 K) + e⁻
```

**注意:** 标准是 0 K,不是 25°C!

**典型数据(第一电离能):**
| 原子 | ΔH°ion(kJ/mol) | 工程用途 |
|------|------------------|----------|
| H | 1312.0 | 等离子体 |
| **Na** | 496 | 钠灯 |
| K | 419 | 钾光电池 |
| Mg | 738 | 镁合金 |
| Ca | 590 | 钙合金 |
| Fe | 762 | 钢铁 |
| O₂ | 1175 | 等离子体 |
| O | 1314 | 等离子体 |

**核心应用:**
- 等离子体物理
- 火焰 / 电离过程
- 周期表规律

### 2.5 标准电子亲和焓 ΔH°ea #12

**定义:**
> 0 K 气态基态**原子 + 电子 → 1- 气态阴离子**

**反应:**
```
A(g, 0 K, 基态) + e⁻ → A⁻(g, 0 K)
```

**典型数据(电子亲和能):**

| 原子 | ΔH°ea(kJ/mol)| 含义 |
|------|----------------|------|
| H | -72.8 | 氢化物形成 |
| O | -141 | 氧负离子 |
| F | -328 | 最强亲合 |
| Cl | -349 | 强亲合(卤素)|
| Br | -325 | |
| I | -295 | |
| C | -121 | 阴离子 |
| N | (0 或略正)| 较难形成 |
| Ne | (positive)| 稀有气体极难 |

**应用:**
- 化学键能(卤化物)
- 等离子体物理
- 卤化反应机理

### 2.6 标准水合焓 ΔH°hyd #13

**定义:**
> 25°C, 1 bar 下,**气态离子 + nH₂O → 1 mol 水合离子**的焓变。

**反应:**
```
A⁺(g) + nH₂O(l) → A⁺(aq)         ΔH°hyd(A⁺)
```

**典型数据(25°C, 1 bar):**

| 离子 | ΔH°hyd(kJ/mol)| 工程用途 |
|------|------------------|----------|
| **H⁺** | -1091 | 水的电离 |
| Li⁺ | -519 | 锂电池 |
| **Na⁺** | -409 | 海水中钠 |
| K⁺ | -322 | 钾肥 |
| Mg²⁺ | -1922 | 镁合金 |
| **Ca²⁺** | -1577 | 石灰石 |
| Al³⁺ | -4665 | 铝离子 |
| NH₄⁺ | -307 | 铵盐 |
| F⁻ | -483 | 氟化物 |
| **Cl⁻** | -340 | 海水中氯 |
| Br⁻ | -309 | |
| I⁻ | -247 | |
| OH⁻ | -510 | 碱溶液 |

**工程用途:**
- 电解质溶液热效应
- 离子交换热
- 电池反应

### 2.7 标准中和焓 ΔH°neut #14

**定义:**
> 25°C, 1 bar 下,**H⁺(aq) + OH⁻(aq) → H₂O(l)**的焓变。

**反应:**
```
H⁺(aq, ∞ dilution) + OH⁻(aq, ∞ dilution) → H₂O(l)    @ 25°C, 1 bar
```

**标准值(强酸 + 强碱):**
```
ΔH°neut = -55.84 kJ/mol
```

**注意:**
- 是"通用常数":不论强酸 (HCl, HBr, HI) 还是强碱 (NaOH, KOH),中和热都接近 -55.84 kJ/mol
- 弱酸 + 强碱:**数值不同**(因为弱酸还要分步电离)
- 弱酸 + 弱碱:**计算复杂**

**典型数据:**
| 酸碱组合 | ΔH°neut(kJ/mol)|
|---------|------------------|
| HCl + NaOH | -55.84 |
| HBr + NaOH | -55.84 |
| HNO₃ + NaOH | -55.84 |
| CH₃COOH + NaOH | -56.07(微差异)|
| HCOOH + NaOH | -54.5 |
| HCN + NaOH | -43(显著小)|

### 2.8 标准吸附焓 ΔH°ads #15

**定义:**
> 25°C, 1 bar 下,**1 mol 气体 → 1 mol 吸附态(化学/物理吸附到固体表面)**的焓变。

**反应:**
```
A(g, 25°C, 1 bar) + 表面(*, 25°C) → A*(吸附态, 25°C)
```

**典型数据(物理吸附 vs 化学吸附):**

| 类型 | ΔH°ads 范围 | 应用 |
|------|---------------|------|
| **物理吸附**(弱)| -10 ~ -40 kJ/mol | 干燥、过滤 |
| **化学吸附**(强)| -40 ~ -400 kJ/mol | 催化 |
| **不可逆吸附**(极强)| > -400 kJ/mol | 催化剂腐蚀 |

**应用:**
- 催化剂设计
- 空气净化
- 储气(活性炭、MgH₂、LaNi₅)
- 膜分离

## 三、8 种次要焓的工程汇总

| # | 名 | 反应 | 数值范围 | 女王工程场景 |
|---|-----|------|----------|--------------|
| ⑧ | ΔH°sol | 纯 → 溶液 | ± 50 kJ/mol | 萃取、结晶 |
| ⑨ | ΔH°at | 化合物 → 原子 | 数百~2000 kJ/mol | 反应机理(教学)|
| ⑩ | ΔH°BD | A-B → A + B | 200~1000 kJ/mol | 自由基化学、燃烧理论 |
| ⑪ | ΔH°ion | 原子 → 阳离子 | 100~2000 kJ/mol | 等离子体物理 |
| ⑫ | ΔH°ea | 原子 + e⁻ → 阴离子 | ± 350 kJ/mol | 卤化反应、电化学 |
| ⑬ | ΔH°hyd | 离子(g) → 离子(aq) | -200 ~ -5000 kJ/mol | 电池、电解 |
| ⑭ | ΔH°neut | H⁺ + OH⁻ → H₂O | -55.84 kJ/mol(常数)| 中和反应 |
| ⑮ | ΔH°ads | 气体 → 吸附态 | -10 ~ -400 kJ/mol | 催化、储存 |
