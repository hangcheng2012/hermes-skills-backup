# ΔG°f vs ΔH°f —— Gibbs-Helmholtz 关系详解

> **本文件是 standard-enthalpies SKILL 的 references/ 详解之一**。
> 详解 Gibbs 生成自由能 ΔG°f 与焓变 ΔH°f 的关系 —— 不是"标准自由焓",而是 Gibbs 自由能。

---

## 一、女王问的"标准自由焓"——严格定义

### 1.1 标准说法

> **"标准自由焓"是口语化的说法,严格术语是"标准 Gibbs 生成自由能 ΔG°f"。**

**核心事实:**
- G = Gibbs 自由能,**不是焓**(H)
- G = H - T·S → ΔG° = ΔH° - T·ΔS°
- ΔG°f 是 G 的特定反应(稳定单质 → 1 mol 化合物)在标准态下的变化
- **物理意义:** 反应"驱动力"或"反应方向倾向",不是热量。

### 1.2 严格说:ΔG 是"自由能",不是焓

**女王口语:"标准自由焓"——按字面应理解为:**

| 术语 | 是否是焓 | 状态 | 反应 |
|------|---------|------|------|
| **ΔG°f 标准 Gibbs 生成自由能** | **不是焓,是 Gibbs 自由能** | 25°C, 1 bar | 稳定单质 → 1 mol 化合物 |
| **ΔA°f 标准 Helmholtz 生成自由能** | 不是焓,是 Helmholtz 自由能 | 25°C, 1 bar | 稳定单质 → 1 mol 化合物 |
| **ΔH°f 标准生成焓** | **是焓** | 25°C, 1 bar | 稳定单质 → 1 mol 化合物 |

## 二、Gibbs-Helmholtz 方程

### 2.1 核心公式

```
ΔG° = ΔH° - T·ΔS°        (Gibbs-Helmholtz 方程)
```

**变量说明:**
- ΔG°:标准 Gibbs 自由能变(单位:kJ/mol)
- ΔH°:标准焓变(单位:kJ/mol)
- ΔS°:标准熵变(单位:J/(mol·K))
- T:温度(单位:K)

### 2.2 对具体标准生成量的应用

```
ΔG°f = ΔH°f - T·ΔS°f        (T = 298.15 K)

ΔS°f:标准生成熵变(从稳定单质生成 1 mol 化合物的熵变)
```

**注意:** T = 298.15 K 是数据表的隐含默认温度。

## 三、ΔG°f 与 ΔG°r 的关系(Hess 类似)

### 3.1 标准反应 Gibbs 自由能

**任意反应的 ΔG°r:**
```
ΔG°r = Σ(产物 ν_i · ΔG°f_i) - Σ(反应物 ν_j · ΔG°f_j)
```

(类似 Hess 定律)

### 3.2 ΔG°f 的核心用途

| 用途 | 公式 | 说明 |
|------|------|------|
| **反应方向判断** | ΔG°r < 0:反应自发<br>ΔG°r > 0:反应非自发<br>(标准态)| 工程上反应器选择性的依据 |
| **平衡常数** | **ΔG°r = -RT ln K** | 计算反应平衡常数 |
| **电化学** | **ΔG°r = -nFE** | 计算电池电势 |
| **温度影响** | **ΔG°(T) = ΔH° - T·ΔS°** | 判断任意温度下的反应方向 |

---

## 四、反应方向判断的工程应用

### 4.1 判断规则

```
在标准态下:
   ΔG°r < 0   → 反应自发(正向)
   ΔG°r > 0   → 反应非自发(正向不自发)
   ΔG°r = 0   → 反应平衡(K = 1)
```

### 4.2 温度影响反应方向

**特殊情况:ΔG°r(T) = ΔH°r - T·ΔS°r**

- 当 **ΔH°r < 0, ΔS°r > 0**:任何 T 都自发
- 当 **ΔH°r > 0, ΔS°r < 0**:任何 T 都不自发
- 当 **ΔH°r < 0, ΔS°r < 0**:低温自发,高温非自发
- 当 **ΔH°r > 0, ΔS°r > 0**:高温自发,低温非自发

### 4.3 算例:碳氧化反应温度影响

**反应:** C(石墨) + O₂(g) → CO₂(g)
- ΔH°r = -393.52 kJ/mol
- ΔS°r = +213.79 - 197.66 - 205.04 = +2.61 J/(mol·K)
- ΔG°r(298 K) = -393.52 - 298.15 × 0.00261 = -394.30 kJ/mol(自发)

**这反应在任何温度都自发**(因为 ΔH° < 0 且 ΔS° > 0)

## 五、ΔG°f 与反应平衡(K)

### 5.1 核心公式

```
ΔG°r = -RT ln K

K:反应平衡常数(纯经验值,需要实验测定)
```

### 5.2 各反应类型的 K 公式

| 反应类型 | K 表达式 | 来源 |
|----------|----------|------|
| A + B ⇌ C + D | K = (cC · cD) / (cA · cB) | 浓度 |
| A + B ⇌ C | K = cC / (cA · cB) | 浓度 |
| A(g) ⇌ B(g) | K_p = pB / pA | 分压 |
| A ⇌ B(l) + C(g) | K_p = pC | 仅分压 |
| A(aq) ⇌ B(aq) + H⁺ | K_a(酸常数)| 酸类 |

### 5.3 算例:CO₂ + H₂ ⇌ CO + H₂O(逆水煤气变换)

**反应:** CO₂ + H₂ ⇌ CO + H₂O(g)

```
ΔG°r = [ΔG°f(CO) + ΔG°f(H₂O, g)] - [ΔG°f(CO₂) + ΔG°f(H₂)]
     = [(-137.17) + (-228.57)] - [(-394.36) + 0]
     = -365.74 - (-394.36)
     = +28.62 kJ/mol

K = exp(-ΔG°r / RT) = exp(-28620 / (8.314 × 298.15))
  = exp(-11.54)
  ≈ 9.5 × 10⁻⁶

(K 很小,反向(CO + H₂O → CO₂ + H₂)自发进行)
```

## 六、ΔG°f 与电化学

### 6.1 核心公式

```
ΔG°r = -n·F·E°cell

n:反应转移的电子数
F:法拉第常数(96485 C/mol)
E°cell:标准电池电动势(V)
```

### 6.2 算例:锌铜电池

**反应:** Zn + Cu²⁺ → Zn²⁺ + Cu

```
标准 ΔG°r = -ΔG°f(Zn²⁺) + (-ΔG°f(Cu²⁺))
          = -147.16 + 65.49
          ≈ -213.65 kJ/mol(估算)

n = 2 电子

E°cell = -ΔG°r / (nF) = 213650 / (2 × 96485) = 1.107 V

(实际标准电势 1.10 V,与计算一致)
```

## 八、ΔH°f 与 ΔG°f 在工程上的对比应用

### 8.1 反应器热平衡——用 ΔH°f

```
目的:计算反应器"放热/吸热"
工具:ΔH°f 字典 + Hess 定律
结果:反应器的热负荷(kW)
```

### 8.2 反应方向 + 平衡——用 ΔG°f

```
目的:判断反应能否发生
工具:ΔG°f 字典 → ΔG°r
公式:ΔG°r = -RT ln K(平衡常数)
结果:反应器产率估计
```

### 8.3 决策选择

| 需要做的事 | 用的标准量 |
|------------|------------|
| 反应热平衡计算 | **ΔH°f** |
| 反应选择催化剂 | **ΔG°f**(反应路径)|
| 反应平衡产率估计 | **ΔG°r** |
| 反应温度选择 | **ΔG°(T) = ΔH° - T·ΔS°** |
| 燃料热值 | **ΔH°c**(来自 ΔH°f)|
| 电化学电池设计 | **ΔG°r → E°cell**|

## 九、ΔG°f 的常见工程误区

### 误区 ①:误把 ΔG°f 当作"标准自由焓"

**正解:ΔG°f = 标准 Gibbs 生成自由能,不是焓。**
"自由焓"是口语化叫法,严格说应叫"生成自由能"。

### 误区 ②:ΔG°f < 0 = 反应绝对发生

**正解:**
- ΔG°f < 0 → 标准态下自发
- 但**实际反应速率可能慢**(动力学问题)
- 工程还要考虑催化剂、活化能

### 误区 ③:ΔG°r 是温度无关常数

**正解:**
- ΔG°r 随温度变化
- 严格公式:ΔG°r(T) = ΔH°r - T·ΔS°r(假设 ΔH, ΔS 不随 T 变)

### 误区 ④:用 ΔG°r 算反应器热负荷

**正解:**
- 反应器热负荷用 **ΔH°r**(焓变)
- **ΔG°r 不能算热负荷**(它不含能量)
