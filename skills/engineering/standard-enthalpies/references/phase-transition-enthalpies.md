# 相变焓 ΔH°fus / ΔH°vap / ΔH°sub —— 三种主要相变焓详解

> **本文件是 standard-enthalpies SKILL 的 references/ 详解之一**。
> 详解三个相变焓,以及它们的工程应用 + 女王 scCO₂-PET 工艺中的实际用法。

---

## 一、三个相变焓的严格定义

### 1.1 标准熔化焓 ΔH°fus

**定义:**
> 在正常熔点 T_m(物质自身熔点),**1 mol 物质**从**固(s)→液(l)**的焓变。

**反应方程式:**
```
1 mol 物质 (s, T_m, 1 bar) → 1 mol 物质 (l, T_m, 1 bar)
```

**状态:**
- 反应物:固体 @ T_m, 1 bar
- 产物:液体 @ T_m, 1 bar

### 1.2 标准汽化焓 ΔH°vap

**定义:**
> 在正常沸点 T_b(物质自身沸点),**1 mol 物质**从**液(l)→气(g)**的焓变。

**反应方程式:**
```
1 mol 物质 (l, T_b, 1 bar) → 1 mol 物质 (g, T_b, 1 bar)
```

**状态:**
- 反应物:液体 @ T_b, 1 bar
- 产物:气体 @ T_b, 1 bar

### 1.3 标准升华焓 ΔH°sub

**定义:**
> 在标准态下(25°C, 1 bar),**1 mol 物质**从**固(s)→气(g)**的焓变。

**反应方程式:**
```
1 mol 物质 (s, 25°C, 1 bar) → 1 mol 物质 (g, 25°C, 1 bar)
```

**注意:** 严格说 ΔH°sub 可以是任何温度下的"固→气",但标准值常用 25°C 或物质三相点(因为 ΔH°fus + ΔH°vap 路径常用三相点温度)。

## 二、三相变焓的"温度不在 25°C"细节

**关键细节:**

| 相变焓 | 标准温度 | 为什么? |
|--------|----------|----------|
| ΔH°fus | T_m(正常熔点)| 因为固体在 T_m 才开始熔化 |
| ΔH°vap | T_b(正常沸点)| 因为液体在 T_b 才开始气化 |
| ΔH°sub | 25°C 或三相点 | 数据表常用的温度 |

**严格说:** 这三个相变焓**都不是 25°C 标准焓**——它们都在相变特定温度。所以要"标准"加 ° 角标需谨慎。

**实际工程处理:**
- ΔH°fus、ΔH°vap **数值随温度变化**(随 T 升高而减小)
- 临界点:ΔH°fus、ΔH°vap 均 = 0(气液不可分)

---

## 三、三相变焓的关系

### 3.1 三相变焓的"加和性"

**关键事实:**
```
ΔH°sub = ΔH°fus + ΔH°vap
```

**这是 Hess 定律的特例:**
```
固(s, 25°C) → 液(l, 25°C):ΔH°fus (理论值)
液(l, 25°C) → 气(g, 25°C):ΔH°vap (理论值)
固(s, 25°C) → 气(g, 25°C):ΔH°sub
```

**完整版本(三相点 T_tp):**
```
ΔH°sub(T_tp) = ΔH°fus(T_tp) + ΔH°vap(T_tp)
```

## 五、相变焓的工程应用

### 5.1 蒸发器热负荷

**蒸发 1000 kg/h H₂O,25°C 的水到 100°C 的蒸汽:**

```
蒸发热负荷 = 1000 kg × 40.65 kJ/mol × (1 mol / 18.02 g) × 1000 g/kg
          = 1000 kg × 2256 kJ/kg
          = 2,256,000 kJ/h
          = 627 kW
```

### 5.2 冷凝器热负荷

**冷凝器热负荷(蒸汽冷凝器):**
```
冷凝放热 = 蒸汽流量 × ΔH°vap

(同 ΔH°vap 数值,因为冷凝 = 反向蒸发)
```

### 5.3 结晶器设计

**结晶器热负荷 = 冷却水 + 熔化焓(熔解热)**

### 5.4 干冰制造 / CO₂ 凝固

**形成 1 ton 干冰需要放热:**
```
放热 = 1 ton × (1000 kg/ton) × 25.2 kJ/mol × (1 mol / 44.01 g)
     = 1000 × 25.2 / 44.01 × 1000 / 1000
     ≈ 573 kJ = 159 Wh
```
**反向:从固态 CO₂ 升华出 1 ton → 吸热 159 kWh**

### 5.5 制冷循环

**氨制冷:**
```
T_evap = -33°C:ΔH°vap(NH₃) = 23.3 kJ/mol
冷凝器放热 = 量 × 23.3(对应冷凝温度)
蒸发器吸热 = 量 × 23.3(对应蒸发温度)
```

## 六、相变焓随温度变化的规律

### 6.1 经验规则

**大多数物质:**
```
ΔH_vap (T_critical) = 0                  (临界点关键事实)
ΔH_vap 随 T ↑ 而 ↓
```

**经验公式(Watson 公式):**
```
ΔH_vap(T) / ΔH_vap(T_b) = [1 - T/T_c] / [1 - T_b/T_c]^0.38
```

(利用归一化估算任意 T 下的 ΔH_vap)

### 6.2 ΔH°fus 随温度的变化

**ΔH°fus 几乎不随 T 变化** —— 因为反应物和产物的温差很小。

### 6.3 ΔH°sub 随温度的变化

**ΔH°sub 随 T 升高而减小** —— 因为 ΔH°sub = ΔH°fus + ΔH°vap,而 ΔH°vap 减小显著。

---

## 七、ΔH°vap 数据的"工程速算"

### 7.1 Widom 经验公式

**Trouton 规则(粗算):**
```
ΔH°vap(T_b) ≈ 10.5 · R · T_b       (kJ/mol)
```
(适用于非极性液体;**极性液体误差大** —— 水、醇有氢键)

| 物质 | T_b (K) | Trouton 估算 | 实际 |
|------|---------|----------------|------|
| H₂O | 373 | **+10.5·8.314·373/1000 = +32.5** | +40.7 |
| 苯 | 353 | **+30.8** | +30.8(吻合)|
| 乙醇 | 351 | +30.6 | +38.6(异常)|
| 己烷 | 342 | +29.9 | +28.9(吻合)|

**注意:** Trouton 规则对强极性和氢键液体误差大。

### 7.2 Clausius-Clapeyron 方程(用于 ΔH°vap 估算)

**核心公式:**
```
ln P_sat = -ΔH_vap / (R T) + C

从两个 (P_sat, T) 数据点估算 ΔH_vap
```

## 九、特殊物质相变焓的应用注意

### 9.1 CO₂ 在常压下不能液相

**重要事实:**
- CO₂ 在 1 atm **不经过液相**,只能从**固直接升华为气**(ΔH°sub,不是 ΔH°fus + ΔH°vap)
- CO₂ 在三相点(-56.6°C, 0.518 MPa)才能液相
- **所以常压下的 CO₂ "干冰"应用,只涉及 ΔH°sub**

### 9.2 过冷水与过冷水

**过冷水(25°C 以下不结冰的水):**
- 显热 + 熔化焓**严格相等**(状态函数)
- ΔH°fus (过冷水) ≈ ΔH°fus(常冰) - CP·25°C ≈ +5.9 - 5.8 ≈ +5.8 kJ/mol
- 工程上记 +6.0 kJ/mol 即可

### 9.3 气体"液化为液" 的双步骤

**气体液化为液:**
```
气(g) → 液(l):ΔH_vap(反向,液化放热)
气(g) → 固(s):ΔH_sub(反向,凝华放热)
液(l) → 固(s):ΔH_fus(反向,凝固放热)
```
