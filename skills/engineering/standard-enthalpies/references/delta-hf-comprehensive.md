> **本文件是 standard-enthalpies SKILL 的 references/ 详解之一**。

---

## 一、ΔH°f 的严格定义

### 1.1 反应方程式

**通用形式:**
```
Σ(稳定单质,25°C, 1 bar) → 1 mol 化合物(25°C, 1 bar)
```

**具体示例:**

**CO₂ 的 ΔH°f:**
```
C(石墨) + O₂(g) → CO₂(g)        @ 25°C, 1 bar
ΔH°f(CO₂, g) = -393.52 kJ/mol
```

**H₂O(l) 的 ΔH°f:**
```
H₂(g) + 1/2 O₂(g) → H₂O(l)     @ 25°C, 1 bar
ΔH°f(H₂O, l) = -285.83 kJ/mol
```

**H₂O(g) 的 ΔH°f:**
```
H₂(g) + 1/2 O₂(g) → H₂O(g)     @ 25°C, 1 bar
ΔH°f(H₂O, g) = -241.82 kJ/mol
```

### 1.2 符号解读

- **Δ** = "过程的" / "起点→终点的差"
- **H** = 焓(enthalpy)
- **°**(角标)= "标准态"(25°C, 1 bar, 稳定单质)
- **f** = "formation"(形成 / 生成)

## 二、状态的严格规定

### 2.1 反应物的状态

**统一规定:必须是"最稳定单质"**

| 单质 | 状态 | 25°C, 1 bar 形态 |
|------|------|------------------|
| C | **石墨**(s)| 固体 |
| H₂ | **气态** | 理想气体 |
| O₂ | **气态** | 理想气体 |
| N₂ | **气态** | 理想气体 |
| Cl₂ | **气态** | 气体 |
| Br₂ | **液态** | 液体(红棕色)|
| I₂ | **固态** | 固体(紫色晶体)|
| S | **斜方硫 S₈(s)** | 固体 |
| P | **白磷 P₄(s)** | 固体(分子晶体)|
| Fe | **α-Fe(s)** | 固体(室温稳定的铁素体)|
| Cu | **金属 Cu(s)** | 金属晶体 |
| Na | **金属 Na(s)** | 金属晶体 |

### 2.2 产物的状态

**严格的物理形态规定:**
- **ΔH°f(CO₂, g)** = -393.52 kJ/mol,意味着产物是**气态 CO₂**
- **ΔH°f(H₂O, l)** = -285.83 kJ/mol,产物是**液态水**
- **ΔH°f(H₂O, g)** = -241.82 kJ/mol,产物是**气态水**

**注意:**
- 同一物质,**气态 vs 液态 vs 固态的 ΔH°f 不同**
- 差值 = 相变焓
- 例如:ΔH°f(H₂O, g) - ΔH°f(H₂O, l) = -241.82 - (-285.83) = **+44.01 kJ/mol**(就是 25°C 时的汽化焓)

### 2.3 状态约定

**反应标准态 = 25°C, 1 bar 现代标准**

- 温度:数据表默认 25°C,但严格说"任意"
- 压力:**1 bar(100 kPa)**

## 四、ΔH°f 数据来源说明

### 4.1 三家主要数据源

| 数据源 | 数据质量 | 覆盖 | 备注 |
|--------|---------|------|------|
| **NIST WebBook** | ★★★★★ | 极全 | 首选 |

| **DIPPR** | ★★★★ | 1440 种工业物质 | 工业介质首选 |

### 4.2 数据冲突处理

**经常遇见的冲突:**
- 不同数据源对同一物质 ΔH°f 有 1~5 kJ/mol 的差异
- 处理规则:**以 NIST WebBook 优先**,JANAF 次之,DIPPR 再次
- 极罕见差异(> 10 kJ/mol)→ 查原始文献

## 五、ΔH°f 的工程应用清单

### 5.1 反应热计算(核心)

**Hess 定律:**
```
ΔH°r = Σ(产物 ΔH°f) - Σ(反应物 ΔH°f)
```

**算例:** PTA + 2 EG → BHET + 2 H₂O

```
反应:C₈H₆O₄ + 2 C₂H₆O₂ → C₁₂H₁₄O₄ + 2 H₂O
   PTA        EG         BHET       水
ΔH°r ≈ (-978) + 2·(-285.83) - [(-816) + 2·(-455.4)]
     ≈ (-978 - 571.66) - (-816 - 910.8)
     ≈ -1549.66 - (-1726.8)
     ≈ -177.14 → 需用反应物实际数据校正

典型 PET 反应文献值:~ -25 kJ/mol BHET(链节)
```

### 5.2 燃料热值

**燃料热值 = -ΔH°c**(正值)

### 5.3 化工品合成路径选择

**多个反应路径选项时,选放热更少的:**
- 因为放热多 = 能耗少,但反应器需冷却
- 平衡:反应热与反应器控制难度综合考虑

### 5.4 储存稳定性

**ΔH°f 数值与稳定性:**
- 越负 → 越稳定
- ΔH°f 接近 0 或正 → 不稳定
- 极端:C₇H₈NO₃ 高能量化合物(爆炸物)= ΔH°f 大负

## 六、常见物质 ΔH°f 的"PFD 出图"标注

### 6.1 PFD 物性节点标注惯例

**反应节点(入/出流):**
```
反应器入流:
   PTA:    25°C, 1 bar(s)     ΔH°f = -816.0 kJ/mol
   EG:     25°C, 1 bar(l)     ΔH°f = -455.4 kJ/mol

反应器出流:
   BHET:   25°C, 1 bar(s)     ΔH°f ≈ -978 kJ/mol
   H₂O:    25°C, 1 bar(l)     ΔH°f = -285.83 kJ/mol
```

### 6.2 反应热计算器(PFD 文档常用公式)

```
反应热(kJ/s) = Σ(出流 mol流量 · ΔH°f) - Σ(入流 mol流量 · ΔH°f)
```

## 七、ΔH°f 数据的"自查"小技巧

### 7.1 同位素预测法

**当一个物质没有 ΔH°f 实验值,可用相近物质估算:**
- CH₃OH vs C₂H₅OH:差 -CH₂- ≈ -18 kJ/mol
- 这是简单的同源估算(工程上不到万不得已不用)

### 7.2 基团加和法(Joback 法)

**Joback(1984)基团贡献法:**
- 已知常见基团贡献(>20 种)
- 适用:分子量 50~500 的有机物
- 误差:~10 kJ/mol
- 工程上"查不到数据时的退路"

### 7.3 NIST WebBook 的"在线计算"

**网址:** https://webbook.nist.gov/chemistry/

**操作:** 进入"Thermo" → 输入物质 → 选物性表(enthalpy of formation)→ 得到 ΔH°f
