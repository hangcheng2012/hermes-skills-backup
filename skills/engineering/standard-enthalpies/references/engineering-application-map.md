## 一、女王常用工程组件的标准焓对应表

### 1.1 反应器

| 反应器类型 | 主要使用 | 关键计算 |
|----------|---------|----------|
| **反应釜(间歇)** | **ΔH°f**(反应热) | 反应器热平衡、冷却/加热功率 |
| **管式反应器** | **ΔH°f** | 沿管长的温度分布 |
| **流化床** | ΔH°f + ΔH°ads(催化剂)| 反应热 + 催化剂状态 |
| **scCO₂ 反应器** | ΔH°f + ΔH°sol + ΔH°at | 反应热 + CO₂ 溶解 + 解离 |

### 1.2 分离设备

| 设备 | 主要使用 | 关键计算 |
|------|---------|----------|
| **精馏塔** | **ΔH°vap**(关键)| 塔釜再沸器热负荷、塔顶冷凝器热负荷 |
| **吸收塔** | **ΔH°sol** | 吸收过程热效应 |
| **萃取塔** | ΔH°sol(溶解热) | 萃取热效应 |
| **闪蒸罐** | ΔH°vap | 闪蒸温度降 |
| **结晶器** | **ΔH°fus**(熔化热)| 结晶热 = -ΔH°fus |

### 1.3 储罐与运输

| 设备 | 主要使用 | 关键计算 |
|------|---------|----------|
| **常压储罐** | ΔH°fus, ΔH°vap | 凝固/气化控制 |
| **压力储罐** | ΔH°sub(干冰相关)| 干冰储罐设计 |
| **LNG 储罐** | ΔH°vap(低温)| 低温隔热损失 |
| **冷藏罐** | ΔH°fus(冰蓄冷)| 储能 |
| **管道** | 沿程焓变(主要是 ΔH°vap)| 流动温降 |

### 1.4 热交换设备

| 设备 | 主要使用 | 关键计算 |
|------|---------|----------|
| **换热器** | ΔH°vap(相变) | 热负荷计算 |
| **再沸器** | ΔH°vap | 加热功率 |
| **冷凝器** | -ΔH°vap | 冷却功率 |
| **蒸发器** | ΔH°vap | 加热功率 |
| **锅炉** | ΔH°c | 燃料需求 |
| **加热炉** | ΔH°f(反应) + ΔH°vap | 加热负荷 |

### 1.5 制冷与空调

| 设备 | 主要使用 | 关键计算 |
|------|---------|----------|
| **压缩制冷** | ΔH°vap(工质) | 蒸发器吸热 |
| **吸收制冷** | ΔH°sol(吸收剂) | 吸收热 |
| **节流制冷** | ΔH°vap + ΔH°fus | 节流温降 |
| **CO₂ 制冷** | ΔH°sub + ΔH°vap | scCO₂ 制冷 |

### 1.6 分离膜

| 设备 | 主要使用 | 关键计算 |
|------|---------|----------|
| **气体分离膜** | ΔH°ads | 选择性吸附 |
| **渗透汽化膜** | ΔH°vap | 部分气化 |
| **纳滤 / 反渗透** | ΔH°sol + 渗透压 | 膜分离 |

| 处理 | 用的标准焓 |
|------|-----------|

| 软化(石灰法)| ΔH°sol(Ca²⁺, Mg²⁺)|

### 2.2 气体处理

| 处理 | 用的标准焓 |
|------|-----------|
| 脱硫(胺法)| ΔH°sol(CO₂, H₂S)|
| PSA(变压吸附)| ΔH°ads |
| **CO₂ 捕集** | **ΔH°sol + ΔH°f**(溶剂 + 反应)|
| **CO₂ 液化** | **ΔH°vap**(CO₂)|
| **CO₂ 储运** | **ΔH°sub**(干冰)|

| 燃料 | 用的标准焓 |

| 燃料比较 | ΔH°c / (CO₂ 释放)|

| 氯碱 | NaCl → Na + Cl₂ | ΔH°f + 电化学 ΔG |

| **乙醇** | C₂H₄ + H₂O → C₂H₅OH | ΔH°f |

| 苯乙烯 | 苯 + 乙烯 → 苯乙烯 | ΔH°f |

## 三、女王 scCO₂-PET 工艺的标准焓清单

### 3.1 反应器段

**反应 1:酯化反应**
```
PTA(s) + 2 EG(l) → BHET(s) + 2 H₂O(l)
ΔH°r ≈ -25 kJ/mol(实际工艺值,工业数据)
```

**所需数据:**
| 物质 | ΔH°f(kJ/mol)| 备注 |
|------|----------------|------|
| **PTA** | **约 -816**(估算)| 关键反应物 |
| **EG** | **-455.4**(液) | 反应物 |
| BHET | 约 -978(估算)| 中间产物 |
| H₂O | -285.83(液)| 反应副产物 |

**反应 2:缩聚反应**
```
n BHET(s) → PET + n EG(l)
ΔH°r ≈ -12 kJ/mol(链节)
```

**反应 3:DEG 副反应**
```
EG + EG → DEG + H₂O
ΔH°r ≈ -10 ~ -20 kJ/mol(副反应)
```

### 3.2 减压脱气段

**关键相变焓应用:**
- 减压脱气后 CO₂ 部分相变 → ΔH°vap(CO₂)
- EG 在罐底凝出 → ΔH°cond(EG 汽化潜热,反向)
- DEG 在罐底凝出 → ΔH°cond(DEG)
- H₂O 蒸气在罐底凝出 → ΔH°cond(H₂O)

### 3.3 CO₂ 循环段

| 段 | 用的标准焓 |
|----|-----------|
| 减压到 4 MPa | ΔH°vap(CO₂)|
| CO₂ 凝出为液 CO₂ | -ΔH°vap(CO₂)|
| CO₂ 升压循环 | ΔH^R(剩余焓) — 不在标准焓范畴 |
| scCO₂ 进入反应器 | 显热 |

### 3.4 反应器热平衡(综合)

**总反应热(酯化 + 缩聚):**
```
Q_total(反应) = Σ ΔH°f(产物) - Σ ΔH°f(反应物)
             = ~ -25 kJ/mol(酯化 + 缩聚总,折合每链节)
```

**反应器设计:**
```
Q_反应器_净 = Q_反应 + Q_加热(夹套/盘管) + Q_蒸发(EG 蒸出) - Q_损失
```

## 五、标准焓数据"风险点"清单

### 5.1 风险点 ①:ΔH°f 数据冲突

**场景:** 同一物质在 NIST vs DIPPR 差 5 kJ/mol
**对策:** 用 NIST 优先,DIPPR 交叉验证

### 5.2 风险点 ②:ΔH°fus 数据缺失

**场景:** 复杂物质(如 BHET、TDI、PTA)的 ΔH°fus 查不到
**对策:** 用 Joback 基团加和法估算

### 5.3 风险点 ③:ΔH°vap 不在 T_b

**场景:** 工程上需要 100°C 的 CO₂ 汽化焓,但数据表给 -56°C
**对策:** 用 Watson 公式外推

### 5.4 风险点 ④:DEG 等副产物的 ΔH°sub

**场景:** 减压脱气罐底的 DEG 蒸出焓
**对策:** ΔH°vap(DEG, 245°C) ≈ +56 kJ/mol(估算)

### 5.5 风险点 ⑤:高温差下的 Kirchhoff 校正

**场景:** 100°C 下的酯化反应焓,与 25°C 数据表不同
**对策:** 用 Kirchhoff 公式:
```
ΔH(T) = ΔH(25°C) + ∫[25°C→T] ΔCp dT
```

## 七、女王工艺的标准焓"查询清单"

**开始一个新反应 / 工艺段前,查这些:**

### 7.1 反应器热平衡(必备清单)

- ☐ 反应物 1 的 ΔH°f(标准生成焓)
- ☐ 反应物 2 的 ΔH°f
- ☐ 产物 1 的 ΔH°f
- ☐ 产物 2 的 ΔH°f
- ☐ 副产物的 ΔH°f
- ☐ ΔCp 数据(用于 Kirchhoff 校正)
- ☐ 反应温度下的 ΔH(校正后)

### 7.2 精馏塔热负荷(必备清单)

- ☐ 关键物料的 ΔH°vap(在塔釜/塔顶温度)
- ☐ Watson 公式(从 T_b 外推到任意 T)
- ☐ 关键物料的 ΔH°f(用于全塔热损失)

### 7.3 冷凝器/再沸器(必备清单)

- ☐ 冷凝器的 ΔH°cond(=-ΔH°vap)
- ☐ 再沸器的 ΔH°vap
- ☐ 蒸气潜热数据

### 7.4 反应控制(可选)

- ☐ ΔG°f(判断反应方向)
- ☐ ΔG°r = -RT ln K(平衡常数)
- ☐ 弱电解质的电离数据

### 7.5 副反应分析(可选)

- ☐ 副产物 ΔH°f
- ☐ ΔH°sol(溶液副反应)
- ☐ ΔH°ads(催化剂吸附副反应)
