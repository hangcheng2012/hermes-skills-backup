# 标准反应焓 ΔH°r + Hess 定律 —— 从 ΔH°f 字典算任意反应热

> **本文件是 standard-enthalpies SKILL 的 references/ 详解之一**。
> 详解 ΔH°r 的定义、Hess 定律 + 多种典型反应的算例。

---

## 一、ΔH°r 的严格定义

### 1.1 定义

**任意化学反应的焓变(标准态):**
```
反应物 @ 25°C, 1 bar → 产物 @ 25°C, 1 bar
```

**符号:** ΔH°r(r = reaction)

### 1.2 重要细节

**ΔH°r 不是"反应在实际温度进行的焓变"** — 而是"反应物 + 产物都在 25°C 的虚拟焓变"。

**实际温度下反应焓(任意 T)用 Kirchhoff 公式:**
```
ΔH(T) = ΔH°r(25°C) + ∫[25°C→T] ΔCp dT

ΔCp = Σ(产物 Cp) - Σ(反应物 Cp)
```

---

## 二、Hess 定律(Hess's Law)

### 2.1 核心内容

**Hess 定律(1840 年由 Hess 提出):**

> 化学反应的焓变只与起点和终点有关,与反应路径无关。

### 2.2 数学表达

```
ΔH°r = Σ(产物 ν_i · ΔH°f_i) - Σ(反应物 ν_j · ΔH°f_j)
       —————————————————————————————————————————————
       (Hess 定律的核心公式)
```

### 2.3 Hess 定律的实际意义

**有了这张公式 + 一本 ΔH°f 字典表,任何反应的 ΔH°r 都能算出!**
- 不用每个反应都做实验测量
- 不用试反应路径
- 直接字典表查表 + 加和

## 三、典型算例(分类型)

### 3.1 燃烧反应(最常用)

**反应:** CH₄(g) + 2 O₂(g) → CO₂(g) + 2 H₂O(l)
```
ΔH°r = ΔH°f(CO₂) + 2ΔH°f(H₂O, l) - [ΔH°f(CH₄) + 2·ΔH°f(O₂)]
     = (-393.52) + 2×(-285.83) - [(-74.85) + 2×(0)]
     = -393.52 - 571.66 + 74.85
     = -890.33 kJ/mol(CH₄ 完全燃烧生成液水)
```

**注意:**
- 产物是 H₂O(l)(液态水)
- 若是 H₂O(g)(气态水),数值 +44 kJ/mol:
```
ΔH°r = -890.33 + 2×40.65 = -803.08 kJ/mol
       = ΔH°f(CO₂) + 2ΔH°f(H₂O, g) - ΔH°f(CH₄) - 0
       = -393.52 + 2×(-241.82) + 74.85
       = -802.31(差 0.77 因为 ΔH°vap 不是 40.65 而是 44.01 在 25°C)
```

**关键:** CH₄ 的标准燃烧焓 ΔH°c(CH₄) = **-890.33 kJ/mol**(约定水为液)

### 3.2 合成反应

**反应:** N₂ + 3 H₂ → 2 NH₃
```
ΔH°r = 2ΔH°f(NH₃) - [ΔH°f(N₂) + 3ΔH°f(H₂)]
     = 2×(-45.94) - [0 + 0]
     = -91.88 kJ/mol(N₂ 反应生成 2 mol NH₃ 的放热)

换算到 1 mol NH₃:-45.94 kJ/mol(经典 Haber-Bosch 数据)
```

### 3.3 分解反应

**反应:** CaCO₃(s) → CaO(s) + CO₂(g)
```
ΔH°r = ΔH°f(CaO) + ΔH°f(CO₂) - ΔH°f(CaCO₃)
     = (-635.09) + (-393.52) - (-1206.92)
     = +178.31 kJ/mol(吸热反应)
```

**工程含义:** 石灰石煅烧反应,**吸热**,需要外部供热。

### 3.4 酯化反应(女王 PET 工艺相关)

**反应:** PTA(s) + 2 EG(l) → BHET(s) + 2 H₂O(l)
```
假设 BHET 的 ΔH°f ≈ -978 kJ/mol(估算)
ΔH°r = ΔH°f(BHET) + 2ΔH°f(H₂O, l) - [ΔH°f(PTA) + 2·ΔH°f(EG)]
     = (-978) + 2×(-285.83) - [(-816) + 2×(-455.4)]
     = -978 - 571.66 - (-816 - 910.8)
     = -1549.66 - (-1726.8)
     = +177.14(吸热)

但 PET 工业酯化反应典型放热 ~25 kJ/mol BHET(与上面估算冲突)
说明 BHET 的实际 ΔH°f 不是 -978 kJ/mol
需查精确数据校正。
```

**注意:** PET 反应热是工程关键数据,需要查**工艺文献**+ **ΔH°f 字典**双重交叉验证。

### 3.5 中和反应

**反应:** HCl(aq) + NaOH(aq) → NaCl(aq) + H₂O(l)
```
ΔH°r = ΔH°f(NaCl, aq) + ΔH°f(H₂O, l) - [ΔH°f(HCl, aq) + ΔH°f(NaOH, aq)]
     = (-407.0) + (-285.83) - [(-167.46) + (-470.0)]
     = -692.83 - (-637.46)
     = -55.37 kJ/mol

理论中和热 ≈ -55.84 kJ/mol(这是公认的"通用值")
```

### 3.6 氧化还原反应

**反应:** 4 Fe(s) + 3 O₂(g) → 2 Fe₂O₃(s)
```
ΔH°r = 2ΔH°f(Fe₂O₃) - [4ΔH°f(Fe) + 3ΔH°f(O₂)]
     = 2×(-824.25) - [0 + 0]
     = -1648.50 kJ/mol(4 mol Fe)
       ≈ -412.13 kJ/mol Fe(放热)
```

### 3.7 异构化反应

**反应:** n-C₄H₁₀ → i-C₄H₁₀
```
ΔH°r = ΔH°f(i-C₄H₁₀) - ΔH°f(n-C₄H₁₀)
     = (-134.2) - (-126.0)
     = -8.2 kJ/mol

(i-C₄H₁₀ 更稳定,所以异构化放热)
```

### 3.8 燃烧具体计算(火电厂 / 锅炉)

**煤(典型):** CHₓOᵧSᵤ + O₂ → CO₂ + H₂O + SO₂

**丙烷燃烧:**
```
C₃H₈(g) + 5 O₂(g) → 3 CO₂(g) + 4 H₂O(l)
ΔH°r = 3·(-393.52) + 4·(-285.83) - [(-104.7) + 5·(0)]
     = -1180.56 - 1143.32 + 104.7
     = -2219.18 kJ/mol(丙烷)(经典值)
```

## 四、Hess 定律的扩展应用

### 4.1 路径加和法

**复杂反应可以拆分成几步简单反应的加和:**
```
总反应 = 步骤 1 + 步骤 2 + 步骤 3

ΔH(总) = ΔH(步骤 1) + ΔH(步骤 2) + ΔH(步骤 3)
```

**示例:** 葡萄糖氧化(代谢反应)
```
C₆H₁₂O₆ + 6 O₂ → 6 CO₂ + 6 H₂O       ΔH°r ≈ -2800 kJ/mol

可以用 Hess 定律分步:
步骤 1:C₆H₁₂O₆ → 6 C + 6 H₂O(l)         ΔH₁ = ?
步骤 2:6 C + 6 O₂ → 6 CO₂                 ΔH₂ = 6×(-393.52)
步骤 3:6 H₂O(l) → 6 H₂O(l)(无变化)|       ΔH₃ = 0
```

### 4.2 反应路径选择

**比较不同路径的反应热:**
- 路径 A:反应热为负 100 kJ/mol
- 路径 B:反应热为负 50 kJ/mol
- **选择 B(放热少,反应器易控制)**

### 4.3 反应副反应评估

**PFD 评估副反应:**
- 主反应 ΔH°r = -500 kJ/mol
- 副反应 ΔH°r = -100 kJ/mol(放热少)
- **计算产率时考虑副反应程度**

## 六、Hess 定律的工程"反例"

### 6.1 反例 ①:忽视了反应物不是稳定单质

**错:**
```
"通过 C(钻石) + O₂ → CO₂ 计算 ΔH°r,得 -391.62 kJ/mol"
```

**对:**
```
应该用 C(石墨) + O₂ → CO₂,得 -393.52 kJ/mol
```

**原因:** 反应物必须用**稳定单质**,否则不是 ΔH°f。

### 6.2 反例 ②:忽视了物质形态

**错:**
```
"CH₄ + 2 O₂ → CO₂ + 2 H₂O 的 ΔH°r 为某一值"
```

**对:**
```
必须明确 H₂O 是气还是液(差 44 kJ/mol)
```

### 6.3 反例 ③:用错温度的 ΔH°f

**错:**
```
"用 100°C 的 ΔH°f 算 100°C 反应的 ΔH°r"
```

**对:**
```
ΔH°r 都默认 25°C。要算 100°C 用 Kirchhoff 公式校正。
```

### 6.4 反例 ④:混淆 ΔH°r 与 ΔH°c

**ΔH°r 是"任意反应",ΔH°c 是"完全燃烧"。**
**虽然"CH₄ + 2 O₂ → CO₂ + 2 H₂O(l)"的 ΔH°r = ΔH°c(CH₄),但其他反应的 ΔH°r ≠ ΔH°c。**

## 七、Hess 定律与反应热的工程速算

### 7.1 速算模板

```
反应方程式: A + B → C + D (配平)

步骤 1:列出 ΔH°f
   A:  ΔH°f(A) [kJ/mol]
   B:  ΔH°f(B)
   C:  ΔH°f(C)
   D:  ΔH°f(D)

步骤 2:代入 Hess 公式
   ΔH°r = ΔH°f(C) + ΔH°f(D) - ΔH°f(A) - ΔH°f(B)

步骤 3:记入 PFD 反应节点
```

### 7.2 女王当前 scCO₂-PET 反应的 Hess 速算

**反应 1:酯化反应(主反应)**
```
PTA + 2 EG → BHET + 2 H₂O

ΔH°r ≈ -25 kJ/mol(BHET)(实际工艺值)
```

**反应 2:缩聚反应(链增长)**
```
n BHET → PET + n EG

ΔH°r ≈ -12 kJ/mol(链节)
```

**反应 3:DEG 副反应**
```
EG + EG → DEG

ΔH°r ≈ +5 ~ -10 kJ/mol(吸热或微放热)
```
