# 标准焓家族 —— 分类与定义词典

> **本 skill 是工艺专业下面的通用工具子 SKILL**(与 valve-piping-arrangement、
> equations-of-state、pump-selection-design 平级),用于所有化工/石化项目热化学焓查询与分类,
> **不绑定特定项目**。
>
> **核心定位**:所有"标准 X 焓"都是同一个体系的产物——**标准态下某个"过程"的焓变**。
> 本 skill 用**铁律 + 词典速查 + 关系图 + 反例**的形式,让女王任何项目涉及热化学焓时
> **先调本 skill 再下笔**。

## 一、核心铁律(8 条,违反必出错)

### 铁律 1:所有"标准 X 焓"都基于标准态三位规定——任何"标准"离开状态都是耍流氓

**依据**:IUPAC 1982 推荐标准、CODATA 推荐值。

**三位的国际标准:**

| 维度 | 标准 |
|------|------|
| **温度** | 数据表常用 298.15 K = 25°C(没有强制要求,但数据表常以 298.15 K 为基准)|
| **压力** | **1 bar = 100 kPa**(现代标准)|
| **物质状态** | **最稳定同素异形体 + 标准态物理形态** |

### 铁律 2:"标准焓"是口语化集合名词,具体指代看语境

**含义**:"标准焓"在不同工程语境下可指:
- 教科书标题"标准焓表" = ΔH°f 表(标准生成焓)
- 论文中"标准反应焓" = ΔH°r
- 燃烧实验报告"标准燃烧焓" = ΔH°c

严谨问:**使用时要明确"标准什么焓"。**

### 铁律 3:标准生成焓 ΔH°f 是其他标准焓的"地基"

**含义**:热化学事实——
- **任何 ΔH°r、ΔH°c 都能从 ΔH°f 字典表推出**(Hess 定律)
- **任何 ΔG°r 都能从 ΔG°f 推出**(类似法则)
- 工程师只要查一张"ΔH°f 字典表",就能算所有反应热

**反例:**
- ❌ "找不到 CH₄ 燃烧焓的实验值,只能拍脑袋" → 不对,有 ΔH°f 字典就能算
- ✅ **工程上一定先查 ΔH°f 表或 NIST WebBook**

### 铁律 4:ΔG°f 是 Gibbs 生成自由能,不是焓——别再说"标准自由焓"

**含义**:
- G(Gibbs 自由能) ≠ H(焓)
- ΔG°f 状态与 ΔH°f 完全相同(25°C, 1 bar, 最稳定单质),但量不同
- ΔG° = ΔH° - T·ΔS°(Gibbs-Helmholtz 关系)

### 铁律 5:Hess 定律是连接器

**公式:**
```
ΔH°r = Σ(产物 ν_i · ΔH°f_i) - Σ(反应物 ν_i · ΔH°f_i)
```

含义:**任何反应的 ΔH°r 都能从 ΔH°f 字典表算出**;不需要每个反应都实验测量。

### 铁律 6:稳定单质必须用"最稳定同素异形体",不能选错

**含义:**
- 碳:**石墨**(不是金刚石)
- 氧:**O₂ 气**(不是臭氧 O₃)
- 磷:**白磷 P₄**(不是红磷)
- 硫:**斜方硫 S₈**(不是单斜硫)
- 氢:**H₂ 气**(不是单个 H 原子)

### 铁律 7:ΔH°fus、ΔH°vap 等相变焓的"标准温度"不是 25°C

**含义:**
- ΔH°fus @ 正常熔点 T_m(不是 25°C)
- ΔH°vap @ 正常沸点 T_b(不是 25°C)
- ΔH°sub @ 25°C(也可以是 T_sub 的特定温度)

### 铁律 8:NIST WebBook / JANAF / DIPPR 是数据源三巨头

**含义:**
- **第一查 NIST WebBook**(免费 + 全面)
- 化学热化学 → JANAF
- 工业介质物性 → DIPPR
- **任何"标准 X 焓"数值都要查这三家**

## 三、标准态的"三位规定"详解

### 3.1 温度

**历史:IUPAC 标准不强制规定温度,但数据表常用 298.15 K = 25°C 为基准。**

**变温相关:**
- **Kirchhoff 公式**(从 25°C 算到任意 T):
```
ΔH(T) = ΔH(25°C) + ∫[25°C→T] ΔCp dT
```

### 3.2 压力(1 bar vs 1 atm)

| 标准源 | 压力规定 |
|--------|----------|
| **现代 IUPAC(1982 以来)** | **1 bar = 100 kPa = 10⁵ Pa** |
| **旧 IUPAC(1982 之前)** | 1 atm = 101.325 kPa |
| **CODATA 推荐** | 1 bar |

**压力差异约 1.3%(ΔP = 1.325 kPa),工程上一般不区分。**

### 3.3 物质状态(稳定单质 + 物理形态)

**稳定单质(必须用最稳定同素异形体):**

| 元素 | 稳定单质 | 同素异形体(不用) |
|------|----------|--------------------|
| C | **石墨** | 金刚石、富勒烯 |
| O | **O₂ 气** | 臭氧 O₃ |
| S | **S₈ 斜方硫** | 单斜硫 |
| P | **白磷 P₄** | 红磷 |
| H | **H₂ 气** | 单原子 H |
| N | **N₂ 气** | — |
| Cl | **Cl₂ 气** | — |
| Br | **Br₂ 液** | — |
| I | **I₂ 固** | — |

**物理形态(必须明确 g/l/s):**

**同一个物质,不同形态的 ΔH°f 不同:**
- ΔH°f(H₂O, l) = **-285.83** kJ/mol
- ΔH°f(H₂O, g) = **-241.82** kJ/mol
- 差值 = +ΔH°vap(H₂O, 25°C) = **+44.01** kJ/mol

## 四、7 大主要标准焓详解

### 4.1 标准生成焓 ΔH°f ★

**定义:**
> 在 25°C, 1 bar 标准态下,**从最稳定单质经过反应生成 1 mol 该化合物**时的焓变。

**符号:** ΔH°f(f = formation)

**反应形式:**
```
Σ(稳定单质) → 1 mol 化合物      @ 25°C, 1 bar
```

**关键要素:**
- 反应物:**最稳定单质**(石墨、O₂、H₂、Cl₂ 等)
- 产物:**1 mol 指定化合物**(明确物理形态)
- 标准态:**1 bar**
- 默认温度:**25°C**

**核心数据(常见物质):**

| 物质 | ΔH°f (kJ/mol) |
|------|---------------|
| CO₂(g) | **-393.52** |
| H₂O(l) | **-285.83** |
| H₂O(g) | -241.82 |
| CO(g) | -110.53 |
| CH₄(g) | -74.85 |
| C₂H₄(g) | +52.47 |
| C₂H₆(g) | -84.68 |
| C₃H₈(g) | -104.7 |
| n-C₄H₁₀(g) | -126.0 |
| C₆H₆(l) | +49.04 |
| CH₃OH(l) | -239.10 |
| C₂H₅OH(l) | -277.6 |
| NH₃(g) | -45.94 |
| H₂S(g) | -20.6 |
| HCl(g) | -92.31 |
| N₂O(g) | +81.6 |
| NO₂(g) | +33.2 |
| 蔗糖(s) | -2221.2 |

**数据源:** NIST WebBook + JANAF + DIPPR

### 4.2 标准反应焓 ΔH°r ★

**定义:**
> 在 25°C, 1 bar 标准态下,**任意指定反应的反应物 → 产物**的焓变。

**Hess 定律:** 任何反应的 ΔH°r 都能从 ΔH°f 字典算出:
```
ΔH°r = Σ(产物 ν_i · ΔH°f_i) - Σ(反应物 ν_i · ΔH°f_i)
```

**示例(甲烷燃烧):**
```
CH₄(g) + 2 O₂(g) → CO₂(g) + 2 H₂O(l)
ΔH°r = ΔH°f(CO₂) + 2ΔH°f(H₂O, l) - [ΔH°f(CH₄) + 2·0]
     = (-393.52) + 2·(-285.83) - (-74.85)
     = -890.33 kJ/mol
```

### 4.3 标准燃烧焓 ΔH°c ★

**定义:**
> 25°C, 1 bar 下,**1 mol 化合物 + O₂ 完全燃烧**的焓变。

**产物状态(国际约定):**
- C → **CO₂(g)**
- H → **H₂O(l)**(注意是液态!不是气态)
- S → SO₂(g)
- N → N₂(g)(约定,实际可能形成 NOₓ)
- 卤素 → HX(aq)或气态(由数据表约定)

**典型数据:**

| 物质 | ΔH°c (kJ/mol) |
|------|---------------|
| H₂(g) | -285.83 |
| C(石墨) | -393.52(= -ΔH°f(CO₂)) |
| CO(g) | -282.99 |
| CH₄(g) | **-890.33** |
| C₂H₂(g) | -1301.1 |
| C₂H₆(g) | -1561.4 |
| C₃H₈(g) | -2219.2 |
| n-C₄H₁₀(g) | -2876.1 |
| C₈H₁₈(l) | -5470.7 |
| C₆H₆(l) | -3267.6 |
| CH₃OH(l) | -726.6 |
| C₂H₅OH(l) | -1366.7 |

### 4.4 标准生成 Gibbs 自由能 ΔG°f ★

**定义:**
> 在 25°C, 1 bar 标准态下,**从稳定单质生成 1 mol 该化合物**的 Gibbs 自由能变。

**与 ΔH°f 的关系(Gibbs-Helmholtz 公式):**
```
ΔG°f = ΔH°f - T·ΔS°f       (T = 298.15 K)
ΔS°f:标准生成熵变(也称标准生成过程的熵变)
```

**典型数据:**

| 物质 | ΔH°f (kJ/mol) | ΔG°f (kJ/mol) |
|------|----------------|------------------|
| CO₂(g) | -393.52 | **-394.36** |
| H₂O(l) | -285.83 | -237.13 |
| H₂O(g) | -241.82 | -228.57 |
| CO(g) | -110.53 | -137.17 |
| CH₄(g) | -74.85 | **-50.5** |
| C₂H₄(g) | +52.47 | +68.15 |
| CH₃OH(l) | -239.10 | -166.6 |
| NH₃(g) | -45.94 | -16.45 |

**用途:**
- 反应方向判断:ΔG°r > 0 反应不自发(标准态)
- 反应平衡常数:ΔG°r = -RT ln K
- 电化学:ΔG°r = -nFE(电池电势)

### 4.5 标准熔化焓 ΔH°fus ★

**定义:**
> 在**正常熔点 T_m** 下,**1 mol 物质**从固(s)→液(l)的焓变。

**状态:**
- 反应物:1 mol 固体 @ T_m, 1 bar
- 产物:1 mol 液体 @ T_m, 1 bar

**典型数据:**

| 物质 | T_m (°C) | ΔH°fus (kJ/mol) |
|------|-----------|--------------------|
| H₂O | 0 | +6.01 |
| 苯 | 5.5 | +9.87 |
| NaCl | 801 | +30.2 |
| Fe | 1538 | +13.8 |
| 萘 | 80.3 | +18.8 |
| 蔗糖 | 186 | +36.1 |
| 苯甲酸 | 122 | +18.1 |

### 4.6 标准汽化焓 ΔH°vap ★

**定义:**
> 在**正常沸点 T_b** 下,**1 mol 物质**从液(l)→气(g)的焓变。

**状态:**
- 反应物:1 mol 液体 @ T_b, 1 bar
- 产物:1 mol 气体 @ T_b, 1 bar

**典型数据:**

| 物质 | T_b (°C) | ΔH°vap (kJ/mol) |
|------|-----------|--------------------|
| H₂O | 100 | +40.65 |
| 苯 | 80.1 | +30.8 |
| 甲醇 | 64.7 | +35.3 |
| 乙醇 | 78.4 | +38.6 |
| 丙酮 | 56 | +29.1 |
| 己烷 | 69 | +28.9 |
| 乙酸 | 118 | +23.7 |
| NH₃ | -33 | +23.3 |
| CO₂ | -78.5(升华) | (见 ΔH°sub) |

**注意细节:**
- ΔH°vap 数值随温度升高而**降低**
- 临界点处 ΔH°vap **= 0**(气液不可分)

### 4.7 标准升华焓 ΔH°sub ★

**定义:**
> 25°C, 1 bar 下,**1 mol 物质**从固(s)→气(g)的焓变。

**状态:**
- 反应物:1 mol 固体 @ 25°C, 1 bar
- 产物:1 mol 气体 @ 25°C, 1 bar

**重要物质:**

| 物质 | ΔH°sub (kJ/mol) | 状态 |
|------|------------------|------|
| **CO₂** | **+25.2** | 干冰制造 |
| I₂ | +62.4 | 碘升华提纯 |
| 萘 | +72.4 | 工业提纯 |
| H₂O(冰) | +50.9 | 冰干燥 |

**CO₂ 的 ΔH°sub = 25.2 kJ/mol**(重要:CO₂ 常压下不经过液相,只能升华)

## 五、8 种次要标准焓速查

### 5.1 标准溶解焓 ΔH°sol

**定义:** 25°C, 1 bar 下,**1 mol 纯态物质 → 溶液**(典型浓度 1 mol/kg 溶剂)。

**典型数据:**
- ΔH°sol(NaCl, ∞ dilution)= +3.88 kJ/mol
- ΔH°sol(NH₄NO₃)= +25.7 kJ/mol
- ΔH°sol(NaOH)= -44.5 kJ/mol

### 5.2 标准原子化焓 ΔH°at

**定义:** 25°C, 1 bar 下,**1 mol 化合物 → 各原子(气态)**。

**用途:** 配合键离解焓求键能,计算化学反应热

### 5.3 标准键离解焓 ΔH°BD

**定义:** 切断 A-B 键所需焓变:
```
A-B(g) → A(g) + B(g)   @ 25°C
```

**典型数据:**
- ΔH°BD(H-H)= +436 kJ/mol
- ΔH°BD(C-H, CH₄ 第一)= +439 kJ/mol
- ΔH°BD(C-C)= +346 kJ/mol
- ΔH°BD(C=O, CO₂)= +799 kJ/mol

### 5.4 标准离子化焓 ΔH°ion

**定义:** 0 K 基态原子 → 1+ 气态阳离子 + 电子
```
A(g) → A⁺(g) + e⁻
```

**典型数据(第一电离能):**
- ΔH°ion(Na)= +496 kJ/mol
- ΔH°ion(H)= +1312 kJ/mol
- ΔH°ion(O₂)= +1175 kJ/mol

### 5.5 标准电子亲和焓 ΔH°ea

**定义:** 0 K 基态原子 + 电子 → 1- 气态阴离子
```
A(g) + e⁻ → A⁻(g)
```

### 5.6 标准水合焓 ΔH°hyd

**定义:** 1 mol 气态离子 + nH₂O → 1 mol 水合离子

**典型数据:**
- ΔH°hyd(Na⁺) = -406 kJ/mol
- ΔH°hyd(Cl⁻) = -363 kJ/mol
- ΔH°hyd(H⁺) = -1090 kJ/mol(关键电化学值)

### 5.7 标准中和焓 ΔH°neut

**定义:** 1 mol H⁺ + 1 mol OH⁻ → 1 mol H₂O
- 强酸 + 强碱 ≈ -55.84 kJ/mol(与酸碱基本无关)

### 5.8 标准吸附焓 ΔH°ads

**定义:** 1 mol 气体 + 固体表面 → 1 mol 吸附态
- 用于催化、过滤、干燥

## 六、Hess 定律:连接所有标准焓的桥梁

### 6.1 核心公式

**任意反应的标准焓变,等于产物标准生成焓总 - 反应物标准生成焓总:**
```
ΔH°r = Σ(产物 ν_i · ΔH°f_i) - Σ(反应物 ν_i · ΔH°f_i)
```

### 6.2 算法步骤

```
1. 写出反应化学方程式(配平)
2. 列出反应物 + 产物的 ΔH°f
3. 代入公式
4. 得到 ΔH°r
```

### 6.3 多种算例

| 反应 | ΔH°r 计算 | 工程应用 |
|------|-----------|----------|
| CH₄ + 2O₂ → CO₂ + 2H₂O(l) | -890.33 kJ/mol | 燃料热值 |
| C₂H₄ + H₂O → C₂H₅OH | -44.12 kJ/mol | 乙醇合成 |
| N₂ + 3H₂ → 2NH₃ | -91.88 kJ/mol | 合成氨 |
| CaCO₃ → CaO + CO₂ | +178.3 kJ/mol | 石灰窑 |
| PTA + 2 EG → BHET + 2 H₂O | ~ -25 kJ/mol | PET 反应 |

## 七、各种标准焓的关系图

```
              [稳定单质, 25°C, 1 bar]
                       │
                       │ ΔH°f (地基)
                       ↓
              [化合物 1 mol, 25°C, 1 bar]
                       │
        ┌──────────────┼─────────────────┐
        │              │                 │
   ΔH°c            ΔH°fus             ΔH°vap
        ↓              ↓                 ↓
[完全燃烧产物]   [液相, T_m, 1 bar] [气相, T_b, 1 bar]
        │              │                 │
        │              ↓                 │
        │         ΔH°sub = ΔH°fus + ΔH°vap
        │              │
        ↓              ↓
   ΔH°sol         ΔH°sub
        ↓              ↓
  [溶液, 25°C]   [气相, 25°C](干冰)


   任一路径的 Σ ΔH = 总焓变(Hess 定律)
   ΔG°f = ΔH°f - T · ΔS°f(Gibbs-Helmholtz)
```
