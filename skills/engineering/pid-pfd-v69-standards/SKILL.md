## 18 条铁律速查 (Quick Reference)

### A. 几何布局 (8 条)

| # | 铁律 | 关键点 |
|---|---|---|
| ① | **主管不延伸** | 主管画到最后一个需要该公用工程的设备即止,不留悬空/不延伸 |
| ② | **阀门在流股中点** | TCV/PCV/LCV/FCV 全部位于流股几何中点 |
| ③ | **信号线只走横+竖 90° 折角** | 无斜线、无曲线 |
| ④ | **信号线止于圈外** | 终点 y = valve_y - 21 (阀门上方小圆圈顶部),不穿入阀门中心 |
| ⑤ | **信号线竖线错开** | V-201 x=228/236/244, R-301 x=842/850/858/866/874, V-401 x=1552/1556 (8-10px 间距) |
| ⑥ | **伴热短平行线** | 横向偏移 6px,严禁大填充矩形覆盖泵 |
| ⑦ | **伴热区分** | 蒸汽=红色虚线,电伴热=橙色实线 |
| ⑧ | **设备独立标号** | P-XXX 柱塞泵 / CM-XXX 浇注机 / M-XXX 模具(不重号) |

### B. 仪表控制 (5 条)

| # | 铁律 | 关键点 |
|---|---|---|
| ⑨ | **真空设备→泵→排气处理** | 设备→真空泵→T-601+X-601,严禁绕过真空泵 |
| ⑩ | **S-XXX 标签贴流股线 ±20px** | 矩形框居中覆盖流股(±10-20px) |
| ⑪ | **装填系数规范** | 储罐 0.85 / 吸热 0.45 / 放热 0.50 / 真空脱气 0.50 |
| ⑫ | **V-102 必 304SS+玻璃衬里** | 防 Fe³⁺ 催化 TDI 二聚(规范强制) |
| ⑬ | **XV 紧急切断阀在 N₂ 主管流股线中点** | 如 XV-301 在 (1280, 230),介于 N₂ 主管 y=60-350 中点 |

### C. 仪表连线两类型 (3 条) ⭐ v6.6/v6.9 新规

| # | 铁律 | 关键点 |
|---|---|---|
| ⑭ | **仪表一侧实线 tap(到设备本体)** | process tap 黑色实线,只画在测点在设备本体时 |
| ⑮ | **仪表另一侧虚线控制(到控制元件)** | 控制信号红色虚线 |
| ⑯ | **不同控制系统虚线断开另起** | 禁止公共竖线汇合(v6.5 作废);TIRC 双信号从 TOP/BOTTOM 分别引出断开 |

### D. 过程 tap 铁律 (2 条) ⭐ v6.9 新规

| # | 铁律 | 关键点 |
|---|---|---|
| ⑰ | **过程 tap 只在测点在设备本体时画** | TIRC/LRC/AI 等测内部参数(温度/液位/分析)→ 画 tap |
| ⑱ | **管线测点(PIRC 真空/压力, FRC 流量)不画 tap 到设备本体** | 测点在管线上→ 只留虚线控制,不要画 tap 到设备 |

### 工艺决策(06-23 女王)

- V-401 / O-401 真空度统一 **10 mbar**(原 V-401 5 mbar, O-401 旋片+罗茨 → 现旋片即可无需罗茨串联)
- V-401 HO 立管 (1660, 735-982) 中点 (1660, 858) = TCV-401H 位置
- 配方: PTMG:TDI:DETDA = 100:20.4:11.0 (NCO%=4.7%)
- 装填: 储罐 0.85 / R-301=0.50 / V-201=0.45 / V-401=0.50

## 使用方法 (How to use this skill)

### 步骤 1: 加载参考文件

出图前必读:
- `references/v69-pid-template.html` — v6.9 完整 P&ID 模板(几何布局/接管标注/仪表/阀门全标注)
- `references/v69-equipment-list.html` — v6.9 设备清单(13 阀门完整列表)
- `references/v69-18-rules.md` — 18 条铁律详细说明
- `references/error-history.md` — v6.5→v6.9 历史错误+避坑指南
- `references/equipment-tables-checklist.md` — 设备清单检查清单

### 步骤 2: 出图前自检

按 `references/checklist.md` 逐项检查(18 条铁律 + 几何/仪表/工艺专项)。

### 步骤 3: 出图后验证

将新 P&ID 与 v6.9 模板对比,确认:
- 主管"不延伸"原则
- 阀门在流股中点
- 信号线竖线错开(8-10px 间距)
- 仪表实线 tap 正确(测点在设备本体)
- XV 紧急切断阀在 N₂ 主管中点
- 13 阀门全标注(FCV/LCV/PCV/TCV/XV/PSV)

### 步骤 4: HTTP 挂服务器

新 P&ID 生成后,挂 HTTP 服务器供女王点开审查:
```bash
cd references/ && python3 -m http.server 28082 --bind 0.0.0.0 &
# 测试: curl -I http://127.0.0.1:28082/[新文件名].html
```
