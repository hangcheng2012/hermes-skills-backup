# N₂ 减压阀失效与 PSV 必设 — 工艺安全专项参考

> 女王 06-25 立规铁律。本文档详细说明 N₂ 减压阀 5 大失效模式、PSV 紧急泄放阀必要性、真空泄放阀选型。

---

## 1. N₂ 减压阀 5 大失效模式

### 1.1 超大压差(根本原因)
- 标准自力式减压阀**最大减压比 ≤ 10:1**
- V-101/V-103 实际:N₂ 主管 0.6 MPa → 封 0.5-1 kPa = **600-1200 倍**
- 远超能力,必然失效

### 1.2 气穴 (Cavitation)
- 焦耳-汤姆逊效应:N₂ 减压急冷(可至 -40°C)
- 阀芯处局部液化 → 气泡溃灭 → 微射流损坏阀芯
- 表现:剧烈振动 + 高频噪音 + 麻点

### 1.3 膜片破裂
- 膜片承受全部上游压力(0.6 MPa)
- DN15 膜片 Ø50 mm 推力 = **1,176 N (120 kgf)**
- 橡胶/金属膜片**3-5 年内必疲劳破裂**
- 失效瞬间:阀门全开,0.6 MPa 直冲罐

### 1.4 弹簧失效
- 疲劳:设定压力漂移
- 断裂:阀门全开/全关
- 腐蚀:N₂ 含微量水/油雾长期累积
- 需**每年校验**

### 1.5 反馈管路堵塞
- 减压阀靠下游反馈压力调节
- 反馈管堵 → 减压阀感知不到下游压力 → 持续开大
- 即使减压阀完好,只要反馈堵,阀就失控

## 2. PSV 紧急泄放阀必设(规范强制)

### 2.1 规范依据
- **GB 150** + **SH/T 3007-2014**:压力容器必须设 PSV
- 即使 N₂ 减压阀"完好",仍需 PSV(防火/失控反应)

### 2.2 PSV 设定原则
| 参数 | 值 |
|---|---|
| 设计压力 | 10 kPa(V-101 升级后) |
| PSV 设定压力 | **5-10 kPa**(2.5-5 倍设计压力) |
| 类型 | **弹簧式安全阀** (GB/T 12241) |
| 通径 | DN25(200L 罐足够) |
| 排放能力 | 至少 50% N₂ 主管流量 |
| 出口 | 接至火炬或安全地点 |

---

## 3. 正压呼吸阀 vs 真空泄放阀

### 3.1 正压呼吸阀可省
- N₂ 封压 0.5-1 kPa
- 正压呼吸阀设定值 +2 kPa
- **N₂ 封压 < 呼吸阀设定,呼吸阀不启动**
- N₂ 系统的减压阀已能泄压

### 3.2 真空泄放阀 PVRV 建议设(防罐塌陷)
- N₂ 系统失效场景:N₂ 钢瓶空 / PSA 故障 / 减压阀卡死
- 罐内物料被继续抽出 → 压力降至大气压以下
- 200L 304SS 罐设计为正压 N₂ 封,**不耐真空**
- 真空下罐体会**塌陷**(100 kPa 大气压压扁)
- 解决方案:**PVRV 真空泄放阀**(吸气阀),设定 -0.2 kPa

## 4. PTMG 储罐设计标准

### 4.1 罐型选择
- **立式椭圆形封头 (2:1)** 罐 = 标准做法
- 卧式也可(占地较大)
- 200L 小罐用立式更经济

### 4.2 罐体规格
| 项目 | 规格 | 依据 |
|---|---|---|
| 罐型 | 立式 2:1 椭圆封头 | SH/T 3007 |
| 容积 | 200L(实际装填 64%) | 周用量 127kg |
| 材质 | 304SS | PTMG 无腐蚀 |
| 上下封头 | 2:1 标准椭圆 EHA | GB/T 25198 |
| 罐底 | 平底+排净口 DN25 | 标准 |

### 4.3 罐顶接管布置
1. PSV-101 紧急泄放阀 DN25(5-10 kPa)
2. N₂ 封接管 DN15(从两级减压阀来)
3. 进料口 DN25
4. 排空口 DN25
5. 真空泄放阀 PVRV-101(-0.2 kPa)
6. 液位计接口 DN20
7. 温度计接口 DN20
8. 压力表接口 DN15

## 5. V-101 整改方案(基于 v6.9 P&ID)

### 5.1 N₂ 减压: 单级 → 两级
```
N₂ 主管 0.6 MPa → PCV-101A(50 kPa) → PCV-101B(0.5-1 kPa) → V-101
```

### 5.2 新增阀门清单(V-101 罐顶)
| 位号 | 阀门类型 | 设定值 |
|---|---|---|
| PCV-101A | 第一级减压阀 | 50 kPa |
| PCV-101B | 第二级减压阀 | 0.5-1 kPa |
| PSV-101 | 紧急泄放阀(弹簧式) | 5-10 kPa |
| PVRV-101 | 真空泄放阀 | -0.2 kPa |

### 5.3 设计压力升级
- 原:2 kPa(SH/T 3007 偏低)
- **新:10 kPa**(PSV 设定 5-10 kPa 更合理)

### 5.4 投资估算
- 减压阀 ×2:¥4,000-6,000
- PSV-101:¥3,000-5,000
- PVRV-101:¥1,500-2,500
- **合计:¥8,500-13,500**
- 避免风险(罐体爆炸 + PTMG 泄漏):>¥500,000 + 人员伤亡

## 6. 同类问题 — V-102/V-103 整改

V-102 (TDI 罐) 和 V-103 (DETDA 罐) 也是 N₂ 封罐,同样存在减压阀失效风险。

### V-102 (TDI 储罐)
- 设计压力:0.1 MPa(N₂ 压料,已较高)
- N₂ 减压:0.6 MPa → 0.1 MPa = 6 倍(单级可承受)
- **已有 Z-102 + XV-102 切断阀**
- 仍需加:**PSV-102**(防火/超压,设定 25-50 kPa)
- 可省 PVRV(0.1 MPa 正压不会塌陷)

### V-103 (DETDA 储罐)
- 设计压力:2 kPa(SH/T 3007 偏低,**同 V-101 问题**)
- N₂ 减压:0.6 MPa → 0.5-1 kPa = 600 倍
- **整改同 V-101**:加两级减压 + PSV-103 + PVRV-103
