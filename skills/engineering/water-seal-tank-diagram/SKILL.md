# 水封罐 U 形溢流管示意图

> **本图为标准合规示意图**，适用于石油化工可燃性气体排放系统（火炬系统前端水封）。
> 编制依据：SH 3009-2013《石油化工可燃性气体排放系统设计规范》§8.2.7 + §8.2.8 + HG/T 20570.17-95《液封的设置》§1.0.1

## ⚠ 关键几何铁律（v5.0 起，2026-06-06 女王当面纠正）

| 铁律 | 错误做法 | 正确做法 |
|------|----------|----------|
| **U 形管形状** | 倒U (∩)，U-bend 在上 | **正U (∪)**，U-bend 在下 |
| **U-bend 位置** | 罐顶上方、罐外、液面**上** ❌ | 罐内、**水面下** ✓ |
| **U-bend 顶 vs 液面** | U-bend 顶 > 液面 ❌ | U-bend 顶 < 液面（差 1.75×P_max）✓ |
| **破真空口** | 与 U 形管混淆 ❌ | 单独接管 DN25 ≥300mm，**严禁切断阀** |

> **反复犯过的错**：把水封罐的 U 形管画成"倒U 字"挂在罐顶——这是错的！水封罐的 U 形管是**正U**，U-bend 永远在**罐内水面下**。**倒U 字是破真空口**（单独接管，DN25）。

## SH 3009-2013 §8.2.7 四条强制要求

| 序号 | 条款 | 工程意义 |
|------|------|---------|
| 1 | U 形结构 + 不得设切断阀门 | 水封失效时气体可立即泄放，防止憋压/回火 |
| 2 | h_水封 ≥ 1.75 × P_max（m 水柱 / MPaG） | 75% 安全系数，防回火 |
| 3 | 溢流管直径 ≥ DN50 | 防堵塞，常用 DN50/DN80/DN100 |
| 4 | **高点处管道下部内表面 = 水封液面** | "同一水平高度"——U 形管管口下沿内壁与水封液面齐平 |

## SH 3009-2013 §8.2.8 破真空接管

| 参数 | 标准要求 |
|------|---------|
| 位置 | U 形管**高点**上（N4 顶部） |
| 规格 | DN25 |
| 高度 | **≥ 300mm** |
| 切断阀 | **严禁**（装了就失效） |
| 末端配件 | 防雨帽 + 阻火器（可燃介质） |

## HG/T 20570.17-95 §1.0.1（铁律）

> "通过**液封管插入液封罐液面下**的深度来维持设备系统内一定压力"

⇒ U 形管（液封管）必须**插入液面下** ⇒ U-bend 在液面下 ⇒ **正U管 (∪)**

## v5.0 几何（唯一合规）

```
y=90    破真空接管顶端（DN25, ≥300mm, 附阻火器+防雨帽）
y=140   N4 U管腿顶部
y=230   罐顶（U管两腿穿过此处）
y=540   罐内最高液面（U管管口下沿 = 液面，§8.2.7）
y=740   U-bend 顶部（**液面下 200px** = 1.75×P_max 水封高度）← 关键
y=820   罐底 / U-bend 底（弧形连接 N3/N4）
```

**水封高度 = 1.75 × P_max**（m 水柱 / MPaG），即 U-bend 顶部到罐内最高液面的垂直距离。

## 水封高度计算示例

- **介质**：LPG 储罐排放气，最大操作压力 P_max = 0.5 MPaG
- **h_水封** = 1.75 × 0.5 = **0.875 m**（m 水柱）
- 等价于 0.875 / 102 × 1000 = 8.58 mbar 表压能承受

### 关键订正（v4.0 → v5.0）

- **触发**：女王当面纠正"U-bend 水平段顶部应低于罐内最高液位，U 形管应该是正U 管"
- **根因**：v2.0/v4.0 都把水封罐的 U 形管画成倒U，挂在罐顶上方——是错的
- **铁证**：
  1. SH 3009-2013 §8.2.7 "高点处管道下部内表面与水封液面处于同一水平高度"
  2. HG/T 20570.17-95 §1.0.1 "液封管插入液封罐液面下"
  3. 化工工艺设计手册 "冷凝液经 U 形管排到中间槽"
  4. 专利 CN201439953U "U 型管"（主水封）vs "反 U 型"（破真空）
- **新几何**：U-bend 在罐内水面下（y=740 < 液面 y=540），U 形管两腿从罐顶向下延伸到 U-bend
- **破真空口**：独立 DN25 接管 ≥300mm，在 N4 顶部，附阻火器，严禁切断阀

### ⚠ 反复犯同一个错的根因（自我检讨）

- 误把 "U 字" 想象成"倒U 字"（字面理解，未查证图示）
- 没调 HG/T 20570.17-95 原文和化工设计手册关于 U 形管的标准图示
- 凭"逻辑链"反推，没查权威源头

**铁律**：水封罐的 U 形管 = **正U (∪)**，U-bend 永远在液面下。**倒U 是破真空接管**（独立小接管，DN25），不是主水封结构。
