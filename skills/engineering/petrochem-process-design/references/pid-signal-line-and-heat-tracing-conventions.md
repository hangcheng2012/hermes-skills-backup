## 一、信号线路由铁律

### 1.1 绝对铁律:无斜线

**所有信号线必须由 90° 横线和 90° 竖线组成,不允许任何斜线**。

女王 06-22 当面纠正:斜线信号线是工艺设计错误,直接关联到控制工程师读图混乱。
v6.0 案例:TIRC-401 → TCV-401H 用 `(1580,500)→(240,900)` 斜线,被识别为严重错误(且终点位置也错)。

### 1.2 起点:从仪表圆圈**边界**出发,不是中心

R-301 / V-401 / V-201 仪表圆圈 r=20 (R-301) 或 r=18 (V-201/V-401),信号线必须从边界(LEFT 边)引出:

| 仪表位置 | LEFT 边坐标 (r=20) | LEFT 边坐标 (r=18) |
|---|---|---|
| 圆心 (cx, cy) | (cx-20, cy) | (cx-18, cy) |

**反例(常见错误)**:从圆心 (cx, cy) 直接画线 → 信号线**贯穿整个圆圈**,视觉混乱。

### 1.3 终点:止于阀门**圆顶**(不穿阀门体)

阀门符号结构(SVG):
```
<g transform="translate(x,y)">
  <path d="M -10 -6 L 0 0 L -10 6 Z M 0 0 L 10 -6 L 10 6 Z"/>  ← 阀体 (y±6)
  <circle cx="0" cy="-16" r="5"/>                                ← 圆顶指示器 (y=-16, r=5)
  <line x1="-8" y1="-20" x2="8" y2="-20"/>                      ← 顶部横线 (y=-20)
</g>
```

**信号线终点 = 阀门圆顶顶部 = `(valve_x, valve_y - 21)`**

| 阀门示例 | 中心 (x, y) | 信号线终点 |
|---|---|---|
| TCV-301H (220, 908) | (220, 908) | (220, 887) |
| TCV-301C (1340, 878) | (1340, 878) | (1340, 857) |
| LCV-301 (1490, 855) | (1490, 855) | (1490, 849) (顶部横线) |
| PCV-301 (1280, 350) | (1280, 350) | (1280, 329) |
| TCV-201H (360, 858) | (360, 858) | (360, 837) |
| PCV-201 (380, 360) | (380, 360) | (380, 339) |
| TCV-401H (1660, 858) | (1660, 858) | (1660, 837) |
| PCV-401 (1780, 360) | (1780, 360) | (1780, 339) |

**反例(常见错误)**:信号线终点 = 阀门中心 (valve_x, valve_y) → 止于阀体内部,视觉穿圈。

### 1.4 仪表连线**两类型**(v6.7 女王 06-23 立规)

仪表有 2 种类型,**连线方式完全不同**:

| 类型 | 示例 | 实线 process tap | 虚线控制信号 |
|---|---|---|---|
| **类型 1:无控制信号** | AI-301 在线分析、QT-601 气体检测 | ✅ 一侧实线到设备 | ❌ **不画虚线**(无控制功能) |
| **类型 2:有控制信号** | TIRC/FRC/LRC/PIRC | ✅ 一侧实线到设备 | ✅ 另一侧虚线到功能阀门 |

**反例(常见错误)**:给 AI-301 画虚线控制信号 → AI 是**纯测量仪表**,无控制功能。

### 1.5 信号线按**控制系统**分离(v6.6 女王纠正, **拒绝公共竖线汇合**)

**❌ 旧 v6.5 公共竖线模式**(已废弃):
- 多个仪表信号线汇合到 1 条公共竖线(如 V-201 x=190 / R-301 x=830 / V-401 x=1530)
- **视觉上错误地"连接"了不同控制系统的虚线**
- 串级控制混乱(TIRC 控 HO 和 CW 用同一条公共线)

**✅ v6.6+ 正确模式**:**每个控制回路独立虚线**

```
TIRC-301 ──→ 实线 tap ──→ R-301 (process tap)
            └──→ 独立虚线 ──→ TCV-301H (HO 控制)
            └──→ 独立虚线 ──→ TCV-301C (CW 控制)  [与上条断开]

FRC-301  ──→ 实线 tap ──→ R-301 进料管
            └──→ 独立虚线 ──→ FCV-301 (TDI 流量控制)

LRC-301  ──→ 实线 tap ──→ R-301
            └──→ 独立虚线 ──→ LCV-301 (液位控制)

PIRC-301 ──→ 实线 tap ──→ R-301 顶部
            └──→ 独立虚线 ──→ PCV-301 (N₂ 补压控制)  [起点 y 与上条不同]
```

**关键铁律**:
- 不同控制系统的虚线**必须断开、另起虚线**(不共用路径)
- 串级控制(TIRC 控 2 个 TCV):TIRC 信号线从仪表 **TOP 和 BOTTOM** 分别引出
  - TOP (900, 460) → TCV-301H (220, 887) HO 控制
  - BOTTOM (900, 500) → TCV-301C (1340, 857) CW 控制
- 实线 process tap: `stroke="#000" stroke-width="1.5"`(黑色实线)
- 虚线控制信号: `stroke="#FF6F00" stroke-dasharray="4,3"`(橙色虚线)

### 1.6 信号线竖线**错开 8px**(v6.7 女王纠正)

**问题**:多个仪表的虚线竖向段若共享同一 x 坐标,会在 y 范围内**视觉重叠**

**方案**:每个仪表的虚线竖向段**分配独立 x 坐标**,8-10px 间距

| 仪表群 | 仪表 | 竖线 x | 与仪表 LEFT 边距离 |
|---|---|---|---|
| **V-201** (LEFT 边 x=242) | TIRC-201 | **228** | -14px LEFT |
| | LRC-201 | **236** | -6px LEFT |
| | PIRC-201 | **244** | +2px RIGHT |
| **R-301** (LEFT 边 x=880) | PIRC-301 | **842** | -38px LEFT |
| | TIRC-301H (TOP) | **850** | -30px LEFT (从中心 -50px) |
| | TIRC-301C (BOTTOM) | **858** | -22px LEFT (从中心 -42px) |
| | FRC-301 | **866** | -14px LEFT |
| | LRC-301 | **874** | -6px LEFT |
| **V-401** (LEFT 边 x=1562) | TIRC-401 | **1552** | -10px LEFT |
| | PIRC-401 | **1552** / **1556** (v6.8 优化) | -10px / -6px LEFT |

**实现方法**:从仪表 LEFT 边引**短水平线**(10-30px)到独立竖线 x,然后竖向段独立

**反例(常见错误)**:所有仪表虚线竖向段都用 x=242(V-201)或 x=880(R-301)或 x=1562(V-401) → 在 y 重叠区域视觉混乱

### 1.7 串级控制(TIRC 控 2 个 TCV)

**场景**:一个 TIRC 串级控制 2 个 TCV(如反应器温度同时控 HO 和 CW)

**正确处理**(v6.6+):TIRC 信号线从仪表 **TOP 和 BOTTOM** 分别引出(不在同一位置引 2 条):

```
TIRC-301 中心 (900, 480)
    ├── TOP (900, 460)    → TCV-301H HO 控制 (220, 887)  [竖线 x=850]
    └── BOTTOM (900, 500) → TCV-301C CW 控制 (1340, 857) [竖线 x=858]
                              [两条线在 TOP/BOTTOM 处断开,完全分离]
```

**反例**:从 TIRC-301 引 2 条横线到同一公共竖线(视觉重复 + 控制系统混乱)

### 1.8 完整信号线渲染示例

参考 `polyurethane-TDI-10tpa-pid-v6.8.html`:
- V-201: 3 实线 tap + 3 独立虚线(竖线 x=228/236/244 错开)
- R-301: 5 实线 tap + 5 独立虚线(竖线 x=842/850/858/866/874 错开,TIRC 双信号 TOP/BOTTOM 断开)
- V-401: 2 实线 tap + 2 独立虚线(竖线 x=1552/1556 错开 — v6.8 优化)

## 二、伴热 + 保温 可视化规范

### 2.1 核心铁律:**短平行线 + 标签,严禁大矩形**

**错误做法**(v6.2 踩坑):用 `<rect>` 大矩形覆盖伴热管段,导致覆盖泵/阀门/其他设备。

**正确做法**(v6.3 起的标准):

每条伴热管段 = **3 段短平行线**(竖管 + 横管 + 竖管) + 1 个文字标签。

### 2.2 平行线偏移标准

| 主管方向 | 平行线偏移 | 颜色 | stroke-dasharray | 用途 |
|---|---|---|---|---|
| 竖管 (x=主) | x = 主+6 (右移 6px) | `#C62828` (红) | `"3,2"` (虚线) | **蒸汽伴热** |
| 横管 (y=主) | y = 主-6 (上移 6px) | `#C62828` (红) | `"3,2"` (虚线) | **蒸汽伴热** |
| 竖管 (x=主) | x = 主+6 (右移 6px) | `#FF6F00` (橙) | `""` (实线) | **电伴热带** |
| 横管 (y=主) | y = 主-6 (上移 6px) | `#FF6F00` (橙) | `""` (实线) | **电伴热带** |

**关键**:**横管伴热 y 必须上移 6px**(不与主管同 y),否则与主管线视觉重叠。

### 2.3 SVG 模板(蒸汽伴热 + 保温)

复制后改坐标(主管段端点 (x1, y1)→(x2, y2)):

```svg
<!-- ★ 蒸汽伴热 + 保温 (短平行线,横向上移 6px,竖向右移 6px) -->
<!-- 竖管段 -->
<line x1="x1+6" y1="y1" x2="x1+6" y2="y2"
      stroke="#C62828" stroke-width="1.2" stroke-dasharray="3,2"/>
<!-- 横管段 (上移 6px) -->
<line x1="x1+6" y1="y_mid-6" x2="x2+6" y2="y_mid-6"
      stroke="#C62828" stroke-width="1.2" stroke-dasharray="3,2"/>
<!-- 末段竖管 -->
<line x1="x2+6" y1="y_mid" x2="x2+6" y2="y2"
      stroke="#C62828" stroke-width="1.2" stroke-dasharray="3,2"/>
<!-- 标签 (在伴热线上方 4-5px) -->
<text x="x_mid" y="y_mid-10" font-family="SimHei" font-size="7"
      fill="#C62828" text-anchor="middle">▬▬ 蒸汽伴热+保温</text>
```

### 2.4 跳过泵符号(伴热不穿过泵)

泵位置(圆心 x, y, r=14):伴热平行线在 x+6 处断开,跳过泵 28px 范围(x-14 到 x+14)。

## 三、迭代版本化 P&ID 修改工作流(2026-06-23 实战)

### 3.1 适用场景

- 客户/上级要求对已发布 P&ID 进行**多轮**修改
- 每轮修改包含**多个整改项**(>5 个)
- 需要保留**历史版本**可追溯

### 3.2 命名规范(v6.0→v6.8 完整列表)

```
polyurethane-TDI-10tpa-pid-v6.0.html  ← 初版 (DETDA 工艺, 06-23 09:51)
polyurethane-TDI-10tpa-pid-v6.1.html  ← 旧 MOCA 版 (06-21, 已废弃但保留)
polyurethane-TDI-10tpa-pid-v6.2.html  ← 第 1 轮:伴热+保温 / 阀门定位 / 信号线
polyurethane-TDI-10tpa-pid-v6.3.html  ← 第 2 轮:泵重叠 / 伴热 y 偏移 / S-102 / V-401 10mbar
polyurethane-TDI-10tpa-pid-v6.4.html  ← 第 3 轮:公共信号线 / PCV-401
polyurethane-TDI-10tpa-pid-v6.5.html  ← 第 4 轮:P-601/CM-601 / PCV-301 避电机 / R-301+V-401 公共竖线
polyurethane-TDI-10tpa-pid-v6.6.html  ← 第 5 轮:S-401 接 MX-601 / 仪表实线 tap / 信号线按系统分离
polyurethane-TDI-10tpa-pid-v6.7.html  ← 第 6 轮:信号线竖线错开 8px + 仪表两类型规则
polyurethane-TDI-10tpa-pid-v6.8.html  ← 第 7 轮:V-401 PIRC 错开 TIRC / 13 阀门完整清单 / 备注编号修正
```

### 3.3 工作流(每轮修改)

| 步骤 | 动作 | 工具 |
|---|---|---|
| 1 | 读取上一版 v(N-1) | `read_file` |
| 2 | 写 `/tmp/build_vNN.py` 持久化脚本 | `write_file` |
| 3 | 脚本内 `replace(old, new, desc)` 逐项修改 | Python 字符串替换 |
| 4 | `python3 /tmp/build_vNN.py` 执行 | `execute_code` 或 `terminal` |
| 5 | 检查未匹配项 → 写 `/tmp/patch_vNN.py` 补丁 | `write_file` |
| 6 | HTTP 200 验证 + UTF-8 BOM 验证 | `curl` + `file` |
| 7 | 关键坐标 grep 验证 | `grep` |
| 8 | 汇报实施报告 | WeChat |

### 3.4 关键 Pitfall(已踩)

- **必须保留旧版**(v6.0 同时存在,**不要删除 v6.1**)
- **未匹配项必须补 patch 脚本**(不要硬塞到主脚本)
- **每次实施后必须 grep 关键坐标** 确认(用户会看)
- **文件大小会增长 1-2KB/轮**(正常)
- **UTF-8 BOM 从 v(N-1) 继承**(不用每次加,除非首次创建)
- **v6.6 关键教训**:3.2 列表中 v6.5 用了"公共竖线"模式, v6.6 起改为"独立虚线"模式 → 写 v6.6+ 脚本时**不能照搬 v6.5 的 replace 字符串**

### 3.5 模板代码

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Build vNN from v(N-1): [本次整改描述]."""

SRC = '<path-to-v(N-1)>'
DST = '<path-to-vNN>'

with open(SRC, 'r', encoding='utf-8') as f:
    c = f.read()

original_size = len(c)
changes = []

def replace(old, new, desc):
    global c
    if old in c:
        c = c.replace(old, new, 1)
        changes.append(f"  ✓ {desc}")
    else:
        changes.append(f"  ✗ {desc} [未找到匹配]")

# 1. 标题栏更新
replace('<title>...v(N-1)</title>', '<title>...vNN</title>', '1.1 <title>')
# 2. 整改项 1
replace('OLD_SVG', 'NEW_SVG', '2.1 ...')
# 3. 整改项 2
replace('OLD_SVG', 'NEW_SVG', '3.1 ...')
# ...

with open(DST, 'w', encoding='utf-8') as f:
    f.write(c)

print(f"原始 v(N-1): {original_size} bytes")
print(f"新 vNN:   {len(c)} bytes")
print(f"增量:     +{len(c) - original_size} bytes")
for ch in changes:
    print(ch)
```

## 五、V-401 双仪表信号线错开(2026-06-23 v6.8 女王立规)

**问题场景**:V-401 仪表群只有 2 个仪表(TIRC-401 y=500 / PIRC-401 y=540),但两者信号线容易**在 y=500 水平交叉**,因为 TIRC-401 横线在 y=500 从 (1562, 500) 向左出发,与 PIRC-401 竖线在 x=1562 重叠 40px 距离。

**通用错开规则**(适用于任何 2 个相邻仪表):

| 仪表 | y | 仪表 LEFT 边 | 竖线 x (推荐) | 起点 → 错开 → 路径 |
|---|---|---|---|---|
| TIRC-401 | 500 | 1562 | **1552** (-10px) | (1562,500)→(1552,500)→(1552,858)→(1648,858) |
| PIRC-401 | 540 | 1562 | **1556** (-6px) | (1562,540)→(1556,540)→(1556,360)→(1768,360) |

**关键技巧**:即使只有 2 个仪表,**也要让它们的横线段不在同一 y 高度重叠**:
- TIRC-401 横线 y=500:从 (1562, 500) 出发向左(不会与 PIRC 的 (1562, 540) 起点冲突)
- PIRC-401 横线 y=540:从 (1562, 540) 出发向左,到 (1556, 540) — 与 TIRC 的 y=500 错开 40px

**反例(常见错误)**:V-401 仍用 2 个独立 x=1562 起点 → TIRC 横线在 y=500 出发,PIRC 横线在 y=540 出发,但**两横线起点都在 x=1562**,与 PIRC 竖线在 x=1562 重叠 y=360-540 → **y=500 处视觉交叉**。

**修复**:
- TIRC-401 竖线 → x=1552 (左移 10px)
- PIRC-401 竖线 → x=1556 (左移 6px,介于 TIRC 竖线 1552 和仪器边 1562 之间)
- **不重叠**(差 4px,虽窄但视觉清晰)

**关键技巧**:当 2 个仪表只差 40px y 距离时,**必须让 2 条横线起点错开 x**(避免在仪表 LEFT 边 x 起点处冲突),然后各自走独立竖线。

## 七、备注编号管理铁律(2026-06-23 v6.8 女王发现)

**问题场景**:P&ID 图面下方有 6-8 个"备注 N"段落,因**多次迭代修改**常出现**重复编号**(两个 备注 5,两个 备注 6)。

**正确编号顺序**:
```
备注 1: 单元划分说明
备注 2: 工艺说明(DETDA/MOCA 选型理由)
备注 3: 主管/伴热整改
备注 4: 阀门符号说明(13 阀完整)
备注 5: 字母代号说明(ISA-S5.1)
备注 6: 介质代号说明(S-XXX 流股标识)
备注 7: 工艺泵汇总
```

**v6.8 整改案例**(PU 弹性体 P&ID):
- 整改前:6 个 备注,两个 备注 5(阀门符号)+ 两个 备注 6(字母代号),且阀门符号只 8 阀,缺 5 阀
- 整改后:7 个 备注,编号唯一 1-7,阀门符号含全部 13 阀

**铁律**:
1. **每次迭代前**用 `grep "备注 [0-9]"` 列出所有备注标题,确认**无重复**
2. **新加的备注**接在最大编号后(如有 6,新加为 7)
3. **删除重复段**时,先确认两段内容是否完全相同(若是,删除其一)
4. **内容相似的两段**(如"字母代号"和"介质代号"内容不同)需用不同编号 + 不同标题

**自检脚本**:
```bash
grep -oE "备注 [0-9]+" pid-vN.html | sort | uniq -c | sort -rn
# 应输出每个编号只出现 1 次。若某编号 >1,说明有重复
```

**注意**:删除重复段时,旧字符串可能含多行 `<tr>` 标签,直接用 `replace(old, new, 1)` 找不到。**先用 `read_file` 看 30-50 行上下文,确认精确文本**。
