## 2. 泄放工况（事故场景）选择

### 2.1 依据 HG/T 20570.2-95 §7.0，常见工况清单

| 条款 | 工况 | 适用场景 |
|------|------|---------|
| 7.0.1 | 阀门误关闭 | 切断阀误关导致超压 |
| 7.0.2 | 循环水故障 | 塔顶冷凝器断水 |
| 7.0.3 | 电力故障 | 停电停泵 |
| 7.0.4 | 不凝气积累 | 冷凝器不凝气累积 |
| 7.0.5 | 控制阀故障 | 控制阀全开/全闭 |
| 7.0.6 | 过度热量输入 | 加热盘管/夹套切断阀误开 |
| 7.0.7 | 易挥发物料进入高温系统 | 水/轻烃误入热油（**用爆破片而非安全阀**）|
| 7.0.8 | 换热器管破裂 | 壳侧与管侧压差＞2/3 |
| 7.0.9 | 化学反应失控 | 飞温（**用爆破片**）|
| 7.0.10 | **外部火灾** | **无保温、地面安装的默认工况** |

### 2.2 默认工况选择规则

- **无保温 + 地面安装 + 立式容器** → §7.0.10 外部火灾（默认最保守）
- **有明确进料流量 + 出口切断阀** → §7.0.1 阀门误关闭
- **火灾工况超压 21%**（即 P_d = 1.21×P_s），其他工况超压 10%（P_d = 1.10×P_s）

## 3. 外部火灾工况泄放量计算（核心公式）

### 3.1 湿润面积（依据 §7.0.10.2）

```
A = π·D_o·(L + 0.3·D_o)            — 立式/卧式容器
   取较小值：7.5m 高度内表面积 vs 正常最高液位以下表面积
```

注：罐总高 H < 7.5m 时，A ≈ 容器总外表面积

### 3.2 外壁校正系数 F（依据 §7.0.10.3）

| 情况 | F |
|------|---|
| 地面无保温 | 1.0 |
| 地下砂土覆盖 | 0.3 |
| 顶部水喷淋（≥10 L/min·m²）| 0.6 |
| 完好保温 | 按 §7.0.10-2 公式 |

### 3.3 火灾输入热

```
Q_fire = 2.55×10⁵ × F × A    （kJ/h）
```

### 3.4 质量泄放量（液体工况，有汽化潜热）

```
W = Q_fire / H_l   （kg/h）
H_l = 汽化潜热（kJ/kg）
```

### 3.5 质量泄放量（**气体工况，无汽化潜热**——超临界流体/纯气相）

```
W = Q_fire / (C_p × T)        （kg/h）
T = 绝对温度（K）
C_p = 气体定压比热（kJ/(kg·K)）
```

**关键判别**：
- 若 T > T_c（临界温度）→ **超临界流体** → 用气体公式
- 介质临界参数查证：化源网、basechem.org、NIST WebBook
- 临界温度/压力对照常见物质：

| 介质 | T_c (°C) | P_c (MPa) |
|------|---------|-----------|
| 甲醇 | 240 | 8.1 |
| 水 | 374 | 22.1 |
| 乙醇 | 241 | 6.1 |
| 丙烷 | 97 | 4.2 |
| 丙烯 | 92 | 4.6 |

## 4. API 520 Part I 安全阀口径计算（气体）

### 4.1 临界流系数 C

```
C = √[k × (2/(k+1))^((k+1)/(k-1))]      — 临界流（喉部流速达声速）
k = C_p / C_v
```

### 4.2 临界压力比

```
r_c = (2/(k+1))^(k/(k-1))
```

### 4.3 临界流判定

```
若 P_back / P_1 < r_c → 临界流成立，使用 C 计算
若 P_back / P_1 ≥ r_c → 亚临界流，使用另一组公式
P_1 = 泄放压力（绝压）
P_back = 阀后背压（含下游管路+水封+大气）
```

### 4.4 质量流量公式（临界流）

```
W (kg/s) = C × K_d × A (m²) × P_1 (kPa abs) × √(M / (Z × T))

K_d = 0.975（API 520 排放系数）
M = 分子量（kg/kmol 或 g/mol）
Z = 压缩因子（超临界 ≈ 0.5~0.8）
T = 绝对温度（K）
```

### 4.5 API 520 标准喷嘴面积（mm²）

| 喷嘴代号 | 面积 | 喉径 (mm) | 阀门口径（入口×出口）|
|---------|-----|-----------|---------------------|
| D | 71 | 9.5 | DN15×DN25 |
| E | 126 | 12.7 | DN20×DN25 |
| F | 198 | 15.9 | DN25×DN40 |
| G | 325 | 20.3 | DN40×DN50 |
| H | 506 | 22.2 | DN50×DN80 |
| J | 830 | 32.5 | DN65×DN100 |
| K | 1186 | 38.9 | DN80×DN100 |
| L | 1841 | 48.4 | DN100×DN150 |

**选型原则**：计算所需面积 ≤ 喷嘴面积 → 选用该喷嘴

### 4.6 出口管径经验

```
出口管径 = 入口管径 + 1~2 级
（防止背压过高影响安全阀再开启）
```

## 5. 缓冲罐（分液罐）设计

### 5.1 容积确定

```
方法 A（基于停留时间）：
V_缓冲 = (W × t) / ρ
t = 5~10 min（一般取 10 min）
ρ = 缓冲罐设计压力、温度下的介质密度

方法 B（基于 SH 3009-2013 §8.2）：
立式分液罐直径 D = (简化)
卧式分液罐 L/D ≥ 2~3
```

### 5.2 长径比选择（依据 HG/T 20570.1）

| L/D | 适用 | 评价 |
|-----|------|------|
| 1.0~1.5 | 卧式分离罐 | 占地大 |
| **1.5~2.5** | **立式缓冲罐** | **✅ 推荐** |
| 2.5~4.0 | 精馏塔、反应器 | 高径比大 |

### 5.3 容积公式（标准 2:1 椭圆封头）

```
V_总 = (π/4) × D² × L + 2 × V_封头
V_封头 = (π/12) × D³        （含直边段近似）
V_总 = (π/4) × D² × (L + D/3)
```

当 L/D = K 时：
```
V_总 = (π/4) × D² × (K + 1/3) × D
     = (π/4) × (K + 1/3) × D³
反解：D = [4V_总 / (π(K + 1/3))]^(1/3)
```

### 5.4 标准压力容器直径系列（GB 150）

DN 800, 1000, 1200, 1400, 1600, 1800, 2000, 2200, 2400, 2600, 2800, 3000 mm

### 5.5 筒体壁厚（GB 150.3 §5.6.1）

```
t = P × D / (2 × [σ]^t × φ - P)
[σ]^t = Q245R 在设计温度下的许用应力
φ = 焊接接头系数（一般 1.0）
+ 钢板厚度负偏差 0.3mm + 腐蚀裕量 1.0mm
```

## 6. 水封罐设计（SH 3009-2013 §8.1）

### 6.1 直径公式（§8.1.17-1，核心）

```
D_1 = 5.07×10⁻² × (Q_1 / L_1)^0.5

D_1 = 水封罐直径（m）
Q_1 = 泄放气标况体积流量（m³/h，0°C 101.325 kPa）
L_1 = 进出气口中心距（m）
L_1 = K_1 × D_1
K_1 = 系数，按 SH 3009 表 8.1.17 选取（立式 1.0~1.5）
```

反解 D_1（当 L_1 = K_1 × D_1）：
```
D_1 = (2.57×10⁻³ × Q_1 / K_1)^(1/3)
```

### 6.2 水封高度（§8.1.5）

```
h_水封 = 1.75 × P_max    （m 水柱）
P_max = 水封罐内气相空间最大操作压力（MPaG）
```

**重要**：水封高度必须同时满足
- ≥ 1.75×P_max（防回火）
- ≤ 安全阀允许背压 / 10（防憋压）

### 6.3 U 形溢流管（§8.1.4 推荐）

```
溢流管水封高度 ≥ 1.75 × P_max
溢流管直径 ≥ DN50（无切断阀）
高点处管道下部内表面应高于最高液位
```

#### 6.3.1 U 形管形状：必须**正U (∪)**，不能**倒U (∩)**【2026-06-06 女王当面纠正】

水封罐的 U 形溢流管必须是**正U管 (∪)**：U-bend 在底部（罐内**水面下**），两腿向上穿过液面、穿过罐顶，到罐外。

**倒U (∩) 是错配**：倒U (∩) 是**破真空接管**的结构（N4 顶部 DN25 ≥300mm 独立接管），不是主水封管。

**铁证三重交叉**：

| 来源 | 关键句 | 推论 |
|------|--------|------|
| **SH 3009-2013 §8.2.7** | "高点处管道下部内表面与水封液面处于**同一水平高度**" | U 形管管口下沿 = 液面 ⇒ U-bend 在液面下 ⇒ 正U |
| **HG/T 20570.17-95 §1.0.1** | "通过**液封管插入液封罐液面下**的深度" | 液封管（U 形管）插入液面下 ⇒ U-bend 在液面下 ⇒ 正U |
| **化工工艺设计手册** | "**冷凝液经 U 形管排到中间槽**" | 液体自流入下游，U-bend 在底部 ⇒ 正U |
| **专利 CN201439953U** | "U 型管"（主水封，正U）vs "反 U 型"（破真空接管，倒U） | 主水封≠破真空接管 |

**正U管几何示意**（v5.0 标准）：

```
       罐顶
   ─────N3─N4─────  ← 罐顶接管（U 管两腿穿过此处）
       │  │
   ────│──│────  ← 罐内最高液面（U管管口下沿 = 液面）
   ▓▓▓▓│██│▓▓▓▓
   ▓▓▓▓│██│▓▓▓▓  ← U 管两腿在液面下（充满水）
   ▓▓▓▓│██│▓▓▓▓
   ▓▓▓▓└──┘▓▓▓▓  ← U-bend 顶部（液面下 1.75×P_max）
   ▓▓▓▓▓▓▓▓▓▓▓▓▓
   ▓▓▓▓ U-bend ▓▓▓
   ▓▓▓▓▓▓▓▓▓▓▓▓▓
       罐底
```

**反复犯过的错**（自我检讨）：v2.0/v4.0 都把 U 形管画成倒U (∩) 挂在罐顶上方——这是错的。根因：凭"U 字=倒U 字"字面理解，没查证权威图示。

**判定口诀**：
- 水封 = **正U (∪)**，U-bend 在下
- 破真空 = **倒U (∩)**（小接管），DN25 独立设置
- 两者**不能混淆**

### 6.4 缓冲罐与水封罐接口

```
进气管：DN50~DN80（按 W/ρ/(π/4×D²) = 15~25 m/s 流速选取）
出气管：同进气管
N₂ 注入管：DN15~DN25
```

## 7. N₂ 吹扫（置换）流量计算

### 7.1 维持正压（正常操作）

```
Q_N2 = 5~20 m³/h
作用：维持缓冲罐微正压（0.1~0.5 MPaG），防止空气倒流
```

### 7.2 事故时稀释到 0.5×LFL（不推荐，经济性差）

```
目标：x_甲醇 ≤ 0.5 × LFL_MeOH = 0.5 × 6.7% = 3.35%
体积稀释比 N₂ : 甲醇 = (1 - 0.0335) / 0.0335 = 28.85:1
Q_N2 = Q_甲醇(标况) × 28.85
```

⚠️ **关键陷阱**：如果工程中给出的"10:1"等比例是估算值，**必须反算验证**：
- 10:1 → 1/11 = 9.09% > 6.7% LFL → 仍在爆炸区间，**危险**！
- 必须 30:1 以上才能达到 0.5×LFL

### 7.3 实际工程方案（推荐）

| 方案 | N₂ 流量 | 排放方式 | 评价 |
|------|---------|---------|------|
| 大流量 N₂ 稀释到 0.5×LFL | 16,000+ m³/h | 排大气 | ❌ 不经济 |
| **N₂ 维持正压 + 火炬** | **5~50 m³/h** | **接火炬** | **✅ 主流** |
| N₂ 维持正压 + 冷凝回收 | 20~50 m³/h | 回收甲醇 | 适合大型装置 |

## 8. 完整设计流程清单（自查用）

1. ☐ 确认泄放工况（HG/T 20570.2-95 §7.0）
2. ☐ 计算湿润面积 A
3. ☐ 确定外壁校正系数 F
4. ☐ 查证介质物性（特别注意 T_c，判断是否超临界）
5. ☐ 计算火灾输入热 Q_fire
6. ☐ 计算泄放量 W（液体/气体分别用对应公式）
7. ☐ 选定安全阀喷嘴（API 520 标准喷嘴代号）
8. ☐ 校核背压（P_back / P_1 < r_c 临界流）
9. ☐ 缓冲罐容积计算（停留时间法）
10. ☐ 缓冲罐几何尺寸（D、L 长径比 1.5~2.5）
11. ☐ 水封罐直径（SH 3009 §8.1.17-1）
12. ☐ 水封高度（≥1.75×P_max）
13. ☐ N₂ 流量确定（维持正压 or 稀释到 LFL）
14. ☐ 排放方式（接火炬/排大气/冷凝回收）

## 9. 常见陷阱

| 陷阱 | 后果 | 正确做法 |
|------|------|---------|
| 用"潜热法"算超临界流体泄放 | 严重低估泄放量 | 改用气体显热法 C_p × T |
| 估算 N₂ 稀释比（如 10:1）| 实际可能仍超 LFL | 严格按 V_甲醇/V_总 ≤ 0.5×LFL 计算 |
| 火灾工况按 110% 超压算 | 泄放面积偏小 | 火灾工况按 121% 超压（HG/T 20570.2-95 §5.0.1）|
| 缓冲罐按常压算 | 容积巨大（150 m³）| 合理承压（0.5~1.0 MPa）可大幅缩容积 |
| 水封高度照搬经验值 | 太高导致安全阀不开 | 严格按 1.75×P_max 并校核背压 |
| 用空气密度算缓冲罐内气体 | 密度偏低 → 容积偏大 | 用实际工作压力、温度下的密度 |
| 设备"无液位"仍按液体工况算 | 泄放量错误 | 气体/超临界介质应用气体公式 |

## 10. 重要事实（查证自知识库 + 行业标准）

- **甲醇临界温度 T_c = 240°C（240.1°C）**，临界压力 P_c = 8.1 MPa（8.22 MPa）
- **甲醇 LFL = 6.7%**（NFPA、CRC 手册、维基多源验证）
- **甲醇 UFL = 36%**
- **甲醇分子量 M = 32.04 g/mol**
- **甲醇沸点 = 64.7°C，闪点 = 11°C**
- 甲醇 260°C、6 MPaG 状态：**超临界流体**（T > T_c，P < P_c）
- HG/T 20570.2-95 §7.0.10 火灾工况允许超压 **21%**（即 P_d = 1.21×P_s）

## 11. 完整计算示例（甲醇 6 MPaG、260°C 案例）

> 完整案例见会话存档。关键结果：
> - 泄放量 W = 830 kg/h（按超临界气体显热法）
> - 安全阀：F 喷嘴（198 mm²），阀门口径 DN25×DN40
> - 缓冲罐（承压 0.5 MPaG）：DN2400×L=4800mm，V=29 m³
> - 水封罐：DN1200×L=1700mm（按 SH 3009 §8.1.17-1 公式核算）
> - N₂ 流量：正常 5~20 m³/h（维持正压），事故 200~500 m³/h（推气至火炬）
> - 排放方式：**接火炬**（不靠 N₂ 稀释到 LFL）
