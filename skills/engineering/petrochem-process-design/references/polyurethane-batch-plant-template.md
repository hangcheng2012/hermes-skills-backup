## 一、工艺路线（成熟商业化工艺）

**预聚物法**（prepolymer method）— UBE Adiprene® pPDI 体系
- 国际商业化 40+ 年
- 工艺：多元醇脱水 → 预聚反应 → 真空脱气 → 扩链浇注 → 硫化

**反应体系**：PPDI（1,4-苯二异氰酸酯）+ PTMG-1000（聚四氢呋喃醚二醇）+ MOCA（3,3'-二氯-4,4'-二氨基二苯甲烷）

## 十、关键安全提示

1. **PPDI 剧毒**（GB 6.1 类，LD₅₀ 800 mg/kg）：可燃有毒气体检测 + 正压防护服
2. **MOCA 有毒**（疑似致癌，GB 6.1 类）：密闭化操作 + 局部排风
3. **N₂ 保护全流程**：R-301/V-401/V-501/V-601 全程 N₂ 封
4. **温度控制**：预聚反应放热 ~80 kJ/mol NCO，控温严防 ≥ 95°C 支化
5. **加料顺序**：PTMG 先进，PPDI 后加（防局部 NCO 过量暴聚）
6. **废气处理**：脱气尾气含 PPDI → 活性炭吸附 + 碱液喷淋后高空排放

## 十一、可复用模板场景

本模板适合以下类似项目：
- **小批量特种聚氨酯**（≤100 t/a）：CPU 浇注型、TPU、PU 涂料
- **反应釜式间歇工艺**：加料 → 反应 → 真空 → 出料
- **N₂ 保护 + 真空脱气 + 浇注成型** 流程
- **有毒/剧毒原料操作**（异氰酸酯、光气衍生物、氰化物等）

**需要调整的关键参数**：
- 异氰酸酯类型：PPDI → TDI/MDI/HDI/NDI 等（活性和毒性不同）
- 多元醇类型：PTMG → PPG/PBA/PCL 等
- 扩链剂类型：MOCA → BDO/HQEE/HER 等
- 预聚体 NCO%：5%（硬度 85A）→ 3~10%（弹性体硬度调节）
- 真空脱气温度：依 NCO 活性和蒸气压
