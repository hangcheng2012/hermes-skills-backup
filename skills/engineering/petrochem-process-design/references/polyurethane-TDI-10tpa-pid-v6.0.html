备注 2：DETDA 工艺说明（⭐ 改用液体扩链剂）

• 配方：PTMG : TDI : DETDA = 100 : 20.4 : 11.0（重量比），NCO/OH=1.05，预聚体 NCO%=4.7±0.3%
• DETDA 是室温液体（黏度 280 cP@25°C，密度 1.02 g/cm³），省去 V-501 熔化工序，省去 O-501 真空泵
• V-103 DETDA 储罐 25L 304SS 常温 25°C，需要 N₂ 封（DETDA 易氧化变色）
• DETDA 投料：用 P-501 齿轮泵（0.05 m³/h 0.37 kW）从 V-103 → MX-601 侧进
• DETDA 反应速度比 MOCA 快 30 倍，R-301 反应时间缩短至 1.5-2h
• DETDA 蒸汽压高，V-401 脱气时间略延长（30-45 min）
• V-104 DOS 增塑剂已取消（DETDA 体系不必须）

备注 3：N₂ / 真空 / CW / HO 主管整改（⭐ 不延伸原则）

• N₂ 主管段 1：x=200-620（V-101/V-102/V-103 顶部 N₂ 封），不延伸到 V-201 位置
• N₂ 主管段 2：x=1270-1290 短横线（只 R-301 顶部 N₂ 封）
• HO 主管 y=982/945：x=220-1700（起点连 R-301 左接管，终点 V-401 接管位置），进 V-401 后右边不延伸
• CW 主管 y=922/885：x=200-1400（仅 R-301）
• 真空管路：V-201 + V-401 → 排气总管 y=320 → T-601 活性炭 → X-601 RTO → 排放
• V-401 进/出口接管错开：进口 NO-401A x=1700，出口 NO-401B x=1740（避免 R-301→V-401 与 V-401→MX-601 流股在 x=1720 处交叉）
• 管路原则：所有主管只延伸到最后一个需要设备，不悬空，不延伸
