# P&ID 真空系统拓扑设计铁律

**源由**：女王 2026-06-22 项目中，P&ID v6.0 真空管路有严重矛盾，**真空泵位置错误**导致 V-201/V-401 顶部接管绕过真空泵直接到排气总管。本文件总结真空系统设计通用规则。

---

## 一、常见错误（必须避免）

### ❌ 错误设计 1：真空设备直接连排气总管

```
V-201 顶部接管 ──→ 真空排气总管 y=320 ──→ T-601 活性炭
                  ↑（V-201 气体绕过真空泵）
                  
O-201 真空泵（公用工程底层 y=1340）──→ 垂直管 ──→ y=320 主管
                                              ↑（真空泵"出口"也连同一主管）
```

**问题**：
- V-201 内的真空是**谁产生的**？逻辑上说不清
- 真空泵 O-201 抽的是哪里来的气？
- 气体流向不清晰（看起来真空泵"出口"和 V-201 顶部接管都连同一主管）

### ❌ 错误设计 2：真空泵出口与总管位置混乱

如果真空泵画在公用工程底层（y=1340），出口垂直向上到主管（y=320），**入口在哪**？
- 真空泵入口必须接 V-201/V-401 顶部接管
- 真空泵入口和出口必须在视觉上有方向性

---

## 二、✅ 正确设计（真空系统拓扑）

### 真空泵位置：**在 V-201/V-401 顶部接管和 T-601 之间**

```
V-201 顶部 NO-201B ──→ O-201 真空泵入口（V-201 上方）──→ O-201 出口 ─┐
                                                                          ├─→ T-601
V-401 顶部 NO-401B ──→ O-401 真空泵入口（V-401 上方）──→ O-401 出口 ─┘
```

### 关键概念

| 概念 | 解释 |
|---|---|
| **真空泵位置** | 在真空设备之后、T-601 之前（**主流程区**，不在公用工程底层）|
| **真空泵入口** | 接 V-201/V-401 顶部接管（**流体方向：V-201 → 真空泵**）|
| **真空泵出口** | 接 T-601 活性炭（**流体方向：真空泵 → T-601 → X-601**）|
| **真空泵作用** | ①产生 V-201/V-401 真空（10/5 mbar）②推动气体向下游流动 |
| **真空排气支管** | 从 O-201/O-401 出口到 T-601 入口（**y=290 水平线**）|

### 真空排气支管（不是总管）

- O-201 出口 → 水平线 y=290 → 延伸到 T-601
- O-401 出口 → 水平线 y=290 → 延伸到 T-601（与 O-201 汇合）
- 两条真空排气支管在 T-601 入口前**汇合** → T-601 → X-601 RTO → QT-601 → 排放

### 整改示例（P&ID v6.0 → v6.1 真空管路）

**整改前**：
- V-201 顶部 NO-201B 顶出 VAC（垂直 y=400 → y=340 → y=320 主管）
- V-401 顶部 NO-401B 顶出 VAC（垂直 y=400 → y=340 → y=320 主管）
- y=320 真空排气总管 x=380-1780
- O-201/O-401 真空泵在 y=1340 公用工程底层，连到 y=320 主管

**整改后**：
- 删除 y=320 真空排气总管
- V-201 顶部 NO-201B 顶出 VAC（垂直 y=400 → y=320，连接到 O-201 真空泵入口）
- O-201 真空泵位置：V-201 上方 y=320（主流程区）
- O-201 出口 → 真空排气支管 y=290 → 水平到 x=1820 → 垂直到 T-601 (y=990)
- V-401 顶部 NO-401B 顶出 VAC（垂直 y=400 → y=320，连接到 O-401 真空泵入口）
- O-401 真空泵位置：V-401 上方 y=320（主流程区）
- O-401 出口 → 真空排气支管 y=290 → 水平到 x=1820 → 汇入 T-601
- 公用工程底层原 O-201/O-401 块改为"N₂ 主管接入区"或取消

### 2. 真空接管标注

- **NO-201B** 顶出 VAC（V-201 顶部接管）
- **NO-401B** 顶出 VAC（V-401 顶部接管）
- **NO-501B** 顶出 VAC（V-501 顶部接管，如果存在）

### 3. 真空排气处理（T-601 + X-601 + QT-601）

- **T-601 活性炭吸附**：物理吸附（气→固）>99% 去除有机物
- **X-601 RTO 焚烧**：化学分解（750°C 蓄热氧化）>99.9% 分解
- **QT-601 在线监测**：TDI < 0.02 ppm

## 四、真空系统常见设备配置

| 真空度 | 设备配置 | 应用 |
|---|---|---|
| **粗真空（10-100 mbar）** | 旋片真空泵（单级）| V-201 PTMG 脱水 |
| **中真空（1-10 mbar）** | 旋片+罗茨真空泵（两级）| V-401 PU 脱气 |
| **高真空（<1 mbar）** | 旋片+扩散泵 | 真空蒸馏 |
| **极高真空（<10⁻³ mbar）** | 分子泵 + 离子泵 | 半导体工艺 |

---

## 五、配套真空排气处理（强制要求）

真空系统排出气体**必须经过处理才能排放**：

| 废气成分 | 处理设备 | 原理 |
|---|---|---|
| 有机蒸汽（TDI/DETDA/PU 等）| T-601 活性炭吸附 | 物理吸附 >99% |
| 有机物分解 | X-601 RTO 焚烧 | 750°C 蓄热氧化 >99.9% |
| 排放浓度监测 | QT-601 在线监测 | 实时监测 < 0.02 ppm |

**女王要求（2026-06-22）**：TDI 真空废气**不能直接排空**（剧毒），必须两道处理（活性炭 + RTO 焚烧）。

---

## 六、可复用场景

本真空系统拓扑规则适用于任何带真空设备的工艺：
- 真空脱水（如 PTMG 脱水 V-201）
- 真空脱气（如 PU 预聚体脱气 V-401）
- 真空精馏
- 真空干燥
- 真空过滤

**关键检查点（每次出图前）**：
1. 真空泵是否在**主流程区**（不在公用工程底层）？
2. 真空泵**入口**是否接真空设备顶部接管？
3. 真空泵**出口**是否接真空排气处理设备（T-601/X-601）？
4. 是否存在真空设备直接连排气总管的错误？
