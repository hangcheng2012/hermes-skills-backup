| 反应压力 | 2.5~3.2MPa | |
| 催化剂 | Fe基或Co基 | |
| CO单程转化率 | 60~80% | |
| H₂/CO进料比 | 1.6~2.0 | |
| 反应热 | ≈ -165 kJ/mol CO | 强放热 |

> ⚠️ **温度分级重要区分**：
> - **低温F-T（LTFT）**：< 260°C（本次设计）
> - **中温F-T（MTFT）**：260~275°C（宁煤400万t/a装置，《煤炭学报》2020年数据）
> - **高温F-T（HTTF）**：310~350°C（Sasol工业化）
>
> 查文献时注意：中温F-T数据**不可**直接用于低温F-T设计，两者产物分布和热集成方案不同。

### 浆态床反应器流向：下进上出（关键！）

| 方向 | 物流 | 说明 |
|------|------|------|
| **▼ 底部进入** | 新鲜合成气 + 循环气 | 气体分布器从反应器底部单点/多点进料 |
| **▲ 顶部出去** | 反应产物（气液混合物） | 携带蜡、油、催化剂细粉的气液混合物从顶部出口排出 |

> ⚠️ **设计院PFD绘制注意**：浆态床反应器在工艺流程图上必须标注清楚进出口方向。
> 合成气从**底部进入**（进料口朝下），产物从**顶部出去**（出料口朝上）。
> 连线时：进料管线画垂直向下箭头（↓），出料管线画水平向右箭头（→）。

> **⚠️ 干式旋风分离器 vs 水力旋流器（重要区分，已查证）**
> - **干式气固旋风分离器**：用于反应器出口**气相**除催化剂细粉（气-固离心分离），高温~260°C，是本流程的标准配置
> - **水力旋流器**：用于热高分底部**液相**的油蜡与催化剂颗粒分离（液-固），两者适用相态完全不同，不可混用

## 三、管壳式换热器 + 加热炉分析

### 用户给定参数（本次设计）
- 压缩机出口合成气温度：**100°C**
- 反应器进料目标温度：**230°C**
- 反应器出口气温度：**260°C**
- 设计端差 ΔT_min：**20°C**

### 热量平衡计算

```
热端：反应器出口气 260°C → 降温至 T_hot_out
冷端：合成气 100°C → 升温至 230°C

方案A（ΔT_min落在冷端）：
  T_hot_out = 100 + 20 = 120°C
  热量验证：260 - 120 = 140°C 降量 > 230 - 100 = 130°C 升量 ✓  热量足够！
  校核热端：260 - 230 = 30°C > 20°C ✓

方案B（ΔT_min落在热端）：
  T_hot_out = 230 + 20 = 250°C
  热端温差：260 - 250 = 10°C < 20°C ✗  不满足ΔT_min
  → 不可行
```

### 结论

| 方案 | 正常运行 | 冷态开车 | 低负荷 |
|------|---------|---------|--------|
| 单台管壳式换热器（无加热炉） | ✅ 热回收 | ❌ 无热源 | ⚠️ 裕量不足 |
| 管壳式换热器 + 加热炉补充 | ✅ 节能 | ✅ 必需 | ✅ 调节手段 |

**设计要点：**
- 加热炉用于**冷态开车和低负荷调节**，不可省略
- 管壳式换热器负责正常运行时的热量回收，节能
- 两者不是"二选一"，而是**互补组合**
- ΔT_min=20°C落在**冷端**（T_hot_out=120°C vs. T_cold_in=100°C）

### 浆态床 vs. 固定床 预热差异
- **固定床**：反应器本身是管束，预热和反应段可一体化设计
- **浆态床**：反应器为单容器热回收依赖外部换热器 + 催化剂冷却盘管产汽；进料预热完全依赖外部换热器，热端更紧张

## 四、热高分罐（Hot High-Pressure Separator）设计

### 费托蜡物性
- 重质蜡凝固点：**≈60~80°C**
- 低温下黏度急剧增加，**一旦降温即凝固**

### 设计结论

| 问题 | 答案 |
|------|------|
| 反应器出口气能否直接进热高分？ | ✅ **可以，且必须**——费托蜡凝固点高，必须在热状态下分离 |
| 热高分温度 | ≈反应温度（200~260°C），不降温 |
| 热高分压力 | ≈反应压力（2.5~3.2MPa），无需再压缩 |
| 分离原理 | 重力沉降 + 入口撞击分离 |

### 废锅位置（已查证，2025年5月）

**低温F-T浆态床主流配置（废锅在热高分之后）：**

```
反应器出口气
    |
    v
干式旋风分离器（气-固离心分离，干式，除催化剂细粉）
    |
    v
热高分罐（V101，高温气液分离，~260°C）
    |
    +-- 顶部气相 --> 废热锅炉（E103，~260°C→~130°C，产中压蒸汽）
    |       |
    |       v
    |   低温分离器（V102，~130°C→~70°C）
    |       |
    |       +-- 气相 --> 循环气压机 --> 返回压缩机进口
    |       +-- 液相 --> 精馏系统
    |
    +-- 底部液相（蜡+油+催化剂） --> 过滤/沉降 --> 粗蜡缓冲罐
```

> **⚠️ 干式旋风分离器与水力旋流器的核心区分（重要！）**
> - **干式气固旋风分离器**：用于反应器出口**气相**除催化剂细粉（气-固离心分离），高温~260°C工况
> - **水力旋流器**：用于热高分底部**液相**的油蜡与催化剂分离（液-固离心分离）
> - 两者适用相态完全不同：气相用于反应器出口，液相用于热高分底部液相后处理

**查证依据：**
1. **宁煤400万t/a装置**（《煤炭学报》2020年）：反应器→旋风分离器→换热分离器（废锅+热高分合一体）→下游精制。注：该装置为中温MTFT（260~275°C），但分离序列与LTFT一致
2. **Sasol SPD流程**（全球最成熟LTFT技术）：反应合成段→产物分离/废热回收→产品精制
3. **Chalmers LTFT Thesis（2013）**：明确LTFT标准流程中热分离（hot separator）在废热回收（waste heat boiler）之前
4. **宁煤标定数据**（煤炭学报2020）：旋风分离器数量从10个增至40个，入口速度从9.63 m/s提升至19.46 m/s，压降控制30~50 kPa

**设计原因（工程逻辑）：**
- 热高分在前：除去气体中携带的蜡液滴和催化剂颗粒，保护废锅列管不被蜡/催化剂混合物堵塞
- 废锅在后：处理经热高分分离后的相对干净的气相物流
- 废锅出口温度（~130°C）由产汽压力决定（2.5~4.0MPa饱和蒸汽）

## 八、低温泉态床F-T典型工艺流程（整体，已查证版本）

```
合成气 → 变换(调H₂/CO比) → 压缩机 → 预热器(管壳式+加热炉)
    → 浆态床反应器(220~240°C, 2.5~3.2MPa, Fe/Co基催化剂)
    → 干式旋风分离器（气-固离心分离，除催化剂细粉）
    → 热高分罐(V101, ≈反应温度，不降温，防蜡凝固)
        ├── 底部液相(蜡+油+催化剂) → 过滤/沉降 → 粗蜡缓冲罐 → 精馏系统
        └── 顶部气相
            → 废热锅炉(E103, ~260°C→~130°C, 产中压蒸汽)
            → 低温分离器(V102, ~130°C→~70°C)
                ├── 气相 → 循环气压机 → 返回压缩机进口
                └── 液相(油/水) → 精馏系统 → 石脑油/柴油/蜡产品
```

### 各单元关键设计点

| 单元 | 设计要点 |
|------|---------|
| 变换 | 调H₂/CO至1.6~2.0；注意变换炉温升和催化剂床层热点 |
| 压缩机 | 多段压缩+段间水冷；出口温度用户指定100°C |
| 预热器 | 管壳式换热器回收反应气热量 + 加热炉补充（开车/低负荷必需） |
| 浆态床反应器 | 冷却盘管产0.5~1.0MPa蒸汽；催化剂悬浮在蜡介质中 |
| 干式旋风分离器 | 气-固离心分离；入口速度~19 m/s（改造后）；压降30~50 kPa |
| 热高分罐 | 直接接反应器出口，≥260°C，防蜡凝固；顶部气相去废锅 |
| 废锅 | 回收高温气热量产蒸汽；注意压降和结垢风险 |
| 低温分离器 | 进一步分离轻油和水；操作温度100~150°C |
| 精馏 | 常压/减压精馏切割产品；蜡侧线抽出 |
| 尾气循环 | 返回压缩机进口（推荐），惰性气累积需定期放空 |

## 九、催化剂再生氮气流程

```
① N2吹扫 → 置换反应器内合成气（至CO/H2检测合格）
② N2+空气逐步升温 → 烧碳（200°C→400~450°C，缓慢温升）
③ 空气继续氧化 → 彻底除去积碳
④ N2冷却 → 床层降温至≤150°C
⑤ 还原（合成气或H2/N2） → 恢复活性Fe3O4相
⑥ 重新投料运行
```

> ⚠️ 烧碳温度上限：Fe基催化剂≤450°C，防止高温烧结
> 初始O2含量通常≤1%~2%（N2稀释），逐步提高

## 十、干式旋风分离器 vs 水力旋流器 vs 聚结分离器

| 设备 | 适用相态 | 分离对象 | 典型应用 |
|------|---------|---------|---------|
| **干式气固旋风分离器** | 气相 | 固体催化剂颗粒 | 反应器出口气（260°C）|
| **水力旋流器** | 液相 | 液体中的固体或轻重液滴 | 热高分底部液相（油蜡+催化剂）|
| **聚结分离器** | 液-液 | 油中带水（液滴聚结） | LPG/石脑油脱水 |

### 费托过滤器 vs 聚结分离器

| 项目 | 费托内置/外置过滤器 | 聚结分离器（Coalescing） |
|------|-------------------|------------------------|
| 分离对象 | 固-液（催化剂/蜡液） | 液-液（油中带水）或液-固 |
| 工作原理 | 过滤介质截留固体 | 液滴聚结→重力沉降 |
| 典型介质 | 金属丝网、多孔板 | 聚结纤维层 |
| 温度工况 | ≈260°C高温，需保温 | 常温或低温 |
| 应用场景 | F-T反应器顶部/出口 | LPG/石脑油脱水，油水分离 |
