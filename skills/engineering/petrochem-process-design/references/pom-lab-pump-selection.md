## 三、单螺杆泵（微型级）选型

### 3.1 流量覆盖验证

**HJ/T 国家环保标准（单螺杆泵，起草单位：杭州兴龙泵业）表3 — 流量分级：**

| 级别 | 100 r/min 理论流量 |
|---|---|
| 微型 | **≤10 L** |
| 小型 | ≤100 L |
| 中型 | ≤400 L |
| 大型 | ≤800 L |
| 特大型 | >800 L |

**能否覆盖 1700 g/h（≈1.7 L/h，标况水）？**

- POM浆料密度≈1.4 g/cm³ → 1700 g/h ≈ 1.2 L/h（料浆）
- 微型泵100 r/min时最大理论流量≤10 L → 需求约15~20 r/min即可匹配
- 单螺杆泵流量与转速严格线性比例，**通过变频调速可精确控制**
- ✅ 微型级完全覆盖小试需求

### 3.2 推荐参数

| 参数 | 推荐值 |
|---|---|
| 泵型 | 单螺杆泵（微型级） |
| 流量 | 0.2~400 m³/h（标准型）；微型可低至0.001 ml/min |
| 转速控制 | 变频调速（15~20 r/min匹配1700 g/h） |
| 固含适应性 | ≤40%（标准）；粒径<0.5mm时≤70% |
| 转子材质 | 304不锈钢 |
| 定子材质 | 丁腈橡胶（NBR） |
| 密封 | 机械密封 |
| 温度 | 进料需预热防POM凝固 |

## 四、甲醛蒸汽流量计选型

### 4.1 流量计算

- 甲醛蒸汽：400 g/h ≈ 6.4 L/min（标况）
- 进料压力：0.2 MPa（表压≈0.3 MPa绝压）
- 温度：≈80°C（甲醛聚合温度，需伴热）

### 4.2 量程对比

| 流量计类型 | 典型量程 | 能否覆盖6.4 L/min |
|---|---|---|
| 热式质量流量计（微流量型）| 0.1~500 g/h | ✅ **完全覆盖** |
| 超声波流量计 | 最小0.05~0.5 m³/h（≈50~500 L/min）| ❌ 量程下限远高于6.4 L/min |

### 4.3 热式质量流量计注意事项

**❌ 标准型毛细管热式流量计无法仅靠外壳电伴热达到80°C。**

- 80°C 易聚合气体（甲醛）需选 **自带内置伴热型**（如 Bronkhorst 内加热型）
- 内加热型：毛细管内部有伴热通道，可精确控温防止气体在测量段聚合
- 精度：±0.5~1% FS

> ⚠️ "声吸收特性"无科学依据；超声波流量计真正问题是**量程下限不足**（最小量程50 L/min >> 6.4 L/min需求）。

## 五、单螺杆泵直管段要求（补充知识）

单螺杆泵入口前需直管段的原因：
- 螺杆泵对入口流动的均匀性敏感
- 弯头会导致吸入不均匀，产生振动和流量脉动
- 建议入口直管段 ≥ 3~5D（管径倍数）
- 出口安全阀设置见 `waste-catalyst-slurry-transfer.md` 第八节
