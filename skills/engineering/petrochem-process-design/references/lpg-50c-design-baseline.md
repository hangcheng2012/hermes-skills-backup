# LPG/烃类 50°C 设计基准温度 + 饱和蒸气压速查

> 来源：化工工艺设计手册（第五版）下册 第30章 §5.1
> 适用：液化石油气/烃类储存容器、安全阀、工艺设计

## 1. 为什么是 50°C？

中国石化行业对**常温储存的烃类液化气体或混合液化石油气**有统一规定：
- **50°C = 最高工作温度工况** = 容器设计压力取值的基准温度
- 即使装置所在地极端气温远低于 50°C，无保冷设施的常温储罐仍按 50°C 饱和蒸气压设计
- 依据：下册 P22 §5.1 原文（line 3731-3751）

> "盛装临界温度高于 50°C 的液化气体的压力容器,当设计有可靠的保冷设施时,其最高压力为所盛装液化气体在可能达到最高工作温度下的饱和蒸气压力;**如无保冷设施,其最高压力不得低于该液化气体在 50°C 时的饱和蒸气压力**。"

## 2. 设计压力分级（按 50°C 饱和蒸气压分档）

依下册第30章 表30-5（line 3689-3707）：

| 介质 | 50°C Psat 范围 (MPa G) | 容器设计压力 (MPa G) | 法兰磅级 |
|------|------------------------|----------------------|----------|
| 丁烷/丁烯/丁二烯 | < 1.57 | 1.57 | Class 150 |
| 液态丙烷 或 Psat 1.57~1.62 | 1.57~1.62 | 1.77 | Class 150 |
| 液态丙烯 或 Psat 1.62~1.94 | 1.62~1.94 | **2.16** | Class 300 |
| 混合液化气 > 1.94 | > 1.94 | 按实测 | ≥ Class 300 |

**实操要点**：
- 混合液化气按 **最高组分 Psat** 套档（设计保守侧）
- 异丁烷 → 丙烷 → 丙烯 依次升级（依下册 line 3746-3751 原文）
- 设计压力含 1.05~1.10 倍安全阀整定压力系数（HG/T 20570 / API 520）

## 3. 关键物性速查（DIPPR + NIST + 知识库交叉确认）

| 物质 | 沸点 1atm (°C) | 临界温度 Tc (°C) | 临界压力 Pc (MPa abs) | 50°C Psat (MPa abs) | 50°C Psat (MPa G) |
|------|----------------|-------------------|------------------------|---------------------|---------------------|
| 丙烯 C₃H₆ | **-47.7** | 91.8 | 4.66 | 1.71 | **1.61** |
| 丙烷 C₃H₈ | -42.1 | 96.8 | 4.25 | 1.70 | 1.60 |
| 异丁烷 i-C₄H₁₀ | -11.7 | 134.7 | 3.65 | 0.65 | 0.55 |
| 正丁烷 n-C₄H₁₀ | -0.5 | 152.0 | 3.80 | 0.51 | 0.41 |
| 1-丁烯 | -6.3 | 146.4 | 4.02 | 0.62 | 0.52 |
| 异丁烯 | -6.9 | 144.9 | 4.00 | 0.65 | 0.55 |
| 1,3-丁二烯 | -4.4 | 152.0 | 4.33 | 0.66 | 0.56 |

**丙烯的工程地位**：
- 沸点最低（-47.7°C）→ 常压储存需低温保冷
- Tc 91.8°C **超过 50°C** → 50°C 时仍为亚临界液体 → Psat 高 → 容器设计压力最高档
- 50°C Psat ≈ 1.71 MPa abs，与下册表 1.62~1.94 MPa(G) 区间吻合

## 4. "汽化最低气温"的两种工程含义

用户常问"X 的汽化最低气温"，必须先确认指哪种：

1. **常压沸点**（1 atm 下能汽化的最低温度）= 表中第 2 列
   - 丙烯 = -47.7°C
   - 低于此温度：需抽真空汽化 或 加热汽化
2. **汽化器设计最低环境气温**（空温式汽化器设计边界）
   - 依项目所在地极端最低气温
   - 东北/西北：-25 ~ -39°C
   - 华北：-15°C 左右
   - 华南：约 0°C
   - **< -47.7°C 风险**：翅片管可能冻堵 → 须配水浴式或蒸汽式辅助

## 6. 应避免的坑

- **不引"GB 150 蒸气压"** — GB 150 是压力容器制造标准，不含物性数据
- **不混用"常压沸点"与"标准沸点"** — 二者数值相同（101.325 kPa），但含义不同
- **不分"abs"与"G"** — 饱和蒸气压数据常给绝压，设备设计取表压，差 0.101 MPa
- **不引混合液化气的"加权平均 Psat"** — 设计保守侧按最高组分的 Psat
- **不写"丙烯临界温度 92°C"** — 精确值 91.8°C，差 0.2°C 看似微小但 50°C Psat 校核敏感
