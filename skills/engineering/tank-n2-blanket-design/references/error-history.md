# 错误历史 + 避坑指南 (Error History)

> 女王 06-25 立规: 这次出的错以后都避免。本文档记录 v6.5 → v6.9 期间所有错误、原因、整改、根源,供未来 N₂ 封设计避坑。

## 错误清单(按错误类型排序)

### 错误 1:❌"自力式减压比 ≤ 10:1"(混淆阀型)

**症状**:在 N₂ 减压阀失效分析中,我错误地说"标准自力式减压阀的最大减压比 ≤ 10:1"。

**根因**:**混淆了气动调节阀和自力式调节阀的减压比限制**。
- 气动调节阀:减压比 ≤ 10:1(气蚀/闪蒸限制)
- 自力式(带指挥器 ZZDQ):减压比可达 600:1+(指挥器承受大压差)

**避坑**:
- 气动阀和自力式阀**减压比完全不同**
- 减压比讨论前**先确认阀型**
- 减压比 > 100 必须用**带指挥器自力式**

**整改**:6-25 女王追问后,网上查证 ZZVP/N 规范:"减压比大于100 要用两级降压",但 ZZDQ 指挥器式自力式可单级达 600:1+。

---

### 错误 2:❌"N₂ 阀前必须加 PRV"(用错阀型分析)

**症状**:在 V-101 N₂ 减压分析中,我错误建议加 PCV-101A + PCV-101B 两级减压阀。

**根因**:**用气动调节阀的分析去套用 N₂ 封场景**。
- N₂ 封场景**专用 ZZDQ 自力式阀**,直接接 N₂ 主管即可
- 我错误地认为"N₂ 主管 0.6 MPa 太高压,PV 受不了",但忽略了指挥器的作用

**避坑**:
- N₂ 封场景**首先考虑 ZZDQ 自力式阀**
- ZZDQ 设计减压比 600:1+,无需外加 PRV
- 网上查证 ZZDQ/ZZH/ZZN 系列产品规格

**整改**:6-25 女王指出"设计院直接用 PV 调节",网上查证 ZZDQ 供气压力 0.1-1 MPa,出口 0.2-40 kPa,完全匹配 V-101 应用。

---

### 错误 3:❌"常压罐需要 PSV"(混淆常压罐与压力容器)

**症状**:在 V-101 (PTMG 200L, 设计压力 2 kPa) 设计中,我错误建议加 PSV-101。

**根因**:**把常压储罐当成压力容器**。
- 压力容器(GB 150):必须 PSV
- 常压储罐(SH/T 3007):不需 PSV,用紧急泄放装置

**避坑**:
- 罐设计压力 ≤ 100 kPa → 常压储罐
- 罐设计压力 > 100 kPa → 压力容器(需 PSV)
- V-101 设计压力 2 kPa = 常压储罐
- V-102 设计压力 0.1 MPa = 边界(按压力容器处理,TDI 剧毒)

**整改**:6-25 女王指出"常压储罐是不是就不用设安全阀了",网上查证 SH/T 3007 + API 2000,常压罐**不强制要求 PSV**,用紧急泄放装置。

---

### 错误 4:❌"需要气动调节阀"(没充分比较)

**症状**:在 N₂ 阀选型讨论中,我建议用气动调节阀方案。

**根因**:**没充分考虑自力式阀在 N₂ 封场景的优势**。
- N₂ 封特点:调节简单(只压力)、流量小、压力低
- 气动方案复杂且贵(¥30,000-50,000)
- 自力式方案简洁且优(¥5,000-15,000)

**避坑**:
- N₂ 封场景**首选自力式**(无电无气/防爆/可靠)
- 气动方案仅在需要 DCS 联锁/精确流量控制时用
- 储罐 N₂ 封**不需要气动**

**整改**:6-25 网上查证自力式阀 5 大优势,确认 N₂ 封用 ZZDQ 自力式最优。

---

### 错误 5:❌"设计压力升级到 10 kPa"(基于错误前提)

**症状**:在 V-101 设计中,我错误建议把设计压力从 2 kPa 升到 10 kPa。

**根因**:**基于错误 3**(认为需要 PSV,所以设计压力要升)。
- 既然不需要 PSV,设计压力保持 2 kPa 即可
- 设计压力升级会增加罐体造价

**避坑**:
- 设计压力只用于**罐体强度计算**,不影响附件配置
- V-101 设计压力 2 kPa,罐体造价低,符合常压罐标准

**整改**:取消设计压力升级,保持 2 kPa。

---

### 错误 6:❌"加真空泄放阀 PVRV-101"(多余附件)

**症状**:在 V-101 设计中,我建议加 PVRV-101 真空泄放阀(¥1,500-2,500)。

**根因**:**没考虑呼吸阀已具备真空保护功能**。
- 呼吸阀 = 正压阀 + 负压阀(双阀盘)
- 呼吸阀**已包含真空保护**

**避坑**:
- 呼吸阀 = 正负压复合阀,不需要单独 PVRV
- 真空保护由呼吸阀的负压阀盘承担

**整改**:取消 PVRV-101,只用呼吸阀(双阀盘)。

---

### 错误 7:❌"紧急泄放阀口径很大,封头不能开孔"(误判)

**症状**:女王担心紧急泄放阀口径大,椭圆封头开不了。

**根因**:**我未能明确说明开孔可行性**。
- 200L 小罐紧急泄放装置 DN100,**可在椭圆封头顶部中心开孔**
- 无需补强(DN100 以下标准允许)

**避坑**:
- DN100 以下椭圆封头开孔**无需补强**(GB 150)
- 大口径(DN500+)用大法兰人孔,不在封头开

**整改**:6-25 网上查证 GB 150 + GB 50341,DN100 以下椭圆封头开孔可行。

### 错误 8:❌"减压阀前需 PRV 还是 ZZDQ 自力式阀"(混淆减压比能力)

**症状**:前后矛盾地说"自力式减压比 ≤ 10:1"(错误)和"自力式减压比大,可达 100:1+"(正确)。

**根因**:**没区分阀型**:
- 自力式(单级无指挥器):减压比 ≤ 100:1
- 自力式(带指挥器 ZZDQ):减压比可达 600:1+

**避坑**:
- 减压比讨论时**先确认阀型**
- 自力式阀有"指挥器"和"无指挥器"之分
- 指挥器是减压比大的关键

**整改**:6-25 女王追问,网上查证三类阀型减压比分层(10:1 / 100:1 / 600:1+)。

## 错误根源分析

### 共同根源:混淆"压力容器"与"常压储罐"

我多次把常压储罐的保护哲学套用压力容器的,导致:
- 错误要求加 PSV
- 错误要求加 PRV
- 错误要求气动阀
- 错误升级设计压力

**根本认知**:常压储罐 ≠ 压力容器,保护哲学完全不同。

### 共同根源:不熟悉 ZZDQ 自力式阀

ZZDQ 是国内 N₂ 封专用阀(带指挥器),具有:
- 减压比 600:1+
- 单级搞定
- 无需外加 PRV
- 价格便宜(¥8,000-12,000)
- 防爆

我多次忽略 ZZDQ 的存在,按通用调节阀思路设计。

### 共同根源:凭印象回答,未查证标准

我多次凭"印象"和"工业实践"回答,未实际查证 SH/T 3007、API 2000、GB 50341 等标准。

**改进**:所有 N₂ 封相关问题,**必须先查网上/标准/规范**,再回答。

## 避坑检查清单 (出方案前必查)

### 罐型判定 (3 项)
- [ ] **罐设计压力 ≤ 100 kPa?**
  - 是 → 常压储罐(呼吸阀+紧急泄放装置)
  - 否 → 压力容器(必须 PSV)
- [ ] **介质可燃/有毒?**
  - 是 → 接火炬 + 阻火器
  - 否 → 可直排大气
- [ ] **介质特性**(凝固点/沸点/闪点/黏度)
  - 决定是否需要伴热/保温

### N₂ 阀选型 (3 项)
- [ ] **N₂ 减压比?**
  - ≤ 10:1 → 气动/电动调节阀(可精确控制)
  - 10-100:1 → 自力式(单级无指挥器)
  - **> 100:1 → ZZDQ 自力式(带指挥器)** ⭐
- [ ] **罐区位置?**
  - 偏远罐区 → 自力式(无电无气)
  - 控制室附近 → 任意
- [ ] **介质可燃?**
  - 是 → 防爆型
  - 否 → 普通型

### 罐顶附件 (5 项)
- [ ] **N₂ 封接管**(DN25-50)
- [ ] **呼吸阀 PVRV**(±0.5 kPa,双阀盘)
- [ ] **紧急泄放装置**(2-3 kPa,大罐用人孔)
- [ ] **阻火器 FA**(可燃介质必须)
- [ ] **液位计/温度计/压力表**(工艺要求)

### 设计参数 (3 项)
- [ ] **设计压力** = 最大操作压力 × 安全系数
- [ ] **操作温度** = 工艺要求 ±5°C
- [ ] **装填系数** = 储罐 0.85,吸热 0.45,放热 0.50
