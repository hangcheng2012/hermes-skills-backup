# 8 铁律详细说明 (v1.0)

> 女王 06-25 立规: 储罐 N₂ 封设计按本 8 铁律执行。本文档详细说明每条铁律的来由和实施细节。

## 铁律 ① 常压储罐 ≠ 压力容器

### 规则
- **常压储罐**(设计压力 ≤ 100 kPa):不用 PSV,用**紧急泄放装置**
- **压力容器**(设计压力 > 100 kPa):必须 PSV(GB 150 + GB/T 12241)

### 实施
| 设备类型 | 设计压力 | 超压保护 |
|---|---|---|
| 储罐(常压) | 2-10 kPa | **紧急泄放人孔**(DN100-1500) |
| 容器(低压) | 10-100 kPa | PSV(弹簧式)+ 紧急泄放装置 |
| 容器(中压) | 100-1000 kPa | PSV(必须) |
| 容器(高压) | > 1000 kPa | PSV(必须)+ 安全阀组 |

### 来源
女王 06-25 指出 "常压储罐是不是就不用设安全阀了",网上查证 SH/T 3007 + API 2000 + GB 50341 确认:
- 常压储罐**强制要求**:**呼吸阀 + 紧急泄放装置**(非 PSV)
- PSV 只用于压力容器

## 铁律 ② ZZDQ 自力式阀(带指挥器)直接接 N₂ 主管

### 规则
- **N₂ 主管 0.6 MPa → ZZDQ 自力式阀 → 罐顶 0.5-1 kPa**
- 单级减压即可
- 减压比 600:1+ 完全可处理

### 实施
```
N₂ 主管 0.6 MPa (600 kPa)
    ↓
ZZDQ 自力式阀(带指挥器)
    ↓
罐顶 N₂ 封 0.5-1 kPa
```

### ZZDQ 工作原理
- **指挥器(pilot)先承受大压差** → 产生小信号
- **主阀(main)跟随指挥器信号** → 大流量调节
- 类似"先小阀再大阀"的两级逻辑
- 单阀实现减压比 600:1+

### 来源
网上查证:
- ZZDQ/ZZH/ZZN 系列产品规格
- PN1.6 MPa 等级
- 调压范围 0.2-40 kPa(根据 DN)
- 供气压力 0.1-1 MPa

## 铁律 ③ ZZDQ = 供氮 + 泄氮一体化

### 规则
- ZZDQ **一个阀**兼供氮和泄氮功能
- 不需要单独泄氮阀

### 实施
| 功能 | 触发条件 | ZZDQ 动作 |
|---|---|---|
| 供氮 | 罐压 < 设定值 | 指挥器开大主阀,N₂ 进罐 |
| 泄氮 | 罐压 > 设定值 | 指挥器关小主阀,N₂ 排出 |
| 维持 | 罐压 = 设定值 | 主阀微调,维持压力 |

### 来源
ZZDQ 型氮封装置标准:
- 供氮装置:ZZH 型带指挥器自力式压力调节阀
- 泄氮装置:ZZN 型自力式压力调节阀
- 二者通过指挥器联动,**1 个阀组同时实现**

## 铁律 ④ 可燃介质必须接管去火炬

### 规则
- **可燃介质**(PTMG、TDI 等)不可直排大气
- 必须接 NF 管至火炬或 VOC 回收装置
- 排火炬口必须加阻火器

### 实施
| 介质类型 | 排放方式 | 理由 |
|---|---|---|
| 惰性气体(N₂、空气、水蒸气) | 可直排大气 | 无燃爆风险 |
| **可燃气体/蒸汽**(PTMG 等) | **必须接管去火炬** ⭐ | 防燃爆 + 防 VOCs |
| **毒害气体**(TDI 等) | **必须火炬 + 处理** | 防中毒 + 防污染 |
| 油气 | 接管 VOC 回收 | 环保节能 |

### 阻火器必须
- 排火炬口前必须装阻火器
- 防火焰回窜至罐体
- 符合 SH/T 3413 标准

## 铁律 ⑤ 常压罐标配:呼吸阀 + 紧急泄放装置

### 规则
- **呼吸阀**:±0.5 kPa,日常热胀冷缩保护
- **紧急泄放装置**:2-3 kPa,防火灾/超压保护
- **不是 PSV**(PSV 只用于压力容器)

### 实施

#### 呼吸阀 PVRV
| 参数 | 值 |
|---|---|
| 类型 | 双阀盘(正压+负压) |
| 正压设定 | +0.5 kPa |
| 负压设定 | -0.2 kPa |
| 通径 | DN50-100 |
| 用途 | 日常热胀冷缩 |

#### 紧急泄放装置
| 参数 | 值 |
|---|---|
| 类型 | 铰链盖/弹簧式 |
| 设定压力 | 2-3 kPa |
| 通径 | DN50-1500(根据罐容) |
| 200L 小罐 | DN50-100 |
| 2-100 m³ 中罐 | DN150-300 |
| 100+ m³ 大罐 | DN500-1500(人孔) |
| 用途 | 防火灾/超压/失控反应 |

## 铁律 ⑥ 椭圆封头可开孔

### 规则
- 椭圆封头**(2:1 椭圆比)顶部中心**可以开孔
- 开孔尺寸规范:
  - DN100 以下:无需补强
  - DN100-300:需补强(按 GB 150 计算)
  - DN300+:用大法兰人孔,需详细计算

### 实施
- N₂ 封接管:DN25-50(无需补强)
- 紧急泄放装置:DN100(200L 小罐,无需补强)
- 呼吸阀:DN50-100(无需补强)
- 阻火器:DN50-100(无需补强)
- 液位计:DN20(无需补强)

### 椭圆封头应力分布
- 顶部中心:应力最小(薄膜应力)
- 边缘过渡区:应力最大(弯曲应力)
- 推荐:接管开在顶部中心区域
- 避免:接管开在封头边缘(应力集中)

## 铁律 ⑦ 三类阀减压比限制

### 减压比 = 阀前压力 / 阀后压力

| 阀型 | 减压比上限 | 失效模式 | 来源 |
|---|---|---|---|
| **气动调节阀**(普通) | **≤ 10:1** | 气蚀/闪蒸/阀芯振动 | GB/T 4213 |
| **自力式(单级无指挥器)** | **≤ 100:1** | 主阀膜片疲劳 | ZZVP/N 规范 |
| **自力式(带指挥器 ZZDQ)** ⭐ | **600:1+** | 指挥器故障(罕见) | ZZDQ 设计 |

### 实际应用案例

| 应用 | 阀前 | 阀后 | 减压比 | 适用阀型 |
|---|---|---|---|---|
| V-101 PTMG N₂ 封 | 0.6 MPa | 0.5-1 kPa | **600:1** | **ZZDQ(带指挥器)** |
| V-102 TDI N₂ 压料 | 0.6 MPa | 0.1 MPa | 6:1 | 任何阀 |
| V-103 DETDA N₂ 封 | 0.6 MPa | 0.5-1 kPa | 600:1 | ZZDQ |
| 反应釜 N₂ 微调 | 50 kPa | 50 kPa | 1:1 | 自力式微压 |

### 来源
- ZZVP/N 规范:"减压比大于100 要用两级降压"
- ZZDQ 设计规格:供气 0.1-1 MPa,出口 0.2-40 kPa
- 气动调节阀:GB/T 4213 ≤ 10:1(气蚀/闪蒸限制)

## 铁律 ⑧ 自力式不需气源/电源

### 规则
- 自力式调节阀利用**介质自身能量**驱动
- **不需要**外部电源或气源
- 适合偏远罐区/危险区

### 自力式优势

| 优势 | 详细 |
|---|---|
| **无电无气** | 利用被调介质自身压力的变化作为动力源 |
| **绝对防爆** | 无电气元件,符合 EN 13463-1 标准 |
| **故障点少** | 相对气动/电动,无中间仪表/辅助仪表 |
| **节能** | 不消耗压缩空气/电力 |
| **维护简单** | 几乎免维护,运行中可调压力设定点 |

### 气动 vs 自力式对比

| 对比项 | 自力式 | 气动调节阀 |
|---|---|---|
| 驱动能源 | 介质自身 | 0.4-0.6 MPa 压缩空气 |
| 控制信号 | 无 | 4-20 mA / 0.02-0.1 MPa |
| 辅助设备 | 几乎无 | 气源管+电磁阀+定位器+I/P |
| 防爆性 | 绝对防爆 | 需防爆型 |
| 价格 | ¥5,000-15,000 | ¥30,000-50,000 |
| 运行费用 | 几乎为 0 | 压缩空气消耗 |
| 适用场景 | **储罐 N₂ 封** | 流量/温度/液位精确控制 |
