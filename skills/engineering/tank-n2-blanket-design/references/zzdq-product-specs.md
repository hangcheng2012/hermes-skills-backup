## 一、ZZDQ 氮封装置概述

### 工作原理

ZZDQ 氮封装置由**供氮装置**和**泄氮装置**两部分组成:
- 供氮装置:ZZH 型带指挥器自力式压力调节阀
- 泄氮装置:ZZN 型自力式压力调节阀

**协调工作**:
- 罐压 < 设定值 → 供氮阀打开,N₂ 进罐
- 罐压 > 设定值 → 泄氮阀打开,N₂ 排出
- 罐压 = 设定值 → 两阀微调,维持压力

## 五、安装要求

### ZZDQ 阀安装规范

| 项目 | 要求 |
|---|---|
| 安装位置 | 距离管件 ≥ 6 倍 DN |
| 管道方向 | 水平管道,阀体向上 |
| 引压管位置 | 顶部或侧面(不底部) |
| 取压点 | 离调压阀 ≥ 6 倍 DN |
| 上下游阀门 | 装截止阀 + 旁通阀 |
| 压力表 | 上下游各 1 个 |
| 安装前 | 冲洗管道,清除杂质 |
| 安装时 | 无压状态 |
| 安装方向 | 介质流向与箭头一致 |

## 六、调压步骤(投运)

### 启动前检查
1. 检查阀门外观无损坏
2. 检查紧固件无松动
3. 确认流向正确
4. 冲洗管道,清除杂质
5. 安装压力表
6. 关闭上下游截止阀

### 调压步骤
1. **关闭旁通阀**
2. **缓慢打开上游截止阀**
3. **观察压力表,达到预定压力**
4. **调整设定点调节器**:
   - 顺时针 → 提高设定压力
   - 逆时针 → 降低设定压力
5. **缓慢打开下游截止阀**
6. **观察罐压变化**,微调设定点
7. **记录设定压力**

### 停运步骤
1. 关闭下游截止阀
2. 关闭上游截止阀
3. 打开旁通阀(如有)
4. 释放管内压力
5. 拆卸阀门(如需)

## 七、维护要求

### 定期检查

| 项目 | 频次 | 内容 |
|---|---|---|
| 压力表校验 | 每年 | 精度 ±1% |
| 设定压力校验 | 每年 | 与设计压力对比 |
| 膜片检查 | 每 2 年 | 是否老化/破裂 |
| 弹簧检查 | 每 2 年 | 是否疲劳/腐蚀 |
| 阀芯阀座 | 每 2 年 | 密封性,是否磨损 |
| 整体更换 | 每 5 年 | 大修或更换 |

### 常见故障

| 故障 | 原因 | 解决 |
|---|---|---|
| 罐压持续升高 | 供氮阀堵塞/泄氮阀失效 | 检查指挥器,清理阀芯 |
| 罐压持续降低 | 泄氮阀失效/供氮阀开度小 | 检查指挥器,清理阀芯 |
| 设定压力漂移 | 弹簧疲劳/膜片老化 | 更换弹簧/膜片 |
| 阀门泄漏 | 阀芯磨损/密封圈损坏 | 更换阀芯/密封圈 |
| 阀门卡死 | 杂质堵塞/腐蚀 | 清洗或更换阀门 |

## 八、选型计算示例

### V-101 PTMG 储罐 N₂ 封选型

**已知**:
- 罐容积:V = 200 L
- 罐操作压力:P₂ = 0.5-1 kPa
- N₂ 主管压力:P₁ = 0.6 MPa = 600 kPa
- N₂ 温度:T = RT(25°C)
- N₂ 纯度:99.999%
- 减压比:600/1 = 600:1

**选型步骤**:
1. **确定阀型**:减压比 600:1 → **ZZDQ 自力式(带指挥器)** ⭐
2. **确定 DN**:N₂ 流量小 → DN25
3. **确定 PN**:PN1.6 MPa(足够)
4. **确定调压范围**:0.5-1 kPa → 选 DN25 调压范围 0.5-4.5 kPa
5. **确定材质**:PTMG 无腐蚀 → WCB(碳钢)或 CF8(304)
6. **确定温度**:N₂ RT → 标准配置

**最终选型**:
```
ZZDQ-16-25-C-WCB-0.5/4.5 kPa
│  │ │  │ │     │     │
│  │ │  │ │     │     └─ 调压范围
│  │ │  │ │     └─ 阀体材质
│  │ │  │ └─ 连接(法兰)
│  │ │  └─ DN25
│  │ └─ PN1.6
│  └─ ZZDQ 氮封装置
└─ 完整型号
```
