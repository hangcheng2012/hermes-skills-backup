# 常压储罐 vs 压力容器:保护哲学完全对比

> 女王 06-25 立规: 这是 N₂ 封设计最根本的认知。常压储罐与压力容器的保护哲学**完全不同**,不能用同一套思路。

---

## 一、定义与分类

### 设计压力分类

| 类型 | 设计压力范围 | 规范分类 |
|---|---|---|
| **常压储罐** | -0.5 ~ +10 kPa (典型 2 kPa) | SH/T 3007 + GB 50341 |
| **低压储罐** | 10 ~ 100 kPa | SH/T 3046 |
| **压力容器** | > 100 kPa (0.1 MPa) | GB 150 + TSG 21 |

### 设计压力判定(简化)

```
设计压力 P
├─ P ≤ 10 kPa → 常压储罐(SH/T 3007)
├─ 10 < P ≤ 100 kPa → 低压储罐(SH/T 3046)
└─ P > 100 kPa → 压力容器(GB 150)
```

### V-101 PTMG 储罐
- 设计压力:**2 kPa**
- **常压储罐** ✅
- 规范:SH/T 3007-2014 + GB 50341-2014

### V-102 TDI 储罐
- 设计压力:**0.1 MPa = 100 kPa**
- **边界**(按压力容器 GB 150 处理,因为 TDI 是剧毒品)
- 规范:GB 150 + TSG 21

## 二、保护哲学根本差异

### 常压储罐保护哲学

**核心思想**:**罐体不能承受高压力,失压保护采用大面积泄放**。

**保护装置**(3 大件):
1. **呼吸阀**(Breather Valve)
   - 设定压力:**±0.5-2 kPa**
   - 功能:日常热胀冷缩
   - 通径:DN50-150(大罐用更大)

2. **紧急泄放装置**(Emergency Vent)
   - 设定压力:**2-5 kPa**
   - 功能:防火灾/超压/失控反应
   - 通径:**DN500-1500(人孔级)** ⭐
   - 不是阀门,是大面积泄放

3. **阻火器**(Flame Arrester)
   - 设定:—
   - 功能:防回火
   - 通径:DN50-100

**设计原则**:
- **没有 PSV**(弹簧式安全阀)
- **没有 PRV**(压力调节阀,大罐有 PIC 分程控制)
- 用大面积泄放应对火灾
- 用呼吸阀应对日常热胀

### 压力容器保护哲学

**核心思想**:**罐体能承受高压力,失压保护用弹簧式安全阀**。

**保护装置**(必须):
1. **PSV(Pressure Safety Valve)** ⭐ 必须
   - 设定压力:**设计压力 × (1.05-1.10)**
   - 功能:超压保护
   - 通径:DN25-100
   - 符合 GB/T 12241

2. **PRV(Pressure Regulating Valve)**
   - 设定压力:工艺操作压力
   - 功能:压力调节
   - 通径:DN25-100

3. **爆破片**(Rupture Disc)
   - 设定压力:**设计压力 × 1.0**
   - 功能:紧急失压保护
   - 可与 PSV 串联或单独使用

**设计原则**:
- **必须 PSV**(GB 150 强制)
- 用弹簧式安全阀精确控制
- 火灾工况用 PSV 排放,容器能承受

## 三、对比表

| 维度 | 常压储罐 | 压力容器 |
|---|---|---|
| **设计压力** | -0.5 ~ +10 kPa | > 100 kPa |
| **超压保护** | **紧急泄放装置**(大面积泄放) | **PSV**(弹簧式安全阀) |
| **超压设定** | 2-5 kPa | 设计压力 × 1.05-1.10 |
| **超压通径** | DN500-1500(人孔级) | DN25-100(阀门) |
| **日常保护** | 呼吸阀(±0.5 kPa) | PIC + PRV |
| **失压保护** | 呼吸阀负压部分 | 爆破片或 PIC |
| **阻火器** | 必须(可燃介质) | 按需 |
| **泄放去向** | 大气(不可燃)或火炬(可燃) | 火炬或回收 |
| **规范** | SH/T 3007 + GB 50341 | GB 150 + TSG 21 |
| **计算方法** | API 2000(火灾工况) | GB 150(超压保护) |
| **设计余量** | 小(操作压力低) | 大(操作压力高) |

## 四、为什么会有这种差异?

### 物理本质

**常压储罐**:
- 罐壁薄(200L 罐 ~3-4 mm)
- 设计压力低(2 kPa)
- **失压能力差**:100 kPa 大气压会**压塌罐体**
- 紧急工况需要**快速大面积泄放**而非精确控制
- 用**大面积泄放装置** = 人孔级 DN500+

**压力容器**:
- 罐壁厚(中压容器 ~10-20 mm)
- 设计压力高(0.1-10 MPa)
- 失压能力强:罐体能承受内压
- 紧急工况可以用**小阀门精确控制**
- 用**PSV**(DN25-100)

### 工业实践

| 工业应用 | 罐型 | 保护方案 |
|---|---|---|
| 油品储罐 | 常压储罐 | 呼吸阀 + 紧急泄放人孔 + 阻火器 |
| 化工原料储罐 | 常压/低压 | 呼吸阀 + 紧急泄放 + N₂ 封 |
| 反应釜 | 压力容器 | PSV + PIC + PRV |
| 分离器 | 压力容器 | PSV + PIC |
| 缓冲罐 | 压力容器 | PSV + PIC |
| 换热器 | 压力容器 | PSV(每台) |

## 五、对 V-101/V-102/V-103 的应用

### V-101 PTMG 储罐(200L, 2 kPa) — 常压储罐 ⭐

**设计压力**:2 kPa
**规范**:SH/T 3007 + GB 50341
**保护方案**:
- **不用 PSV** ⭐(常压罐不需要)
- 呼吸阀 PVRV-101 ±0.5 kPa
- 紧急泄放装置 DN100(2-3 kPa)
- ZZDQ 氮封装置(自力式)
- 阻火器 FA-101

### V-102 TDI 储罐(50L, 0.1 MPa) — 边界(按压力容器) ⭐

**设计压力**:0.1 MPa = 100 kPa
**规范**:GB 150 + TSG 21(按压力容器)
**保护方案**:
- **必须 PSV-102** ⭐(压力容器边界)
- PSV 设定:0.11-0.15 MPa
- 呼吸阀
- ZZDQ 氮封装置
- 阻火器

**理由**:TDI 是剧毒品(甲类),即使设计压力在边界,也按压力容器严格处理,加 PSV。

### V-103 DETDA 储罐(25L, 2 kPa) — 常压储罐 ⭐

**设计压力**:2 kPa
**规范**:SH/T 3007 + GB 50341
**保护方案**:
- **不用 PSV** ⭐(常压罐)
- 呼吸阀 PVRV-103 ±0.5 kPa
- 紧急泄放装置 DN80(2-3 kPa)
- ZZDQ 氮封装置(自力式)
- 阻火器 FA-103

## 七、紧急泄放装置 vs PSV:关键区别

### 紧急泄放装置(Emergency Vent)

| 项目 | 值 |
|---|---|
| **设定压力** | 2-5 kPa(罐操作压力的 2-5 倍) |
| **类型** | 铰链盖/弹簧式大面积泄放 |
| **通径** | DN500-1500(人孔级) |
| **工作原理** | 重锤/弹簧/铰链,超压自动打开 |
| **排放能力** | 大(几百 m³/h) |
| **泄漏等级** | 不要求严密(泄放用) |
| **规范** | API 2000 / SH/T 3007 |
| **适用** | **常压储罐**(设计压力低) |

### PSV(Pressure Safety Valve)

| 项目 | 值 |
|---|---|
| **设定压力** | 设计压力 × 1.05-1.10(精度高) |
| **类型** | 弹簧式安全阀 |
| **通径** | DN25-100 |
| **工作原理** | 弹簧压缩,超压自动打开 |
| **排放能力** | 中(几十 m³/h) |
| **泄漏等级** | 严密(VI级) |
| **规范** | GB/T 12241 / API 520/521 |
| **适用** | **压力容器**(设计压力高) |

### 为什么常压罐用紧急泄放装置而不是 PSV?

**关键原因**:常压罐不能承受高压力。
- PSV 设定压力 = 设计压力 × 1.05-1.10
- 常压罐设计压力 2 kPa
- PSV 设定压力 = 2.1-2.2 kPa
- 紧急泄放装置设定压力 = 2-3 kPa(类似)

**但当火灾时**:罐内物料温度升高,蒸汽压上升
- PTMG 闪点 200°C,火灾温度 800°C
- 罐内压力可能升至 5-10 kPa
- **罐壁承受不了 10 kPa**(设计压力 2 kPa)
- 罐会先于 PSV 失效

**解决方案**:用紧急泄放装置(大面积泄放)
- 设定 2-3 kPa,罐压稍升即打开
- 大面积快速泄放,不让罐压持续上升
- 即使 PSV 也来不及,需要面积足够大的泄放装置

**结论**:常压罐用**大面积紧急泄放装置**,不是 PSV。
