# 储罐 N₂ 封设计前自检清单 (Pre-design Checklist)

> 女王 06-25 立规: 每次出储罐 N₂ 封方案前必过此清单。**打勾 = 确认 = 出方案**

---

## A. 罐型判定 (4 项)

- [ ] **A1.** 罐设计压力确认
  - 设计压力 ≤ 100 kPa → 常压储罐
  - 设计压力 > 100 kPa → 压力容器
  - **本罐设计压力 = ___ kPa**

- [ ] **A2.** 罐容积确认
  - 容积 = ___ L(或 m³)
  - 装填系数 = ___(储罐 0.85 / 吸热 0.45 / 放热 0.50)
  - 装填量 = ___ L

- [ ] **A3.** 介质类型判定
  - 惰性气体 / 不可燃液体 → 可直排大气
  - **可燃液体/蒸汽 → 必须接管去火炬** ⭐
  - 毒害品 → 必须火炬 + 处理
  - **本罐介质 = ___, 类别 = ___(可燃/不可燃/毒害)**

- [ ] **A4.** 罐顶形状判定
  - **椭圆封头(2:1)** ✅ 推荐
  - 锥顶
  - 平顶
  - **本罐顶形状 = ___**

---

## B. N₂ 阀选型 (3 项) ⭐ 关键

- [ ] **B1.** N₂ 减压比计算 ⭐
  - 减压比 = N₂ 主管压力 / N₂ 封压力 = ___ MPa / ___ kPa = ___:1
  - **如果 > 100:1** → 必须用 **ZZDQ 自力式(带指挥器)**
  - **如果 10-100:1** → 可用普通自力式
  - **如果 ≤ 10:1** → 可用气动调节阀

- [ ] **B2.** 阀型选择 ⭐
  - **N₂ 封场景首选 ZZDQ 自力式(带指挥器)** ⭐
  - 不需要外加 PRV
  - 不需要气源/电源
  - 减压比能力:600:1+

- [ ] **B3.** 阀参数确认
  - DN = ___(N₂ 封常用 DN25)
  - PN = ___(常用 PN1.6 MPa)
  - 调压范围 = ___(V-101: 0.5-1 kPa)
  - 材质 = ___(WCB/CF8/CF8M,根据介质)

---

## C. 罐顶附件 (5 项)

- [ ] **C1.** N₂ 封接管(必须)
  - DN25-50
  - 位置:椭圆封头顶部中心
  - 接 ZZDQ 阀出口

- [ ] **C2.** 呼吸阀 PVRV(必须)
  - DN50-100
  - 设定:±0.5 kPa(正压+负压双阀盘)
  - 位置:罐顶封头边缘
  - **注意:呼吸阀已含真空保护,不需要单独 PVRV** ⭐

- [ ] **C3.** 紧急泄放装置(必须) ⭐
  - DN50-1500(根据罐容)
  - 200L 小罐:DN100
  - 设定:2-3 kPa
  - 类型:铰链盖/弹簧式
  - 位置:罐顶(小罐在封头边缘,大罐在筒体顶部人孔)

- [ ] **C4.** 阻火器 FA(可燃介质必须)
  - DN50-100
  - 位置:排火炬口前
  - 符合 SH/T 3413

- [ ] **C5.** 工艺接管(按需)
  - 液位计:DN20
  - 温度计:DN20
  - 压力表:DN15
  - 进料口:DN25-50
  - 出料口:DN25-50

---

## D. 排放方式 (2 项)

- [ ] **D1.** 排放位置确认
  - 可燃介质 → **必须接管去火炬(NF)** ⭐
  - 惰性气体 → 可直排大气
  - 毒害品 → 必须火炬 + 处理
  - 油气 → 接管 VOC 回收

- [ ] **D2.** 火炬接口确认
  - NF 至火炬管规格 = ___
  - 阻火器在 NF 接管前
  - 与厂区火炬系统连接

---

## E. 设计参数 (3 项)

- [ ] **E1.** 操作温度
  - **本罐操作温度 = ___ °C**
  - 依据:介质凝固点/工艺要求
  - 防凝固/防过热

- [ ] **E2.** 操作压力
  - **本罐操作压力 = ___ kPa**(常压罐 0.5-3 kPa)
  - 设计压力 = 操作压力 × 安全系数
  - **常压罐设计压力通常 ≤ 10 kPa**

- [ ] **E3.** 装填系数
  - 储罐 = 0.85
  - 吸热反应 = 0.45
  - 放热反应 = 0.50
  - 真空脱气 = 0.50

## F. 防爆与安全 (3 项)

- [ ] **F1.** 介质特性
  - 闪点 = ___ °C
  - 爆炸极限 = ___ %(V/V)
  - 毒性 = ___(LD50)
  - MSDS 已查证

- [ ] **F2.** 防爆要求
  - 介质可燃/有爆炸危险?
  - **N₂ 封阀 + 仪表必须防爆型** ⭐
  - 自力式阀**绝对防爆**(无电气元件)

- [ ] **F3.** 报警联锁
  - 罐压高报警(>2 kPa)
  - 罐压低报警(<0.3 kPa)
  - N₂ 流量异常报警
  - O₂ 含量分析(可燃介质)

## H. 安装要求 (3 项)

- [ ] **H1.** ZZDQ 阀安装位置
  - 距离管件 ≥ 6 倍 DN(避免流体扰动)
  - 水平管道,阀体向上
  - 引压管:**顶部或侧面**(不底部,防杂质)
  - 上下游装截止阀 + 旁通阀
  - 上下游装压力表

- [ ] **H2.** 罐顶接管位置
  - N₂ 封接管:椭圆封头顶部中心
  - 呼吸阀:罐顶封头边缘
  - 紧急泄放装置:罐顶(小罐在封头)
  - 阻火器:排火炬口前

- [ ] **H3.** 管线连接
  - N₂ 封管线 DN25(常用)
  - 火炬管线 DN25-50
  - 进料/出料管线 DN25-50
  - 仪表管线 DN15

## I. 历史错误避免 (8 项) ⭐ 06-25 立规

- [ ] **I1.** 常压罐不加 PSV
  - **用紧急泄放装置**(非 PSV)
  - V-101 设计压力 2 kPa = 常压储罐
  - PSV 只用于压力容器(>100 kPa)

- [ ] **I2.** N₂ 阀首选 ZZDQ 自力式(带指挥器)
  - 单级减压即可,减压比 600:1+
  - 不需要外加 PRV
  - 不需要两级减压

- [ ] **I3.** ZZDQ = 供氮 + 泄氮一体化
  - 1 个阀搞定全部
  - 不需要单独泄氮阀

- [ ] **I4.** 可燃介质接管去火炬
  - 不可直排大气
  - NF 管 + 阻火器
  - PTMG/TDI 等必须遵守

- [ ] **I5.** 常压罐标配呼吸阀 + 紧急泄放装置
  - 呼吸阀 ±0.5 kPa(日常保护)
  - 紧急泄放装置 2-3 kPa(防火灾)
  - 不是 PSV

- [ ] **I6.** 椭圆封头可开孔
  - DN100 以下无需补强
  - DN100-300 需补强
  - 顶部中心应力最小

- [ ] **I7.** 三类阀减压比分清
  - 气动 ≤ 10:1
  - 普通自力式 ≤ 100:1
  - **带指挥器自力式(ZZDQ) 600:1+** ⭐

- [ ] **I8.** 自力式不需气源/电源
  - 介质自身能量驱动
  - 绝对防爆
  - 适合罐区/危险区
