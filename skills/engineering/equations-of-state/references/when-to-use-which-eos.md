# EOS 选择决策树 — 何时用 SRK / PR / SW / 其他

> **本文件是 equations-of-state SKILL 的 references/ 详解之一**。
> 为女王工程决策提供具体可执行的 EOS 选择规则。

---

## 一、EOS 选择的核心判据(3 个维度)

**任何 EOS 选择,都先问 3 个问题:**

1. **精度需求:** ± 5%?± 1%?± 0.1%?
2. **工况:** 临界点附近?高压气相?液相密度?VLE?
3. **物质:** CO₂?烃类?极性?混合物?

**3 个维度决定 EOS 选择。**

## 二、按工况选择(决策树主图)

### 2.1 总决策树

```
开始
│
├── 计算什么?
│   ├── 单组分物性
│   │   ├── 远离临界点 + 工艺精度(±5%)
│   │   │   └── PR EOS(若无 + 良好 k_ij)
│   │   │
│   │   ├── 临界点附近 / 国家标准
│   │   │   └── 多参数 EOS(SW for CO₂、IAPWS for 水、GERG for 天然气)
│   │   │
│   │   └── 教学 / 示意
│   │       └── SRK EOS
│   │
│   ├── 混合物 VLE 或闪蒸
│   │   ├── 一般工艺(±5%)
│   │   │   └── PR EOS + 混合规则 + k_ij
│   │   │
│   │   ├── 高精度 / 强极性
│   │   │   └── PR + Huron-Vidal 混合规则
│   │   │       (或 NRTL / UNIQUAC,不再用 EOS)
│   │   │
│   │   └── 含水 / 缔合
│   │       └── SAFT-γ Mie 或 SAFT-VR Mie
│   │
│   ├── 反应器热平衡 / 物料平衡
│   │   ├── 气相反应
│   │   │   └── PR EOS
│   │   ├── 液相反应
│   │   │   └── PR EOS(反应物 / 产物在液相)
│   │   └── 超临界反应(scCO₂ etc.)
│   │       └── PR EOS(远离临界点)或 SW EOS(临界附近)
│   │
│   ├── 压力容器 PSV / 安全泄放
│   │   ├── 临界点附近 / 干冰风险
│   │   │   └── SW EOS + 气体流量
│   │   └── 一般气体 / 蒸气
│   │       └── PR EOS + ASME 标准
│   │
│   └── 流体输送 / 黏度 / 密度
│       └── PR EOS(常温恒压)+ CoolProp / VisCalc(变温变压)
│
├── 需要实验级精度?
│   └── 是 → SW / IAPWS / GERG + REFPROP 校核
│
└── 具体介质?
    ├── CO₂ → SW EOS(REFPROP 默认)
    ├── H₂O / 蒸汽 → IAPWS-IF97
    ├── CH₄ / 天然气 → GERG-2008
    ├── 烃类混合物 → PR EOS(石油化工标准)
    ├── 极性(醇、醛、酮、羧酸)→ PR + Huron-Vidal 或 NRTL
    └── 缔合 / 离子液体 → SAFT-γ Mie / COSMO-RS
```

## 三、按介质类型的选择表

### 3.1 主流介质 — 推荐 EOS 对照

| 介质 | 推荐 EOS | 实现方式 | 误差 |
|------|----------|----------|------|
| **CO₂** | **SW EOS** | REFPROP / CoolProp | < 0.1% |
| **水 / 蒸汽** | **IAPWS-IF97** | 内置 + 数据库 | < 0.1% |
| **天然气(CH₄ + CO₂ + N₂ + ...)** | **GERG-2008** | REFPROP / CoolProp | < 1% |
| **空气(N₂ + O₂)** | **PR EOS** | CoolProp / Aspen | < 1% |
| **CH₄(纯)** | **PR EOS** | CoolProp | 2~5% |
| **C₂H₆~C₄H₁₀(轻烃)** | **PR EOS** | Aspen / ProMax | 2~3% |
| **C₅+ 烃类** | **PR EOS + DB**(DIPPR)| Aspen | 3~5% |
| **H₂** | **PR EOS**(临界参数 33 K, 1.3 MPa)| CoolProp | 1~3% |
| **NH₃** | **PR EOS + Huron-Vidal** | Aspen | 2~5% |
| **Cl₂ / HCl / HBr / HF** | **PR EOS** | Aspen | 1~3% |
| **醇(甲醇、乙醇、... )** | **PR EOS + Huron-Vidal**或**SAFT** | Aspen / 自实现 | 3~7% |
| **羧酸(乙酸、丙酸)** | **SAFT-γ Mie** | 自实现 / COSMO | 5~10% |
| **离子液体** | **COSMO-RS** | COSMO 软件 | 5~15% |
| **聚合物熔体** | **SAFT-VR Mie** | 自实现 | 5~10% |
| **强缔合流体(乙酸、HF)** | **SAFT + association term** | 自实现 | 5~10% |

## 六、按工艺阶段的工程选择

### 6.1 概念设计 / PFD 出图

**目标:** 给物料 + 能量衡算 **数量级正确**(±10%)

**推荐:** PR EOS + Aspen 默认物性库

**关键:**
- 不必纠结 EOS 精度
- 用 CO₂ 时换 SW EOS
- 强极性(醇 + 水)换 SAFT 槽

### 6.2 工艺包 / P&ID 出图

**目标:** 给设备选型提供物性输入(±5%)

**推荐:** PR EOS + 实验校核关键点

**关键:**
- 临界点附近换 SW
- 强极性换 PR + Huron-Vidal
- 部分关键物性需实验测定

### 6.3 详细设计 / 反应器 / 减压脱气

**目标:** 物性输入与设计计算一致(±1~3%)

**推荐:** SW EOS 或 SW + REFPROP 校核

**关键:**
- 整个工艺都用 SW
- 用 CoolProp 编程算全流程
- 实验数据校核各关键点

### 6.4 国家级 / 高精度 / 论文 / 国防

**目标:** 误差 < 0.5%

**推荐:** REFPROP(全温压拟合)+ 实验校核

**关键:**
- 不允许用立方型 EOS
- 全部用 SW / IAPWS / GERG
- 报告列出每项 EOS 的选择依据

## 七、EOS 选择常见误区

### 7.1 误区 ① "Aspen 默认就够"

**错!** Aspen 默认 PR + 自带物性库 = 5% 误差,对**国家级别精度**远远不够。

**正确:** 国家级数据必须用 REFPROP(SW EOS)

### 7.2 误区 ② "用 SW EOS 一定更好"

**对!** 但 SW EOS 需要数据库支持。**没有 CoolProp / REFPROP 时,SW EOS 不能直接用。**

**正确:** 没有数据库支持时,用 PR EOS + 实验校核;有数据库时,工况允许就用 SW。

### 7.3 误区 ③ "PR EOS 适用于任何物质"

**错!** PR 是弱极性优先的立方型 EOS。

**错的应用:**
- 醋酸(强缔合)用 PR → 5~15% 误差
- 离子液体用 PR → 30%+ 误差
- 醇 + 水用 PR → 5~10% 误差(需 Huron-Vidal)

### 7.4 误区 ④ "二元混合物不加 k_ij"

**错!** 混合物必需有交互参数 k_ij,**不查表 = 5~15% 误差**。

**正确:** 严格查 NIST TDE / DECHEMA / DIPPR

### 7.5 误区 ⑤ "EOS 给的密度精确到 g/cm³ = 直接用"

**警惕!** EOS 给的密度在某些工况下偏差大:
- 临界 ±5%:立方型误差 5~15%
- 强极性 + 高压:可能偏差更大

**正确:** 校核关键点 vs NIST 实验数据

## 九、决策树速查

```
1. 介质是什么?
   ├── CO₂ → SW EOS(CoolProp)
   ├── 蒸汽 → IAPWS-IF97
   ├── 天然气 → GERG-2008
   ├── 烃类 → PR EOS(Aspen 默认)
   └── 极性 / 缔合 → SAFT 系

2. 计算精度?
   ├── ±0.1% → SW / IAPWS / GERG + REFPROP 校核
   ├── ±1% → SW EOS + CoolProp
   ├── ±5% → PR EOS + 实验校核
   └── ±10% → PR EOS

3. 临界点附近?
   ├── 是 → SW EOS / IAPWS(必须)
   └── 否 → PR EOS 可用

4. 强极性 / 缔合?
   ├── 是 → SAFT-γ Mie / COSMO
   └── 否 → PR EOS / SW EOS

5. 混合物 k_ij 数据?
   ├── 有 → PR + 混合规则
   ├── 无 → NRTL / UNIQUAC
   └── 含水 + 缔合 → SAFT-γ Mie
```
