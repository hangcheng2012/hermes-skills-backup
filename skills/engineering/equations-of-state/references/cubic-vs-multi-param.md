# 立方型 EOS vs 多参数 Helmholtz EOS —— 本质差别与选择规则

> **本文件是 equations-of-state SKILL 的 references/ 详解之一**。
> 对比两类状态方程的本质数学差别,以及它们在不同工况下的适用规则。

---

## 一、两类 EOS 的根本差别

### 1.1 立方型 EOS(Cubic EOS)

**代数形式:** 压力 P 是体积 V 的**三次多项式**(对 V 求导有 3 个根)。

**通用形式(对所有立方 EOS 适用):**

```
                RT                  a(T)
   P = ────────────────  −  ───────────────────
          V − b             V² + u·b·V + w·b²
```

**常见立方 EOS 的 (u, w):**

| EOS | 提出年份 | u | w | 形状 |
|-----|----------|---|---|------|
| **vdW** | 1873 | 0 | 0 | (V-b) · V² 分母,简单 |
| **RK** | 1949 | 1 | 0 | V(V+b),中肯 |
| **SRK** | 1972 | 1 | 0 | V(V+b),常用 |
| **PR** | 1976 | 2 | -1 | V² + 2bV - b²,改进 |

### 1.2 Helmholtz 多参数 EOS(Multi-Parameter EOS)

**代数形式:** 用无量纲亥姆霍兹自由能 α(δ, τ)的多项式拟合。

```
A(T, ρ)        A^ideal(T, ρ)    A^R(T, ρ)
─────────  =  ──────────────  +  ──────────
  R·T            R·T              R·T

δ = ρ / ρ_c      对比密度
τ = T_c / T      对比温度倒数
```

**剩余项拟合:**
```
A^R(δ, τ)
   = Σᵢ₌₁ᴺ nᵢ·δ^dᵢ·τ^tᵢ               (多项式项)
   + Σⱼ₌₁ᴹ nⱼ·δ^dʲ·τ^tʲ·exp(−δ^cʲ)    (指数项)
```

**拟合系数数量(关键差别):**

| EOS | 项数 N + M | CO₂ / 流体类型 |
|-----|-----------|-----------------|
| **SW(CO₂)** | ~12 + ~28 项多项式 + ~12 临界指数项 ≈ 540 项总 | CO₂(REFPROP 用)|
| **IAPWS-IF97** | 短程 ~30 项 + 通用 ~40 项 | 水蒸气(工业蒸汽标准)|
| **GERG-2008** | 多组分混合项数十项 × 物质对数 | 天然气混合物(LEL / UEL)|

**精度差距的根源:**
- 立方型:3 个系数拟合 1 个温度依赖 + 1 个压力依赖 = **2 维数据难以 5 系数内精确**
- 多参数:数十到数百系数拟合 2 维数据 = **拟合精度随系数指数增长**

## 二、为什么多参数 EOS 更精确?(数学层面)

### 2.1 拟合自由度对比

**立方型 EOS 的"自由度":**
- 3 个参数(T_c, P_c, ω)
- 拟合临界点 + 蒸汽压 + 液密度 3 个性质
- **每个拟合分点只剩 0 个自由度**——硬约束

**多参数 EOS 的"自由度":**
- ~580 个系数
- 拟合 10000+ 个实验数据点
- **每个点有充足自由度**

### 2.2 误差级别对比(CO₂ 实测)

| EOS | 标称密度误差 | 标称焓误差 | 适用 T 范围 | 适用 P 范围 |
|-----|--------------|------------|--------------|--------------|
| **RK** | 6~13% | 5~10% | T < 0.9 T_c 不好 | P < 50 MPa |
| **SRK** | 2~8% | 3~7% | T < 0.95 T_c 勉强 | P < 50 MPa |
| **PR** | 2~6% | 3~5% | T < 0.95 T_c 勉强 | P < 80 MPa |
| **SW** | **< 0.05%**(CO₂)| **< 1%** | 216~1100 K | 0~800 MPa |

**关键点:** SW 的误差比 PR 低 1~2 个数量级——对于国家标准和科研这是必须的。

### 2.3 临界点附近的行为差别(最关键)

**临界点附近的"剧变":**

```
临界压缩因子 Z_c:
   PR 预测:0.307(实验:0.274,误差 +12%)
   SRK 预测:0.333(误差 +22%)
   SW 预测:0.274(误差 < 0.1%)
```

**原因分析:**
- 临界点附近 Z, ρ, h, s **剧烈波动**(微小 ΔP, ΔT → 大性质变化)
- 立方 EOS 用 3 个参数硬约束临界点,但临界点附近实际数据点偏离预测
- SW 用 ~580 项拟合直接描摹"剧烈波动区"——能精细刻画

## 三、关键数据对比表

### 3.1 CO₂ 在临界点附近的实测对比(30 MPa, 280°C)

| 工况 | 数据类型 | vdW | RK | SRK | PR | SW(标准)|
|------|----------|-----|-----|-----|-----|----------|
| ρ | kg/m³ | 严重偏离 | 60 | 55 | 50 | **42.4** |
| 误差 | % | > 50% | 41% | 30% | 18% | **< 0.05%** |
| Z | — | 严重偏离 | 0.85 | 0.78 | 0.75 | **0.690** |
| 误差 | % | > 50% | 23% | 13% | 8.7% | **< 0.05%** |

### 3.2 各 EOS 的"甜蜜区"

| EOS | 甜蜜区(误差 < 3%) | 不推荐区(误差 > 10%) |
|-----|-------------------|----------------------|
| **SRK** | 气相, 1 MPa < P < 30 MPa,远离临界点 | 临界 ±5%, 液相密度 |
| **PR** | 气相, 1 MPa < P < 50 MPa,远离临界点 | 临界 ±5%, 强极性 |
| **SW** | 全温压区(216~1100 K, 0~800 MPa)| 几乎没有不推荐区 |
| **IAPWS-IF97** | 水的全温压区(273~2000 K)| 仅有水的反应 |
| **GERG-2008** | 天然气混合物(-180~700 K)| 强极性 / 重组分 |

## 四、两类 EOS 的"工程取舍"

| 维度 | 立方型(PR 首选) | 多参数(SW 首选) |
|------|------------------|------------------|
| **编程难度** | ★(简单)| ★★★(复杂)|
| **数据库依赖** | 仅 T_c, P_c, ω | 全部依赖数据库 |
| **精度** | 中(2~8%)| 高(< 0.5%)|
| **软件支持** | Aspen / ProMax / CHEMCAD 默认 | REFPROP / CoolProp |
| **计算速度** | 快(简单代数)| 慢(数值微分)|
| **适用阶段** | 概念设计 / 工艺包 / P&ID | 详细设计 / 国家级 / 论文 |
| **学习曲线** | 周(简单数学)| 月(多项式 + 数值)|

**权衡原则:**
- **工艺计算 ≠ 国家标准计算 ≠ 学术论文**
- 工程包用 PR + NIST 实验校核
- 国家级 / 高精度用 REFPROP(SW)

## 五、编程实现的差别

### 5.1 PR EOS 编程(CoolProp 内置示例)

```python
# PR EOS 在 Aspen / CoolProp 都内置
# 自实现 PR EOS ~80 行 Python 代码
from CoolProp.CoolProp import PropsSI

T = 553.15  # K
P = 30e6    # Pa

# CoolProp 自动选 PR EOS
ρ = PropsSI('D', 'T', T, 'P', P, 'CO2')   # 42.7 kg/m³ (PR 估计)
h = PropsSI('H', 'T', T, 'P', P, 'CO2')   # h(P, T)
```

### 5.2 SW EOS 自实现复杂度

```python
# SW EOS 自实现需要:
# 1. 加载 ~580 个拟合系数(读入数据文件)
# 2. 实现 α^ideal 和 α^R 的多项式 + 指数求和
# 3. 实现 α 对 δ, τ 的偏导数(高精度数值微分)
# 4. 从 A, dA/dT, dA/dρ 推出 h, s, Cp, Cv, 声速, 逸度
# 5. 立方型 EOS 通常 80~150 行 Python;SW EOS 通常 800~2000 行

# 实际工程 / 研发都用 CoolProp / REFPROP 内置
# 自实现 SW EOS 是科研级工作,非工程所需
```

### 5.3 第三方库对比

| 库 / 软件 | 默认 EOS | CO₂ 适用 | 速度 |
|-----------|----------|----------|------|
| **CoolProp**(开源)| PR + SW(自动切换)| 全温压 | 中等 |
| **REFPROP**(NIST)| SW(CO₂ 黄金标准)| 全温压 | 极快 |
| **Aspen Plus** | PR + 用户指定 | 全温压 | 极快 |
| **Cantera** | PR + 用户指定 | 全温压 | 快 |

## 六、决策规则:何时用立方型,何时用多参数

### 6.1 决策树

```
工作类型?
├── 概念设计 / 工艺包 / PFD 出图
│   └── 立方型 EOS(PR 首选)
│        └── 临界 ±5% ?
│            ├── 否 → PR EOS 足够
│            └── 是 → 改用 SW EOS / REFPROP 校核
│
├── 国家级数据 / 论文发表
│   └── 多参数 EOS(Span-Wagner for CO₂)
│        └── 必须用 REFPROP 或 CoolProp
│
├── 反应器 / 减压阀 / 临界点工况设计
│   └── 多参数 EOS(Span-Wagner for CO₂)
│        └── 推荐 CoolProp(开源 + Python 友好)
│
├── 教学 / 示意图 / 课程作业
│   └── SRK EOS(简单清晰,公式对称)
│
└── 实验数据分析
    └── 实验数据 + NIST 校核(基准是 NIST 实验)
```

### 6.2 女王工作常用规则

| 女王工作场景 | 推荐 EOS | 实现方式 |
|--------------|----------|----------|
| **PFD / P&ID 设计**(P-T 节点)| **PR EOS** | Aspen 默认 / CoolProp |
| **反应器热平衡 + 物料平衡** | **PR EOS** | Aspen / 手算 + CoolProp |
| **临界点附近精算**(CO₂ / 制冷) | **SW EOS** | REFPROP / CoolProp |
| **小试/中试放空管** | **SW EOS**(防干冰) | CoolProp |
| **scCO₂ 减压脱气计算** | **SW EOS**(临界点)| REFPROP / CoolProp |
| **CO₂ 储存计算** | **SW EOS** | REFPROP / CoolProp |
