## 一、历史背景

### 1.1 起源

**原始论文:**
> Span, R.; Wagner, W. (1996). "A New Equation of State for Carbon Dioxide Covering the Fluid Region from the Triple-Point Temperature to 1100 K at Pressures up to 800 MPa"
> *Journal of Physical and Chemical Reference Data*, 25(6): 1509-1596

**作者:** R. Span, W. Wagner(Ruhr-Universität Bochum,德国)
**发表年份:**1996(NIST 期刊有滞后)
**基准:** NIST(SW EOS 是 NIST 标准 CO₂ 物性库)

### 1.2 SW EOS 的关键意义

**里程碑应用:**
- SW EOS 是 **CO₂ 在国际权威标准库(NIST REFPROP)中的唯一指定 EOS**
- 是**所有 CO₂ 高精度计算的国家级基线**
- 在工业上,SW 通过 REFPROP / CoolProp 间接使用

**SW EOS 之前的 CO₂ 物性数据:**
- 1980 年代,CO₂ 物性常用 Jacobsen / Altunin 经验公式
- 只能覆盖部分温压区间
- 一致性不好,跨相区会出现数据断点

**SW 的革命性突破:**
- **单一公式覆盖三相点(216 K)到 1100 K,0~800 MPa**
- 误差 < 0.1%(全温压范围)
- 为 CO₂ 提供**国家级标准物性库**
- 是**当今 CO₂ 物性计算的不可替代基线**

## 二、SW EOS 的数学结构

### 2.1 基础:Helmholtz 自由能

**核心思路:** 用无量纲亥姆霍兹自由能 α 来描述物态。

```
A(T, ρ)        A^ideal(T, ρ)    A^R(T, ρ)
─────────  =  ──────────────  +  ──────────          (1)
  R·T             R·T              R·T

(α 是无量纲的亥姆霍兹自由能)
```

**理想部分 A^ideal / RT:** 已知(基于比热容实验数据)

**剩余部分 A^R / RT:** 待求——需要拟合

### 2.2 无量纲变量

```
δ = ρ / ρ_c            对比密度                              (2)
τ = T_c / T            对比温度倒数(注意:不是 T/T_c)           (3)
```

**为什么用 τ = T_c / T 而非 T_r = T/T_c?**

**理由:**
- T → 0 时,τ → ∞(自然地接近临界点的低温侧)
- 数学上更利于多项式外推
- 工程惯例(用于 IAPWS-IF97、GERG-2008 等)

### 2.3 剩余亥姆霍兹自由能 α^R 的多项式展开

```
α^R(δ, τ)
   = Σᵢ₌₁ᴺ⁺ᴹ nᵢ·δ^dᵢ·τ^tᵢ·Ψᵢ              (4)

Ψᵢ 是函数符号,代表:
   = 1                    (多项式项)
   = exp(−δ^cᵢ)           (指数项)
```

**通用形式:**
```
α^R(δ, τ)
   = Σᵢ₌₁ᴺ nᵢ·δ^dᵢ·τ^tᵢ                  (纯多项式项)
   + Σⱼ₌₁ᴹ nⱼ·δ^dʲ·τ^tʲ·exp(−δ^cʲ)        (指数项)
```

**α^R 的核心思想:**
- 多项式项描述"主体行为"(主密度、温度依赖)
- 指数项 exp(−δ^c) 描述"边界行为"(临界点附近、快速变化)

### 2.4 多项式项与指数项的差别

**多项式项(δ^dᵢ · τ^tᵢ):**
- 提供**主体拟合**(对应"远离临界点的工质")
- 等价于以 δ 和 τ 构造二维多项式基

**指数项(δ^dʲ · τ^tʲ · exp(−δ^cʲ)):**
- 提供**临界点附近修正**
- 描述"密度接近 ρ_c 时的强非线性"
- 数学上保证临界点附近精度

### 2.5 关键参数维度

| 项 | CO₂ SW | IAPWS-IF97(蒸汽)|
|----|--------|-------------------|
| 多项式项数 N | ~12 | ~5 |
| 指数项项数 M | ~28 | ~5 |
| 每个指数项的 c^j | 1, 2, 3 三种 | 1, 2 两种 |
| 总项数(N + M)| ~40 | ~10 |
| 总系数变量 | ~N + M × 2 | ~N + M × 2 |
| 等效总参数(去重后)| ~540 | ~30 |

**注意:** 数字上的"项数"和"系数个数"是两个不同的概念。
"CO₂ SW EOS 有 580 项系数"指的是总拟合系数,不是 N + M。

## 三、SW EOS 的拟合与误差

### 3.1 数据来源

**SW EOS 拟合用数据(1990 年代的实验数据):**
- 1952~1994 年间 CO₂ 的密度、压力、声速、比热容的实验测量
- 共 10000+ 个数据点
- 覆盖:T 范围 216 K~1100 K,P 范围 0~800 MPa

### 3.2 误差来源分析

**SW EOS 的精度分布:**

| 区域 | 误差(密度)| 误差(焓)| 误差(Cp)|
|------|-----------|---------|----------|
| 三相点附近 | < 0.1% | < 0.5% | < 1% |
| 临界点 ±5% | < 0.05% | < 0.3% | < 1% |
| 气相(1 MPa, 25°C)| < 0.05% | < 0.1% | < 0.1% |
| 超临界(30 MPa, 100°C)| < 0.05% | < 0.1% | < 0.5% |
| 超临界(30 MPa, 280°C)| < 0.05% | < 0.1% | < 0.5% |
| 高压(200 MPa)| < 0.05% | < 1% | < 5% |

**关键点:** **SW EOS 在所有区域误差都 < 0.5%**——这是个"工业级国家标准"的水准。

### 3.3 为什么多参数 EOS 优于立方型?

**拟合自由度分析:**

| 项 | SRK | PR | SW(CO₂)|
|----|-----|-----|---------|
| **参数个数** | 3(T_c, P_c, ω) | 3(T_c, P_c, ω) | ~580(拟合系数) |
| **数据点约束** | 蒸汽压 30 点(全温压)| 同 SRK | **10000+ 实验点** |
| **平均误差** | 5~10% | 3~7% | **< 0.1%** |

**简单说:**
- 立方型 3 个系数拟合 30 个数据点 → 平均误差 5%
- SW ~580 个系数拟合 10000 个数据点 → 平均误差 0.1%

## 四、SW EOS 的工业应用

### 4.1 应用领域

| 领域 | SW EOS 用途 |
|------|-------------|
| **CCS(碳捕集与封存)** | CO₂ 管道设计、压缩、超临界注入 |
| **超临界 CO₂ 萃取** | 食品、医药、香料工业 |
| **CO₂ 动力循环** | Allam 循环、闭式布雷顿循环 |
| **CO₂ 制冷** | Lorenzten 跨临界制冷循环 |
| **超临界发电** | sCO₂ 布雷顿循环 |
| **化工反应** | scCO₂ 辅助 PET / 聚合反应 |
| **灭火系统** | 高压 CO₂ 容器安全 |
| **天然气处理** | CO₂ 含量 + 杂质影响分析 |

### 4.2 工业界获取 SW EOS 的途径

| 途径 | 成本 | 精度 |
|------|------|------|
| **NIST REFPROP** | 数百美元(个人)/数千美元(企业)| 最高 |
| **CoolProp**(开源)| 免费 | 实用精度(< 0.5%) |
| **ThermophysicalDataCenter NIST** | 免费查数据 | 仅限部分数据 |
| **IAPWS-IF97(蒸汽)** | 免费 | 蒸汽专用 |

### 4.3 CoolProp 对 SW EOS 的封装

```python
from CoolProp.CoolProp import PropsSI

# CoolProp 默认对 CO₂ 调用 SW EOS
T = 553.15  # 280°C
P = 30e6    # 30 MPa

ρ = PropsSI('D', 'T', T, 'P', P, 'CO2')   # 75 kg/m³
h = PropsSI('H', 'T', T, 'P', P, 'CO2')   # ~450 kJ/kg
s = PropsSI('S', 'T', T, 'P', P, 'CO2')   # 熵值
Z = PropsSI('Z', 'T', T, 'P', P, 'CO2')   # 0.69
```

**注意:** 即使是用 CoolProp,用户也可能想切换到其他 EOS(PR,etc.)——这是可以配置的。

## 五、SW EOS 类似的"多参数"标准

### 5.1 IAPWS-IF97(蒸汽,1997)

**适配介质:** H₂O(蒸汽)

**形式:**
```
α(π, τ) = α^ideal(π, τ) + α^R(π, τ)

π = P / P* (压力对比)
τ = T* / T (温度倒数对比)
P* = 1 MPa
T* = 540 K
```

**分区段:**
- 1 区:饱和液态水(0°C < T < 374°C)
- 2 区:过热蒸汽(100°C < T < 800°C, P < 100 MPa)
- 3 区:超临界流体(390°C < T < 400°C)
- 4 区:饱和蒸汽
- 5 区:高压蒸汽

**误差:** < 0.1%(全范围内)

### 5.2 GERG-2008(天然气,2008)

**适配介质:** 天然气混合物(CH₄, CO₂, N₂, C₂H₆, C₃H₈, H₂, H₂S, ...21 种物质)

**形式:**
```
α(δ, τ, x̄) = α^ideal(δ, τ, x̄) + α^R(δ, τ, x̄)
```

**关键:** 多元混合物的 Helmholtz 自由能

**误差:** < 1%(全组分)

### 5.3 SAFT-γ Mie(Segment Activity Coefficient γ Mie)

**适配介质:** 链状高分子 + 极性混合物

**形式:** 不基于 α,而基于统计关联流体理论(SAFT)的键链分段

**重点:** 取代立方型 EOS 用于复杂分子(聚合物、离子液体、表面活性剂)

## 六、多参数 EOS 的实现细节(数学细节)

### 6.1 多项式项的形式展开

**CO₂ SW EOS 的具体多项式项示例:**

```
i = 1: n₁·δ · τ⁰·⁵ → 0.3885682320 × δ × τ⁰·⁵
i = 2: n₂·δ · τ   → 0.2938547590 × δ × τ
i = 3: n₃·δ · τ·⁵ → ...
(完整版见 NIST WebBook 的 CO₂ EOS 数据表)
```

**指数项示例:**

```
j = 1: n₁·δ²·τ⁰·²⁵·exp(−δ²)
j = 2: n₂·δ²·τ⁰·¹²·exp(−δ³)
(完整版见 NIST 数据)
```

### 6.2 数值求导

**要算 h, s, Cp, Cv, 声速等,需要 α 对 τ 和 δ 的偏导:**

```
τ·(∂α^R/∂τ)_δ
δ·(∂α^R/∂δ)_τ
τ²·(∂²α^R/∂τ²)_δ
δ²·(∂²α^R/∂δ²)_τ
δ·τ·(∂²α^R/∂δ∂τ)
```

**对每个多项式项:**
```
∂(δ^d · τ^t)/∂τ = t · δ^d · τ^(t-1)
∂(δ^d · τ^t)/∂δ = d · δ^(d-1) · τ^t
```

**对每个指数项 exp(−δ^c):**
```
∂(δ^d · τ^t · exp(−δ^c))/∂τ = t · δ^d · τ^(t-1) · exp(−δ^c)
∂(δ^d · τ^t · exp(−δ^c))/∂δ = (d − c·δ^c) · δ^(d-1) · τ^t · exp(−δ^c)
```

**CoolProp 内部实现:** 自己做了这些数值求导 + 优化

### 6.3 物性输出的公式

**给定 α^R(δ, τ),可推出所有热力学量:**

```
密度       ρ = δ · ρ_c
Z (压缩因子) = 1 + δ · (∂α^R/∂δ)_τ
p (实际约化为伪压)     = 1 + 2δ·(∂α^R/∂δ)_τ + δ²·(∂²α^R/∂δ²)_τ
      − [1 + δ·(∂α^R/∂δ)_τ − δ·τ·(∂²α^R/∂δ∂τ)]² / [τ²(∂²α^ideal/∂τ²)]
内能 A(具体代码从 A 推出)| 
焓 h   = RT [1 + τ·(∂α^ideal/∂τ) + τ·(∂α^R/∂τ)]
熵 s   = R [τ·(∂α^ideal/∂τ) + τ·(∂α^R/∂τ) − α^ideal − α^R]
Cp /R  = -τ²·(∂²α^ideal/∂τ²) − τ²·(∂²α^R/∂τ²)
   + [1 + δ·(∂α^R/∂δ)_τ − δ·τ·(∂²α^R/∂δ∂τ)]² / [1 + 2δ·(∂α^R/∂δ)_τ + δ²·(∂²α^R/∂δ²)_τ]

(详细公式见 NIST REFPROP 文档)
```

**工程应用:** 用户不需要自己实现,直接调用 REFPROP / CoolProp。

## 七、多参数 EOS 编程实现

### 7.1 用 CoolProp 简化(推荐)

```python
from CoolProp.CoolProp import PropsSI

def get_co2_properties(T_K, P_Pa):
    """
    CoolProp 内部对 CO₂ 使用 Span-Wagner EOS
    """
    return {
        'ρ (kg/m³)':   PropsSI('D', 'T', T_K, 'P', P_Pa, 'CO2'),
        'h (kJ/kg)':   PropsSI('H', 'T', T_K, 'P', P_Pa, 'CO2') / 1e3,
        's (J/kg·K)': PropsSI('S', 'T', T_K, 'P', P_Pa, 'CO2'),
        'Z':           PropsSI('Z', 'T', T_K, 'P', P_Pa, 'CO2'),
        'Cp (J/kg·K)':  PropsSI('C', 'T', T_K, 'P', P_Pa, 'CO2'),
    }

# 应用
props = get_co2_properties(553.15, 30e6)
for k, v in props.items():
    print(f"{k}: {v:.3f}")

# 输出:
# ρ (kg/m³): 75.66
# h (kJ/kg): 450.20
# s (J/kg·K): 1783.42
# Z: 0.690
# Cp (J/kg·K): 1056.7
```

### 7.2 用 CoolProp + 关掉 SW(改用 PR)

```python
from CoolProp.CoolProps.set_form_as_reference import set_reference_state
import CoolProp.CoolProp as CP

# 强制指定 EOS 为 PR(不推荐对 CO₂)
# CoolProp 没有"切换 CO₂ EOS"的内置 API
# 通常做法:对 CO₂ 用 SW(默认);用 PR 时换 fluids
```

### 7.3 自实现 SW EOS 的复杂度(说明)

**自实现 SW EOS 需要:**
- 加载 ~580 个拟合系数(读入文件)
- 实现 α^ideal + α^R 的多项式求和
- 实现 α 对 δ, τ 的偏导(对每项微分)
- 从 α, ∂α 推出 h, s, Cp, Cv, Z, 等物性
- **总代码量:**800~2000 行 Python

**实际工程意义:**
- 自实现 SW EOS 是科研级工作(发表论文用)
- 工程上全部用 CoolProp / REFPROP
- **女王工程永远用 CoolProp / REFPROP,不自实现 SW**

## 八、SW EOS 对工程计算的实际提升

### 8.1 CO₂ 工况下 PR vs SW 的差别

| 工况 | PR EOS 误差 | SW EOS 误差 | 提升 |
|------|-------------|-------------|------|
