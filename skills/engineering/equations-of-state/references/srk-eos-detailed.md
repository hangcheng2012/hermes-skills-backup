## 一、历史背景

### 1.1 起源

**Redlich-Kwong EOS(1949)** 提出第一代实用立方型 EOS,引入了温度相关的吸引力项。
**SRK EOS(Soave,1972)** 在 RK 基础上做了**温度函数的重新拟合**,让临界点附近的汽液平衡预测显著改进。

**原始论文:**
> Soave, G. (1972). "Equilibrium constants from a modified Redlich-Kwong equation of state"
> *Chemical Engineering Science*, 27(6): 1197-1203

**论文被引用次数:** 30,000+(2026)— 是化工热力学史上引用最多的论文之一

### 1.2 在化工工程中的位置

**里程碑式应用:**
- 1980 年代起,SRK 成为石油化工蒸馏模拟主流
- 替代了 vdW 成为更可靠的计算工具
- 1990 年代被 Peng-Robinson(1976)在某些方面超越(液体密度更准)
- 但 SRK 在气体密度 + 轻烃 VLE 上仍优

**今天的状态:**
- Aspen / ProMax / CHEMCAD 默认 EOS 通常是 **PR** 而不是 SRK
- 但 SRK 在**气体密度预测**和**简单物质 VLE** 上仍有优势
- SRK 是**化学工程师必须熟悉的 EOS**

## 二、SRK EOS 的完整公式

### 2.1 显式形式 P = f(T, V)

```
              RT              a(T)·α
    P = ──────────  −  ──────────────          (1)
          (V − b)          V(V + b)
```

**关键符号:**

| 符号 | 物理意义 | 单位 |
|------|----------|------|
| R | 通用气体常数 | 8.314 J/(mol·K) |
| T | 绝对温度 | K |
| V | 摩尔体积 | m³/mol(或 L/mol)|
| P | 绝对压力 | Pa(或 MPa)|
| b | 协体积(排斥体积)| m³/mol |
| a(T) | 温度依赖的吸引力参数 | J·m³/mol² |
| α(T) | 温度依赖函数(无量纲)| - |

### 2.2 参数 a_c 和 b(基于临界参数)

```
       0.42747 · R² · T_c²
a_c = ────────────────────                    (2)
              P_c

       0.08664 · R · T_c
b   = ────────────────────                    (3)
                P_c
```

**来源:** 临界点处 ∂P/∂V = 0 和 ∂²P/∂V² = 0(临界点的两个稳定性条件)

### 2.3 温度依赖 α(T)

```
α(T) = [1 + m(1 − √(T_r))]²                  (4)

T_r = T / T_c                                (5)

m    = 0.48 + 1.574·ω − 0.176·ω²             (6)
```

**核心创新(Soave 的贡献):** α 的形式使 EOS 自动满足**蒸汽压预测**——这是 Soave 的关键改进,也是 SRK 流行的核心原因。

### 2.4 偏心因子 ω(Acentric Factor)

| 物质 | ω | 含义 |
|------|---|------|
| **CO₂** | **0.225** | 中度不对称 |
| H₂O | 0.344 | 强极性 |
| H₂ | -0.216(负数)| 量子效应,H₂ 反常 |
| Ar | -0.002 | 几乎球对称 |
| CH₄ | 0.011 | 接近球对称 |
| C₆H₁₄ | 0.399 | 长链烃 |
| H₂S | 0.100 | 弱极性 |

**ω 反映:** 分子偏离球对称的程度(派生自蒸汽压数据)

### 2.5 SRK 完全参数化(用 ω 表征)

**标准 SRK 只需要 3 个参数:** T_c, P_c, ω

```
ω → m → α(T) → a(T)
T_c → a_c
T_c, P_c → b
```

## 三、SRK EOS 的物理意义

### 3.1 推到代数形式

```
SRK = RK + 温度依赖吸引力项
```

**RK(1949):** α = 1/√(T_r)(温度反向相关)

**SRK(1972):** α = [1 + m(1 - √(T_r))]²
- T = T_c 时, α = 1
- T = 0 时, α → 很大(物理上非真实,但是数学上保证了低温 VLE 预测)

### 3.2 物理含义的两种解读

**解读 ①:** 排斥(动能项) + 吸引(内压项)

```
                  (动力)            (吸引,内压,P ↓)
   P = [RT/(V-b)]  −  [a(T)/(V(V+b))]
        ↑                               ↑
        分子动能推压                    分子间吸引力拉压
```

**解读 ②:** 有效体积 + 修正压力

```
   (V-b)  排斥:"分子本身占体积" → 把 V "减去" b
   a/V(V+b)  吸引:"内压力" → 比单独 V² 项温和
```

## 四、SRK EOS 的实际算例(CO₂)

### 4.1 CO₂ 临界参数

```
T_c  = 304.25 K
P_c  = 7.38 MPa
ω    = 0.225
M    = 44.01 g/mol
R    = 83.14472 cm³·bar/(mol·K) = 8.314 J/(mol·K)
```

### 4.2 计算参数 a, b

```
a_c = 0.42747 × (8.314)² × (304.25)² / (73.8 × 10⁵)
    = 0.42747 × 69.12 × 92568 / 7380000
    ≈ 3.8546 × 10⁵ Pa·(m³/mol)²
    ≈ 0.3855 J·m³/mol²

b   = 0.08664 × 8.314 × 304.25 / (73.8 × 10⁵)
    ≈ 2.901 × 10⁻⁵ m³/mol
    ≈ 29.01 cm³/mol
```

### 4.3 计算 m, α

```
m  = 0.48 + 1.574 × 0.225 − 0.176 × 0.225²
   = 0.48 + 0.354 − 0.009
   = 0.825

α(553 K)  = [1 + 0.825 × (1 − √(553/304.25))]²
         = [1 + 0.825 × (1 − √(1.818))]²
         = [1 + 0.825 × (1 − 1.348)]²
         = [1 + 0.825 × (−0.348)]²
         = [1 − 0.287]²
         = 0.713²
         = 0.508

a(553 K) = a_c × α = 0.3855 × 0.508 ≈ 0.196 J·m³/mol²
```

### 4.4 解 EOS(三次方程)

**将 SRK 写成 V 的三次方程:**

```
P·V³ − (R·T + b·P)·V² + a(T)·V − a(T)·b = 0
```

**(30 MPa, 280°C = 553 K)代入:**

```
30e6·V³ − (8.314 × 553 + 2.901e-5 × 30e6)·V² + 0.196·V − 0.196 × 2.901e-5 = 0
30e6·V³ − (4597.6 + 870.3)·V² + 0.196·V − 5.69e-6 = 0
30e6·V³ − 5467.9·V² + 0.196·V − 5.69e-6 = 0
```

**用 Cardano 或 Newton-Raphson 求解(略,数值计算):**

```
解:V ≈ 2.36 × 10⁻⁴ m³/mol = 236 cm³/mol
```

**换算密度:**
```
ρ = M / V = 44.01 g/mol / (236 cm³/mol) ≈ 0.187 g/cm³ = 187 kg/m³
```

**与 NIST SW EOS 对比(标准值):**
```
ρ(SW EOS) ≈ 70 ~ 80 kg/m³                 (SRK 高估)
```

**SRK 在 30 MPa, 280°C 工况误差:**
```
实际值:~70 kg/m³ (SW EOS)
SRK 预测:187 kg/m³
误差:~167%  ✗ 严重偏离
```

**原因:** 280°C 离临界温度较远,但 P_r = 4.07 仍偏高——SRK 在高压下液体密度预测总是偏高(液体压缩性差)。

### 4.5 为什么 SRK 不准?

**对比实测密度:**

| EOS | ρ (kg/m³) | 误差 |
|-----|-----------|------|
| **SW(标准)** | **70~80** | **0%** |
| PR | 80~90 | +8% |
| SRK | 180~190 | +150% |
| vdW | 400 | +400% |

**这是为什么在临界点 + 高压下工程改用 PR 而非 SRK。**

## 五、SRK 在液相密度预测上的"已知缺陷"

**已知行为:**
- SRK 对饱和液密度预测偏高约 **30~50%**
- SRK 对压缩液密度预测偏高更严重
- 这就是 PR(1976)的设计改进目标

**机制:**
- PR EOS 在临界点的 **Z_c 预测更准**(0.307 vs SRK 0.333),原因是 PR 公式形式修正了临界点附近液体侧预测

**实际工程:**
- 1980 年代后,PR EOS 几乎完全替代了 SRK EOS 作为通用工艺 EOS
- 但 SRK 在气体密度 + 简单烃类 VLE 上仍有价值

## 六、SRK EOS 的编程实现(Python)

### 6.1 完整 SRK EOS 实现

```python
import numpy as np

def srk_eos(T, P, Tc, Pc, omega, R=8.314):
    """
    输入:
        T, P: 温度 K, 压力 Pa
        Tc, Pc: 临界温度 K, 临界压力 Pa
        omega: 偏心因子
    返回:
        Z: 压缩因子
        V_m: 摩尔体积 m³/mol
        rho: 密度 kg/m³
    """
    # 参数计算
    a_c = 0.42747 * R**2 * Tc**2 / Pc
    b   = 0.08664 * R * Tc / Pc
    m   = 0.48 + 1.574*omega - 0.176*omega**2

    # α(T)
    Tr = T / Tc
    alpha = (1 + m * (1 - np.sqrt(Tr)))**2

    # 立方方程系数(PV³ - P₁V² + P₂V - P₃ = 0)
    P1 = R*T + b*P          # (1)
    P2 = -a_c * alpha        # (2)
    P3 = -a_c * alpha * b    # (3)
    P0 = P                    # V³ 系数

    # 解三次方程
    coeffs = [P0, -P1, -P2, -P3]
    roots = np.roots(coeffs)

    # 选实根 + 物理上合理(0 < V < 1 cm³/mol 量级)
    V_real = roots[np.isreal(roots)].real
    V_valid = V_real[(V_real > 1e-6) & (V_real < 1e-1)]

    if len(V_valid) == 0:
        raise ValueError("No physical root found!")

    # 取最大根(稳定气相)
    V_m = V_valid.max() if len(V_valid) > 1 else V_valid[0]

    # Z = PV_m / RT
    Z = P * V_m / (R * T)
    rho = 44.01e-3 / V_m   # CO₂ 假设(实际用 M)

    return Z, V_m, rho


# 测试:CO₂ 在 30 MPa, 280°C
T = 553.15   # 280°C
P = 30e6     # 30 MPa
Tc = 304.25  # K
Pc = 7.38e6  # Pa
omega = 0.225

Z, V_m, rho = srk_eos(T, P, Tc, Pc, omega)
print(f"Z     = {Z:.4f}")       # 期望 ~ 0.85 (高于 SW 标准值 0.69)
print(f"V_m   = {V_m*1e6:.2f} cm³/mol")
print(f"rho   = {rho:.2f} kg/m³")
# CO₂ @ 30 MPa, 280°C 真实: ρ ≈ 75 kg/m³(SW 标准)
```

### 6.2 用 CoolProp 替代自实现(SW EOS 精度)

```python
print(f"CoolProp(SW) ρ = {ρ_real:.2f} kg/m³ (误差 < 0.1%)")
```

## 七、SRK EOS 的限制与延伸

### 7.1 失效场景

| 场景 | 偏差 | 原因 |
|------|------|------|
| 临界点 ±5% | 10~30% | 立方型公式硬约束临界点,无法描述临界点附近的剧烈波动 |
| 高压(> 50 MPa)| 5~15% | 立方型 EOS 在高压下体积预测偏差 |
| 强极性物质(醇、羧酸)| 5~20% | 立方型 EOS 假设弱吸引力主导 |
| 复杂混合物(醇 + 水)| 5~20% | 二元交互参数不够,需 NRTL/UNIQUAC |

### 7.2 常见改进

**PSRK(普通化 SRK):** 加入 Stefan-Wagner 或 Holderbaum-Gmehling α 函数,用于极性物系

**SRK + Huron-Vidal 混合规则:** 用于强极性混合物 VLE

**SRK-MC(混合立方):** 加入 Margules 二元参数

**实际:**大多数工业软件直接用 PR + 专用物性包,而非 SRK + 改进

## 八、SRK vs PR 选择规则

| 维度 | SRK | PR |
|------|-----|-----|
| 简单物质气相密度 | 略好 | 略差 |
| 简单物质液相密度 | 偏差大 | 较好 |
| 临界点附近 | 都不行 | PR 略好(Z_c 0.307 vs 0.333)|
| 气体密度预测 | 较好 | 较好 |
| 编程复杂度 | 简单 | 简单 |
| 软件默认 | 旧代码用 | 新代码默认 |
| 学习曲线 | 周 | 周 |

**结论:** **当代工程几乎默认选 PR**,SRK 主要作为历史 / 教学参考。
