## 一、理想气体假设的本质

### 1.1 分子模型

**理想气体假设的两个特征:**
1. **分子间无吸引力**——分子视为"无相互作用的弹球"
2. **分子本身体积可忽略**——分子视为"点质量"

**状态方程:**
```
P·V = n·R·T          (克拉伯龙方程, 1834)
```

**常见常数:**
```
R = 8.314462618 J/(mol·K)        (CODATA 2018, 2018 后精准值)
R = 0.082057366 L·atm/(mol·K)     (常用单位)
R = 83.14472 cm³·bar/(mol·K)      (常用的"工程常数")
R = 1.985875 kcal/(mol·K)         (化学工程常用)
```

### 1.2 适用极限

**理想气体假设严格成立的情况:**
- 极限密度趋于零(压力无穷低)
- 即:**高温 + 低压极限**

**定量判据:**
- **T_r > 2 且 P_r < 0.1** 时,误差 < 5%
- **T_r < 0.5** 任何压力都不行(分子间相互作用强)

## 二、为什么工程上必须修正(数值证据)

### 2.1 CO₂ 在 30 MPa, 280°C:理想气体 vs 真实流体的差距

| 工况 | 理想气体预测 | 真实流体(SW EOS) | 偏差 |
|------|--------------|-------------------|------|
| 摩尔体积 V_m | 1.51 L/mol | 1.04 L/mol | -31% |
| 密度 ρ | 29.1 kg/m³ | 42.4 kg/m³ | +46% |
| 压缩因子 Z | 1.000 | 0.690 | -31% |
| 焓 h | **+232 kJ/kg**(只算显热)| **+450 kJ/kg**(显热 + 剩余)| **+94%** |

**关键数据**(CO₂ 实测,NIST):
```
T  = 553 K(280°C)
P  = 30 MPa
ρ  = 42.4 kg/m³                 (SW EOS 计算)
Z  = 0.690                       (Z = PV/RT)
h  ≈ 450 kJ/kg                   (相对 25°C, 1 atm 基准)
h^R ≈ 200 kJ/kg                  (剩余焓修正)
```

**结论:** 30 MPa, 280°C 下,**理想气体公式漏算 +94% 焓值**——这个精度不可接受。

## 三、显热计算(无修正的起点)

### 3.1 标准焓(基准态参考值)

**最常引用的标准态:**
```
T° = 298.15 K = 25°C
P° = 101325 Pa = 1 atm
```

| 物质 | ΔH°f(气态, 25°C)| ΔH°f(液态, 25°C)| 标准蒸发焓 ΔH°vap(25°C)|
|------|---------------------|---------------------|--------------------------------|
| CO₂ | **-393.52 kJ/mol** | -393.52(隐含) | +15.6 kJ/mol(@ T_tp)|
| H₂O | -241.82 kJ/mol | -285.83 kJ/mol | +44.01 kJ/mol |
| NH₃ | -45.94 kJ/mol | 暂无 | +23.33 kJ/mol |
| CH₄ | -74.85 kJ/mol | 暂无(> T_b 时无液相)| — |
| CH₃OH | -200.94 kJ/mol | -239.10 kJ/mol | +38.16 kJ/mol |
| C₂H₅OH | -235.21 kJ/mol | -277.6 kJ/mol | +42.32 kJ/mol |

### 3.2 Cp(T) 拟合(NIST Shomate 方程)

**CO₂ 的 Shomate 方程(NIST 数据):**

```python
# T 范围 298~1200 K
# 形式 Cp° = A + B·t + C·t² + D·t³ + E/t²  (J/mol·K)
# t = T(K) / 1000

A = 24.99735
B = 55.18696
C = -33.69137
D = 7.948387
E = -0.136638
F = -403.6075  (积分常数,用于焓)

# 高温段 1200~6000 K 是另一组拟合
# 低温段 200~298 K 也是另一组
```

**显热积分:**
```
ΔH = ∫[T°→T] Cp(T) dT
   = ∫(A + B·t + C·t² + D·t³ + E/t²) · dt
   = [A·(T-T°) + B·(T²-T°²)/2 + C·(T³-T°³)/3 + D·(T⁴-T°⁴)/4 - E·(1/T - 1/T°)] · 1000
```

**用 NIST Shomate 在线计算器:** 可输入 T 得到 h - h(298),直接减去 h° 就是 Δh。

### 3.3 CO₂ 显热估算(数量级)

```
h_ideal(CO₂, 280°C, 1 atm)
= ∫[25°C→280°C] Cp(T) dT
≈ 232 kJ/kg                        (主档数字)
= 10.2 kJ/mol
```

**数值校核:** NIST WebBook CO₂ 在 553.15 K 与 298.15 K 的焓差 = 10089 J/mol = **10.09 kJ/mol**——**与估算一致**。

## 四、为什么理想气体假设在工程上不能用

### 4.1 物理层面

**1. 分子间力不可忽略:** 即使是稀有气体,临界点附近也会强烈偏离理想行为
**2. 液体密度高:** 液体密度比气体高 1000 倍,分子紧密接触,排斥力主导
**3. 临界点附近连续相变:** T → T_c, V 剧烈变化,理想气体模型完全失效

### 4.2 工程层面

| 工程任务 | 不能用理想气体 |
|----------|------------------|
| 反应器热平衡 | 真实 h 必须查 EOS |
| 压力容器设计 | 蒸汽压必须用真实 EOS |
| 精馏塔塔板数 | 相对挥发度必须用真实 EOS |
| 流体输送计算 | 真实 ρ, μ 不可拍脑袋 |
| 制冷循环 COP | 跨临界 CO₂ 在临界点附近强烈偏离 |

### 4.3 数字层面的铁证

**Pr 工况:**

```
工况 A(常压 25°C 烟气)
   T_r = 0.9, P_r = 0.0001
   Z = 0.999
   误差 < 0.1%
   → 理想气体可用

工况 B(CO₂ 临界 7.4 MPa, 31°C)
   T_r = 1.0, P_r = 1.0(临界!)
   Z = 0.274(临界压缩因子)
   误差 ~ 73%!
   → 必须用 SW EOS

工况 C(CO₂ 30 MPa, 280°C, 超临界)
   T_r = 1.82, P_r = 4.07
   Z = 0.69
   误差 31%
   → 必须用 PR 或 SW EOS
```

## 五、修正方法论(为本 SKILL 后续主题铺路)

### 5.1 立方型 EOS(本 SKILL 重点)

**两类核心思路:**
1. **修正排斥项**:把 V 减去分子本身体积,加入"有效体积" V - b
2. **修正吸引力项**:减去分子间吸引力,加入"内压项" a/V²

**立方型 EOS 的本质:** P = 动能(吸引) + 内压

### 5.2 Helmholtz 多参数 EOS(本 SKILL 重点)

**核心思路:** 直接拟合物态 A(T, ρ),所有性质从 A 推出

**优点:** 全温压范围内精度均匀
**缺点:** 需要 ~580 项拟合系数

### 5.3 数值应用(CoolProp / REFPROP)

**用软件避免手工算 v, Z 的复杂度:**
```python
from CoolProp.CoolProp import PropsSI
ρ = PropsSI('D', 'T', 553.15, 'P', 30e6, 'CO2')
h = PropsSI('H', 'T', 553.15, 'P', 30e6, 'CO2')
Z = PropsSI('Z', 'T', 553.15, 'P', 30e6, 'CO2')
# 输出:精确值,内部用 SW EOS
```
