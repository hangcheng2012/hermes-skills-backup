# P&ID v5.0 出图自检清单

> v5.0 是当前强制版（2026-06-06 女王当面确立）。出图前必须逐项打勾。
> 比 v3.5 多了 5 大类共 13 项，全部源自 v3.5/v4.0/v5.0 三版连续纠正。

## A. 基础项（v3.5 已有）

- [ ] 阀门用 ▷◁ 无缝蝴蝶结（path 一笔画成，不分开）
- [ ] 信号线连接到具体控制阀门（TIRC→TCV, FRC→FCV, PIRC→PCV, LRC→LCV）
- [ ] 设备不重叠，文字不压字
- [ ] 管道带箭头、流向清晰
- [ ] 仪表用 ISA 标准圆圈
- [ ] PSHH/TSHH 安全联锁用红色
- [ ] 图例完整
- [ ] UTF-8 BOM
- [ ] HTML 4.01 Transitional DOCTYPE
- [ ] 无 `<style>` 块，无内联 style
- [ ] 无 JavaScript

## B. 设备规模项（v3.3 已有）

- [ ] 反应釜/储罐装填率 40-65%
- [ ] 泵流量 = 釜容积 × 3~5 次/h
- [ ] 锅炉/冷水机组功率匹配加热/冷却负荷
- [ ] 投资估算基于真实规模

## C. 接管 + 箭头项（v3.4 已有）

- [ ] 每个设备所有接管都有 nozzle 圆点 + 接管 stub
- [ ] 接管位置标签（顶/侧/底 进/出）清晰可见
- [ ] 接管编号（NO-XXXA~N）系统化编排
- [ ] 所有管道箭头方向明确（按 4 情形表）

## D. v4.0 新增项（4 大类共 8 项）

### D-1 箭头与线之间 8-10px 间距（v4.0 起强制）
- [ ] 管线终止于 y=y_stop
- [ ] 留 8-10px 空白间隔
- [ ] 箭头 polygon 单独绘制（tip 指向下一级设备）
- [ ] 箭头尺寸：宽度 16px × 高度 18px

### D-2 夹套虚线框显著加粗（v4.0 起强制）
- [ ] stroke-width: **3-4px**（不再是 1-2px）
- [ ] stroke-dasharray: **"8,4"**（不再是 "3,2"）
- [ ] 填充: `fill="#E3F2FD" fill-opacity="0.5"`
- [ ] 矩形尺寸: 设备本体宽 + 30-50px, 高 + 40-60px
- [ ] 标签 "▣ HO 夹套 (200°C)" 置于框右上角
- [ ] 全部 4 类带夹套设备 (V-201/R-301/V-401/V-501) 一致应用

### D-3 HO/CW 物料线止于框边（v4.0 起强制）
- [ ] 物料线**只能画到夹套虚线框的边缘**（不穿过框进入设备本体）
- [ ] 例：R-301 夹套框底边 y=745 → 物料线止于 y=755（框下方 8-10px）
- [ ] 箭头尖端接触 y=745（框边），base 在 y=755

### D-4 零重叠防压字（v4.0 起强制）
- [ ] 每个标签独占 25-30px 高度空间
- [ ] 设备间最小水平间距 ≥ 80px，垂直间距 ≥ 50px
- [ ] 接管标签位置: 接管侧方或上下方（不在管线上）
- [ ] 阀门位号: 阀门正上方 12px
- [ ] 用搜索工具数 `<text>` 和 `<polygon>` 总数，验证无坐标重叠

## E. v5.0 新增项（5 大类共 13 项 — 女王当面立规）

### E-1 多股进料三 y 高度零重叠
- [ ] **N₂ 进料路由 y=145 高度**（最上方）
- [ ] **PPDI 进料路由 y=240 高度**（中间）
- [ ] **PTMG 进料路由 y=120 高度**（独立）
- [ ] 三股水平段在不同 y 高度，**绝不共享 y 高度**
- [ ] 标尺参考：典型 viewBox 2600×1800，y 间距 ≥ 50px 视为安全

### E-2 进料汇聚总管 (Convergence Manifold)
- [ ] 多股进料（≥2 股）进入同一设备时，**必须**先汇聚到一条总管
- [ ] 总管高度 y=380（位于 R-301 顶部上方）
- [ ] 总管矩形规格：fill="#FFFDE7" stroke="#FF6F00" stroke-width="2.5"，510×22px
- [ ] 总管标签："R-301 进料汇聚总管" + "PTMG + PPDI + N₂ 混合进料"
- [ ] 三股进料各自带**箭头**指向总管（不同 x 位置入总管）
- [ ] 总管出口: 单条管线带 **↓ 朝下箭头** NO-301A 顶进 R-301

### E-3 HO/CW 4 接管清晰区分
- [ ] 4 个夹套接管水平错开 x 位置（30px 间距）：
  - x=1010: ↓ HO 供应 (200°C)
  - x=1040: ↑ HO 返回 (160°C)
  - x=1070: ↓ CW 供应 (5°C)
  - x=1100: ↑ CW 返回 (20°C)
- [ ] 每个接管下方加**温度标签**
- [ ] 供应管用蓝色实线，返回管用蓝色虚线 `stroke-dasharray="6,3"`

### E-4 同设备顶部多接管错开
- [ ] 同一设备顶部若有 ≥2 个接管，**必须错开**：
  - 水平 x 位置：每个接管 x 间距 ≥ 40px
  - 垂直 y 位置：manhole 投料口与真空接管不在同一 y 范围
- [ ] 投料 manhole: 40×14 虚线矩形 + ↓ 箭头朝下
- [ ] 真空接管: ↑ 箭头朝上
- [ ] MOCA 投料安全警示：必须加 "致癌物!" 红色警告 + "人工+手套箱"

### E-5 混合设备双进料错开位置
- [ ] MX-601 静态混合器有两个进料口：脱气预聚体 (V-401) + MOCA 熔料 (V-501)
- [ ] **顶进 + 侧进**错开：
  - V-401 → MX-601: **顶进** (y=860 → y=1080 进入顶部) ↓ 箭头
  - V-501 → MX-601: **侧进** (y=1100 进入左侧面) → 箭头
- [ ] 两个入口的 y 高度差 ≥ 20px
- [ ] 出口: MX-601 底出 (y=1180 → y=1220) → 浇注口 ↓ 箭头

## 版本演进总结
