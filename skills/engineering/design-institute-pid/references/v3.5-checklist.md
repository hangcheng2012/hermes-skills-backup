## 五、设备规模（v3.3 必检）

- [ ] 反应釜/储罐装填率 **40-65%**
- [ ] 泵流量 = 釜容积 × 3~5 次/h
- [ ] 锅炉/冷水机组功率匹配加热/冷却负荷
- [ ] 投资估算基于真实规模（不套用商业装置规格）
- [ ] 设备规格按市售标准件圆整（50/100/150/200/300/500/1000L）

**反算公式**：
```
单釜产量 = 年产量 ÷ 釜数
单釜体积 = 单釜产量 ÷ 物料密度 (kg/L)
反应釜有效容积 = 单釜体积 ÷ 装填率
```

**真实案例**（10 t/a PU 弹性体）：
- 10000 kg/a ÷ 150 釜 = 67 kg/釜 → 63.5L/釜 → 150L 反应釜（装填 42%）

## 六、接管 nozzle + 位置标签（v3.4 必检）

- [ ] 每个设备所有接管都有 nozzle 圆点（`<circle r="3" fill="#XXX"/>`）
- [ ] 每个接管都有短接管 stub（`<line stroke-width="1.5"/>`）从圆点垂直伸出
- [ ] 每个接管有位置标签：`NO-XXXA 顶进` / `顶回` / `侧进` / `底出` 等
- [ ] 接管编号系统化（V-201 = NO-201A~D, R-301 = NO-301A~F, V-401 = NO-401A~D, V-501 = NO-501A~E）
- [ ] 图例区含 nozzle 接管符号

**接管位置类型**：
| 位置 | 含义 | 典型用途 |
|---|---|---|
| 顶进 | 顶部接管，进入 | 蒸汽 HS、N₂、原料进料 |
| 顶出 | 顶部接管，排出 | 真空 VAC、PSV/RD 泄放 |
| 顶回 | 顶部接管，夹套回流 | 导热油/冷冻水回 |
| 侧进 | 侧面（夹套）接管 | 导热油/冷冻水进夹套 |
| 底进 | 底部接管，进入 | 极少用（重力流例外）|
| 底出 | 底部接管，排出 | 物料排放、底阀 |

## 七、箭头方向铁律 4 情形表（v3.5 必检，**女王硬规**）

> ⚠️ **女王 2026-06-06 当面纠正**：v3.4 把顶进接管箭头方向画反了。**必须按此 4 情形表**：

| 接管位置 | 流体方向 | **箭头方向** | polygon tip 位置 |
|---|---|---|---|
| **从上面进入**（顶进） | ↓ 流向下 | **↓ 朝下** | tip y > base y（如 1080,462） |
| **从上面离开**（顶出） | ↑ 流向上 | **↑ 朝上** | tip y < base y（如 2050,695） |
| **从下面进入**（底进） | ↑ 流向 | **↑ 朝上** | tip y < base y（如 290,1247） |
| **从下面离开**（底出） | ↓ 流向下 | **↓ 朝下** | tip y > base y（如 1210,1082） |

**自检铁律**：
- [ ] N₂ / PPDI / PTMG 进 R-301 顶部 NO-301A/B/C：**↓ 朝下**
- [ ] E-701 HO 进 R-301 jacket NO-301E：**↓ 朝下**
- [ ] C-701 CW 进 R-301 jacket NO-301F：**↓ 朝下**
- [ ] R-301 → V-401 预聚体出料 NO-301D 底出 → 进 V-401 顶：**↑ 朝上**（底进）
- [ ] V-401 → MX-601 进料 NO-401B 底出：**↓ 朝下**（V-401 顶进）
- [ ] 真空 VAC 出 V-201 / V-401 顶出：**↑ 朝上**
- [ ] MOCA 投料进 V-501 NO-501A：**↓ 朝下**

## 快速失败模式（v3.5 新增）

| 错误 | 根因 | 修正 |
|---|---|---|
| 顶进接管箭头朝**上** | 错把"箭头指下一级"理解成总是朝上 | 查七节箭头方向 4 情形表，**顶进 ↓ 朝下** |
| 导热油去向不明 | 漏画返回管 | 闭路循环必须双向：供应 + 返回 |
| 夹套只画管线条 | 漏画外层虚线框 | 加 rect 虚线框 + 引线 ↓ 入框 |
| 固体釜无进料 | 漏画人工投料口 | 顶部 manhole 40×14 + ↓ 投料箭头 |
| 设备只有输出无输入 | 没检查输入完整性 | 自检每个设备至少一个输入接管 |
| 投资浪费 60% | 设备规模过大 | 按 v3.3 设备规模匹配铁律重算 |
