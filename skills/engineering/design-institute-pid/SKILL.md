## 一、技术栈约束（强制）

| 项 | 要求 | 原因 |
|----|------|------|
| DOCTYPE | **HTML 4.01 Transitional** | 最古老最兼容 |
| 编码 | **UTF-8 + BOM** | Windows 记事本友好 |
| 绘图方式 | **SVG 矢量** | 不重叠、可缩放、支持所有浏览器 |
| CSS | **不使用 `<style>` 块** | 部分安全策略屏蔽 |
| 内联 style | **不使用** | 简化渲染 |
| 现代 CSS（flex/grid/clip-path/伪元素）| **禁止** | Edge 旧版/IE 11 不支持 |
| JavaScript | **不使用** | 安全/兼容问题 |
| 字体 | **SimHei, Arial, sans-serif** | Windows 11 自带 |
| 颜色 | **直接 hex 写在 SVG 属性** | 不依赖 CSS 解析 |
| 文件大小 | **≤ 60 KB**（单张图纸）| 微信传输友好 |

## 二、阀门符号 SVG 规范（▷◁ 无缝对接）

**核心铁律**：阀门用**单个 `<path>` 一笔画成蝴蝶结**（▷◁），两三角形**在中心点无缝对接**，不分开画、不留缝。

### 2.1 阀门标准尺寸
- 阀门宽度 24px，高度 16px
- 中心点 (cx, cy) 是管道的通过点
- 中心点必须与管道中线精确对齐

### 2.2 各类型阀门 SVG 代码

```svg
<!-- 闸阀（Z） -->
<path d="M -12 -8 L 0 0 L -12 8 Z M 0 0 L 12 -8 L 12 8 Z"
      fill="#FFFFFF" stroke="#000" stroke-width="1.5"/>
<line x1="0" y1="-8" x2="0" y2="-15" stroke="#000" stroke-width="1.5"/>
<rect x="-3" y="-22" width="6" height="7" fill="#000"/>

<!-- 截止阀（J）：仅蝴蝶结 -->
<!-- 球阀（Q）：圆 + 对角线 -->
<!-- 止回阀（H）：三角 + 顶横线 -->
<!-- 调节阀（CV/FCV/TCV/PCV/LCV）：蝴蝶结 + 圆形执行器 -->
<!-- 安全阀（PSV）：竖线 + 三角 + 弹簧 -->
<!-- 爆破片（RD）：矩形 + X -->
<!-- 紧急切断阀（XV）：蝴蝶结 + X -->
```

完整代码示例见各阀门类型章节（详见模板文件）。

## 三、仪表符号 SVG 规范（ISA 标准圆圈）

### 3.1 通用仪表圆

```svg

```

### 3.2 仪表位号命名（ISA-5.1）

**基础字母表 + 组合后缀** 详见 `pid-pfd-v69-standards`（§ISA-5.1 仪表代号）。

**本 skill 复用规则**：
- TIRC = 温度指示+记录+控制（DCS 完整回路）
- PIRC/FRC/LRC 同理
- PSHH/TSHH/LSHH = 高高联锁（红色圆圈，SIL 联锁）
- 仪表位号必须**从控制仪表圆圈连接到具体控制阀**

### 3.3 仪表线型分类

| 类别 | 线型 | 颜色 | 用途 |
|------|------|------|------|
| **仪表安装线** | 实线 1.5px | `#000` 黑 | 测量仪表 → 设备 |
| **控制信号线** | 虚线 1.2px `dasharray="4,3"` | `#FF6F00` 橙 | 控制仪表 → 控制阀 |
| **安全联锁线** | 虚线 1px `dasharray="3,2"` | `#C62828` 红 | PSHH/TSHH → 切断阀 XV |

5. 仪表位号文字**居中**在圆圈内，字号 9-10px
6. 设备位号用**较大字号**（16-22px）且加粗

## 十三、设备规模匹配铁律

**触发场景**：用户给出设计产能（如 10 t/a）+ 釜数（如 150 釜/年），需反算设备规格。

```
单釜产量 = 年产量 ÷ 釜数
单釜体积 = 单釜产量 ÷ 物料密度 (kg/L)
反应釜有效容积 = 单釜体积 ÷ 装填率
```

**核算步骤**：
1. 获得年产量、釜数、装填率（默认 0.5）
2. 查物料密度（PTMG 1.0, PPDI 1.2, MOCA 1.4, 预聚体 ~1.05）
3. 反算反应釜/储罐有效容积
4. 按市售标准规格向上圆整（50/100/150/200/300/500/1000L）
5. 验证装填率落在 40-65% 区间
6. 同步缩泵流量（反应釜容积 × 3~5 次/h）、换热面积、冷凝器、锅炉/冷水机组功率

**禁区**：
- ❌ 套用"中试装置 500L" / "商业装置 2000L" 不验证
- ❌ 反应釜装填率 < 30% 或 > 70%
- ❌ 储罐只考虑批次量不考虑周转/储量周期

## 十六、PU 弹性体 CPU 工艺专项（女王 06-18/06-19 总结）

> 本节为 PU 弹性体 CPU 工艺 P&ID 专项铁律（仅适用该工艺），出 PU 弹性体 P&ID 必读。完整工艺设计参考见 `references/polyurethane-cpu-elastomer-design.md`。

### 工艺分流（女王 06-18 铁律第一条）
- **弹性体 CPU** = 预聚物法（R-301 预聚 + V-401 脱气 + V-501 扩链）— **本项目**
- 软/硬泡 = 一步法/RIM（混合头+发泡箱）
- 涂料 = 半预聚物法
- **接 PU 设计先确认产品类型**（设备完全不同）

### 出图铁律（女王 06-19/06-20 连续强调）

1. **箭头方向 = 流体方向**（唯一判据，不为视觉交替而硬反向）
2. **箭头、文字标注、流体方向 三者必须一致**
3. **TDI 储罐按一周储存量计算**（V-102 50L 满足 23 kg/周）
4. **横向延伸**（viewBox 宽 ≥ 2400 px）
5. **不分单元**（一张 P&ID 贯通所有设备 + 公用工程）
6. **所有管线只走横/竖**（直角走线，禁斜线/曲线）
7. **公用工程只出水电气风**（水/电/气/风）+ 底部备注说明原单元划分
8. **MOCA 储罐不需要 N₂**（干燥密封即可），MOCA 熔化釜必须 N₂ 保护
9. **TDI 不要泵**（用 N₂ 压料，避免密封泄漏）
10. **6 台工艺泵**：P-101/P-201/P-301/P-401/P-501/P-601（齿轮泵 + 柱塞计量泵）

### 严禁提 PDI（除非该工艺确实用 PDI）
- 女王当前工艺 = **TDI**（不是 PDI）
- 出图前确认工艺用哪种异氰酸酯
- **如非 PDI 工艺，严禁在图上/文字/标题/文件名提 PDI**
