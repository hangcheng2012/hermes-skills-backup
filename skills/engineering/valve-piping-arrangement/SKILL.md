# 化工装置通用阀门设置与管路布置

> **本 skill 是工艺专业下面的子 SKILL**（与 petrochem-process-design 平级），
> 用于所有化工/石化项目（小试/中试/工业化）的阀门选型与 P&ID 布置，**不绑定特定项目**。
>
> **核心定位**：阀门是化工装置中"件数最多、最容易出错、最常被忽略布置细节"的元件。
> 本 skill 用**铁律 + 流程图 + 决策树 + 反例**的形式，让女王任何项目出图/审图时**先调本 skill 再下笔**。

## 一、核心铁律（8 条，违反必出问题）

### 铁律 1：任何工艺设备/阀门，前后必须设切断阀

**依据**：《化工工艺设计手册（第五版）》下册 §36.1.2.1 + 上册 §27 章泵部分。

**含义**：减压阀、调节阀、过滤器、止回阀、流量计、换热器、分离器……**任何需要隔离维修的元件**，前后都设切断阀（闸阀 Z 或球阀 Q）。

**反例**：
- ❌ 减压阀前没有切断阀 → 减压阀损坏时无法在线更换，全装置停车
- ❌ 止回阀后没有切断阀 → 止回阀失效/更换时无法隔离下游
- ✅ **切断阀必须设**（例外：背压阀后无阀、PSV 前后可仅有切断阀）

### 铁律 2：减压阀后**通常**需要止回阀（5 种触发条件）

**依据**：下册 §36.1.2.4 ⑥ 公用工程站规则 + §27 章泵出口规则（推广到减压阀场景）。

**5 种触发条件**（任一成立即必须设）：

| # | 触发条件 | 工程实例 |
|---|----------|----------|
| ① | **阀后介质会倒流回上游系统** | 公用物料（蒸汽/压缩空气/氮气）减压后通入工艺系统 |
| ② | **阀后介质有危险性，倒流会造成安全事故** | LPG/烃类蒸汽减压、可燃气体管路 |
| ③ | **阀后是多用户管路** | 蒸汽减压站母管 → 多个用户支管 |
| ④ | **阀后是工艺容器/设备，停用时不能倒流** | 减压后到反应器、精馏塔、加热炉 |
| ⑤ | **阀后有压力更高的旁路源** | 减压阀 + 旁路闸阀并联 |

**何时不需要**：
- 阀后是单用户、用量稳定、停用时阀门全关
- 阀后是开放式排放/排向火炬总管（无密闭回路）
- 阀前已有可靠止回阀，再加重复

### 铁律 3：离心泵出口**必须**设止回阀，容积式泵通常不设

**依据**：上册 §27 章泵部分原文：
> "**离心泵或漩涡泵在泵出口与切断阀之间应设止回阀，直径与切断阀相同**。
> 容积式泵通常不需要设止回阀。"

**位置**：泵出口 → **止回阀 → 切断阀**（**止回阀靠近泵，切断阀靠管路**）

### 铁律 4：止回阀只能防"突然倒流"，密封性欠佳；严格禁倒流的物料必须双保险

**依据**：下册 §36.1.1.2(5) 原文：
> "止回阀只用以防止突然倒流，但**密封性能欠佳**，因此对严格禁止倒流的物料，**还应采取其他措施**。"

**双保险方案**：
- 关键物料（剧毒、易燃易爆、贵重）：双止回阀串联
- 高压场合：止回阀 + 紧急切断阀（XV）
- LNG/液烃：止回阀 + 真空破坏阀（防虹吸）

### 铁律 5：减压阀上游**必须**设安全阀（PSV）保护减压阀不被超压

```
上游管 ──[闸阀①]──[过滤器]──[减压阀 PCV]──[止回阀]──[闸阀②]── 下游管
                              │
                              └──[PSV]──(泄放至安全地点)
```

**PSV 设定压力** = 减压阀上游设计压力（**保护减压阀阀体不被超压**）。

⚠️ PSV 必须画在减压阀**前**——女王出 P&ID 时容易漏的反例。

### 铁律 6：调节阀（含 PCV/FCV/TCV/LCV）需要旁路阀（手轮型可省）

```
──[闸阀①]──[调节阀]──[闸阀②]──
                │
                └──[旁路闸阀]──
```

**例外**："带手轮的调节阀，根据工艺条件，可不设旁路"（下册 §36.1.2.4 引）。
**旁路阀尺寸**：通常与主管同径（DN 与调节阀相同）。

### 铁律 7：阀门的选用按功能定类型

| 功能 | 推荐阀门类型 | 原因 |
|------|-------------|------|
| 切断（不上全开全关频繁） | **闸阀 Z** | 阻力小、流体直通、密封好 |
| 切断（频繁启闭） | **球阀 Q** | 启闭快、轻便、密封好 |
| 流量调节（中等流量） | **截止阀 J** | 调节性好 |
| 流量调节（精细微调） | **针形阀** | 微调性能好 |
| 防倒流 | **止回阀 H** | 单向导通 |
| 压力/流量/温度自动调节 | **调节阀**（气动/电动）| 配 PC/FC/TC 控制系统 |
| 超压保护 | **安全阀 A / PSV** | 紧急泄放 |
| 快速切断（紧急） | **XV 紧急切断阀** | SIS 联锁 |
| 浆料/含固 | **隔膜阀 G / 刀闸阀** | 防卡阻 |

### 铁律 8：P&ID 上阀门的位号与符号必须规范

| 阀门 | 位号前缀 | P&ID 符号 |
|------|----------|----------|
| 闸阀 / 球阀 / 截止阀 | 无（仅做切断功能时）| `▌▌` / `▷◁` / `⊥` |
| 止回阀 | 无（仅做防倒流时）| `▷◁` + 流向箭头 |
| 调节阀 | `PCV / FCV / TCV / LCV` | `Ⓒ` |
| 安全阀 | `PSV` | `Ⓢ` |
| 紧急切断阀 | `XV-XXX` | `▷◁` + 弹簧 |
| 自力式/减压阀 | `PCV-XXX` | `Ⓒ` + 弹簧 |

## 二、典型阀门布置（4 种核心场景）

### 场景 1：蒸汽减压站 / 公用气体调压站

```
上游管 ──[闸阀①]──[过滤器]──[减压阀 PCV]──[PSV]──[止回阀]──[闸阀②]── 下游管
                              └──[旁路闸阀]──(从闸阀①后引到闸阀②前)
```

**元件清单**（最小集）：闸阀×2 + 过滤器×1 + 减压阀×1 + PSV×1 + 止回阀×1 + 旁路阀×1

### 场景 2：离心泵出口管路（最常用）

```
        ┌──[闸阀②]── 下游管
泵 ── → ┤
        └──[止回阀]──[闸阀③]── 下游管（备用）
```

**标准布置**：泵出口 → 止回阀 → 闸阀（**止回阀紧贴泵**）

### 场景 3：调节阀（含 PCV/FCV/TCV）标准布置

```
──[闸阀①]──[调节阀]──[闸阀②]──
                │
                └──[旁路闸阀③]──
```

### 场景 4：精馏塔顶压力控制（PCV + PSV + 止回阀）

```
塔顶 ──[PCV]──[止回阀]── 冷凝器 ── 回流罐 ── 泵
              │
              └──[PSV]── 火炬
```

**关键提醒**：
- PCV 控制塔顶压力
- 止回阀防止冷凝器侧压力高于塔顶时倒流
- PSV 保护塔顶超压（设于塔顶或 PCV 上游）

## 三、决策树：何时设止回阀

```
是否需要在某位置设止回阀？
│
├── 是泵出口？ ── 是 → 离心泵必设；容积式泵通常不设 ──→ 铁律 3
│
├── 是减压阀后？
│   ├── 阀后介质会倒流回上游？ ── 是 → 设 ──→ 铁律 2 ①
│   ├── 阀后物料有危险性？ ── 是 → 设 ──→ 铁律 2 ②
│   ├── 阀后是多用户？ ── 是 → 设 ──→ 铁律 2 ③
│   ├── 阀后是工艺设备？ ── 是 → 设 ──→ 铁律 2 ④
│   ├── 阀后有更高压力旁路？ ── 是 → 设 ──→ 铁律 2 ⑤
│   └── 都不符合？ → 可不设
│
├── 是公用物料切断阀下游？ ── 是 → 设（防工艺流体倒流污染公用工程）
│
├── 是蒸汽/可燃气体管路？ ── 是 → 设
│
└── 是排放/放空管路？ ── 否（开放管路无倒流问题）
```

## 四、决策树：何时设切断阀

```
是否需要在某位置设切断阀？
│
├── 是装置边界（界区）？ ── 是 → 必须设
│
├── 是设备/阀门/仪表的进出口？ ── 是 → 必须设（铁律 1）
│   ├── 减压阀 ── 前后各 1 个
│   ├── 调节阀 ── 前后各 1 个 + 旁路
│   ├── 止回阀 ── 通常下游 1 个
│   ├── 安全阀 ── 上游 1 个（铅封开启 CSO）
│   ├── 换热器 / 过滤器 ── 进出口各 1 个
│   ├── 流量计 ── 上游 1 个（下游可选）
│   └── 离心泵 ── 进出口各 1 个 + 止回阀
│
├── 是用户分支管？ ── 是 → 设根部阀
│
├── 是液化气/可燃/有毒/贵重？ ── 是 → 设双阀
│
└── 是排空/放净/取样？ ── 视物料性质（通常单阀，特殊物料双阀）
```

## 五、常见反例（必须避免）

### 反例 1：减压阀前后未设切断阀
```
❌ 上游管 ──────────[减压阀]────────── 下游管
✅ 上游管 ──[闸阀①]──[减压阀]──[闸阀②]── 下游管
```
**后果**：减压阀损坏时无法在线更换，全装置停车。

### 反例 2：PSV 设错位置（减压阀后）
```
❌ 上游管 ──[减压阀]──[PSV]── 下游管（PSV 在减压阀后）
✅ 上游管 ──[PSV]──[减压阀]── 下游管（PSV 在减压阀前）
```
**错误原因**：减压阀可能被下游高压顶住或失效时上游压力全压到阀体上，PSV 必须保护减压阀本体，设在阀**前**保护的是上游管线+减压阀。

### 反例 3：容积式泵出口多此一举设止回阀
```
❌ 容积式泵（柱塞泵）──[止回阀]── 下游（多余）
✅ 容积式泵 ── 下游（自身结构防倒流）
```
**依据**：上册 §27 章——"容积式泵通常不需要设止回阀"。

## 九、scCO₂ / 超临界流体专题

**完整 Pitfalls 列表（10 条）见 `references/scCO2-pitfalls.md`**

**快速索引**（scCO₂-PET 项目常见踩坑）：
- Pitfall 2：节流"会冻 vs 不冻"取决于阀后压力是否 > 三相点
- Pitfall 3：高压真实气体不能用理想气体公式（误差 40-50%）
- Pitfall 4：scCO₂-PET 工业实际 30 MPa，非文献综述 8-15 MPa
- Pitfall 6：阀后罐底需**伴热**（不是冷却，反直觉）
- Pitfall 7：超临界流体是"第三态"，管路阻力按液体公式
