> **本文件是 valve-piping-arrangement SKILL 的 references/ 详解之一**。

## 一、止回阀的本质

### 1.1 定义
止回阀（Check Valve，代号 H）是**单向阀**，介质正向流动时自动开启，
介质反向流动时自动关闭。**不需要外部动力，靠介质自身压力 + 阀瓣重力/弹簧力**。

### 1.2 关键限制（铁律 4）

**《化工工艺设计手册（第五版）》下册 §36.1.1.2(5) 原文**：
> "止回阀只用以防止突然倒流，但**密封性能欠佳**，因此对严格禁止倒流的物料，**还应采取其他措施**。"

**含义**：
- 止回阀**只能防"突然倒流"**（水锤、快速关停等）
- 慢速倒流 / 长期倒流 / 微小倒流 → 止回阀**可能关不严**
- 严格禁倒流的物料 → **必须双保险**（双止回阀 + XV 切断阀）

## 二、止回阀的分类

### 2.1 旋启式止回阀（H44H）

**结构**：阀瓣绕阀瓣轴旋转启闭，靠重力或弹簧复位。

**特点**：
- 直径范围最广（DN50~DN600+）
- 可装在水平/垂直/倾斜管道上
- 垂直管道上**流体应自下而上流动**
- 流体阻力小（流阻系数 ≈ 2~4）

**应用**：
- 蒸汽管路
- 气体管路
- 大口径水/油管路
- 公用工程管路

### 2.2 升降式止回阀（H41H）

**结构**：阀瓣沿阀体中心线垂直升降，靠重力或弹簧复位。

**特点**：
- 直径范围小（DN15~DN150）
- **只能装在水平管道**（垂直管道上阀瓣不会因重力下落关闭）
- 流体阻力较大（流阻系数 ≈ 6~8）

**应用**：
- 小口径蒸汽/水/油管路
- 配套泵的止回阀

### 2.3 球式止回阀（H45H）

**结构**：阀瓣为球形，靠球体滚动启闭。

**特点**：
- 直径范围小（DN15~DN200）
- 只能装在水平管道
- 流体阻力中等

**应用**：
- 黏度较大的介质（油品、糖浆等）
- 含少量固体的液体

### 2.4 蝶式止回阀（H76H）

**结构**：阀瓣为蝶形板，靠弹簧复位。

**特点**：
- 体积小，重量轻
- 启闭快
- 流体阻力中等

**应用**：
- 大口径水/空气管路
- 排水管路

### 2.5 对夹式止回阀（H71H/H74H）

**结构**：阀体为薄饼状，对夹在两法兰之间。

**特点**：
- 体积最小，重量最轻
- 安装方便
- 价格低

**应用**：
- 公用工程管路
- 不重要场合的防倒流

## 三、止回阀的 5 类应用场景（铁律 2 详解）

### 场景 1：离心泵出口（铁律 3）

**依据**：上册 §27 章泵部分——"离心泵或漩涡泵在泵出口与切断阀之间应设止回阀，直径与切断阀相同"。

**标准布置**：
```
        ┌──[闸阀②]── 下游管
泵 ── → ┤
        └──[止回阀]──[闸阀③]── 下游管（备用线）
```

**为什么必须设**：
- 离心泵停泵后，泵出口压力骤降 → 下游流体倒灌 → 泵倒转损坏
- 止回阀靠弹簧 + 重力迅速关闭，防止倒灌

**位置**：
- 止回阀**紧贴泵出口**（距离越短越好，防倒流冲击）
- 切断阀在止回阀之后（切断阀不承受倒流冲击）

**反例**：
- ❌ 容积式泵（柱塞/螺杆/齿轮）出口设止回阀——**多此一举**（容积式泵自身结构防倒流）
- ❌ 止回阀后没有切断阀——无法隔离下游
- ❌ 止回阀直径小于切断阀——铁律 3 要求直径相同

### 场景 2：减压阀后（5 触发条件）

详细见 `reducing-valve-arrangement.md`。

**5 种触发条件**：
1. 阀后介质会倒流回上游系统
2. 阀后介质有危险性，倒流会造成安全事故
3. 阀后是多用户管路
4. 阀后是工艺容器/设备
5. 阀后有压力更高的旁路源

### 场景 3：公用物料切断阀下游（§36.1.2.4 ⑥）

**原文**："公用物料管道可能由于工艺流体倒流而受到污染时，则在公用物料管切断阀下游设止回阀。"

**典型应用**：
- 氮气管路切断阀后（防工艺流体倒流污染 N₂ 总管）
- 蒸汽管路切断阀后（防工艺流体倒流污染蒸汽总管）
- 压缩空气管路切断阀后

### 场景 4：可燃气体管路

**依据**：铁律 2 ② + GB 50016 防火规范。

**典型应用**：
- LPG 输送管路（防 LPG 倒流回上游）
- 天然气管路
- 氢气管路

**特别要求**：可燃气体管路**止回阀 + 紧急切断阀 XV** 双保险。

### 场景 5：精馏塔 / 反应器 / 加热炉进出口

**典型应用**：
- 塔顶冷凝器出口止回阀（防回流倒流）
- 加热炉出口止回阀（防停料时炉管内流体倒流）
- 反应器出口止回阀（保压）

## 四、双止回阀（Double Check Valve）

### 4.1 何时用双止回阀

**依据**：铁律 4 + 工艺安全要求。

**应用场景**：
- 严格禁止倒流的物料（剧毒、易燃易爆、贵重）
- 倒流会引发重大事故的管路
- 与生活饮用水系统连接（防污染）
- 与公用工程连接（防污染）

### 4.2 双止回阀的布置

**方案 1：两个旋启式止回阀串联**
```
上游 ──[止回阀①]──[止回阀②]── 下游
```

**方案 2：止回阀 + 切断阀组合**
```
上游 ──[止回阀]──[闸阀]── 下游
```

**方案 3：双止回阀 + 监测阀**（双重止回阀站，DCV）
```
上游 ──[止回阀①]──[监测阀]──[止回阀②]── 下游
   │
   └───[泄放阀至大气]──────┘
```
**当监测阀处压力 > 大气压时** → 中间腔有泄漏 → 报警 + 检修

### 4.3 双止回阀站（DCV Station）应用

- **饮用水与工艺水切换**：防饮用水被污染
- **消防水与工艺水切换**：防工艺水污染消防水
- **公用水与工艺水切换**：防工艺水污染公用水

## 五、止回阀的安装位置（关键！）

### 5.1 安装方向

**流体方向必须与阀体上箭头一致**——这是安装时最容易出错的地方。

### 5.2 安装位置规则

| 阀门类型 | 安装方向 | 备注 |
|----------|---------|------|
| 旋启式 | 水平/垂直/倾斜（垂直时流体自下而上） | 倾斜管道可装 |
| 升降式 | **仅水平管道** | 垂直管道不能装 |
| 球式 | **仅水平管道** | 垂直管道不能装 |
| 蝶式 | 任意方向 | 但阀瓣要正确 |
| 对夹式 | 与管道同向 | 法兰对夹 |

### 5.3 与切断阀的相对位置

**原则**：
- **止回阀在切断阀**的**上游侧**（靠近保护设备）
- 切断阀在止回阀的**下游侧**（靠管路）

**例**（离心泵出口）：
```
        ┌──[闸阀②]── 下游管（切断阀在下游）
泵 ── → ┤
        └──[止回阀]──[闸阀③]── 下游管（止回阀紧贴泵）
```

**例**（减压阀后）：
```
[减压阀]──[止回阀]──[闸阀]── 下游
   ↑        ↑          ↑
   PCV   止回阀先    切断阀后
```

## 六、止回阀的选型决策树

```
止回阀选型
│
├── 介质？
│   ├── 蒸汽/气体/水/油 ──→ 旋启式（首选）
│   ├── 黏度大 ──→ 球式
│   ├── 含固体 ──→ 隔膜式/球式
│   └── 腐蚀性 ──→ 衬氟/合金
│
├── 公称直径？
│   ├── DN15~DN50 ──→ 升降式/球式
│   ├── DN50~DN300 ──→ 旋启式
│   ├── DN300+ ──→ 蝶式/旋启式
│
├── 安装方向？
│   ├── 水平管道 ──→ 任意类型
│   ├── 垂直管道（流体自下而上） ──→ 旋启式
│   └── 倾斜管道 ──→ 旋启式
│
├── 密封要求？
│   ├── 一般 ──→ 软密封（橡胶/PTFE）
│   ├── 高温 ──→ 金属密封
│   └── 严格禁倒流 ──→ 双止回阀
│
└── 工艺要求？
    ├── 快速关闭（水锤保护） ──→ 弹簧复位 + 旋启式
    ├── 慢速关闭（防冲击） ──→ 重锤/阻尼
    └── 无冲击场合 ──→ 普通旋启式
```

## 七、止回阀与切断阀的关系（反例警示）

### 反例 1：止回阀在减压阀前

```
❌ 上游管 ──[止回阀]──[减压阀]── 下游管
✅ 上游管 ──[减压阀]──[止回阀]── 下游管
```

**错误原因**：止回阀的目的是防**阀后倒流**，应设在减压阀后；
设在阀前毫无意义（阀前压力本来就高，倒流方向反了）。

### 反例 2：止回阀前没有切断阀

```
❌ 上游管 ──[止回阀]── 下游管
✅ 上游管 ──[闸阀]──[止回阀]── 下游管
```

**错误原因**：止回阀需要维修/更换时无法隔离系统。

### 反例 3：止回阀位置远离泵出口

```
❌ 泵 ──[10 米管]──[止回阀]── 下游管
✅ 泵 ──[止回阀]── 下游管（紧贴泵）
```

**错误原因**：泵与止回阀之间的管道在停泵瞬间会被倒流的流体冲击，产生水锤。

### 反例 4：止回阀直径小于切断阀

```
❌ 切断阀 DN100 ──[止回阀 DN80]── 下游管（直径不一致）
✅ 切断阀 DN100 ──[止回阀 DN100]── 下游管（直径一致）
```

**错误原因**：手册 §27 章泵部分原文——"**直径与切断阀相同**"。

### 反例 5：可燃气体管路无止回阀

```
❌ 可燃气体上游 ──[调压阀]── 下游用户（无止回阀）
✅ 可燃气体上游 ──[调压阀]──[止回阀]── 下游用户
```

**依据**：铁律 2 ② + GB 50016 防火规范。

## 八、止回阀的维护与检修

### 8.1 常见故障
| 故障 | 原因 | 处理 |
|------|------|------|
| 关闭不严 | 阀瓣/阀座磨损、杂质卡阻 | 拆下清洗或更换阀瓣 |
| 启闭噪声大 | 流速过快、阀瓣振动 | 降低流速或换弹簧加重的止回阀 |
| 水锤 | 突然停泵/关阀 | 装缓闭止回阀（带阻尼） |
| 阀瓣卡死 | 杂质/腐蚀 | 拆下清洗 + 防腐蚀措施 |

### 8.2 检修周期
- 关键管路止回阀：**每年**至少检修一次
- 一般管路：**每 2 年**检修一次
- 备用管路止回阀：**每 3 年**检修一次
