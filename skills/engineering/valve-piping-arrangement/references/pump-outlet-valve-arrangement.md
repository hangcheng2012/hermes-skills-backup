# 离心泵 / 容积式泵出口阀门布置

> **本文件是 valve-piping-arrangement SKILL 的 references/ 详解之一**。
> 展开 SKILL.md 中关于泵出口阀门（铁律 3）的详解，包括离心泵、容积式泵的对比及完整布置。

---

## 一、泵的分类与阀门设置原则

### 1.1 离心泵 vs 容积式泵

| 类型 | 子类 | 工作原理 | 流量特性 | 扬程特性 | 阀门设置 |
|------|------|----------|----------|----------|----------|
| **离心泵** | 普通离心泵、漩涡泵 | 叶轮高速旋转产生的离心力 | 与转速正比、与压差弱相关 | 随流量增加而下降 | 出口**必设止回阀** |
| **容积式泵** | 柱塞泵、螺杆泵、齿轮泵、隔膜泵 | 容积周期性变化推动流体 | 与转速正比、与压差**无关** | 几乎不随流量变化 | 出口**通常不设止回阀** |

### 1.2 关键差异与阀门设置原因

**离心泵必须设止回阀的原因**：
- 离心泵停泵后，泵出口压力骤降
- 下游管路中的高压流体倒灌回泵
- 倒流的流体推动叶轮反向旋转（**泵倒转**）
- 泵倒转会损坏轴承、机械密封、电机
- **止回阀的作用**：停泵瞬间迅速关闭，防止流体倒流

**容积式泵通常不设止回阀的原因**：
- 容积式泵的排出阀本身就是单向阀（柱塞泵的排出阀、螺杆泵的定子结构）
- 容积式泵自身结构**防止倒流**（停泵时泵腔内流体被锁住）
- 多此一举反而增加阻力损失和泄漏点

## 二、离心泵出口标准布置

### 2.1 最小集布置

```
        ┌──[闸阀②]── 下游管（主流程）
泵 ── → ┤
        └──[止回阀]──[闸阀③]── 下游管（备用流程，少用）
```

**元件说明**：
| 元件 | 位置 | 作用 |
|------|------|------|
| 闸阀② | 泵后 + 止回阀后 | 切断下游主流程 |
| 止回阀 | 泵后 + 闸阀前 | 防下游倒流 |
| 闸阀③ | 止回阀后 | 隔离备用流程 |

### 2.2 完整布置（推荐）

```
        ┌──[闸阀②]── 下游管（主流程）
        │
泵 ── → ┤──[止回阀 H]──[闸阀③]── 下游管（备用流程）
        │
        │
[泵入口]──[闸阀①]──[过滤器]──[泵体]──[压力表 PI]──[止回阀]──[闸阀②]
              │                                            │
              └──[底阀 + 滤网]──（吸上状态时）              └──[流量计]──（可选）
```

**附加元件**：
| 元件 | 位置 | 作用 |
|------|------|------|
| 闸阀① | 泵入口 | 切断泵 |
| 过滤器 | 泵入口 | 防杂质损坏叶轮 |
| 底阀 + 滤网 | 泵入口管端（吸上状态） | 防停泵时泵内液体流出 |
| 压力表 PI | 泵出口 | 监测泵出口压力 |
| 流量计 | 止回阀后（可选） | 监测泵流量 |

### 2.3 多台离心泵并联布置

```
                ┌──[闸阀②A]──┐
[泵 A] ──[止回阀 H_A]──┤
                ├──[闸阀②B]──┤── 汇合母管 ── 下游
[泵 B] ──[止回阀 H_B]──┤
                ├──[闸阀②C]──┤
[泵 C] ──[止回阀 H_C]──┘
```

**要点**：
- 每台泵出口都设止回阀（独立切断）
- 汇合母管前设总闸阀
- 每台泵可独立启动/停止/检修

### 2.4 多台离心泵串联布置

```
[泵 A] ──[止回阀 H_A]── [中间管段] ──[止回阀 H_B]──[闸阀②]── 下游
[泵 B] ──────────────────────────────────────────┘
```

**要点**：
- 中间管段设止回阀 H_B（防泵 B 停时泵 A 高压倒流）
- 串联时扬程叠加，但每台泵的止回阀都不可省

## 三、容积式泵出口标准布置

### 3.1 最小集布置（柱塞泵/螺杆泵）

```
                       [压力表 PI]──[安全阀 PSV]──
                       │                    │
[泵] ───────────────────┼────────────────────┼── 下游管
                       │                    │
                  [脉动阻尼器]          [闸阀②]（可选）
                  （柱塞泵必备）
```

**关键说明**：
- **不设止回阀**（容积式泵自身防倒流）
- **设 PSV**（保护泵体不被下游堵塞超压）
- 柱塞泵**必须设脉动阻尼器**（消除脉动）
- 闸阀②可选（仅在需要切断下游时设）

### 3.2 柱塞泵完整布置

```
                                    [PSV]── 火炬
                                    │
[柱塞泵] ──[脉动阻尼器]──[压力表 PI]──[闸阀②]── 下游
                            │
                            └──[安全阀旁路]──
```

### 3.3 螺杆泵 / 齿轮泵完整布置

```
                          [PSV]── 火炬
                          │
[螺杆泵] ──[压力表 PI]──[闸阀②]── 下游
              │
              └──[过滤器]──（螺杆泵/齿轮泵对杂质敏感）
```

**注**：螺杆泵/齿轮泵的吸入管必须设**永久性过滤器**（位于切断阀与泵进口之间，依据手册 §27 章）。

## 四、特殊泵型阀门设置

### 4.1 漩涡泵

**漩涡泵特性**：类似离心泵，但流量小、扬程高。

**阀门设置**：与离心泵**相同**——出口必设止回阀 + 切断阀。

### 4.2 计量泵

**计量泵特性**：容积式泵的一种，用于精确计量。

**阀门设置**：
- 出口**不设止回阀**
- 设 PSV（保护泵体）
- 出口设脉冲阻尼器（消除脉冲）

### 4.3 磁力泵 / 屏蔽泵

**磁力泵/屏蔽泵特性**：无机械密封，零泄漏，用于有毒/贵重介质。

**阀门设置**：
- 与离心泵**相同**——出口必设止回阀 + 切断阀
- 入口必须设**低压保护开关**（防泵空转损坏）

### 4.4 自吸泵

**自吸泵特性**：泵体有自吸结构，可吸上启动。

**阀门设置**：
- 与离心泵**相同**——出口必设止回阀 + 切断阀
- **入口不设底阀**（自吸结构已替代底阀功能）

## 五、止回阀位置规则（铁律 3 详解）

### 5.1 标准位置：紧贴泵出口

```
        ┌──[闸阀②]── 下游
泵 ── → ┤
        └──[止回阀]──[闸阀③]── 备用
```

**止回阀紧贴泵**（距离越短越好）：
- 减少泵与止回阀之间的管段流体倒流冲击
- 降低水锤压力

### 5.2 止回阀方向：箭头朝下游

**必须**：箭头朝向下游方向（流体正向流动方向）。

### 5.3 止回阀直径：与切断阀相同

**依据**：上册 §27 章泵部分原文——"直径与切断阀相同"。

**反例**：
- ❌ 闸阀 DN100，止回阀 DN80 → 阻力不匹配，止回阀关闭不严
- ✅ 闸阀 DN100，止回阀 DN100 → 阻力匹配，性能稳定

## 六、关键铁律汇总

### 6.1 离心泵（必读）

1. ✅ **泵出口设止回阀**（防停泵倒流）
2. ✅ **泵出口设切断阀**（闸阀或球阀，隔离下游）
3. ✅ **止回阀直径 = 切断阀直径**
4. ✅ **止回阀位置：紧贴泵出口**
5. ✅ **泵入口设切断阀**（闸阀，便于泵检修）
6. ✅ **泵入口根据介质选过滤器**（螺杆/齿轮/柱塞必设，离心通常不设永久过滤器）

### 6.2 容积式泵（必读）

1. ✅ **泵出口通常不设止回阀**（自身防倒流）
2. ✅ **泵出口设 PSV**（保护泵体防超压）
3. ✅ **泵出口设切断阀**（可选）
4. ✅ **泵入口设切断阀**（必设）
5. ✅ **泵入口必设永久性过滤器**（螺杆/齿轮/柱塞对杂质敏感）

## 七、反例警示

### 反例 1：离心泵出口无止回阀

```
❌ [离心泵] ──[闸阀]── 下游（无止回阀，停泵必倒转）
✅ [离心泵] ──[止回阀]──[闸阀]── 下游
```

**错误后果**：停泵瞬间，下游流体倒流，泵倒转，轴承/机械密封损坏。

### 反例 2：容积式泵出口多此一举设止回阀

```
❌ [柱塞泵] ──[止回阀]──[闸阀]── 下游（多此一举）
✅ [柱塞泵] ──[PSV]──[闸阀]── 下游
```

**错误后果**：
- 增加阻力损失
- 增加泄漏点
- 柱塞泵自身排出阀已防倒流，止回阀多余

### 反例 3：止回阀直径小于切断阀

```
❌ [闸阀 DN100]──[止回阀 DN80]── 下游
✅ [闸阀 DN100]──[止回阀 DN100]── 下游
```

**错误后果**：止回阀关闭不严，停泵时流体倒流。

### 反例 4：止回阀位置远离泵出口

```
❌ [泵] ──[5 米管段]──[止回阀]── 下游（5 米管段会被倒流冲击）
✅ [泵] ──[止回阀]── 下游（紧贴泵）
```

**错误后果**：停泵瞬间，5 米管段中的流体产生水锤冲击泵体。
