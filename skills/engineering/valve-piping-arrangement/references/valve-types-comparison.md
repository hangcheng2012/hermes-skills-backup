# 各类型阀门详细对比

> **本文件是 valve-piping-arrangement SKILL 的 references/ 详解之一**。
> 用于工程实践中具体选型时查阅，每类阀门附"标准 / 优点 / 缺点 / 典型应用 / 不适用场景"。

---

## 一、闸阀（Gate Valve，代号 Z）

### 1.1 结构与原理
- 阀杆带动闸板沿阀座垂直方向升降
- 全开时阀座通孔与管径一致，流体几乎无阻力
- 全关时闸板压紧阀座，密封靠阀座与闸板的面接触

### 1.2 分类
- **明杆式** vs **暗杆式**：明杆式启闭程度可见（推荐用于工艺管路，便于操作员判断开度）；暗杆式结构紧凑
- **楔式** vs **平行式**：楔式密封好（液体），平行式用于气体（闸板可自动调整）

### 1.3 优点
- 流体阻力小（流阻系数 ≈ 0.1）
- 启闭缓慢，无水锤现象
- 适用口径范围广（DN15~DN2000+）
- 适用压力温度范围广（PN16~PN420，-196~600°C）

### 1.4 缺点
- 结构复杂，造价较高
- 阀体高，占地面积大
- 半开时阀芯易振动（**只能全开全关，不能调节流量**）
- 阀体内有刻槽，不适用于含固体微粒流体（除非带吹气口）

### 1.5 典型应用
- 装置边界切断阀（§36.1.2.1）
- 减压阀前后切断阀（铁律 1）
- 调节阀旁路阀（铁律 6）
- 蒸汽/水/油/气主管线切断

### 1.6 P&ID 符号（v6.9 规范）
- 单闸板：`▌▌`（双竖线 + 中间横线）
- 明杆：在符号上加竖杆示意

## 二、球阀（Ball Valve，代号 Q）

### 2.1 结构与原理
- 阀体内有带孔球体（通常 90° 通孔）
- 阀杆带动球体旋转 90° 完成启闭
- L 形或 T 形通道可作三通/四通

### 2.2 优点
- 启闭快（旋转 90°）
- 流体阻力小（流阻系数 ≈ 0.1）
- 密封面不易擦伤
- 重量轻，操作方便
- 适用温度范围广（含低温场合）

### 2.3 缺点
- 不能精密调节流量（仅能作粗调或切断）
- 大口径时操作费力（需配齿轮箱或电动）
- 价格比截止阀略高

### 2.4 典型应用
- 频繁启闭的切断阀（推荐替代闸阀）
- 三通/四通切换（用 L/T 形球阀）
- 低温管路
- 黏度较大的流体
- LNG/液烃切断（金属对金属密封球阀）
- 紧急切断阀 XV（电动/气动球阀）

### 2.5 P&ID 符号（v6.9 规范）
- 球阀：`▷◁`（双三角相对）
- 三通球阀：`▷◁` + 三向箭头

---

## 三、截止阀（Globe Valve，代号 J）

### 3.1 结构与原理
- 阀杆带动阀盘沿阀座垂直方向升降（与闸阀相似）
- 但流体流向是"S"形（从阀盘下面往上流动）
- 阀座与阀盘面接触实现密封

### 3.2 优点
- 流量调节平稳
- 严密不漏（密封性比闸阀好）
- 可耐较高压力和温度
- 适用于多种流体

### 3.3 缺点
- 构造复杂，造价较贵
- 流体经过阀门时局部阻力较大（流阻系数 ≈ 6~10，远大于闸阀）
- DN≥150 时体积过大，限制使用
- 不适用于高黏性油品或含固体物料的液体（**流体中的颗粒会冲蚀阀座**）

### 3.4 典型应用
- 泵出口阀（**注意：通常被闸阀替代**——截止阀阻力大，会增加泵的扬程损失）
- 调节阀旁路阀
- 流量计上游阀
- 取样阀
- 小流量精细调节（针形阀）

### 3.5 安装方向
- **必须注意液流方向与阀体上箭头方向一致**（低进高出）
- DN≥150 时反向（流体由阀盘内经上面往下流）
- 无传动装置的截止阀可安装于管路任一位置
- 有传动装置的截止阀应垂直安装于水平管线

### 3.6 P&ID 符号（v6.9 规范）
- 截止阀：`⊥`（倒 T 形）

## 四、止回阀（Check Valve，代号 H）

### 4.1 结构与原理
- 介质正向流动时自动开启
- 介质反向流动时自动关闭
- 关闭靠阀瓣自身重力或弹簧力

### 4.2 分类
- **旋启式**：阀瓣绕轴旋转启闭，直径较大，可装在水平/垂直/倾斜管道上
  - 垂直管道上**流体应自下而上流动**
- **升降式**：阀瓣沿垂直方向升降，只能装在水平管道
- **球式**：阀瓣为球形，只能装在水平管道
- **蝶式止回阀**：阀瓣为蝶形，体积小

### 4.3 优点
- 自动防止倒流
- 不需要外部动力
- 结构相对简单

### 4.4 缺点（关键！）
- **密封性能欠佳**（依《化工工艺设计手册（第五版）》下册 §36.1.1.2(5)）
- 只能防"突然倒流"，不能完全切断
- 慢速倒流时可能不关闭（关阀力矩不足）
- 不适用于含固体颗粒和黏度较大的介质

### 4.5 典型应用（依铁律 2 + 铁律 3）
- 离心泵出口（必设）
- 减压阀后（按 5 触发条件判断）
- 公用物料切断阀下游（防工艺流体倒流污染）
- 多用户支管根部阀后
- 可燃气体管路
- LNG/液烃虹吸保护（倒 U 形防虹吸 + 止回阀双保险）

### 4.6 特殊要求
- 严格禁止倒流的物料：**双止回阀串联**（两旋启式串联）
- 倒流会造成安全事故的物料：止回阀 + 紧急切断阀 XV
- LNG 等低温场合：止回阀 + 真空破坏阀

### 4.7 P&ID 符号（v6.9 规范）
- 止回阀：`▷◁` + 流向箭头（与球阀符号相同，加箭头区分）
- 升降式：箭头朝下（阀瓣朝下关）
- 旋启式：箭头朝右（阀瓣绕轴旋转）

## 五、调节阀（Control Valve，代号 V + PCV/FCV/TCV/LCV）

### 5.1 结构与原理
- 由执行机构 + 阀体两部分组成
- 执行机构根据控制信号（4~20 mA / 0.1~0.6 MPa 气压）调节阀芯开度
- 阀体形式：单座、双座、套筒、角形、三通、蝶形、球形

### 5.2 分类
- **气动调节阀**（工业最常用）：执行机构为薄膜式或活塞式
- **电动调节阀**：执行机构为电动
- **液动调节阀**：用于高压/大口径
- **自力式调节阀**（无执行机构）：靠介质自身压力 + 弹簧平衡
  - **减压阀**（PCV）：保阀后压力
  - **背压阀**：保阀前压力
  - **温度调节阀**（TCV 自力式）：靠温包感温
  - **流量调节阀**（FCV 自力式）：靠孔板压差

### 5.3 优点
- 调节精度高
- 响应快
- 可远程控制

### 5.4 缺点
- 结构复杂，造价高
- 需配气源/电源
- 自力式响应速度慢

### 5.5 典型应用
- 流量控制（FC）
- 压力控制（PC）
- 温度控制（TC）
- 液位控制（LC）
- 任何需要自动调节的工艺参数

### 5.6 标准布置（铁律 6）
```
──[闸阀①]──[调节阀]──[闸阀②]──
                │
                └──[旁路闸阀]──
```

### 5.7 P&ID 符号（v6.9 规范）
- 调节阀：`Ⓒ`（圈 C）
- 自力式调节阀：`Ⓒ` + 弹簧示意
- PCV/FCV/TCV/LCV：前缀代表控制变量

## 六、安全阀（Safety Valve，代号 PSV）

### 6.1 结构与原理
- 阀瓣被弹簧压在阀座上
- 当系统压力超过设定压力时，阀瓣自动开启泄放
- 压力降至回座压力时自动关闭

### 6.2 分类
- **弹簧式安全阀**（A 型）：工业最常用，靠弹簧力平衡
- **先导式安全阀**（PILOT OPERATED）：靠引导阀控制主阀启闭，性能更精确
- **重锤式安全阀**（杠杆式）：用于蒸汽锅炉，靠重锤调节
- **泄压阀**（Relief Valve）：用于液体场合，开启压力可调节

### 6.3 关键铁律（铁律 5）
- **PSV 必须保护减压阀本体** → PSV 设在减压阀**前**（上游）
- PSV 设定压力 = 上游设计压力（不是下游）
- PSV 前设切断阀（铅封开启 CSO），后**不设切断阀**（防失效时下游用户误关）

### 6.4 P&ID 符号（v6.9 规范）
- 安全阀：`Ⓢ`（圈 S）+ 弹簧
- PSV 在 P&ID 上标 `PSV-XXX`

---

## 七、紧急切断阀（Emergency Shutdown Valve，代号 XV）

### 7.1 结构与原理
- 通常是气动或电动球阀/蝶阀
- 在 SIS（安全仪表系统）联锁信号下快速切断
- **故障安全**（Fail-Safe）：失气/失电时关闭（FC）或开启（FO）

### 7.2 应用场景
- SIS SIL 等级要求的紧急切断
- 火灾/泄漏工况下的隔离
- 工艺联锁中的紧急保护

### 7.3 关键铁律（PID v6.9 §信号线）
- XV 在 P&ID 上画弹簧 + 阀体
- 信号线（橙色虚线）从 SIS 控制器连到 XV
- 必须在管路中**位于需要切断的位置**（通常在设备边界、设备前/后）

## 八、其他特种阀门（简表）

| 阀门 | 代号 | 特点 | 典型应用 |
|------|------|------|----------|
| 蝶阀 | D | 大口径、轻、阻力中等 | 流量调节、大口径水/空气管路 |
| 隔膜阀 | G | 流体只接触隔膜 | 腐蚀性介质、悬浮液 |
| 刀闸阀 | - | 闸板带刀刃，能切碎颗粒 | 浆料、含固介质 |
| 旋塞阀 | X | 阀芯为锥形塞 | 温度 < 120°C、压力 < 1.6 MPa |
| 减压阀（自力式） | PCV | 保阀后压力 | 蒸汽/气体减压站 |
| 背压阀（自力式） | PCV | 保阀前压力 | 泵最小流量保护 |
| 针形阀 | - | 阀芯为锥形 | 小流量微调、取样 |
| 底阀 | - | 装在泵进口管端 | 离心泵吸上状态防倒流 |
| Y 形截止阀 | J | 流阻小于普通截止阀 | 高压降场合 |
| 角式截止阀 | J | 兼具改变流向 | 工艺管路转角处 |

## 九、选型决策树（按工艺要求选阀门）

```
阀门选型
│
├── 功能是什么？
│   ├── 切断 ──→ 闸阀（不频繁）或 球阀（频繁）
│   ├── 调节 ──→ 截止阀（小流量）/ 调节阀（自动）/ 蝶阀（大口径）
│   ├── 防倒流 ──→ 止回阀
│   ├── 超压保护 ──→ PSV / 泄压阀
│   ├── 紧急切断 ──→ XV（电动/气动球阀/蝶阀）
│   └── 特殊功能（减压/稳压/温调） ──→ 自力式调节阀
│
├── 介质性质？
│   ├── 清水/油品/气体 ──→ 大多数阀型通用
│   ├── 浆料/含固 ──→ 隔膜阀/刀闸阀
│   ├── 腐蚀性 ──→ 衬氟阀/合金阀
│   ├── 剧毒/易燃 ──→ 双阀/双止回阀 + XV
│   └── 高黏度 ──→ 球阀/Y 形截止阀
│
├── 压力等级？
│   ├── 低压（PN16 以下） ──→ 截止阀/球阀/闸阀通用
│   ├── 中压（PN16~PN64） ──→ 闸阀/球阀
│   ├── 高压（PN64 以上） ──→ 焊接连接闸阀/球阀
│   └── 超高压（PN420 以上） ──→ 锻造阀体 + 焊接
│
├── 温度？
│   ├── 低温（-196°C 以下） ──→ 低温球阀/低温闸阀
│   ├── 常温 ──→ 通用
│   ├── 中温（< 425°C） ──→ 通用
│   └── 高温（> 425°C） ──→ 金属密封闸阀/球阀
│
└── 公称直径？
    ├── DN15~DN50 ──→ 截止阀/球阀（精密调节）/ 螺纹连接
    ├── DN50~DN150 ──→ 闸阀/球阀
    ├── DN150~DN300 ──→ 球阀/蝶阀
    ├── DN300+ ──→ 蝶阀/电动闸阀
```
