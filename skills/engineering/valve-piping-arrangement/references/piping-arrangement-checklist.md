# P&ID 阀门布置审图 Checklist

> **本文件是 valve-piping-arrangement SKILL 的 references/ 详解之一**。
> 用于审图/校核他人 P&ID 时的快速检查清单，按"必查项 → 重要项 → 优化项"分级。

---

## 一、必查项（漏掉必出问题）

### 1.1 减压阀布置检查
- [ ] 减压阀**前**有切断阀（闸阀/球阀）
- [ ] 减压阀**后**有切断阀（闸阀/球阀）
- [ ] 减压阀**前**有过滤器（Y 型）
- [ ] 减压阀**前**有 PSV（保护减压阀本体）
- [ ] 减压阀**旁路**有旁路阀（关键设备时）
- [ ] 减压阀**上下游**有压力表
- [ ] 减压阀**后**根据 5 触发条件判断是否设止回阀

### 1.2 离心泵出口检查
- [ ] 泵出口有止回阀（紧贴泵）
- [ ] 止回阀后有切断阀（闸阀/球阀）
- [ ] 止回阀直径 = 切断阀直径
- [ ] 泵入口有切断阀
- [ ] 螺杆/齿轮/柱塞泵入口有过滤器

### 1.3 容积式泵出口检查
- [ ] 泵出口**无**止回阀（自身防倒流）
- [ ] 泵出口有 PSV（保护泵体）
- [ ] 柱塞泵出口有脉动阻尼器
- [ ] 泵入口有过滤器（螺杆/齿轮/柱塞必设）

### 1.4 调节阀布置检查
- [ ] 调节阀前后各 1 个切断阀
- [ ] 调节阀有旁路阀（关键设备时）
- [ ] 调节阀前有过滤器（防堵塞阀芯）

### 1.5 PSV（安全阀）布置检查
- [ ] PSV 前有切断阀（铅封开启 CSO）
- [ ] PSV 后**无**切断阀（防止下游用户误关，PSV 失去保护）
- [ ] PSV 出口**不**通向封闭系统（必须有安全泄放路径）
- [ ] PSV 设定压力合理（依容器设计压力）

### 1.6 止回阀安装方向检查
- [ ] 止回阀箭头与流体方向一致
- [ ] 升降式/球式止回阀只能装在水平管道
- [ ] 旋启式止回阀在垂直管道时流体方向是自下而上

### 1.7 切断阀布置检查
- [ ] 装置边界处有切断阀（界区阀）
- [ ] 公用物料分支管有根部阀
- [ ] 液化气/可燃/有毒/贵重物料管道设双阀

### 1.8 阀门类型检查
- [ ] 闸阀仅用于全开全关（不是调节）
- [ ] 球阀不能精密调节（仅粗调或切断）
- [ ] 调节阀不是闸阀/球阀替代
- [ ] 浆料/含固介质用隔膜阀/刀闸阀，不用截止阀

---

## 二、重要项（漏掉可能引发问题）

### 2.1 蒸汽减压站
- [ ] 减压阀前后有疏水器（排冷凝水，防水锤）
- [ ] 减压阀前有 Y 型过滤器
- [ ] 减压阀旁路阀两端有疏水器
- [ ] PSV 泄放管不接封闭系统（接屋顶安全排放）

### 2.2 液体减压站
- [ ] 减压阀前后有压力表
- [ ] 减压阀前有过滤器
- [ ] 高压差液体场合选多级减压阀（防气蚀）
- [ ] 高温液体减压考虑闪蒸问题

### 2.3 公用气体调压站
- [ ] N₂/压缩空气切断阀后有止回阀（防工艺流体倒流污染）
- [ ] 天然气减压站有 XV 紧急切断阀（SIS 联锁）
- [ ] 减压阀前有气体过滤器（过滤油水）

### 2.4 可燃气体管路
- [ ] LPG/天然气管路有止回阀（铁律 2 ②）
- [ ] 可燃气体管路有 XV 紧急切断阀（SIS）
- [ ] 止回阀后是否需要双止回阀（剧毒/贵重）

### 2.5 精馏塔 / 反应器
- [ ] 塔顶 PCV 后有止回阀（防冷凝器侧倒流）
- [ ] 塔顶 PSV 保护塔顶超压
- [ ] 加热炉出口止回阀（防停料倒流）
- [ ] 反应器出口止回阀（保压）

---

## 三、优化项（可改善性能/可维护性）

### 3.1 阀门选型优化
- [ ] 大口径（DN300+）选蝶阀（重量轻）
- [ ] 频繁启闭选球阀（启闭快）
- [ ] 不频繁切断选闸阀（阻力小）
- [ ] 高压差液体选多级减压阀（防气蚀）

### 3.2 布置优化
- [ ] 阀门布置预留维修空间（操作手轮 + 维修通道）
- [ ] 阀门布置便于操作（高度 ≤ 1.6 m）
- [ ] 阀门手轮不相互干涉
- [ ] PSV 排放口朝向安全方向（远离操作平台）

### 3.3 仪表优化
- [ ] 减压阀上下游各设 1 个压力表
- [ ] 离心泵出口设压力表
- [ ] PSV 前设压力表（监测设定压力）
- [ ] 关键止回阀两端设压力表（监测泄漏）

### 3.4 标识优化
- [ ] 阀门位号清晰（依 P&ID v6.9 规范）
- [ ] 阀门流向箭头清晰（止回阀尤其重要）
- [ ] PSV 设定压力标在 P&ID 上
- [ ] 减压阀设定压力标在 P&ID 上

---

## 四、按介质分类检查清单

### 4.1 蒸汽管路
- [ ] 减压阀前后有疏水器
- [ ] 减压阀前有过滤器
- [ ] 蒸汽管路坡度 ≥ 0.005（坡向疏水点）
- [ ] 蒸汽管路有保温

### 4.2 气体管路（N₂/压缩空气/天然气）
- [ ] 切断阀后有止回阀（防工艺流体倒流）
- [ ] 减压阀前有气体过滤器（除油水）
- [ ] 可燃气体有 XV 紧急切断阀
- [ ] 天然气管路静电接地（防雷击/静电）

### 4.3 液体管路（水/油/烃类）
- [ ] 离心泵出口有止回阀
- [ ] 容积式泵出口有 PSV（无止回阀）
- [ ] 高黏度液体选球阀/Y 形截止阀
- [ ] 浆料选隔膜阀/刀闸阀

### 4.4 腐蚀性介质（酸/碱）
- [ ] 阀门材质与介质匹配（衬氟/合金/双相钢）
- [ ] 阀门密封件与介质匹配
- [ ] 切断阀操作手轮防腐蚀

### 4.5 低温介质（LNG/液氮/LPG）
- [ ] 阀门材质为低温钢（-46°C 以下用 304/316L）
- [ ] 阀门填料函有冷箱保护
- [ ] LNG 管路设真空破坏阀（防虹吸）

---

## 五、按设备类型检查清单

### 5.1 换热器
- [ ] 进出口各 1 个切断阀
- [ ] 高温/低温场合管路考虑热应力补偿
- [ ] 检修时可隔离（双阀 + 检查阀）

### 5.2 分离器 / 过滤器
- [ ] 进出口各 1 个切断阀
- [ ] 排污阀
- [ ] 压力表

### 5.3 塔器
- [ ] 塔顶至冷凝器**无**切断阀（最小压降）
- [ ] 再沸器与塔体连接管**无**切断阀（除工艺控制需要）
- [ ] 塔顶 PCV 后有止回阀（防冷凝器侧倒流）
- [ ] 塔顶 PSV 保护塔顶超压

### 5.4 反应器
- [ ] 反应器进料管有切断阀
- [ ] 反应器出口有止回阀（保压）
- [ ] 紧急放空管有 XV（紧急泄放）

### 5.5 储罐
- [ ] 罐根阀（每个接口都设）
- [ ] 强腐蚀/恶臭介质设双阀
- [ ] 大罐/远距离罐的根阀最好是遥控阀

## 六、审图流程（标准化）

### 6.1 第一步：通读 P&ID 整体流程
- 识别所有设备（泵、塔、反应器、储罐、换热器）
- 识别所有主管路（按介质分类）
- 识别所有控制阀/调节阀/安全阀
- 识别所有切断阀/止回阀

### 6.2 第二步：按设备逐项检查
- 每台泵 → 检查出入口阀门（依泵类型）
- 每个塔/反应器/换热器 → 检查进出口阀门
- 每个罐 → 检查根部阀
- 每个调节阀 → 检查前后切断阀 + 旁路

### 6.3 第三步：按主管路逐项检查
- 每条蒸汽管 → 检查减压阀前后布置
- 每条气体管 → 检查止回阀位置
- 每条可燃管 → 检查 XV + 止回阀

### 6.4 第四步：按安全保护检查
- 每个容器/管道 → 检查 PSV 设置
- 每个 SIS 联锁 → 检查 XV 设置
- 每个危险介质 → 检查双阀/双止回阀

### 6.5 第五步：按规范一致性检查
- 阀门位号依 P&ID v6.9 规范
- 阀门符号依 v6.9 规范（▌▌/▷◁/⊥/Ⓒ/Ⓢ）
- 阀门类型与功能匹配（依 SKILL 铁律 7）

### 6.6 第六步：输出审图意见
- 列出必查项的漏项（必须整改）
- 列出重要项的漏项（建议整改）
- 列出优化项（可选改进）
