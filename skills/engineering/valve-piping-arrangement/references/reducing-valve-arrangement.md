## 一、减压阀的定义与分类

### 1.1 定义
减压阀（Pressure Reducing Valve，PRV 或 PCV）是**自力式压力调节阀**的一种，
**保持阀后压力恒定**，靠阀前介质压力与弹簧力平衡来调节阀的开度。

### 1.2 分类
| 类型 | 原理 | 减压比 | 适用 |
|------|------|--------|------|
| **直接作用自力式**（弹簧式） | 介质压力直接推动膜片 | ≤ 10:1 | 低压差、稳压要求不高 |
| **先导式自力式**（带指挥器 PILOT） | 引导阀放大后驱动主阀 | 100:1 ~ 600:1 | 中高压差（蒸汽、气体） |
| **气动调节阀 + PC 控制系统** | 外部气源驱动 | 高精度、动态响应 | 高精度调节、快速响应 |
| **电动调节阀 + PC 控制系统** | 外部电源驱动 | 同上 | 有电源、防爆区 |

### 1.3 与其他阀的区别
- **减压阀**：保阀后压力（下游式）
- **背压阀**：保阀前压力（上游式）
- **安全阀**：超压瞬时泄放（紧急保护）
- **泄压阀**：可调节开启压力（紧急或定时排放）

## 二、典型减压阀布置（4 类场景）

### 场景 A：蒸汽减压站

```
上游蒸汽（高压，1.0 MPa）──[闸阀①]──[过滤器]──[减压阀 PCV]──[PSV]──[止回阀]──[闸阀②]──下游蒸汽（低压，0.3 MPa）
                                        │
                                        └──[旁路闸阀]──
                                        │
[压力表]──[安全阀排空至屋顶]
```

**元件清单**（最小集）：
| 元件 | 数量 | 类型 | 作用 |
|------|------|------|------|
| 切断阀① | 1 | 闸阀 Z41H | 隔离上游 |
| 过滤器 | 1 | Y 型过滤器 | 防杂质堵塞减压阀 |
| 减压阀 | 1 | PCV（先导式） | 减压 + 稳压 |
| PSV | 1 | 弹簧式安全阀 | 保护减压阀 |
| 止回阀 | 1 | 旋启式止回阀 | 防下游倒流 |
| 切断阀② | 1 | 闸阀 | 隔离下游 |
| 旁路闸阀 | 1 | 闸阀 | 减压阀失效时手动维持 |
| 压力表 | 1 | 弹簧管压力表 | 上下游压力监测 |

**典型应用**：
- 高压蒸汽（1.0 MPa）→ 中压蒸汽（0.3 MPa）→ 加热器
- 中压蒸汽（0.5 MPa）→ 低压蒸汽（0.1 MPa）→ 蒸汽伴热

### 场景 B：公用气体调压站（氮气、压缩空气、天然气）

```
上游气体（高压，0.8 MPa）──[闸阀①]──[过滤器]──[减压阀 PCV]──[PSV]──[止回阀]──[闸阀②]──下游气体（低压，0.3 MPa）
                                        │
                                        └──[旁路闸阀]──
```

**与蒸汽减压站的区别**：
- 公用气体通常设**两级减压**（一级粗调 + 二级精调）
- 天然气减压站必须设**紧急切断阀 XV**（SIS 联锁）
- 减压阀前设**气体过滤器**（过滤油水）

### 场景 C：工艺介质减压阀（液体）

```
上游液体（高压，2.0 MPa）──[闸阀①]──[过滤器]──[减压阀 PCV]──[PSV]──[止回阀]──[闸阀②]──下游液体（低压，0.5 MPa）
                                       │
                                       └──[旁路闸阀]──
                                       │
                                  [压力表 PIT]
```

**液体减压的特殊考虑**：
- **气蚀风险**：液体减压后压力骤降，若低于饱和蒸气压则发生气蚀
- **闪蒸风险**：高温液体减压后部分汽化，产生两相流
- **抗气蚀结构**：多级减压阀（每级压差 < 0.5 MPa）或带抗气蚀内件
- **建议**：液体减压阀前后温差大时设伴热（防冻凝）

### 场景 D：储罐 N₂ 封减压阀（与 tank-n2-blanket-design SKILL 关联）

```
高压 N₂（0.7 MPa）──[闸阀①]──[过滤器]──[减压阀 PCV（ZZDQ）]──[止回阀]──[闸阀②]──储罐 N₂ 封（1~3 kPa）
```

**特殊要求**：
- 减压比极高（**600:1 以上**）
- 必须用**先导式自力式减压阀（ZZDQ 带指挥器）**
- 一级减压即可，无需两级
- 阀后设**低压侧超压保护**（紧急泄放装置）
- 详细规范见 `tank-n2-blanket-design` SKILL

## 三、PSV（安全阀）的关键铁律（铁律 5）

### 3.1 PSV 必须设在减压阀前（上游）

**理由**：
- 减压阀可能被下游高压顶住或失效时上游压力全压到阀体上
- PSV 必须保护减压阀本体 + 上游管线不被超压
- 设在上游才能在减压阀失效时（阀卡在全开位置）泄放上游压力

### 3.2 PSV 的设定压力

**PSV 设定压力 = 减压阀上游设计压力**（不是下游）。

**设计压力 = 减压阀入口最大可能压力 × 1.1（安全系数）**

### 3.3 PSV 的切断阀

- PSV 前**可设 1 个切断阀**（铅封开启 CSO，正常运行时全开）
- PSV 后**严禁设切断阀**（防止失效时下游用户误关，PSV 失去保护功能）
- 多个 PSV 时可设切换阀（正常 1 用 1 备）

### 3.4 反例

```
❌ ──[减压阀]──[PSV]── 下游（PSV 在减压阀后，错误）
✅ ──[PSV]──[减压阀]── 下游（PSV 在减压阀前，正确）
```

## 四、止回阀的设置原则（铁律 2）

### 4.1 5 种触发条件（任一成立即必须设）

| # | 触发条件 | 工程实例 | 风险 |
|---|----------|----------|------|
| ① | 阀后介质会倒流回上游 | 公用物料减压后通入工艺系统 | 工艺流体污染上游总管 |
| ② | 阀后介质有危险性 | LPG/烃类蒸汽减压、可燃气体 | 火灾/爆炸 |
| ③ | 阀后是多用户 | 减压站母管 → 多个用户 | 单用户停用时倒灌 |
| ④ | 阀后是工艺设备 | 减压后到反应器、精馏塔 | 设备内介质倒流 |
| ⑤ | 阀后有更高压力旁路 | 减压阀 + 旁路闸阀并联 | 高压侧倒灌低压侧 |

### 4.2 何时不需要止回阀
- 阀后是单用户、用量稳定、停用时阀门全关
- 阀后是开放式排放/排向火炬总管
- 阀前已有可靠止回阀（避免重复）
- 工艺明确要求不设（罕见，需设计院签字）

### 4.3 止回阀的安装位置

```
正确：──[减压阀]──[止回阀]── 下游
错误：──[止回阀]──[减压阀]── 下游
```

理由：止回阀的目的是防**阀后倒流**，应设在减压阀后；
设在阀前毫无意义（阀前压力本来就高，倒流方向反了）。

## 五、切断阀 + 旁路阀的设置（铁律 1 + 铁律 6）

### 5.1 切断阀必须设（前后各 1 个）

**理由**：减压阀需要维修或更换时，前后切断阀可以隔离系统。

**类型选择**：
| 介质 | 推荐切断阀 |
|------|-----------|
| 蒸汽/水 | 闸阀 Z41H-16C 或球阀 Q41F-16C |
| 气体 | 球阀 Q41F-16C（启闭快） |
| 烃类 | 球阀 Q41F-16C（带防火结构） |
| 腐蚀性 | 衬氟球阀或不锈钢闸阀 |

### 5.2 旁路阀的设置

**何时设**：
- 减压阀是关键设备 → 设旁路阀（减压阀失效时手动维持生产）
- 减压阀故障不影响生产 → 可不设

**旁路阀类型**：闸阀或球阀（与切断阀同类型）
**旁路阀尺寸**：通常与主管同径（DN 与减压阀相同）

**例外**："带手轮的调节阀，根据工艺条件，可不设旁路"（手册 §36.1.2.4 引）

### 5.3 旁路阀的连接方式

**方式 1：直接连接**（推荐）
```
──[闸阀①]──[减压阀]──[闸阀②]──
                │
                └──[旁路闸阀]──
```

**方式 2：三通阀**（少用）
- 用三通球阀代替减压阀前后的两切断阀 + 旁路阀
- 优点：阀件少
- 缺点：维修时三通阀要全拆

## 六、过滤器 + 压力表的设置

### 6.1 过滤器（Y 型过滤器）

**必须设**，理由：
- 减压阀阀芯对杂质敏感，杂质堵塞阀芯会失效
- Y 型过滤器阻力小，结构简单

**位置**：减压阀前（切断阀①与减压阀之间）
**过滤精度**：通常 20~60 目（蒸汽/气体），100 目（液体）
**口径**：与主管同径

### 6.2 压力表

**必须设**：
- 上游压力表（监测阀前压力，与 PSV 设定值对照）
- 下游压力表（监测阀后压力，与减压阀设定值对照）

**位置**：
- 上游压力表：闸阀①与过滤器之间
- 下游压力表：止回阀与闸阀②之间

**类型**：
- 蒸汽/气体：弹簧管压力表 Y100
- 液体：弹簧管压力表 Y100 + 隔膜片（防腐蚀/防冻）

### 6.3 排污阀（蒸汽场合）

蒸汽减压站必须设排污阀（疏水器）：
- 上游切断阀前：冷凝水排净（防止水锤）
- 下游切断阀后：冷凝水排净（防止水击减压阀）
- 减压阀旁路阀两端：低点排净

## 八、设计计算要点（仅列出，不展开）

### 8.1 减压阀口径计算

按所需工况（流量、压差、温度）查厂家选型样本：
- **C_v 值**（流量系数）：必须 ≥ 工艺要求 C_v × 1.2（20% 余量）
- **允许压差**：≥ 实际压差（防气蚀）

### 8.2 PSV 口径计算

按《化工工艺设计手册（第五版）》下册第 34 章 + API 520 / API 521 计算：
- 火灾工况泄放量（HG/T 20570.2-95）
- 气体喷嘴选型（API 520）

### 8.3 止回阀口径

**直径与切断阀相同**（铁律 3，依据手册原文）
