# 选型铁律 + 决策树 + 算例

> **核心**：本节给出气体增压泵选型的完整工作流，含 3 条铁律、决策树、典型算例。

---

## 一、3 条核心铁律（再次强调）

| # | 铁律 | 公式 |
|---|---|---|
| **铁律 1** | 驱动气 × 增压比 ≥ 目标出口压力 | $P_{drive} \times R \times \eta \geq P_{out,目标}$ |
| **铁律 2** | 入口压力 ≥ 厂家最低吸入压力 | $P_{in} \geq P_{in,min}$ (查样本) |
| **铁律 3** | 流量按 P_in 计算并校核 | $Q_{out} = Q_{sample} \times (P_{in,工况}/P_{in,sample})$ |

---

## 二、选型决策树（完整版）

```
气体增压需求
    │
    ├─ Q1: 流量需求?
    │   ├─ > 50 Nm³/h ──→ 压缩机（往复/螺杆/离心）
    │   └─ < 50 Nm³/h ──→ 进入 Q2
    │
    ├─ Q2: 压力比 P_out/P_in?
    │   ├─ ≤ 100:1 ──→ 单级增压泵 ✓
    │   └─ > 100:1 ──→ 两级或多级串联（参见 §六）
    │
    ├─ Q3: 被增压气介质?
    │   ├─ N₂/空气/Ar/He ──→ 普通型（压缩空气驱动）
    │   ├─ H₂ ──→ N₂ 驱动, 禁铜, 静电接地
    │   ├─ O₂ ──→ N₂ 驱动, 禁油禁脂, 脱脂处理
    │   ├─ CO₂ ──→ 防凝液, 低压缩比
    │   ├─ Cl₂ ──→ 钛合金/哈氏合金
    │   └─ 其他可燃/有毒 ──→ N₂ 驱动 + 全封闭
    │
    ├─ Q4: 入口压力?
    │   ├─ P_in < 1 bar(g) ──→ 不适用, 需上游先增压
    │   ├─ 1-3 bar(g) ──→ 校核厂家 P_in,min, 可能需改型号
    │   └─ > 3 bar(g) ──→ 正常
    │
    ├─ Q5: 驱动气可用?
    │   ├─ 压缩空气 4-8 bar(g) ──→ 可用
    │   ├─ N₂ 钢瓶 ──→ 可用（注意耗量）
    │   └─ 蒸汽/电动 ──→ 不适用, 增压泵必须气动
    │
    └─ Q6: 连续运行要求?
        ├─ 间歇/短时 ──→ 增压泵 ✓
        └─ 连续 24h ──→ 考虑压缩机（活塞磨损）
```

## 三、选型计算工作流

### 步骤 1：明确工艺需求

收集以下数据：
- 被增压气体：介质、流量 Q_in (Nm³/h)
- 入口压力 P_in (bar(g))
- 出口压力 P_out (bar(g))
- 入口温度 T_in (℃)
- 连续/间歇
- 安全等级（普通/易燃易爆/有毒）

### 步骤 2：判定是否用气体增压泵

| 检查项 | 判定 |
|---|---|
| Q_in ≤ 50 Nm³/h | ✓ |
| P_out/P_in ≤ 100 | ✓ |
| P_in ≥ 1 bar(g) | ✓ |
| 间歇或短时运行 | ✓ |

不满足 → 改选压缩机或先上游增压。

### 步骤 3：初选增压比 R

$$R_{初步} = \frac{P_{out} \times 1.2}{P_{in}} \quad (\text{取 1.2 安全系数})$$

注：粗算可用表压；若 R_初步 > 100 → 两级串联。

### 步骤 4：选定 R 后反算驱动气压

$$P_{drive,min} = \frac{P_{out}}{R \times \eta}$$

通常 η 取 0.9：

$$P_{drive,min} = \frac{P_{out}}{R \times 0.9}$$

要求 P_drive,min ≤ 工厂风压力（通常 7 bar(g)）。
若 P_drive,min > 7 bar(g) → 改选更大 R 的型号。

### 步骤 5：校核入口压力

查厂家样本：P_in,min = ?

要求 P_in ≥ P_in,min × 1.2（留 20% 安全裕量）。

### 步骤 6：校核流量

按厂家样本曲线或公式：

$$Q_{out,actual} = Q_{sample} \times \frac{P_{in,actual}}{P_{in,sample}}$$

要求 Q_out,actual ≥ Q_工艺需求。

### 步骤 7：核算驱动气耗量

$$Q_{drive} = \frac{Q_{out} \times R}{\eta_{drive}}$$

校核工厂风管径是否能提供。

### 步骤 8：出选型规格 + 阀组 + PSV

按 `templates/gas-booster-data-sheet.md` 模板出规格书。

## 四、典型算例

### 算例 1：N₂ 仪表风增压

**工艺需求**：
- 介质：N₂
- 流量：8 Nm³/h
- 入口：0.6 MPa(g) = 6 bar(g)
- 出口：3.0 MPa(g) = 30 bar(g)
- 连续运行
- 普通安全等级

**Step 1-2**：流量 8 < 50 ✓，压力比 30/6 = 5 ✓，用单级 ✓

**Step 3**：R_初步 = 30 × 1.2 / 6 = 6，选 **R = 10:1**（留余量）

**Step 4**：P_drive,min = 30 / (10 × 0.9) = 3.33 bar(g) < 7 bar(g) ✓

**Step 5**：P_in = 6 bar(g) > 厂家 P_in,min（通常 1 bar(g)）✓

**Step 6**：查样本 R=10:1 型号，Q_sample 在 P_in=6 bar(g)、P_out=30 bar(g) 时约 15 Nm³/h > 8 ✓

**Step 7**：Q_drive = 8 × 10 / 0.75 = 107 Nm³/h → 校核工厂风管径 ≥ DN50

**Step 8**：出规格书，驱动气压缩空气，阀组按标准配置。

### 算例 2：电解氢增压（高压比场景）

**工艺需求**：
- 介质：H₂
- 流量：20 Nm³/h
- 入口：常压 (0 bar(g))
- 出口：200 bar(g)
- 间歇运行（充瓶）
- 易燃易爆

**Step 1-2**：流量 20 < 50 ✓，压力比 200/1 = 200 > 100 → **需两级串联** ⚠️

**Step 3**：两级方案 R1=10:1, R2=20:1

```
P_in (1 bar(g)) → [1 级 R=10:1] → P_mid (10 bar(g)) → [2 级 R=20:1] → P_out (200 bar(g))
                   ↑ 中间冷却                ↑
                   ↑ 中间稳压罐
```

**Step 4**：每级驱动气压核算
- 1 级 P_drive,min = 10 / (10 × 0.9) = 1.11 bar(g) > 7 bar(g) 不成立，需选更小 R
- 改选 R1=5:1 → P_mid = 5 bar(g) → R2=40:1 → P_out = 5×40×0.9 = 180 bar(g) < 200 ❌
- 再调 R1=5:1, R2=50:1 → P_out = 5×50×0.9 = 225 bar(g) > 200 ✓

**Step 5**：每级 P_in 校核
- 1 级 P_in = 1 bar(g), 厂家 R=5:1 型号 P_in,min 通常 1 bar(g)，边缘
- 2 级 P_in = 5 bar(g) >> 厂家 R=50:1 型号 P_in,min（通常 3 bar(g)）✓

**Step 6**：流量校核
- 查样本两级叠加后流量约 15 Nm³/h < 20，需放大型号

**Step 7**：驱动气耗量（必须 N₂ 驱动）
- 1 级：Q_drive = 20 × 5 / 0.75 = 133 Nm³/h
- 2 级：Q_drive = 20 × 50 / 0.75 = 1333 Nm³/h
- 总驱动 N₂ 耗量极大！→ 需核算 N₂ 钢瓶组或 N₂ 主管

**Step 8**：出规格书，含两级串联 + 中间冷却 + 中间罐 + PSV × 2 + N₂ 驱动

### 算例 3：CO₂ 超临界（防液化场景）

**工艺需求**：
- 介质：CO₂
- 流量：5 Nm³/h
- 入口：55 bar(g)（5.5 MPa.g, 接近临界）
- 出口：100 bar(g)
- 连续运行

**Step 1-2**：流量 5 < 50 ✓，压力比 100/55 ≈ 1.8 < 100，单级 ✓

**Step 3**：R_初步 = 100 × 1.2 / 55 = 2.18，选 **R = 3:1**

**Step 4**：P_drive,min = 100 / (3 × 0.9) = 37 bar(g) > 7 bar(g) ⚠️

→ **R=3:1 不适用**，工厂风压不够

→ 改方案：
- 方案 A：用 R=20:1 + 中间稳压 → P_drive,min = 100 / (20 × 0.9) = 5.6 bar(g) ✓
- 方案 B：直接用压缩机（往复式）

**Step 5-6**：方案 A 需两级串联（1 级 R=3:1 → 2 级 R=20:1）

**关键考量**：CO₂ 在压缩后温升可能进入两相区，需：
- 入口预热到 ≥ 31℃（CO₂ 临界温度）
- 中间冷却
- 防凝液排放

**Step 8**：按 CO₂ 专项配置出规格书，详见 `applications-by-medium.md` §6.4

## 六、多级串联方案设计

### 6.1 两级串联压力比分配

**经验法则**：前级小 R，后级大 R（递减式）

例如：总 R = 100:1
- 方案 A：R1 = 10:1, R2 = 10:1（等分）
- 方案 B：R1 = 5:1, R2 = 20:1（前小后大）✓ 推荐
- 方案 C：R1 = 20:1, R2 = 5:1（前大后小）❌ 不推荐

**理由**：前级流量大、压力低，小 R 适合；后级流量小、压力高，大 R 适合。

### 6.2 两级串联关键设备

```
[P_in] ──→ [F-1 滤] ──→ [1 级泵 R1] ──→ [V-1 中间罐] ──→ [E-1 冷却器] ──→ [2 级泵 R2] ──→ [PSV-2] ──→ [P_out]
                                       (稳压+缓冲)        (强制冷却)
```

| 设备 | 作用 |
|---|---|
| **中间稳压罐 V-1** | 缓冲两级间压力波动，容积取 5-10 倍每循环排量 |
| **中间冷却器 E-1** | 降低 1 级出口气体温度（可达 150℃+），防止 2 级入口温度过高 |
| **排放阀 (每级后)** | 启动排气、检修放空 |
| **压力表 PI (每级后)** | 监控各级压力 |
| **温度计 TI (冷却器后)** | 确保进入 2 级前温度 ≤ 50℃ |

### 6.3 两级串联驱动气消耗

每级都消耗驱动气，总耗量 = 各级之和：

$$Q_{drive,total} = Q_{boosted} \times (R_1 + R_2) / \eta_{drive}$$

**算例**：两级 R1=5, R2=20，被增压 5 Nm³/h
$$Q_{drive} = 5 \times 25 / 0.75 = 167 \text{ Nm}^3/\text{h}$$

## 七、选型常见错误（避坑指南）

### 7.1 错误 1：忽略驱动气耗量

**表现**：选了 R=30:1 的大泵，驱动气消耗 400 Nm³/h，工厂风管径 DN25，远不够。

**纠正**：选型计算必须含 Step 7 驱动气耗量核算。

### 7.2 错误 2：把"压力比"当"增压比"

**表现**：工况压力比 5:1，选了 R=5:1 的泵，实际达不到（因为效率损失）。

**纠正**：必须 R × η ≥ 实际压力比。即 R = 压力比 / 0.9，再向上取整。

### 7.3 错误 3：忽略介质入口最低压力

**表现**：上游 P_in = 0.5 bar(g)，选 R=10:1 的泵，结果流量极低。

**纠正**：Step 5 校核 P_in ≥ P_in,min。

### 7.4 错误 4：用增压泵做大流量主气源

**表现**：工艺需 200 Nm³/h N₂，选了多台增压泵并联。

**纠正**：流量 > 50 Nm³/h 首选压缩机，增压泵仅适合小流量辅助。

### 7.5 错误 5：特殊介质用普通型号

**表现**：H₂ 用压缩空气驱动 → 危险。

**纠正**：H₂/O₂/Cl₂ 等必须按 `applications-by-medium.md` 专项处理。
