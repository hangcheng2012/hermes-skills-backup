## 一、8 铁律自检（核心）

| # | 铁律 | 自检问题 | 通过条件 |
|---|---|---|---|
| ① | 增压比 R 是机械固有参数 | R 来自厂家样本的活塞面积比？ | ✓ 是 |
| ② | 最大出口 = P_drive × R × η | P_drive × R × 0.9 ≥ P_out,目标？ | ✓ 是 |
| ③ | P_in ≠ 决定最大出口 | 选型时未把 P_in 当作最大出口的限制？ | ✓ 是 |
| ④ | 单级 R ≤ 100:1 | R ≤ 100? 否则改两级串联 | ✓ 是 |
| ⑤ | 驱动气按介质危险等级选 | 易燃易爆介质用 N₂ 驱动？ | ✓ 是 |
| ⑥ | P_in ≥ P_in,min | P_in ≥ 厂家最低吸入压力 × 1.2? | ✓ 是 |
| ⑦ | 适应小流量高压比 | Q ≤ 50 Nm³/h? 否则改压缩机 | ✓ 是 |
| ⑧ | 特殊介质有禁忌 | O₂ 禁油禁脂？Cl₂ 禁碳钢？CO₂ 防液化？ | ✓ 是 |

## 三、压力自检

| 检查项 | 自检问题 | 通过条件 |
|---|---|---|
| 入口压力 P_in | 实测或设计值 (bar.g) | 数据明确 |
| 出口压力 P_out | 工艺需求值 (bar.g) | 数据明确 |
| 实际压力比 | P_out / P_in | 计算正确 |
| 增压比 R | 厂家样本标称 | 数据明确 |
| 最大出口(实际) | P_drive × R × 0.9 ≥ P_out × 1.1 (安全裕量) | ✓ 是 |
| 入口最低压力 | P_in ≥ P_in,min × 1.2 | ✓ 是 |
| 下游背压 | P_back ≤ P_out,max × 0.95 | ✓ 是 |
