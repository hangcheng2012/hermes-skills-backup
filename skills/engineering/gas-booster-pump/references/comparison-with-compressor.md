# 气体增压泵 vs 压缩机 — 边界判定

> **核心问题**：什么时候该用气体增压泵，什么时候该用压缩机？
> **结论**：按流量、压力比、连续性综合判断，**流量边界 ≈ 50 Nm³/h** 是经验阈值。

---

## 一、对比矩阵

| 维度 | 气体增压泵 | 压缩机 |
|---|---|---|
| **典型流量** | < 50 Nm³/h | > 50 Nm³/h |
| **压力比（单级）** | 2:1 ~ 100:1 | 1.05:1 ~ 几十:1 |
| **压力范围** | 中高压 (10-700 bar) | 低中高压全覆盖 |
| **驱动方式** | 气动（工厂风/N₂） | 电机/蒸汽/燃机 |
| **连续运行** | 短时/间歇（活塞磨损） | 长期连续 |
| **投资（单台）** | ¥5,000-50,000 | ¥50,000-数百万 |
| **运维** | 简单（更换密封） | 复杂（需专业团队） |
| **效率** | 较低（70-85%） | 较高（85-95%） |
| **噪音** | 高（往复式） | 中（往复式）/低（螺杆/离心） |
| **脉动** | 大（活塞式固有） | 中（往复）/小（离心） |
| **占地** | 小 | 大 |

## 二、决策流程

```
气体升压需求
    │
    ├─ Step 1: 流量评估
    │   ├─ Q > 50 Nm³/h ──→ 优先压缩机 ✓
    │   └─ Q ≤ 50 Nm³/h ──→ 进入 Step 2
    │
    ├─ Step 2: 压力比评估
    │   ├─ P_out/P_in > 100:1
    │   │   ├─ Q > 20 Nm³/h ──→ 多级压缩机
    │   │   └─ Q ≤ 20 Nm³/h ──→ 多级增压泵串联
    │   │
    │   └─ P_out/P_in ≤ 100:1 ──→ 进入 Step 3
    │
    ├─ Step 3: 连续性评估
    │   ├─ 24h 连续 ──→ 优先压缩机（活塞寿命）
    │   └─ 短时/间歇 ──→ 增压泵 ✓
    │
    └─ Step 4: 投资与运维
        ├─ 项目预算紧 ──→ 增压泵
        ├─ 已有工厂风压 4-8 bar.g ──→ 增压泵
        └─ 需要精确流量调节 ──→ 压缩机（变频）
```

## 三、按流量分级推荐

### 3.1 流量 < 5 Nm³/h（实验室/小流量）

**推荐**：气体增压泵

| 理由 | 说明 |
|---|---|
| 流量小 | 压缩机效率低、不划算 |
| 投资省 | 增压泵仅 ¥5,000-20,000 |
| 易操作 | 接工厂风即可 |
| 维护简 | 活塞/密封更换即可 |

**典型应用**：
- 实验室高压气瓶
- 气相色谱载气升压
- 小型氢气瓶充装

### 3.2 流量 5-20 Nm³/h（小型工业）

**推荐**：气体增压泵（首选）

| 理由 | 说明 |
|---|---|
| 流量适中 | 增压泵可覆盖 |
| 压力比灵活 | 可两级串联 |
| 间歇运行 | 寿命够 |

**典型应用**：
- PSA 氢气升压
- N₂ 仪表风增压
- CNG 小型加气站

### 3.3 流量 20-50 Nm³/h（中型工业，边界）

**推荐**：增压泵或压缩机（视具体工况）

| 比较项 | 增压泵 | 压缩机 |
|---|---|---|
| 投资 | ¥30,000-80,000 | ¥100,000-500,000 |
| 流量上限 | 边缘 | 充足 |
| 压力上限 | 高 | 中 |
| 维护 | 简单 | 复杂 |
| 能耗 | 高（驱动气耗） | 中 |

**判定**：
- 高压比 (>50:1) + 间歇 → 增压泵
- 中压比 (<50:1) + 连续 → 压缩机
- 有 N₂/工厂风现成 → 增压泵
- 无气源 → 压缩机（电动）

### 3.4 流量 > 50 Nm³/h（大型工业）

**推荐**：压缩机（强烈推荐）

| 理由 | 说明 |
|---|---|
| 大流量 | 增压泵效率低、不经济 |
| 连续运行 | 压缩机寿命长 |
| 能耗 | 压缩机总能耗更低 |
| 备件 | 压缩机备件充足 |

**典型应用**：
- 空分装置
- 主工艺气源
- 大型 PSA
- 天然气管道增压

## 四、按压力比分级推荐

### 4.1 压力比 ≤ 10:1（低压比）

| 设备 | 推荐度 | 说明 |
|---|---|---|
| **气体增压泵** | ✅ | 简单、便宜 |
| **罗茨鼓风机** | ✅ | 大流量、低压比 |
| **离心式压缩机** | ✅ | 大流量、超低压比 |
| **螺杆压缩机** | ✅ | 中流量 |

### 4.2 压力比 10-50:1（中压比）

| 设备 | 推荐度 | 说明 |
|---|---|---|
| **气体增压泵** | ✅ | 小流量首选 |
| **往复式压缩机** | ✅ | 大流量首选 |
| **螺杆压缩机** | ⚠️ | 中流量可 |

### 4.3 压力比 50-100:1（高压比）

| 设备 | 推荐度 | 说明 |
|---|---|---|
| **气体增压泵（单级）** | ✅ | 边缘，仍可用 |
| **多级气体增压泵** | ✅ | 小流量 |
| **多级往复式压缩机** | ✅ | 大流量 |

### 4.4 压力比 > 100:1（超高压比）

| 设备 | 推荐度 | 说明 |
|---|---|---|
| **气体增压泵（多级串联）** | ✅ | 小流量首选 |
| **多级往复式压缩机** | ✅ | 大流量 |
| **隔膜式压缩机** | ⚠️ | 特殊介质 |

## 五、按介质特殊工况

### 5.1 易燃易爆气体（H₂、CH₄）

| 设备 | 推荐 | 备注 |
|---|---|---|
| **气体增压泵** | ✅ | 小流量、密封好 |
| **隔膜式压缩机** | ✅ | 绝对无泄漏 |
| **往复式压缩机** | ⚠️ | 需良好轴封 |

### 5.2 高纯/洁净气体（O₂、He）

| 设备 | 推荐 | 备注 |
|---|---|---|
| **气体增压泵** | ✅ | 密封好、易清洁 |
| **隔膜式压缩机** | ✅ | 无污染 |
| **无油润滑压缩机** | ⚠️ | 适用但贵 |

### 5.3 强腐蚀气体（Cl₂、HCl）

| 设备 | 推荐 | 备注 |
|---|---|---|
| **气体增压泵（特殊材质）** | ✅ | 钛合金/哈氏 |
| **隔膜式压缩机** | ✅ | 膜片耐腐蚀 |
| **离心式压缩机** | ❌ | 材质难做 |

### 5.4 易液化气体（CO₂、C3+）

| 设备 | 推荐 | 备注 |
|---|---|---|
| **气体增压泵（低 R）** | ✅ | R ≤ 3:1 防液化 |
| **多级压缩机** | ✅ | 防液化设计 |
| **单级压缩机** | ❌ | 易液化 |

## 六、关键判定公式

### 6.1 经济性判定

按单位流量投资估算（2026 年人民币参考）：

| 设备类型 | 单位流量投资 (元/Nm³/h) |
|---|---|
| 气体增压泵 | ¥1,000-5,000 |
| 螺杆压缩机 | ¥10,000-30,000 |
| 往复式压缩机 | ¥15,000-50,000 |
| 离心式压缩机 | ¥5,000-20,000 |

**判定**：流量 < 50 Nm³/h 时，增压泵单位投资是压缩机的 1/5 ~ 1/10。

### 6.2 能耗判定

**增压泵**：
$$W_{drive} = Q_{boosted} \times R \times P_{drive} / \eta_{drive}$$

**压缩机（往复式）**：
$$W_{comp} = Q \times P_{in} \times \frac{1}{\eta_{comp}} \times \left(\frac{P_{out}}{P_{in}}\right)^{\frac{k-1}{k}} - 1$$

**结论**：流量 < 20 Nm³/h 时，增压泵能耗与压缩机相当；流量 > 50 Nm³/h 时，压缩机明显节能。

## 八、边界争议案例

### 案例 1：流量 40 Nm³/h, 压力比 30:1

**两种方案对比**：

| 方案 | 投资 | 能耗 | 维护 | 推荐 |
|---|---|---|---|---|
| 气体增压泵（2 台并联） | ¥60,000 | 中 | 简单 | ✅ |
| 小型往复式压缩机 | ¥150,000 | 低 | 复杂 | ⚠️ |

**结论**：流量 40 接近 50 边界，**仍推荐增压泵**（节省投资 + 维护简单）。

### 案例 2：流量 60 Nm³/h, 压力比 10:1

| 方案 | 投资 | 能耗 | 推荐 |
|---|---|---|---|
| 气体增压泵（3 台并联） | ¥90,000 | 高 | ⚠️ |
| 罗茨鼓风机+增压泵 | ¥120,000 | 中 | ✅ |
| 小型螺杆压缩机 | ¥200,000 | 低 | ✅ |

**结论**：流量 60 > 50，**推荐压缩机**。

### 案例 3：流量 5 Nm³/h, 压力比 200:1

| 方案 | 投资 | 推荐 |
|---|---|---|
| 两级气体增压泵串联 | ¥30,000 | ✅ |
| 三级往复式压缩机 | ¥300,000 | ❌ |

**结论**：流量极小、超高压比，**两级增压泵是唯一经济选择**。
