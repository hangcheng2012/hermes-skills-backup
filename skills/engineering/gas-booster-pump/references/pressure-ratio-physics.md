## 一、增压比的两重定义（常被混淆）

### 1.1 压缩机的"压力比"(Pressure Ratio, Pr)

$$\boxed{P_r = \frac{P_{out,abs}}{P_{in,abs}}}$$

这是**压缩机领域**的定义，表示气体被压缩的剧烈程度。Pr 可变，取决于工况。

例如：入口 1 bar(a) → 出口 10 bar(a)，则 Pr = 10。

### 1.2 气体增压泵的"增压比"(Boost Ratio, R)

$$\boxed{R = \frac{A_1}{A_2}}$$

这是**气体增压泵领域**的定义，表示机械结构上的面积比。**R 是固有参数，设计完成后不可调**。

- A₁ = 驱动活塞面积（受压缩空气侧，大）
- A₂ = 被增压活塞面积（受被增压气体侧，小）

### 1.3 关键区别

| 维度 | 压缩机 Pr | 增压泵 R |
|---|---|---|
| **本质** | 工况参数（可随负荷变） | 机械结构参数（不可变） |
| **决定因素** | 转速/阀门开度 | 活塞面积设计 |
| **典型值** | 1.05:1 ~ 几十:1 | 2:1 ~ 100:1（单级） |
| **能否提高** | 通过多级压缩 | 通过多级泵串联 |

> **重要**：业界常用"增压比"一词指代 R，但有时也指代实际工况下的压力比。**女王日后阅读样本时务必先看是哪种定义**。

## 二、跷跷板模型详解

气体增压泵本质是**两个不同面积的活塞共用一根连杆**，这是理解一切行为的起点。

### 2.1 结构示意

```
                驱动气侧                          被增压气体侧
                (大活塞 A₁)                       (小活塞 A₂)

                ←————— A₁ —————→                  ←—— A₂ ——→
                    │                                  │
                ┌───┴────┐                        ┌────┴───┐
                │ P_drive│                        │ P_out  │
                └────────┘                        └────────┘
                      ╲                              ╱
                       ╲                            ╱
                        ╲__________________________╱
                                 活塞连杆

              [V_in 弹簧复位气室]           [V_out 压缩气室]
                  (回退时充气)                 (压缩时排气)
```

### 2.2 力平衡方程（压缩冲程）

**压缩冲程**：驱动气从左侧推活塞向右运动，压缩右侧气室中的气体。

**力的方向**：
- 驱动气施加的推力：F_drive = P_drive × A₁（向右）
- 被增压气体施加的反推力：F_out = P_out × A₂（向左）

**能动条件**：
$$F_{drive} > F_{out}$$
$$P_{drive} \times A_1 > P_{out} \times A_2$$
$$P_{out} < P_{drive} \times \frac{A_1}{A_2} = P_{drive} \times R$$

### 2.3 力平衡方程（回退冲程）

驱动气通过 4-way 阀切换到排气（接近大气压），同时：
- 残余气体压力 + 复位弹簧推活塞向左回退
- 入口单向阀打开，气室从 P_in 重新充气

**回退条件**：
$$P_{in} \times A_2 + F_{spring} > P_{drive,residual} \times A_1$$

由于驱动气已排气（P_drive,residual ≈ 0），主要由弹簧复位。

### 2.4 平衡位置（Stall Condition）

当下游背压升到使活塞两端力相等时，活塞**停在死点**，不再往复运动：

$$\boxed{P_{out,stall} = P_{drive} \times R \times \eta}$$

其中 η ≈ 0.85-0.95（机械效率因子）。

**这是真正的"平衡位置"**——驱动气无法克服下游背压。**与 P_in 完全无关**。

## 三、单级 vs 多级增压比

### 3.1 单级增压泵的 R 上限

| R 范围 | 典型应用 | 设计难度 |
|---|---|---|
| 2:1 ~ 10:1 | 低压气源升压（仪表风等） | 低 |
| 10:1 ~ 30:1 | 中压气瓶充装 | 中 |
| 30:1 ~ 60:1 | 高压气瓶充装 | 高 |
| 60:1 ~ 100:1 | 超高压气瓶 | 很高 |
| > 100:1 | **不推荐单级** | 几乎不可行 |

**物理极限**：A₁/A₂ 越大，活塞直径差异越大，制造难度剧增，且密封、摩擦损失增大。

### 3.2 多级串联方案

当目标压力比 > 100:1 时，用两级或多级泵串联：

```
[P_in] → [1 级泵 R1=10:1] → [中间压力] → [2 级泵 R2=10:1] → [P_out]
                                    │
                              [冷却器 (重要!)]
```

**总增压比**：
$$R_{total} = R_1 \times R_2 \times \ldots \times R_n$$

**两级泵 R = 10:1 + 10:1 = 100:1**，已接近单级极限。

**三级泵** 可达 1000:1（如电解氢从常压到 35 MPa）。

### 3.3 多级的关键要求

- **中间冷却**：每级压缩后温度上升，必须冷却到接近入口温度再进入下一级
- **中间稳压罐**：缓冲压力波动
- **各级流量匹配**：后级流量需略小于前级（考虑内漏）
- **各级 R 选择**：前级小、后级大（递减式），符合"压力越高、压缩比越小"的工程实践

## 四、增压比与压力比的辨析

### 4.1 实例对比

**场景**：Haskel AGD-30 增压泵（标称 R = 30:1），驱动气 7 bar(g)

**工况 1**：入口 N₂ 1 bar(g)（即 2 bar(a)），目标出口 50 bar(g)（即 51 bar(a)）

| 参数 | 数值 | 说明 |
|---|---|---|
| **驱动气压 P_drive** | 7 bar(g) = 8 bar(a) | 工厂风 |
| **增压比 R** | 30:1 | 厂家标称 |
| **最大出口(理论)** | 8 × 30 = 240 bar(a) = 239 bar(g) | 由 R 决定 |
| **最大出口(实际 η=0.9)** | 239 × 0.9 = 215 bar(g) | 实际可达 |
| **实际工况压力比** | 51/2 ≈ 25.5 | 此时的实际压缩比 |
| **判断** | ✓ R(30) > 实际(25.5)，可达到 | R 是上限 |

**工况 2**：同一台泵，入口 N₂ 7 bar(g)（即 8 bar(a)），目标出口 200 bar(g)（即 201 bar(a)）

| 参数 | 数值 | 说明 |
|---|---|---|
| **驱动气压 P_drive** | 7 bar(g) = 8 bar(a) | 工厂风 |
| **增压比 R** | 30:1 | 厂家标称 |
| **最大出口(实际 η=0.9)** | 215 bar(g) | 由 R 决定 |
| **目标出口** | 200 bar(g) | < 215, 可达 ✓ |
| **实际工况压力比** | 201/8 ≈ 25 | 仍小于 R |

**两种工况实际压力比都是 ~25，但都不超过 R=30**——这正是 R 作为"上限"的意义。

### 4.2 关键洞察

- **R 是上限（capacity）**，不是工况压力比（operating pressure ratio）
- 工况压力比可随负荷在 0 ~ R 之间调节
- **R 决定"能打多高"，压力比决定"实际打多高"**

## 五、增压比标注规范（避免歧义）

### 5.1 P&ID 上的标注

```
泵位号:    P-101
设备名称:  气体增压泵
型号:      Haskel AGD-30
增压比:    R = 30:1            ← 标注机械增压比（厂家标称）
驱动气:    压缩空气 7 bar(g)
最大出口:  215 bar(g)           ← 按 η=0.9 折算
```

### 5.2 与厂家沟通话术

- 问"增压比" → 指 R (机械)，用"厂家标称 R = XX:1"
- 问"压力比" → 指实际工况，用"实际压力比 = XX:1"
- **切勿混用**：若厂家样本写 "Pressure Ratio 30:1"，**默认是 R（机械）**，但需以样本上下文为准

### 5.3 女王日后阅读厂家样本的 3 条提醒

1. **看定义**：样本的"Pressure Ratio"或"Boost Ratio"对应哪个？有时两者通用
2. **看单位**：是用表压还是绝压？表压近似即可但有 <3% 误差
3. **看效率**：样本给的"最大出口压力"是理论值还是实测值？是否已含 η 折算

## 六、常见误区（永久记录于 error-history.md）

| 误区 | 正确认识 |
|---|---|
| ❌ "R = P_in × P_out" | ✓ R = A₁/A₂（机械固有） |
| ❌ "R 可通过调节驱动气压改变" | ✓ R 由活塞面积设计决定 |
| ❌ "R 越大流量越大" | ✓ R 越大单次循环排量越小（活塞面积小） |
| ❌ "P_in 越低最大出口越低" | ✓ P_in 不影响最大出口，只影响流量 |
| ❌ "压力比 = 增压比" | ✓ 压力比（工况）≤ 增压比（机械上限） |
