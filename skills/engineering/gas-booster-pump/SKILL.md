# 气体增压泵 (Gas Booster Pump) 选型与设计子 skill

## ⚠️ Skill 创建背景与核心 pitfall (07-17 女王立规)

**本 skill 因女王捕获关键错误而建立**。07-17 本人第一版回答中错误使用公式：

> ❌ `P_out,平衡 = P_in × R` （错误）

**错误根源**：把压缩机的"压力比定义 Pr = P_out/P_in"(工况变量)与气体增压泵的"增压比定义 R = A₁/A₂"(机械固有)混淆。

**正确公式**：

> ✅ `P_out,max = P_drive × R × η` （η ≈ 0.85-0.95）

**关键洞察**：**P_in 不决定最大出口压力**，只决定**流量与循环可靠性**。

**女王原文确认（07-17）**：

> "是不是只要驱动气入口压力乘以增压比得到的数就是出口压力，出口压力与被增压气体的入口压力无关，但是被增压气体的入口压力很低会对流量造成影响？"

女王的理解**完全正确**。本 skill 全部 8 铁律 + 7 references 都围绕这条核心公理构建。任何选型计算前，**先把这条核心公理刻入脑海**。

**女王速记口诀**：

> **"压力看驱动，流量看入口"**
> - 驱动气 × 增压比 → 决定**最高能打多高**
> - 入口压力 → 决定**打多快（流量）**

完整错误案例与避坑指南见 `references/error-history.md` § 错误 #1。

## 一、物理本质:跷跷板模型

气体增压泵的核心结构是**两个不同面积的活塞共用一根连杆**:

```
        驱动气侧                              被增压气体侧
        (大活塞 A₁)                           (小活塞 A₂)
        ←———— A₁ ————→                        ←— A₂ —→
            │                                      │
        ┌───┴────┐                            ┌────┴───┐
        │ P_drive│                            │ P_out  │
        └────────┘                            └────────┘
              ╲                                  ╱
               ╲                                ╱
                ╲______________________________╱
                       活塞连杆 (刚性连接)
```

### 1.1 增压比 R 的物理定义

$$\boxed{R = \frac{A_1}{A_2} = \frac{P_{out,abs}}{P_{in,abs}}}$$

**注意**:
- R 是**机械固有参数**,由活塞面积比决定,设计完成后不可调
- 严格用**绝压**;工程上表压近似即可
- 常见规格: 2:1, 5:1, 10:1, 25:1, 40:1, 60:1, 100:1

### 1.2 力平衡方程(跷跷板能动的条件)

**压缩冲程**: 驱动气推活塞向右,克服气体侧反推力

$$P_{drive} \times A_1 > P_{out} \times A_2$$

即:

$$P_{out} < P_{drive} \times \frac{A_1}{A_2} = P_{drive} \times R$$

**回退冲程**: 驱动气泄压,残余气压 + 弹簧推活塞回退,入口阀打开,气室充气至 P_in

### 1.3 最大出口压力公式

$$\boxed{P_{out,max} = P_{drive} \times R \times \eta}$$

其中 **η ≈ 0.85-0.95**(机械效率 + 可逆压缩损失 + 密封摩擦损失)

**关键**: **P_in 不出现在此公式中**——入口压力不限制最大出口压力。

## 二、压力关系速查表

| 压力参数 | 决定什么 | 量级 |
|---|---|---|
| **驱动气压 P_drive** | ✅ 最大出口压力(与 R 共同决定) | 通常 4-8 bar.g |
| **增压比 R** | ✅ 最大出口压力(与 P_drive 共同决定) | 2:1 ~ 100:1 |
| **入口压力 P_in** | ❌ 不决定最大出口,决定**流量**与**循环可靠性** | 通常 ≥ 1-3 bar.g |
| **下游背压 P_back** | 决定泵能否稳定循环 | < P_out,max |

### 2.1 P_in 影响流量的机理

```
单次循环吸气量 ∝ V_chamber × P_in

P_in = 1 bar.g   →  吸气量 "正常",循环快速
P_in = 0.2 bar.g →  吸气量约为 1/5,循环极慢
P_in = 0.05 bar.g → 吸气量约为 1/20,可能无法正常循环
```

**直觉**: 像用针筒抽气——抽入口的"源头气压"越高,每次抽满一针筒的"气量"越多,相同循环次数下输送总质量越大。

### 2.2 P_in 过低的失效模式

| 失效模式 | 现象 | 工程后果 |
|---|---|---|
| 入口单向阀密封不良 | 阀座不能紧密闭合 | 内漏 → 流量进一步下降 |
| 吸气时间过长 | 每次循环等几秒至几十秒 | 单位时间排量极低 |
| 入口真空度太高 | P_in < 0 bar.g | 大气压推不开入口阀 → 停循环 |
| 气体温升过高 | 绝热压缩比过大 | 密封件老化,安全风险 |

## 三、选型 3 条核心铁律

| # | 铁律 | 公式 |
|---|---|---|
| **铁律 1** | 驱动气 × 增压比 ≥ 目标出口压力 | P_drive × R × η ≥ P_out,目标 |
| **铁律 2** | 入口压力 ≥ 厂家最低吸入压力 | P_in ≥ P_in,min (查样本,通常 1-3 bar.g) |
| **铁律 3** | 流量按 P_in 计算,按厂家曲线校核 | Q_out = Q_sample × (P_in,工况 / P_in,样本) |

## 四、选型决策树

```
气体增压需求
    │
    ├─ 流量需求?
    │   ├─ > 50 Nm³/h ──→ 压缩机(往复式/螺杆式/离心式)
    │   └─ < 50 Nm³/h ──→ 气体增压泵 ✓
    │
    ├─ 目标压力 / 入口压力?
    │   ├─ 压力比 > 100:1 ──→ 两级或多级增压泵串联
    │   └─ 压力比 ≤ 100:1 ──→ 单级增压泵 ✓
    │
    ├─ 被增压气介质?
    │   ├─ N₂/空气/惰性气体 ──→ 普通型,压缩空气驱动
    │   ├─ H₂ ──→ N₂ 驱动,禁铜,静电接地
    │   ├─ O₂ ──→ 禁油禁脂,无氧清洁,脱脂处理
    │   ├─ CO₂ ──→ 防凝液,入口加热或低压缩比
    │   ├─ Cl₂ ──→ 钛合金/哈氏合金,特殊密封
    │   └─ 其他可燃/有毒 ──→ N₂ 驱动 + 全封闭
    │
    └─ 驱动气选择?
        ├─ 普通惰性气体 ──→ 压缩空气 (4-8 bar.g 工厂风)
        ├─ 易燃易爆被增压气 ──→ N₂ 驱动 (严禁空气)
        └─ 高温/潮湿环境 ──→ N₂ 驱动(避免空气中水分)
```

## 六、特殊介质禁忌 (铁律 ⑧ 展开)

### 6.1 氧气 O₂
- **禁油禁脂**: 所有与 O₂ 接触部件必须脱脂处理(GB/T 34525)
- 驱动气必须 N₂(避免空气中碳氢化合物)
- 入口滤网、密封圈材质需符合 O₂ 兼容
- 推荐厂家: Haskel, Maximator (有 O₂ 专用系列)

### 6.2 氢气 H₂
- **禁铜**: 阀座、密封件禁止铜及铜合金(H₂ 脆化)
- 静电接地必须可靠
- 驱动气必须 N₂(避免空气中 O₂ 与 H₂ 混合)
- 排气端严禁明火

### 6.3 氯气 Cl₂
- **禁碳钢**: 介质接触部件用钛合金/哈氏合金/聚四氟乙烯
- 入口管线必须干燥(Cl₂ + H₂O → 盐酸腐蚀)
- 厂家样本需特别标注 "Cl₂ service"

### 6.4 二氧化碳 CO₂
- **防凝液**: CO₂ 在 5.2 MPa 以上临界状态,压缩后可能液化
- 入口温度需高于临界点,或加预热
- 单级压缩比建议 ≤ 3:1(避免液化)

### 6.5 天然气/甲烷 CH₄
- 防爆区域: 驱动气若用空气,需防爆电气;优先 N₂ 驱动
- 入口滤网防冰堵(焦耳-汤姆逊冷却效应)
- 排放端去火炬或回收

## 七、气体增压泵 vs 压缩机 — 边界判定

| 维度 | 气体增压泵 | 压缩机 |
|---|---|---|
| **流量** | < 50 Nm³/h | > 50 Nm³/h |
| **压力比** | 2:1 ~ 100:1 (单级) | 任意(可多级) |
| **压力等级** | 中高压 (10-700 bar) | 低中高压全覆盖 |
| **驱动方式** | 气动 (工厂风/N₂) | 电机/蒸汽/燃机 |
| **连续运行** | 短时/间歇 (活塞磨损) | 连续运行 |
| **投资** | 低 (¥5k-50k) | 高 (¥50k-数百万) |
| **运维** | 简单 | 复杂 |
| **典型应用** | 高压气瓶充装、实验室、辅助气源 | 主工艺气源、空分、PSA |

**判定原则**:
- **小流量 + 高压比 + 间歇** → 气体增压泵 ✓
- **大流量 + 中低压比 + 连续** → 压缩机 ✓
- **流量边界 ≈ 50 Nm³/h**(经验值,具体看工况)
